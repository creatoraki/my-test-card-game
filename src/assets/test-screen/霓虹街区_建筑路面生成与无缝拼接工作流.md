# 霓虹街区：建筑路面生成与无缝拼接工作流

> 本工作流由 `生态方舟_建筑路面生成与无缝拼接工作流.md` 改编，**处理流程、尺寸约定、合成脚本完全相同**，只把地图换成霓虹街区，并重新设计了建筑主题库、装饰物、夜景光照与高度红线。两份文档各自独立可执行，不需要对照阅读。

## 目标

在透明路面素材上生成霓虹街区的低矮街铺和路面装饰，制作两张不同内容的单图，再将左图和右图横向无缝拼接。

**尺寸约定：只固定高度，不固定宽度。** 单图与拼接图的高度统一为 **1024px**（路面上沿 Y=954、厚20px、底部留空50px）；左图、右图的宽度随各自内容裁切而定，拼接图宽度 = 左图宽 + 右图宽，均不要求等于 1536 或 3072。

所有建筑与装饰按 **1px = 1厘米** 的真实比例设计。左右两张图合计放置 **4～6栋** 建筑（每张单图2～3栋），**以低矮单层街铺为主**：合计 **最多1栋两层**，其余全部为单层，且 **大部分建筑主体高度低于3米（300px）**。建筑从 **25种霓虹街区主题** 中选取互不相同的主题（见「零之三、建筑主题库」）。

> **高度是本工作流的头号风险。** 霓虹街区参考图里到处是摩天楼、高架轻轨和悬浮车，生图模型极易把街铺画成高楼或塔楼。本工作流单列「零之四、高度红线」，任何一条超标即判废稿，不允许缩小补救。

**比例与疏密以 6-2 为示范**（`地面\6-2.png`），实测数据见「零、比例尺」。6-2 是生态方舟画风，只作比例与疏密对照，不作画风参考，也不作 imagegen 输入。

每张单图同时放置 **不少于16件** 街道装饰物（霓虹路灯、消防栓、长椅、垃圾桶、立式灯箱、樱花树池等），装饰物 **允许站在建筑立面前方、遮挡部分墙面**；装饰物之间也允许前后叠压，夜市街道要显得密集、热闹。

建筑与装饰 **不能画成完全平面的立面图**，要求轻微俯视的 2.5D 视角，能看到屋顶上表面、檐口与凸出体块的厚度（见「零之二」）。

建筑与装饰必须保持生成时的原始尺寸。素材处理时对整张生成图只做 **Y 轴平移与 X 轴裁切**，另外允许脚本清理远离物件的淡光雾与孤立噪点。不通过任何缩放方式完成对齐。

## 第零步：选择统一路面（优先直接复用）

**路面可以直接复用，不要求为霓虹街区重新生图。** 优先使用「地面」根目录已有且符合下方尺寸与透明通道标准的 `生态方舟_平台路面_厚20px_底部留空50px.png`。已有合格的霓虹路面也可使用。复用时保留原始配色，不要求增加品红灯线或改成霓虹材质。

选定后，在本次 `生成说明.md` 记录实际使用的路面路径；左右图生成及最终合成都使用同一份素材，脚本必须显式传入该路径。已有合格路面时跳过下方生成步骤。只有没有合格路面或明确要求新建霓虹路面时，才按下方提示词生成。

| 检查项 | 合格标准 |
| --- | --- |
| 尺寸 | 1536×1024 |
| 路面行 | Y=954～973 每行不透明像素（透明度大于200）占满全宽的98%以上 |

## 零之二、视角、体积与夜景光照

> **硬性要求：建筑和装饰物绝不能画成平面的 2D 立面图，必须有明显的透视感与立体体积。** 像设计图、剪纸、贴图的结果一律判为不合格。

### 视角规则

1. **明显俯视**：镜头俯视约20～30°。屋顶上表面、雨棚顶面、门斗顶面、招牌灯箱顶面必须清楚可见，屋顶顶面露出的纵深约80～150px。
2. **三个面可见**：每栋建筑同时露出顶面、正面和右侧墙。右侧墙宽度约为正面宽度的15～25%（约60～120px），明显比正面暗。
3. **正面基本正对镜头**：正面水平线保持水平、竖直线保持竖直，正面底边落在路面上沿。右侧墙与屋顶顶面向右上方斜向退后。
4. **平行投影，统一方向**：斜二测式平行投影，没有汇聚消失点；所有建筑、装饰物、竖向挂牌都露出右侧面与顶面，退后角度一致；左右两图视角完全相同。
5. **体积细节**：雨棚、门斗、窗台、檐口、灯箱、竖向挂牌都要画出厚度；门窗洞画出内凹深度；玻璃店面能看到室内纵深与暖色灯光。
6. **装饰物同一视角**：长椅露出座面与右侧端板，消防栓、垃圾桶、售货机、灯箱露出顶面与右侧面，路灯灯头露出上表面，树池露出池口。
7. **路面不变**：路面仍是 20px 正侧视薄片，不画成俯视地板，不在路面上画地基、投影或倒影。

### 夜景光照（与生态方舟不同）

霓虹街区是夜景，但三个面的明暗关系仍必须分明：

1. **环境主光**：来自左上方的冷色夜空天光（蓝紫色），两张图一致。屋顶顶面受天光最亮（冷蓝紫高光），正面中等，右侧墙最暗（深靛蓝）。
2. **霓虹自发光**：招牌、灯管、店内灯光是局部光源，只照亮紧贴的墙面与檐口下方，不改变三面的整体明暗顺序。
3. **配色比例**：建筑底色以深靛蓝、深紫灰、炭黑金属为主（约60%）；暖橙店内灯光约20%；品红与青色霓虹点缀约20%。不要整面墙都发光，否则体块会糊成一片。
4. **光晕收紧**：霓虹灯管的柔光只贴着灯管外扩约4～8px，不画大范围光晕、光柱、光雾、雨丝、空中粒子或路面倒影。透明区域里的散光会被清理脚本切硬，留下难看的边。
5. 檐口、雨棚、灯箱下方有清晰的暗部阴影。

### 常见失败与规避

- 「横版游戏」「正侧视」只用来描述路面；描述建筑时只用「俯视」「三个面可见」「立体体块」。
- 夜景容易让模型把整张图涂成深色背景。提示词中明确「背景完全透明，夜色只体现在物件自身的配色上」。
- 透视要求在提示词开头写一次，末尾再重申一次。

### 对比例尺的影响

1px=1厘米 以 **建筑正面** 为准测量。屋顶顶面纵深计入主体高，右侧墙宽度计入占地宽度，二者都不计入门高与层高。

### 选题规则

1. 先定建筑总数（**4～6栋**，每张单图2～3栋，推荐左右各3栋），再选同样数量的 **互不相同** 主题，放入 A1、A2、A3、B1、B2、B3 槽位。
2. **屋顶 / 轮廓全部不同**；不能出现两栋都是「平顶方盒子 + 屋顶灯牌」。
3. **主材质至少3种不同**（5～6栋时至少4种）。
4. 所选主题 **至少覆盖3个分类**。
5. 同一张单图里相邻两栋，一栋偏通透轻盈（玻璃、篷布、开放结构），另一栋偏厚重实体（金属、砖、木、混凝土）。
6. 全组 **最多1栋两层**，只能放在 A1 槽位，且只能放层数标有「两层」的主题；N24 胶囊旅馆只有两层版本，只能放 A1。其余槽位一律单层。
7. 每栋建筑至少1块招牌（竖向挂牌、檐口灯箱、屋顶灯牌、门头灯管勾边任选），**全组屋顶灯牌最多3块**，避免天际线被灯牌堆高。
8. 不与上一个 `霓虹街区模板N` 使用过的主题重复（读取其 `生成说明.md` 的选题记录；没有记录时跳过）。
9. 专属装饰可以替换通用装饰中的非必需项，每栋最多替换2件；必需项（路灯、消防栓、长椅、垃圾桶或回收箱、樱花树池或花槽、立式灯箱）不能被替换。
10. 选题结果写入本次 `生成说明.md`，格式为「A1=N01 拉面食堂（两层）」。

## 零之四、高度红线

> 本节是霓虹街区工作流的 **一票否决项**，验收时排在透视感之后第二个检查。

### 红线表

高度一律从 **模型自绘路面上沿** 向上量（合成后即从 Y=954 向上量）。「屋顶附加物」包括屋顶灯牌、排烟罩、天线、风扇、警灯、全息环、绿植等一切高出檐口的东西。

| 对象 | 主体高上限 | 屋顶附加物上限 | 含附加物总高上限 | 合成后顶部不高于 |
| --- | --- | --- | --- | --- |
| 单层建筑（大部分） | 300px | 160px | 460px | Y=494 |
| 单层建筑（个别，最多2栋） | 340px | 120px | 460px | Y=494 |
| 两层建筑（全组唯一，只在 A1） | 600px | 120px | 720px | Y=234 |
| 竖向挂牌 | — | — | 顶端不超过所附建筑屋顶顶面以上60px | — |
| 霓虹高杆路灯 | — | — | 520px | Y=434 |
| 樱花行道树 | — | — | 350px | Y=604 |
| 其他装饰物 | — | — | 200px | Y=754 |

由此得到两条整图红线：

- **A1 及其屋顶附加物以外，所有像素都不得高于路面上沿以上520px（合成后 Y=434）**；最高的只能是路灯。
- **A1 所在单图的最高点不得高于路面上沿以上720px（合成后 Y=234）**；没有两层楼时整组都按 Y=434 执行。

### 禁止出现的「拔高」手法

模型常用以下方式偷偷把房子画高，出现任一项即判废稿：

1. 在屋顶上再叠一层退台小楼、阁楼、塔楼或尖顶。
2. 屋顶灯牌画成比建筑本身还高的巨型广告塔。
3. 竖向挂牌一路伸出屋顶之上很远。
4. 背后画出远景高楼、轻轨高架、天桥或空中平台，把它们和街铺连成一体。
5. 一层楼画出两排窗（层高被压缩冒充单层），或门高不足160px而楼身照常高。

### 提示词里的高度写法

模型对「像素高度」不敏感，对「层数」与「参照物」更敏感。提示词里同时用三种方式约束：

- **层数**：「低矮的一层街边小铺，像老街的单层店面」。
- **参照物**：「门高约为房子主体高度的三分之二」「路灯明显高过所有单层房子的屋顶」。
- **否定**：「不要高楼、塔楼、摩天楼、高架轻轨、天桥、远景城市」。

### 比例验收

生成后先用实际像素核对，任一项不合格就重新生成，**不能用放大或缩小补救**。检查顺序：**透视感 → 高度红线 → 其余项**，前两项任一不合格时其余项无需再看。

| 检查项 | 合格范围 |
| --- | --- |
| 透视感（第一） | 每栋建筑都能清楚看到屋顶顶面（纵深约80～150px）和右侧墙（约60～120px），三面明暗分明；装饰物也能看到顶面与右侧面 |
| 高度红线（第二） | 全部满足「零之四」红线表；A1 以外没有任何像素高于路面上沿以上520px；没有出现五种「拔高」手法 |
| 无高楼背景 | 没有远景高楼、轻轨、天桥、空中平台、悬浮车、天空或水道 |
| 视角一致 | 没有汇聚消失点；同图与两图之间俯视角度、右侧面退后方向、光照方向一致 |
| 夜景明暗 | 顶面亮、正面中、右侧墙暗的顺序清楚；没有整面墙发光把体块糊平；霓虹光晕没有大面积外溢 |
| 建筑数量与层数 | 左右合计4～6栋，每张单图2～3栋；最多1栋两层且在 A1 |
| 建筑风格差异 | 每栋都能一眼认出是所选主题；屋顶轮廓各不相同，主材质至少3种（5～6栋时至少4种）；没有两栋都是黑盒子贴灯牌 |
| 招牌 | 每栋至少1块招牌；全组屋顶灯牌不超过3块；所有招牌没有文字或字母（含乱码汉字、伪文字） |
| 门高 | 180～220px，允许 ±10%（约162～242px） |
| 单层建筑主体高 | 全部单层中至少三分之二在250～300px；任何一栋不超过340px |
| 两层建筑主体高 | 500～600px，允许 ±10% |
| 装饰物数量 | 每张单图不少于16件、至少8种；6项必需装饰齐全 |
| 装饰物密度 | 每栋前至少3件叠加装饰（2栋时4件）；每段楼间空隙至少2件（2栋时3件）；至少2处互叠；门洞以外没有超过约120px的空路段 |
| 装饰物尺寸 | 与「装饰物尺寸」表相差不超过 ±20%；路灯不低于400px |
| 与 6-2 对照 | 并排缩放到同一高度对比，建筑体量、楼间疏密、门与装饰物比例相近；单栋宽度不超过约520px |
| 叠加关系 | 装饰物在建筑前方、轮廓完整，没有融进暗墙里看不清 |
| 门洞 | 所有门洞没有被装饰物挡住 |
| 路面 | 路面仍为正侧视薄片，没有俯视地基、投影或倒影 |
| 左右完整 | 内容最左列 L > 0 且最右列 R < 画布宽 − 1，边缘物件轮廓完整 |

高度超标的重生成写法：在提示词 **最开头** 加一句「这是低矮的一层老街小铺，房子主体不超过3米，屋顶上只有一块小灯牌，绝对没有高楼和塔楼」，把「最重要二」整段提到「最重要一」之前，末尾再重申一次。若仍然超标，删掉屋顶灯牌，改为檐口横向灯箱。

模型出现招牌文字时：在提示词里把「绝对不画任何文字或字母」改写为「所有招牌上只有一个简单图形图标，图标外没有任何笔画」，并在末尾重申。

其余常见失败（看不到右侧墙、门高过小、装饰物缩成墙根一排、省略路灯）的处理与生态方舟工作流相同：在提示词开头单独重申对应要求后重新生成。

### 不需要重新生成的问题

以下问题由合成脚本处理，**不作为废稿理由**：

| 问题 | 处理方式 |
| --- | --- |
| 左右边距不足约100px | 只要没贴到画布边缘，按内容裁切即可 |
| 模型自绘路面位置偏高或偏低 | 自动定位模型路面上沿，整图 Y 轴平移对齐 |
| 模型自绘路面的厚度、颜色与选定的统一路面不同 | 模型路面整段舍弃，换成统一路面 |
| 背景残留淡光雾、霓虹散光、极淡色块 | 光雾清理 |
| 远离物件的零星噪点 | 噪点清理 |

真正需要重生成的只有：透视感不合格、高度红线超标、出现高楼背景、比例不合格、物件被画布边缘截断、数量与密度不达标、门洞被挡、招牌出现文字、残留大面积不透明背景。

### 允许的脚本处理

| 操作 | 作用范围 | 说明 |
| --- | --- | --- |
| Y 轴平移 | 整张生成图 | 让建筑与装饰底部紧接路面上沿 Y=954 |
| X 轴裁切 | 整张生成图 | 只裁掉内容最左列 L 左侧、最右列 R 右侧的透明列 |
| 舍弃模型路面 | 模型路面上沿及以下 | 整段丢弃，换成统一路面 |
| 光雾清理 | 模型路面上沿以上 | 只把远离实心物件的半透明像素清为全透明 |
| 噪点清理 | 模型路面上沿以上 | 只删除面积很小的孤立实心碎块 |

禁止：缩放、拉伸、旋转、重采样；抠出单栋建筑或单件装饰单独移动；调色、描边、羽化、抠边。

检查透明通道时，预览中的黑色不能作为是否透明的依据，需要确认透明通道。夜景素材尤其要注意：深靛蓝的墙面在黑底预览里看起来像背景，必须放到灰底上核对。

### Y 轴：落脚位置

脚本自动定位模型自绘路面上沿：

1. 在生成图左右两侧各取一条窄带（距边缘2列开始、宽8列）。
2. 从上往下逐行检查：两条窄带里不透明度大于200的像素都达到60%，并且向下连续4行都成立，这一行就是路面的实心上沿。
3. 从实心上沿继续向上：只要两条窄带里不透明度大于16的像素仍都达到60%，就把这一行也算作路面（一起舍弃路面顶边的半透明抗锯齿行）。
4. 得到的路面上沿行号即为裁切高度，保留 Y=0～裁切高度 − 1。

内容侵入窄带导致无法定位时，改为手工指定裁切高度。

```text
向下偏移 = 954 − 裁切高度
示例：裁切高度为893px，则向下偏移 = 954 − 893 = 61px
```

偏移后按「零之四」红线表复核各建筑顶部的合成后 Y 坐标。

### 光雾与噪点清理

清理只作用于保留区域，**必须在统计内容左右范围之前完成**：

1. 不透明度大于「实心阈值」的像素视为实心像素，按8连通分块。
2. 面积小于「最小块面积」的孤立实心块视为噪点，清为全透明。
3. 其余实心块向外扩「保留半径」作为保留区，区内像素原样保留。
4. 保留区以外的像素一律清为全透明。

| 参数 | 本工作流默认值 | 说明 |
| --- | --- | --- |
| 实心阈值 | 64 | 半透明玻璃被误清时调低 |
| 保留半径 | **6px** | 比生态方舟（3px）大，用来保住霓虹灯管的柔光；若灯管柔光仍被切硬，可调到8px |
| 最小块面积 | 40px | 细小独立物件（串灯灯珠、远处花瓣）被误删时调小到20px |

清理后核对被清除像素：原不透明度应绝大多数在16以下。若有成片较高不透明度像素被清掉，说明误删了物件或霓虹光，调整参数后重新合成。

### X 轴：按内容裁切

1. 在清理后的保留区域中统计透明度大于8的像素横向范围，得到 L 与 R。
2. L 必须大于0、R 必须小于生成画布宽 − 1，否则重新生成。
3. 单图宽度 W = R − L + 1。

## 三、制作统一且可连续拼接的路面

从第零步选定的统一路面素材提取矩形 X=0、Y=954、宽1536px、高20px，左右两图共用这一条路面。允许直接使用生态方舟等已有合格路面的原始像素与配色。

对路面两端各32px逐行颜色过渡（透明度与红、绿、蓝分别计算），使首尾颜色一致、可以循环平铺：

```text
共同接缝颜色 = 该行左端与右端颜色的平均值
过渡权重 = (31 − 距离边缘的像素数) ÷ 31
输出颜色 = 原始颜色 × (1 − 过渡权重) + 共同接缝颜色 × 过渡权重
```

按拼接总宽度平铺，再切给左右两图：

```text
总宽度 = W左 + W右
平铺路面第 x 列 = 统一路面第 (x mod 1536) 列
左图路面 = 平铺路面 X=0 ～ W左 − 1
右图路面 = 平铺路面 X=W左 ～ W左 + W右 − 1
```

不要让左右两图各自从第0列开始取路面，否则接缝处纹理与灯线会跳变。

## 四、合成两张单图

为每张单图创建 W×1024 的全透明画布：

1. 从清理后的生成图裁出 X=L～R、Y=0～裁切高度 − 1 的区域。
2. 在 X=0、Y=向下偏移 处原尺寸粘贴。
3. 将对应那段平铺路面在 X=0、Y=954 处原尺寸粘贴。
4. 保存为透明 PNG。底部50px直接来自空白透明画布。

第二～五节的全部步骤已由「地面」目录下的共用脚本实现，与生态方舟、废弃楼层工作流 **共用一份**，不需要另写：

## 五、横向拼接

创建 (W左 + W右)×1024 的全透明画布：左图放在 X=0、Y=0，右图放在 X=W左、Y=0，直接相邻，不重叠，不留缝，不缩放。两图交界处不强制留空路。

### 接缝检查

## 人工确认要点

- **透视感足够**：每栋建筑都能看到屋顶顶面、正面、右侧墙三个面，夜景下仍明暗分明；两图视角与光照一致。
- **高度没有超标**：除 A1 外所有物件不高于路面以上520px（只有路灯能到这个高度），单层建筑含附加物不超过460px，A1 不超过720px；没有阁楼、塔楼、巨型灯牌塔、远景高楼与轻轨。
- 比例为1px=1厘米：门高约180～220px，大部分单层主体250～300px；与 6-2 并排对比体量相近。
- 左右合计4～6栋，每张单图2～3栋；最多1栋两层，且在 A1。
- 每栋来自主题库中不同的主题，屋顶轮廓、主材质差异明显；选题已写入 `生成说明.md`。
- 每栋至少1块招牌，全组屋顶灯牌不超过3块；所有招牌、灯箱、屏幕只有图形，没有文字。
- 每张单图不少于16件、至少8种装饰物，含2盏霓虹路灯、消防栓、长椅、垃圾桶或回收箱、樱花树池或花槽、立式灯箱；门洞以外没有大段空路。
- 装饰物站在建筑正面前方遮挡部分墙面，装饰物之间有前后叠压，轮廓在暗墙前依然清楚，不挡门洞。
- 建筑和装饰保持生成原图尺寸，只做整图 Y 轴平移与 X 轴裁切。
- 单图与拼接图高度都是1024px；宽度随内容而定。
- 使用的是第零步选定并记录的同一份路面；允许直接复用生态方舟等已有合格路面及其原始配色。路面20px厚，底部50px透明。
- 拼接处通过接缝检查。
- 建筑与装饰周围为真实透明区域，没有深色夜景背景残留；霓虹柔光没有被切成硬边，光雾清理没有误删物件。
- 全部产出都在本次新建的 `霓虹街区模板X` 文件夹中，「地面」根目录（第零步路面除外）与已有模板文件夹没有被改动。
