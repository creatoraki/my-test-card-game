# 生态方舟：建筑路面生成与无缝拼接工作流

## 目标

在现有透明路面素材上生成街区建筑和路面装饰，制作两张不同内容的单图，再将左图和右图横向无缝拼接。

**尺寸约定：只固定高度，不固定宽度。** 单图与拼接图的高度统一为 **1024px**（路面上沿 Y=954、厚20px、底部留空50px 不变）；左图、右图的宽度随各自内容裁切而定，拼接图宽度 = 左图宽 + 右图宽，均不要求等于 1536 或 3072。合成时只需保证：建筑与装饰完整、没有被裁掉；拼接处路面连续、没有接缝问题（见第五节）。

所有建筑与装饰按 **1px = 1厘米** 的真实比例设计。左右两张图合计放置 **4～6栋** 建筑（每张单图2～3栋），**以低矮单层为主**：合计 **最多1栋两层**，其余全部为单层，且 **大部分建筑主体高度低于3米（300px）**。建筑从 **25种建筑主题** 中选取互不相同的主题（见「零之三、建筑主题库」），避免风格雷同。

**比例与疏密以 6-2 为示范**（`地面\6-2.png`，即 `模板1\生态方舟_建筑路面_左右无缝拼接.png`），实测数据见「零、比例尺」中的「示范：6-2」。

每张单图同时放置 **不少于16件** 街道装饰物（高杆路灯、消防栓、长椅、垃圾桶、行道树池等），装饰物 **允许站在建筑立面前方、遮挡部分墙面**，例如房子正中的墙前立着一根消防栓；装饰物之间也允许前后叠压，街道要显得密集、热闹。

建筑与装饰 **不能画成完全平面的立面图**，要求采用轻微俯视的 2.5D 视角，能看到屋顶上表面、檐口与凸出体块的厚度，具备体积感（见「零之二、视角与体积感」）。

建筑与装饰必须保持生成时的原始尺寸。素材处理时对整张生成图只做 **Y 轴平移与 X 轴裁切**：Y 轴平移用于对齐落脚位置，X 轴按内容最左列与最右列裁掉两侧多余的透明列（不裁到任何物件像素）。另外允许脚本清理远离物件的淡光雾与孤立噪点（见第二节「允许的脚本处理」）。不通过缩小、放大、拉伸或其他缩放方式完成对齐。

### 旧批次的问题

旧批次以「180～210px高的低矮建筑」为目标，门高仅约110px，换算后建筑只有约2米高，比人还矮；装饰物稀少，街区显得空旷。本工作流以上表尺寸取代旧目标。

模板4则走向另一个极端：每张单图只放2栋、单栋宽565～585px、主体高400px以上，建筑显得过大过胖，与路面和装饰物比例失调。本工作流改为每张单图2～3栋、大部分单层主体低于300px，以 6-2 的比例与疏密为准。

## 零之二、视角与体积感

> **硬性要求：建筑和装饰物绝不能画成平面的 2D 立面图，必须有足够明显的透视感与立体体积。** 看起来像建筑设计图、剪纸、贴在墙上的平面贴图的结果，一律判为不合格并重新生成。

### 目标效果

参考 `生态方舟_建筑透视参考.jpg`：镜头明显高于地面向下俯视，能清楚看到屋顶的上表面和坡面、玻璃顶骨架的前后层次、门斗和立柱向前凸出的厚度。建筑是一个个有长宽高的立体房子，而不是一张正面贴图。

本工作流在参考图基础上再加强一级立体感：除屋顶顶面外，每栋建筑还要统一露出右侧墙，让体块的三个面（顶面、正面、右侧面）同时可见。

### 视角规则

1. **明显俯视**：镜头俯视约20～30°。屋顶上表面、平顶边沿、雨棚顶面、门斗顶面必须清楚可见，屋顶顶面露出的纵深约80～150px。
2. **三个面可见**：每栋建筑同时露出顶面、正面和右侧墙。右侧墙宽度约为正面宽度的15～25%（约60～120px），处于背光面，明显比正面暗。
3. **正面基本正对镜头**：正面的水平线保持水平，竖直线保持竖直，正面底边落在路面上沿 Y=954。右侧墙与屋顶顶面向右上方斜向退后。
4. **平行投影，统一方向**：使用斜二测式的平行投影，没有汇聚消失点。同一张图里所有建筑、所有装饰物都露出右侧面与顶面，退后的角度与纵深比例一致；不出现左边建筑露左侧墙、右边建筑露右侧墙的单点透视。左右两张图使用完全相同的视角，保证拼接后视角连贯。
5. **体积细节**：门斗、雨棚、窗台、檐口、立柱、空调外机都要画出凸出厚度；门洞与窗洞画出内凹深度和侧壁；玻璃建筑要能透过玻璃看到室内纵深和后侧骨架。
6. **光影**：日光统一来自左上方，两张图一致。顶面最亮、正面中等、右侧墙最暗，三面明暗差异明显；檐口、雨棚下方有清晰阴影。
7. **装饰物同一视角**：长椅能看到座面与右侧端板，消防栓、垃圾桶、配电箱、快递柜能看到顶面与右侧面，路灯灯头能看到上表面，树池能看到池口。装饰物与建筑保持同一俯视角与同一退后方向。
8. **路面不变**：路面仍是原始素材的 20px 正侧视薄片，不画成能看到大片顶面的俯视地板。建筑正面底边与路面上沿相接，侧墙底边沿路面上沿向右上方退后，不在路面上画出地基或地面投影。

### 常见失败与规避

- 生图模型听到「横版游戏」「正侧视」时，容易把建筑画成纯平面立面。提示词中「正侧视」只用来描述路面，描述建筑时只用「俯视」「三个面可见」「立体体块」。
- 提示词开头就写透视要求，并在末尾再重申一次。
- 若生成结果只能看到正面、看不到屋顶顶面或右侧墙，或者顶面只露出一条细线，直接判为不合格。

### 对比例尺的影响

1px=1厘米 的比例以 **建筑正面** 为准测量：门高、层高都按正面竖向像素计算。

屋顶顶面因俯视而露出的纵深计入主体高，右侧墙宽度计入建筑占地宽度，二者都不计入门高与层高。「单层建筑主体高250～300px」「两层建筑主体高500～600px」已包含屋顶顶面纵深，屋顶绿植与设备另计；布局表中的建筑 X 范围已包含右侧墙。

### 选题规则

1. 每次执行先定建筑总数（**4～6栋**，每张单图2～3栋，推荐左右各3栋），再从主题库中选同样数量的 **互不相同** 主题，放入 A1、A2、A3、B1、B2、B3 槽位（某张单图只放2栋时去掉该图的第3个槽位）。
2. **屋顶 / 轮廓全部不同**；不能出现两栋都是平顶方盒子的情况。
3. **主材质至少3种不同**（5～6栋时至少4种），例如金属、玻璃、木、陶瓷、混凝土、膜材、竹编各取其一。
4. 所选主题 **至少覆盖3个分类**。
5. 同一张单图里相邻两栋，一栋偏通透轻盈（玻璃、膜材、开放结构），另一栋偏厚重实体（金属、混凝土、木），形成对比。
6. 全组 **最多1栋两层**，只能放在 A1 槽位，且只能放层数标有「两层」的主题；A1 也可以放单层主题，此时全部为单层。其余槽位一律按单层绘制。
7. 单层建筑主体高按250～300px 设计；窄型、宽型主题都不例外，个别屋顶造型突出的主题（穹顶、塔亭、风机）主体也不超过340px。
8. 不与上一个 `模板N` 使用过的主题重复（读取其 `生成说明.md` 中的选题记录；没有记录时跳过此条）。
9. 主题的「专属装饰」可以替换通用装饰中的非必需项，每栋最多替换2件；必需项（路灯、消防栓、长椅、垃圾桶或回收箱、树池或花槽）不能被替换。
10. 选题结果写入本次 `生成说明.md`，格式为「A1=T07 植物研究实验室（两层）」。

## 一、分别生成两张图

开始生成前，先按第六节规则在「地面」目录下新建本次的 `模板X` 输出文件夹，之后所有产出都保存到其中。

使用内置 imagegen，每张图单独调用一次。两次都按顺序传入原始路面、地图参考图与建筑视角参考图，并开启透明背景。

明确三张输入图的作用：

1. 原始路面是编辑目标，要求在其上增加建筑和装饰。
2. 地图是画风参考，不能把天空、远景城市、水面或整张地图当作背景画进素材。
3. 建筑视角参考图只用于学习俯视的 2.5D 视角与体积表现，不能照搬它的温室造型（否则所有建筑都会长得像温室），也不能把它的棋盘格背景画进素材。

### 装饰物规则

装饰物按位置分为两类：

| 类型 | 位置 | 示例 |
| --- | --- | --- |
| 叠加装饰 | 站在建筑立面正前方，遮挡一部分墙面、窗户或墙角 | 墙面正中的消防栓、挡住部分窗户的路灯杆、橱窗前的长椅、靠墙的回收箱 |
| 间隙装饰 | 站在两栋建筑之间的街道空段或单图两端的空路上 | 楼间的路灯、配电箱、快递柜、街口的行道树池 |
| 互叠装饰 | 站在另一件装饰物前方，遮挡它的一部分 | 配电箱前的花槽、长椅端头前的小盆栽、路灯底座前的隔离桩 |

叠加装饰的要求：

1. 装饰物处于建筑前方的图层，**遮挡建筑，而不是被建筑遮挡**；轮廓完整、边缘清晰，与墙面颜色有明显区分。
2. 底部与建筑一样落在路面上沿 Y=954，不能挂在墙上或悬空。
3. 不遮挡门洞，门前保留不小于门宽的通行空间。
4. 单件装饰遮挡的建筑立面宽度不超过该建筑宽度的40%，建筑主体轮廓仍可辨认。
5. 只允许在墙面上投下贴近物体的轻微接触阴影，不画向地面延伸的长阴影。
6. 互叠装饰遵循「矮的在前、高的在后」：小盆栽、隔离桩、花槽可以挡住长椅、配电箱、路灯底座的一部分，但被挡的物件仍要能认出来。

数量要求：

- 每张单图装饰物不少于16件，至少覆盖8种装饰物。

- 门洞以外的路段不要出现超过约120px（1.2米）的空白。

## 二、验收比例并确定平移量

### 比例验收

生成后先用实际像素核对，任一项不合格就重新生成，**不能用放大或缩小补救**。**透视感一项最先检查，不合格时其余项无需再看。**

| 检查项 | 合格范围 |
| --- | --- |
| 透视感（首要） | 每栋建筑都能清楚看到屋顶顶面（纵深约80～150px）和右侧墙（约60～120px），顶面、正面、右侧墙三面明暗分明；装饰物也能看到顶面与右侧面；整体不像平面立面图或剪纸贴图 |
| 视角一致 | 没有汇聚消失点；同图所有物件、左右两图之间的俯视角度、右侧面退后方向、光照方向一致 |
| 建筑数量与层数 | 左右合计4～6栋，每张单图2～3栋；合计最多1栋两层，其余全部单层 |
| 建筑风格差异 | 每栋建筑都能一眼认出是所选的不同主题；屋顶轮廓各不相同，主材质至少3种（5～6栋时至少4种）；没有两栋都是蓝灰金属方盒子 |
| 门高 | 180～220px，允许 ±10%（约162～242px） |
| 单层建筑主体高 | 大部分（全部单层中至少三分之二）在250～300px；任何一栋单层不超过340px；屋顶绿植与设备另计 |
| 两层建筑主体高 | 500～600px，允许 ±10% |
| 装饰物数量 | 每张单图不少于16件、至少8种；高杆路灯2盏，消防栓、长椅、垃圾桶或回收箱、行道树池或花槽各至少1件 |
| 装饰物密度 | 每栋建筑前至少3件叠加装饰（2栋时4件）；每段楼间空隙至少2件（2栋时3件）；至少2处互叠；门洞以外没有超过约120px的空路段 |
| 装饰物尺寸 | 与「装饰物尺寸」表相差不超过 ±20%；高杆路灯不低于400px |
| 与 6-2 对照 | 与 6-2 并排缩放到同一高度对比，建筑体量、楼间疏密、门与装饰物的比例相近；单栋宽度不超过约520px |
| 叠加关系 | 装饰物在建筑前方、轮廓完整，没有被墙面吞掉或半透明融进墙里；互叠时矮的在前、高的在后 |
| 门洞 | 所有门洞没有被装饰物挡住 |
| 路面 | 路面仍为正侧视薄片，建筑底部没有向路面延伸出俯视地基 |
| 顶部 | 所有物件完整，没有被画布上沿截断 |
| 左右完整 | 建筑与装饰没有贴着生成画布左右边缘被截断：内容最左列 L > 0 且最右列 R < 画布宽 − 1，边缘物件轮廓完整（整体宽度不再限制） |

模型最容易退回平面立面图。若看不到右侧墙、屋顶顶面只剩一条细线，应把提示词开头的透视段落再加重（例如写明「斜俯视的立体房子，像等距视角游戏里的建筑，但正面朝向镜头」），并在末尾重申后重新生成。

模型可能把建筑整体画小，若门高明显低于160px，应在提示词中进一步强调门高后重新生成。

模型更常见的是把建筑画得又高又胖（如模板4：每图2栋、单栋宽近600px、单层主体400px以上）。若单层主体超过340px、门高超过240px，或单栋宽度超过约520px，应在提示词开头重申「单层房子主体不超过3米」「3栋宽中窄搭配」后重新生成，不用缩小补救。

模型也常把装饰物缩成贴着墙根的一排矮小物件，或干脆省略路灯。若高杆路灯缺失、消防栓找不到、装饰物都挤在楼间空隙里而没有站到立面前，应在提示词开头单独重申装饰物清单与「站在建筑立面正前方」后重新生成。

### 不需要重新生成的问题

以下问题由合成脚本处理，**不作为废稿理由**，不要为它们反复重生成：

| 问题 | 处理方式 |
| --- | --- |
| 左右边距不足约100px、内容整体偏宽 | 只要没贴到生成画布左右边缘（L > 0 且 R < 画布宽 − 1），按内容裁切即可 |
| 模型没有按 Y=954 画路面，自绘路面位置偏高或偏低 | 自动定位模型路面上沿，整图 Y 轴平移对齐 |
| 模型自绘路面的厚度、颜色与原始路面不同 | 模型路面整段舍弃，换成统一路面 |
| 背景残留淡光雾、渐变底色、极淡色块 | 光雾清理（见下文） |
| 远离物件的零星噪点 | 噪点清理（见下文） |

真正需要重生成的只有：透视感不合格、比例不合格（门高、主体高、单栋宽度、装饰物尺寸超出容差）、建筑或装饰被生成画布边缘截断、数量与密度不达标、门洞被挡、残留大面积不透明背景（黑底、白底、棋盘格）。

### 允许的脚本处理

素材处理只允许以下操作，全部原尺寸逐像素完成：

| 操作 | 作用范围 | 说明 |
| --- | --- | --- |
| Y 轴平移 | 整张生成图 | 让建筑与装饰底部紧接路面上沿 Y=954，最终高度固定1024px |
| X 轴裁切 | 整张生成图 | 只裁掉内容最左列 L 左侧、最右列 R 右侧的透明列，单图宽度 = R − L + 1，不裁到任何建筑或装饰像素 |
| 舍弃模型路面 | 模型路面上沿及以下 | 整段丢弃，换成统一路面 |
| 光雾清理 | 模型路面上沿以上 | 只把远离实心物件的半透明像素清为全透明，不改变任何物件像素 |
| 噪点清理 | 模型路面上沿以上 | 只删除面积很小的孤立实心碎块 |

禁止的操作：

- 不缩放、不拉伸、不旋转、不重采样。
- 不把单栋建筑或单件装饰抠出来单独移动。装饰物与建筑是同一层像素且互相遮挡，抠出移动会在后方墙面留下空洞，脚本无法补画。
- 不修改、不重绘物件本身的颜色与形状，不做调色、描边、羽化或抠边。

检查透明通道与路面位置。预览中的黑色不能单独作为是否透明的判断依据，需要确认透明通道。

### Y 轴：落脚位置

分别找到两张生成图中模型自绘路面的上沿，也就是建筑与装饰底部和路面的分界位置。最终只保留建筑与装饰，舍弃模型重新绘制的路面，随后使用原始路面统一替换。

模型自绘路面的位置不固定（实测在 Y=764～888 之间），用脚本自动定位：

1. 在生成图左右两侧各取一条窄带（距边缘2列开始、宽8列）。这两条窄带里只有路面、没有物件，可以避开建筑和装饰的干扰。
2. 从上往下逐行检查：两条窄带里不透明度大于200的像素都达到60%，并且向下连续4行都成立，这一行就是路面的实心上沿。
3. 从实心上沿继续向上检查：只要两条窄带里不透明度大于16的像素仍都达到60%，就把这一行也算作路面。路面顶边的半透明抗锯齿行要一起舍弃，否则会留下一条贯穿全宽的淡色细线。
4. 最终得到的路面上沿行号即为裁切高度，保留 Y=0～裁切高度 − 1。

若内容贴近生成画布左右边缘、侵入窄带，导致无法定位，应改为手工指定裁切高度。

```text
向下偏移 = 目标路面上沿坐标 − 裁切高度
示例：若分界位置为 Y=0～892，裁切高度为893px，则向下偏移 = 954 − 893 = 61px
```

偏移后两张图保留的最后一行都移动到 Y=953，紧接最终路面上沿 Y=954。偏移后建筑顶部也会下移相同距离，需要确认顶部仍在画布内且未被截断；若向下偏移为负数（需要上移），同样确认顶部不越过 Y=0。

若物件底部参差不齐，应调整生成结果，不能靠整图缩放或单件移动解决。

### 光雾与噪点清理

生成图在物件周围和画面两侧常残留肉眼几乎看不见的淡光雾。不清理时，它会把内容左右范围撑宽，拼接处会出现一条淡雾带。清理只作用于保留区域（Y=0～裁切高度 − 1），**必须在统计内容左右范围之前完成**：

1. 不透明度大于64的像素视为实心像素，按8连通分块。
2. 面积小于40px的孤立实心块视为噪点，清为全透明。
3. 其余实心块向外扩3px作为保留区。保留区内的所有像素原样保留，包括物件边缘的半透明过渡、玻璃和灯光的柔边。
4. 保留区以外的像素一律清为全透明（红、绿、蓝、透明度都置0）。

| 参数 | 默认值 | 调整方向 |
| --- | --- | --- |
| 实心阈值 | 64 | 半透明玻璃、水体被误清时调低 |
| 保留半径 | 3px | 灯光柔边被切硬时调大 |
| 最小块面积 | 40px | 细小独立物件（如远处花瓣）被误删时调小 |

清理后必须核对被清除像素：被清除像素的原不透明度应绝大多数在16以下。若有成片的较高不透明度像素被清掉，说明误删了物件，应调整参数后重新合成。模板4实测：左图清除约1.2万像素、右图约2.7万像素，原不透明度中位数为1，没有误删物件。

### X 轴：按内容裁切

1. 在清理后的保留区域（Y=0～裁切高度 − 1）中统计不透明像素（透明度大于8）的横向范围，得到内容最左列 L 与最右列 R。
2. 检查完整性：L 必须大于0、R 必须小于生成画布宽 − 1；若内容贴到生成画布左右边缘，说明物件可能已被截断，需重新生成。
3. 单图宽度 W = R − L + 1，以实际裁切结果为准，不限制大小，左右两图宽度也不必相同。
4. 裁切时取 X=L～R 整列，光雾清理后剩下的像素（包括物件边缘的半透明过渡）原样保留，不再做抠边。

左图宽度记为 W左，右图宽度记为 W右，拼接图宽度 = W左 + W右。

## 三、制作统一且可连续拼接的路面

从原始路面素材提取矩形：X=0、Y=954、宽1536px、高20px。

使用这同一条路面制作左右两张单图，让路面厚度、上沿高度、材质与灯带一致。

为消除路面纹理在左右端点的突变，对路面两端各32px进行逐行颜色过渡：

1. 对路面的每一行，读取最左端和最右端的颜色，包括透明度。
2. 将两端颜色的平均值作为共同的接缝颜色。
3. 在左右边缘分别向内取32px，由共同接缝颜色逐渐过渡到原始像素颜色。
4. 最左列与最右列使用相同颜色；距离边缘31px处保留原始颜色。
5. 路面内部其余像素保留原样。

过渡公式如下，透明度与红、绿、蓝四个通道分别计算：

```text
共同接缝颜色 = 左端与右端颜色的平均值
过渡权重 = (31 − 距离边缘的像素数) ÷ 31
输出颜色 = 原始颜色 × (1 − 过渡权重) + 共同接缝颜色 × 过渡权重
```

此处理仅改变路面两端的颜色，不改变建筑或装饰的尺寸与形状，也不改变20px路面厚度。

经过两端过渡后，这条 1536px 路面首尾颜色一致，可以横向 **循环平铺**。

### 按拼接总宽度平铺路面

单图宽度不再是1536，因此先按拼接图总宽度生成一整条连续路面，再切给左右两张单图，保证接缝处路面像素天然连续：

```text
总宽度 = W左 + W右
平铺路面第 x 列 = 统一路面第 (x mod 1536) 列，x = 0 ～ 总宽度 − 1
左图路面 = 平铺路面 X=0 ～ W左 − 1
右图路面 = 平铺路面 X=W左 ～ W左 + W右 − 1
```

不要让左右两张单图各自从统一路面第0列开始取路面，否则左图末列与右图首列来自统一路面的不同位置，接缝处会出现纹理和灯带跳变。

## 四、合成两张单图

为每张单图创建 W×1024 的全透明画布（W 为该单图的宽度，见第二节记录表）：

1. 从清理后的生成图裁切出 X=L～R、Y=0～裁切高度 − 1 的建筑与装饰区域，保留透明通道。
2. 在 X=0、Y=向下偏移 处原尺寸粘贴。
3. 将该单图对应的那段平铺路面（见第三节）在 X=0、Y=954 处原尺寸粘贴。
4. 保存为透明 PNG。

### 合成脚本

使用 PowerShell 调用原生图像库完成处理。裁切使用像素矩形，粘贴使用原尺寸逐像素复制，不做重采样和尺寸变换。

`模板4` 中的脚本是参考实现，第二～五节的全部步骤都已实现，新一次执行直接复制到本次 `模板X` 使用：

| 文件 | 内容 |
| --- | --- |
| `模板4\合成近景.ps1` | 主流程：定位模型路面、清理、裁切、平移、路面平铺、单图合成、拼接、灰底预览、接缝检查，并打印记录表数据 |
| `模板4\近景像素工具.cs` | 像素处理工具类，由主脚本用 Add-Type 编译；逐像素循环放在 C# 里，速度远快于 PowerShell 循环 |

用法：


底部50px直接来自空白透明画布。舍弃生成图中的旧路面以及旧路面下方内容，避免留下额外地板或光影。

## 五、横向拼接

创建 (W左 + W右)×1024 的全透明画布：

- 左图放置在 X=0、Y=0。
- 右图放置在 X=W左、Y=0。
- 两张图直接相邻，不重叠，不留缝，不缩放。

因为两张单图的路面上沿都位于 Y=954，且路面取自同一条平铺路面的相邻两段，拼接处的路面与青色灯带天然连续。

两图交界处不强制留空路：左图最右侧物件与右图最左侧物件可以直接相邻。两侧物件各自完整，互不覆盖。

### 接缝检查

合成后放大检查交界处 X=W左−1 与 X=W左 两列附近，以下任一项出现即为接缝问题，需排查后重新合成：

| 检查项 | 合格标准 |
| --- | --- |
| 透明裂缝 | 路面区域 Y=954～973 在交界两列都完全不透明，没有1px透明竖线 |
| 上下错位 | 交界两侧路面上沿都在 Y=954，下沿都在 Y=973 |
| 纹理跳变 | 交界两侧路面纹理、灯带亮度与颜色连续，没有明显断层 |
| 物件截断 | 交界两侧的建筑与装饰轮廓完整，没有被切掉一半的物件 |
| 物件落脚 | 交界两侧物件底部都紧接 Y=954，没有一侧悬空或陷入路面 |
| 背景残留 | 交界处没有生成图带来的黑边、白边或棋盘格残留 |

## 六、输出位置与文件

### 输出目录

每执行一次本工作流，就在「地面」目录下新建一个 `模板X` 文件夹，本次的全部产出都放进这个文件夹：

```text
F:\new\my-test-card-game\生图模型输出目录\地面\模板X
```

`X` 的取法：

1. 列出「地面」目录下所有名为 `模板` 加数字的文件夹。
2. 取其中最大的数字加1作为 `X`；一个都没有时 `X=1`。
3. 例如已有 `模板1`、`模板2`，本次就新建 `模板3`。

规则：

- 在第一节调用 imagegen **之前** 先建好 `模板X`，生成原图直接保存进去。
- 不得覆盖、修改或删除已有的 `模板N` 文件夹。
- 本次产出不得写入「地面」根目录。根目录只放本工作流文档与输入素材（原始路面及其生成说明）。
- 验收不合格、需要重新生成的废稿放进 `模板X\生成过程`，按 `左图_第1次.png`、`右图_第2次.png` 的方式编号，不要直接删掉。

PowerShell 创建示例：

```powershell
$root = 'F:\new\my-test-card-game\生图模型输出目录\地面'
$nums = Get-ChildItem $root -Directory | Where-Object { $_.Name -match '^模板(\d+)$' } | ForEach-Object { [int]$Matches[1] }
$next = if ($nums) { ($nums | Measure-Object -Maximum).Maximum + 1 } else { 1 }
$outDir = Join-Path $root "模板$next"
New-Item -ItemType Directory -Path (Join-Path $outDir '生成过程') | Out-Null
```

## 人工确认要点

- **透视感足够**：每栋建筑都能看到屋顶顶面、正面、右侧墙三个面，明暗分明，不是平面立面图；装饰物同样立体；两图俯视角度、退后方向和光照方向一致。
- 比例为1px=1厘米：门高约180～220px，大部分单层建筑主体250～300px（低于3米），两层建筑主体约500～600px；与 6-2 并排对比体量相近。
- 左右合计4～6栋建筑，每张单图2～3栋，以低矮单层为主；合计最多1栋两层。
- 每栋建筑来自主题库中不同的主题，屋顶轮廓、主材质差异明显，不是同一种建筑换颜色；选题已写入 `生成说明.md`。
- 每张单图不少于16件、至少8种装饰物，含2盏高杆路灯、消防栓、长椅、垃圾桶或回收箱、行道树池或花槽；门洞以外没有大段空路。
- 装饰物站在建筑正面前方遮挡部分墙面，装饰物之间有前后叠压，轮廓完整，不挡门洞。
- 建筑和装饰保持生成原图尺寸，只对整张图做 Y 轴平移与 X 轴裁切，没有缩放或单件移动；裁切没有切到任何物件，左右边缘物件完整。
- 单图与拼接图高度都是1024px；宽度随内容而定，不要求等于1536或3072。
- 两图的建筑与装饰落在统一路面上，没有悬空或明显穿入路面。
- 所有物件完整，顶部没有被画布上沿截断。
- 路面保持20px厚，底部保持50px透明留空。
- 拼接处通过第五节「接缝检查」：没有透明裂缝、上下错位、灯带断层、明显颜色跳变或被截断的物件；交界处可以没有空路，两侧物件直接相邻。
- 建筑与装饰周围为真实透明区域，没有背景残留；光雾清理没有误删物件（被清除像素原不透明度绝大多数在16以下）。
- 尺寸不合格时通过重新生成解决，不能用放大或缩小素材代替。
- 全部产出都在本次新建的 `模板X` 文件夹中，「地面」根目录和已有的 `模板N` 文件夹没有被改动。
