# 状态与标记素材目录

素材按实际机制归属，每张正式素材只存放一份。多机制状态按主要用途分类，不按增益或减益笼统分组，也不按角色重复存放。

| 目录 | 归属规则与示例 |
| --- | --- |
| 状态/持续伤害 | 按拍扣血：中毒、灼烧、痛楚 |
| 状态/生命恢复 | 按拍恢复、理赔与治疗触发：再生、生机、保险、止损、受益人 |
| 状态/属性强化 | 攻击、防御、命中、暴击等正向修正：力量、铁壁、锋利、残心·凝神；充能外壳主要提高攻击伤害 |
| 状态/属性削弱 | 属性降低、承伤提高或治疗削弱：虚弱、破甲、穿孔、蚀刻、易燃、焦灼、厄运 |
| 状态/伤害防护 | 减伤、闪避、保命、伤害分摊与免疫：铁衣、罗生门、寿险、共同海损、护航 |
| 状态/控制限制 | 行动、招式时序、目标选择或增益获取限制：眩晕、迟滞、静电、封印、停摆、嘲讽 |
| 状态/触发联动 | 攻击、受击、成熟、状态到期等事件联动：荆棘、反咒、怨咒、花粉、淬火、菌丝网络、衔尾蛇 |
| 状态/资源规则 | 资源获取、容量与结算奖励：星辉、盈余、残心、银河、偿付能力、赏金猎人 |
| 状态/出牌规则 | 改写出牌条件、效果次数、传播或词条判定：倒泻、盛放、回响、贤者之石、咒誓、逢魔、各类预言 |
| 状态/信息标记 | 意图可见与条件替代：洞察、假装受伤 |
| 标记/敌方标记 | 定义中带有 `mark: true`，不计入恶毒减益种类：锁魂、疫病、咒丝 |
| 标记/卡牌标记 | 附着于卡牌的标记：剑冢、多米诺、彗尾、心眼等 |
| 标记/培育 | 培育中、成熟与过熟展示 |
| 部件/组装 | 组装 A—D 部件 |
| 道具/药剂 | 魔药徽记 |
| 战斗/护盾 | 独立护盾值图标；不属于正式状态 |
| 备选 | 未登记使用的备用素材，文件名保留“备用·”前缀 |

痛楚是持续伤害减益，沿用原有状态标识 `boneRot` 与伤害结算机制；卡牌、悬浮说明及设计文档统一使用“痛楚”。

状态图标由 `src/ui/art/battle/statusArt.ts` 及其分模块登记，卡牌标记由 `cardMarkArt.ts` 登记，培育、组装和魔药由 `buffArt.ts` 登记。新增素材时先确定本目录归属，再更新对应登记表。

素材处理脚本通过 `scripts/buff-asset-paths.mjs` 查找现有素材的唯一路径；不要重新创建旧的 buffs、debuffs、dot 或 hexer 子目录。
