# 横向探索美术

废弃楼层分近景、远景两层渲染：近景与可交互物、角色同属世界层 1:1 跟随相机，远景按
`CORRIDOR_LAYOUT.farParallax`(0.35) 慢速跟随制造纵深。素材通过 `ui/art/corridorArt.ts`
登记，并纳入启动预载；分层尺寸与地面对齐参数集中在 `ui/explore/CorridorScene/corridorLayout.ts`。

- `废弃楼层/无限远景.webp`：3285×948 可无缝横向循环的赛博城市远景，按 1080px 高度缩放平铺。
- `废弃楼层/近景/近景1.webp`～`近景3.webp`（均为 2172×724）：废弃楼层和新手关卡共用的三种近景；使用无损 WebP，平台顶面按素材像素位置校准，保持角色、物件和传送门与地面线对齐。尺寸登记在 `explore/dungeon/nearMapGeometry.ts`，地面位置登记在 `ui/explore/CorridorScene/corridorLayout.ts`。
- `生态方舟/近景/生态方舟近景1.webp`～`生态方舟近景4.webp`（均为 2172×724）：以参考近景2的生态方舟地面为基础制作，依次为种子培育区、凝露净化区、生质循环区、母树维护区；使用当前透明 PNG 无损转换的 WebP，保留原始尺寸与透明通道。每个房间随机使用一种方舟近景，首轮保证四种都出现；素材尺寸、房间宽度与各图平台顶面位置分别登记在 `explore/dungeon/nearMapGeometry.ts` 和 `ui/explore/CorridorScene/corridorLayout.ts`，房间重访时保持不变。原始素材存放于 `处理后的WebP素材/组装部件/`，旧版同名 WebP 已替换为本次无损转换的版本，近景目录中的 PNG 已删除，仅保留运行时使用的 WebP。
- `废弃楼层/无限近景-左.png`、`无限近景-右.png`：旧版近景半图，保留作旧素材归档，不再参与运行时渲染。
- `废弃楼层/无限近景-透明.png`：旧版单张近景，保留作旧素材归档，不再参与运行时渲染。
- `废弃楼层/可交互物体/`：交互物独立透明 WebP，已按场景最大显示尺寸等比压缩；原图按 0.35 作为设计画布基准，再按小 0.5、
  中 1.0、大 1.2 三档缩放。每张素材的透明底边由 `CORRIDOR_PROP_ART` 登记并通过负外边距补偿，
  每种物件另有独立的 `CORRIDOR_PROP_Y_OFFSETS` 场景 Y 轴微调值（设计 px，正值向下）。
- `公共交互物/`：各地图通用的童话手绘交互物（来源 `生图模型输出目录/新品交互物体/`），已裁去透明边并等比缩至最长边 640px、WebP 质量 90。
  种类到素材的分配与尺寸档位登记在 `ui/art/corridor/commonPropArt.ts`；部分素材由多个物件共用，文案按同一件实物的不同用法区分。
  `潮汐祈愿门.webp`、`珊瑚宝库.webp` 暂未分配。`废弃楼层/可交互物体/神龛.webp` 也登记在 commonPropArt.ts，用于神龛与各类遗物匣；压缩舱、净水槽、贩卖机仍被三个陷阱引用，其余旧图不再参与运行时渲染。
- `废弃楼层/传送门.webp`、`废弃楼层/蓝色传送门.webp`：旧版房间传送门精灵图与首领红门立绘，保留作旧素材归档，不再参与运行时渲染。
  房间传送门与首领红门现由 `ui/art/portal` 的 GLSL 着色器程序化绘制（无边框的悬空能量门：火焰状边缘 + 旋涡 + 上飘光粒 + 地面光斑，缓慢上下浮动），
  经 `ui/common/fx/GlslSprite` 的共享 WebGL 宿主输出；玩家靠近时内部动画平滑提速到 2 倍并提亮。
  配色按地图区分（废弃楼层青色 / 生态方舟蓝绿 / 首领红门血红），尺寸、悬浮高度与落地参数见 `portalThemes.ts`。
- `人物立绘/站立右移动作帧_透明背景/` 共 13 帧，均为 180×240 透明 WebP：帧 000 为正面静态站姿（初始与停步共用，不播放动画），
  帧 001～012 为侧面右行的完整步态循环，逐帧播放（每秒 10 帧，一轮 1.2 秒）。行走帧取自行走视频 2.4s～3.5s 的 100ms 关键帧，
  该段首尾衔接误差最小。
  `ui/art/corridorPlayerArt.ts` 按帧号登记资源，缺失帧保留空位。
  `ui/art/corridorPlayerFrames.ts` 缓存已解码图片，角色组件通过独立画布同步绘帧，避免逐帧切换图片地址造成显示延迟。
  新素材脚底贴画布底边（站姿留白 4px），站姿与行走帧的水平重心也不一致，校准量登记在
  `ui/explore/CorridorScene/corridorPlayerMotion.ts`，绘制时统一对齐到画布中线与底边；
  角色组件按 240px 高度显示，并通过 `.player` 偏移（下沉 3px）及 `CORRIDOR_LAYOUT.entityGroundOffset` 与近景地面对齐。
- `事件背景/`：事件档案面板右侧插图，已从 1448×1086 等比压缩至 1205×904（面板在 1080P 下的显示高度）。
  由 `ui/art/eventDossierArt.ts` 登记并纳入预载；主题色在 `ui/explore/EventDossier/dossierThemes.ts`，
  物件种类到主题的分配在 `ui/explore/ExploreScreen/curioTheme.ts`。
- 旧版 `售货机.png`、`宝箱.png`、`雕像.png` 保留在目录中，不参与当前走廊运行时渲染。黑影与破地动画仍由 `ShadowEncounter` 独立绘制。
- 旧版 `废弃楼层/背景.png`、`corridor.png`、`ground.png`、`sprites.png` 保留在目录中，不再用于当前走廊场景。

## 旧版素材生成提示词（供追溯）

### 墙景

Q 版横向卷轴游戏背景，3:1 超宽全景，废弃地下研究站的室内墙面，严格正侧视、无透视消失点。重复玻璃实验窗、圆润支柱、封闭实验室门、少量垂落电缆、青色应急灯和琥珀色壁灯。柔和灰、石板蓝、奶油白、青绿与琥珀色，粗而干净的深色轮廓，明亮平涂与柔和赛璐璐阴影，形体简化圆润、明确的 Q 版独立游戏插画。左右边缘可无缝横向循环；只画墙面，不含人物、地面、文字或界面。

### 地台

Q 版横向卷轴游戏前景地台，3:1 横向循环砖块，严格正侧视。画布顶边是一条水平连续的深蓝灰色可行走地面，带浅奶油色与琥珀色边线；下方是厚实清晰的暖灰石块、赭黄色支撑块和少量青色发光管线剖面。轮廓粗而干净，圆润简化形状，明亮平涂与柔和赛璐璐阴影；地面从图像顶行延伸到四边，不留空白，不画墙景、人物、道具、草或文字。

### 角色与物件图集

正方形透明 PNG，严格三列三行等尺寸九宫格，留足单格透明边距、无格线。Q 版 2D 平台游戏插画，圆润比例、粗而干净的深色轮廓、明亮色块与柔和阴影。按从左到右、从上到下：大头短身、奶油白与青绿外套、琥珀背包的可爱探索者；圆角补给箱；带青色十字的医疗柜；破损数据终端；复古售货机；青色发光净化罐；废料与线缆堆；带青色灯槽的投递柜；铺盖、补给包与暖色提灯组成的营地。每格单独居中、底部基线一致、各自完整不越界；背景必须是真实透明，不能绘制棋盘格，不加文字、数字或标志。
