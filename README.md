# 《霓虹都市》· 原型

一个网页版卡牌 Roguelite 原型：以时刻制（tick）战斗为核心，结合个人卡组改造、装备养成、横向场景探索和据点持久化。

世界观与已确认机制见 [`游戏设定.md`](/design/游戏设定.md)。具体代码职责不要从本文件展开，按任务读取 [`docs/code-map/README.md`](docs/code-map/README.md) 中对应的模块说明。

## 核心模块

- `engine/`：纯 TypeScript 战斗引擎，负责卡牌、伤害、状态、敌人排程和回合；玩家生命按当前 HP、体力极限和最大 HP 三段继承。
- `explore/`：纯 TypeScript 探索引擎，负责房间图与传送、房间内的物件交互、黑影遭遇、粒子、背包和远征阶段。
- `items/`：物品类型、容器、装备占格和掉落逻辑。
- `data/`：卡牌、角色、敌人、遭遇战、物品、事件和地图数据。
- `store/`：Zustand 状态层；城镇档案持久化，远征过程为临时状态。
- `ui/`：React 页面、组件、场景表现、动画和素材查表。按功能域分目录，组件样式一律 CSS Modules。
- `styles/`：全局样式层，只剩设计令牌与基础元素皮肤两个文件。

探索事件奖励遵循“先展示、后领取”：成长事件的物品先进入拾取框，经验暂存在远征会话中，卡牌/删卡/装备候选/羁绊重铸进入待办奖励队列；生存事件还会提供体力极限、污染、怪癖、污染卡与遗物处理。战斗胜利会按每名敌人的奖励表并行生成治疗露珠、卡牌奖励或随机装备箱，使用统一掉落系数；治疗不复活，卡牌候选按存活角色生成，装备箱进入战利品盘。风险事件的加权结果使用远征 RNG 抽取，污染在策略结算时即时落地并回填实际角色与卡牌文案；《沉重的负担》通过强制拾取进入背包，不进入可放弃拾取框且不可移除。只有处理完奖励才能确认节点或离开胜利面板。指定食品可在成长事件结算后触发隐藏 NPC 事件；远征途中还可使用一次《野餐》，组合临期食品尝试发现隐藏食谱：部分食谱回复全队体力极限（上限 20），部分食谱给一件仅本趟远征有效的一次性遗物（占背包格，结束后销毁、不能寄回）。出击时总部会按地图与难度配发占用背包格的一次性配额物资，可在远征中使用或丢弃，结束后销毁且不能寄回据点。

角色在远征中阵亡后会永久离开编队，所穿三件装备会掉入战利品盘；医疗室的复苏舱可消耗 200 居民积分复苏队员，复苏后角色档案、装备与卡上模组全部重置。

当前探索使用房间制：一张地图就是一张房间图，房间总数（新手关卡 6 间直线固定蓝图、废弃楼层 12 间）就是这张图的庞大程度，没有「层」的概念。近景素材宽高均按原始尺寸的 2 倍显示，每间房宽度与近景显示宽度一致；镜头在 1920×1080 的可视区域内跟随玩家并在房间两端夹紧。房间最多连通上下左右 4 个方向，传送门优先分配到左右边缘，额外的门与可交互物使用中段槽位。四座传送门外观完全一致，走上去才会在右上角小地图点亮它通往的房间，再按一次交互键才真的传送。随机地图的物件按配额投放：治疗交互约每 6 间房 1 个，风险房约每 5 间房 1 间（进房立即触发、必须在几个轻度代价中选择、不消耗交互粒子），其余物件按权重偏向物品奖励；卡牌三选一奖励均可放弃。普通房会额外投放 1–2 个流浪货商，每个货商随机只收两种临期食品，货架固定六格，商品价格按价值分档消耗食品 ×1–×5；物件采用「兜底决策 + 黑盒放入/职业应对决策」，放错物品会被吞掉。粒子消耗：进新房 −5、回头路 −3；交互按物件分类 −4/−3/−2（货商免费）；战斗每回合 −1 并按档位额外 −2/−4/−6；房间内每走一屏 −1。出击配额附带净化粒子罐，地图中还会刷出粒子净化站补充粒子。房间里的可交互物全部处理完且战斗房黑影已清后，小地图把该房标记为「已探索」；BOSS 房会生成普通物件与红门，开启红门挑战首领后，胜利通关，失败或撤退按撤离副本结算。每图固定两次装备拾取，战斗合计投放一至三件装备；起始房保证一次性遗物，沿途增加免费抽卡、卡组经验和装备调校服务。新手与普通难度禁用删卡。详情见 [房间探索说明](docs/corridor-exploration.md) 与 [探索成长投放](docs/exploration-growth-balance.md)。

可探索地图现包含《生态方舟》：通关废弃楼层后开放，十二间房，五种小怪、两种精英、一名首领与五种专属交互物。普通档以高于普通废弃楼层、低于困难废弃楼层为设计目标；困难／深渊保留各地图自己的敌人与交互池，并分别应用敌人生命 ×1.3／×1.6、攻击 ×1.2／×1.4。内容、素材与平衡入口见 [生态方舟设计](design/关卡事件设计/生态方舟/生态方舟.md)。

## 技术栈

| 领域 | 选型 |
| --- | --- |
| 构建工具 | Vite 5 |
| UI 框架 | React 18 |
| 状态管理 | Zustand 4 |
| 语言 | TypeScript 5（严格模式） |
| 测试 | Vitest 2 |

## 运行方式

```bash
npm install
npm run dev
npm test
npm run test:watch
npm run preview
```
