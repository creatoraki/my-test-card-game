# 《霓虹都市》· 原型

一个网页版卡牌 Roguelite 原型：以时刻制（tick）战斗为核心，结合个人卡组改造、装备养成、区域路由探索和据点持久化。

世界观与已确认机制见 [`游戏设定.md`](/design/游戏设定.md)。具体代码职责不要从本文件展开，按任务读取 [`docs/code-map/README.md`](docs/code-map/README.md) 中对应的模块说明。

## 核心模块

- `engine/`：纯 TypeScript 战斗引擎，负责卡牌、伤害、状态、敌人排程和回合；玩家生命按当前 HP、体力极限和最大 HP 三段继承。
- `explore/`：纯 TypeScript 探索引擎，负责区域路由、节点事件、战斗签老虎机、粒子、背包和远征阶段。
- `items/`：物品类型、容器、装备占格和掉落逻辑。
- `data/`：卡牌、角色、敌人、遭遇战、物品、事件和地图数据。
- `store/`：Zustand 状态层；城镇档案持久化，远征过程为临时状态。
- `ui/`：React 页面、组件、场景表现、动画和素材查表。按功能域分目录，组件样式一律 CSS Modules。
- `styles/`：全局样式层，只剩设计令牌与基础元素皮肤两个文件。

探索事件奖励遵循“先展示、后领取”：成长事件的物品先进入拾取框，经验暂存在远征会话中，卡牌/删卡/装备候选/羁绊重铸进入待办奖励队列；生存事件还会提供体力极限、污染、怪癖、污染卡与临时远征光环处理。战斗胜利会按每名敌人的奖励表并行生成治疗露珠、卡牌奖励或随机装备箱，使用统一掉落系数；治疗不复活，卡牌候选按存活角色生成，装备箱进入战利品盘。风险事件的加权结果使用远征 RNG 抽取，污染在策略结算时即时落地并回填实际角色与卡牌文案；《沉重的负担》通过强制拾取进入背包，不进入可放弃拾取框且不可移除。只有处理完奖励才能确认节点或离开胜利面板。指定食品可在成长事件结算后触发隐藏 NPC 事件。

## 技术栈

| 领域 | 选型 |
| --- | --- |
| 构建工具 | Vite 5 |
| UI 框架 | React 18 |
| 状态管理 | Zustand 4 |
| 语言 | TypeScript 5（严格模式） |
| 测试 | Vitest 2 |

## 运行方式

```bash
npm install
npm run dev
npm test
npm run test:watch
npm run preview
```
