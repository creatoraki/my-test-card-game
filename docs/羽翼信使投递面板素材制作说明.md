参考：`处理后的WebP素材/组装部件/方案1_紫色简约细框.png`，基准画布 1672×941。本次交付拆解规格与独立美术素材，不修改投递面板代码和业务规则。生成模型无法保证逐像素复制；真正的像素级还原需要参考原图逐项对齐布局、描边、字体和素材位置。

## 用 CSS / SVG 实现的部分

|部件|方式|关键细节|
|---|---|---|
|外层细框|SVG 路径|紫色双层切角矩形，主线约 2px，淡紫内亮线和外发光|
|左右分区边框|SVG 路径|独立可伸缩切角路径，顶部断线、底角小段亮线|
|暗色面板底|CSS|深蓝黑半透明渐变，细噪声可用 SVG 滤镜，背景轻微透出|
|背包格子|SVG + CSS|八角细框、深色渐变、左上复选框、底部名称带、右下数量|
|空格子十字|SVG|中心紫色虚线十字，不生成图片|
|支付卡片|SVG + CSS|紫框八角卡片、低对比同心科技圆环，图片与名字分层|
|加减按钮|SVG + CSS|八角框；加号青蓝光晕；减号冷灰青框；字符独立绘制|
|底部按钮|SVG + CSS|双层切角青蓝边、角部短线、内部深蓝渐变与细斜纹|
|关闭、取消、警告|SVG|白色叉、青色叉、紫色菱形感叹号|
|背包、餐具、羽翼标志|SVG|简化剪影、紫色渐变；羽翼按参考轮廓手绘路径|
|标题与装饰|中文文字 + CSS / SVG|中文粗黑体斜切，白至淡紫渐变，硬边阴影；装饰横线、斜杠用 SVG|
|所有名称、计数、说明|真实中文文字|不烘焙进图片，正文字号不小于 18px，英文不用于内容|

标题若要求字形与参考完全一致，应单独人工描摹“羽翼信使”为 SVG 路径，并保留可访问的中文标题；普通字体加倾斜不能保证字形完全一致。不依赖模型生成文字。

已编写 `src/assets/羽翼信使面板/界面图形.svg`，提供关闭、背包、餐具、警告、空格十字、加减、取消、羽翼、背包格框、支付卡框和操作按钮框的可复用 symbol。可通过 `<svg><use href="素材路径#加号" /></svg>` 引用。它们是按参考图绘制的基础部件，最终接入时还需根据实际容器调整描边与光晕。外层大框需要按容器尺寸单独构造路径，不能直接拉伸小格子边框。

背包列间距约 9px，支付列间距约 17px。背包第一行名称带使格子看起来更高，代码布局需统一行高与名称显示方式。全屏背景覆盖，顶部信鸦层置于背景上方、面板内容下方；信鸦下缘由左右面板遮挡。以统一画布缩放控制整体比例，同时保持实际正文字号至少 18px；窄屏应改布局或允许滚动。

参考里的“6/24”表示背包占用格数，不宜误当作投递件数。“0/6”应读取实际食品服务费。现有代码还展示额外包裹区，参考图没有；以后实现时需确认包裹入口、标题计数含义，以及食品是否仍能勾选寄回，不能仅因视觉参考修改业务规则。

## 生成提示词

所有任务以参考图为风格与构图参考，不生成整张界面。不要生成任何文字、数字、按钮、边框、水印。食品保持统一明亮、精致、圆润的游戏道具插画风，带细致体积光和软高光，无落地阴影；每张只有一个物品，占透明画布约 75%，边缘完整且不裁切。

### 01 城市背景

生成独立的 16:9 蓝紫赛博朋克城市背景，匹配参考图的夜景色调、建筑密度和透视。高楼两侧向上延伸，少量暖橙窗灯，青蓝与紫色霓虹，柔和浅景深。中心和下方暗且低对比，供界面叠放。只保留城市，不要信鸦、货箱、界面、边框、食品、文字和可读招牌。

### 02 机械信鸦与货箱

生成透明背景的横向顶部装饰：黑色机械信鸦栖息在深黑金属货箱上，头朝右，紫色发光眼睛；左翼向左上展开，分层机械羽毛带鲜亮紫色边缘光，右翼自然收拢。货箱右后方是一块蓝紫透明全息屏，屏上只有线描鸟图形，没有文字。匹配参考图上方造型与视角。完整保留翼尖，左右留安全边；不要背景、界面或边框。横向约 2:1 构图。

### 03 牛奶

生成透明背景白蓝牛奶纸盒，乳白纸面、浅蓝色块、顶部折叠封口，三分之四视角，略向右转，匹配参考图。无任何包装文字或标志。

### 04 面包

生成透明背景金黄短法棍，圆润饱满，四道弧形割纹，表皮橙金高光，左上至右下倾斜，匹配参考图。

### 05 可乐

生成透明背景红黑可乐铝罐，银色罐顶与拉环，右倾约 18 度，红色高光与黑色弧形装饰，无商标无文字，匹配参考图。

### 06 汉堡

生成透明背景饱满芝麻汉堡，橙金面包、绿色生菜、黄色奶酪、红番茄、深棕肉饼，正面略俯视，匹配参考图。

### 07 炸鸡

生成透明背景橙金脆皮鸡腿，鸡肉主体在右上，白色骨柄朝左下，表面脆皮细节与油亮高光，匹配参考图。

### 08 披萨

生成透明背景单片三角芝士香肠披萨，尖端朝左下，厚金黄饼边在右上，红色香肠圆片、橙黄色芝士，匹配参考图。

## 接入模块建议

沿用 `src/ui/explore/MessengerPanel/`，拆分面板外壳、顶部品牌、背包网格、食品支付卡、底部操作区、共用 SVG 装饰。美术引用集中在素材映射文件中；选择状态和数量逻辑留在主面板。不要把交互、计数和文案塞进背景图，不使用原生 title 悬浮提示。单文件保持在 500 行以内。

## 面板接入记录

已按“大致还原”要求重绘 `src/ui/explore/MessengerPanel/`，接入全部 8 张美术素材与 SVG 部件。组件拆为主面板、物品与支付卡片部件、素材映射及独立样式。大屏六列四行背包、三列两行食品；较窄窗口改为上下排列并允许滚动，正文字号最低 18px。

SVG 在面板内注册 symbol，避免小文件被打包为数据地址后无法通过外部 use 引用。格框和按钮框按容器拉伸，物品插画保持原比例。背包标题显示已占用格数；投递件数在底部显示。支付与投递数量读取业务规则，现有每次最多投递 6 件、支付 2 份食品，保留食品与投递物品互斥规则以及整堆投递方式。已有包裹通过底部入口展开查看。

TestScreen 已有平面素材场景中的信使演示复用新版面板；右上角“羽翼信使 · 新版面板演示”打开，“重置并预览”恢复六种食品数据并直接打开。演示投递仍调用真实包裹校验逻辑，但不写入正式游戏状态。本轮只进行源码审阅，没有运行测试、构建或浏览器验证，效果由用户确认。

## 用户确认后的调整

背景移入面板内部，由独立背景层裁切，面板外只保留半透明遮罩。

实际接入的背景为 `城市背景.webp`（1632×918，约242KB），信鸦横幅为 `机械信鸦与货箱.webp`（744×234，约54KB）。信鸦按原有容器 cover 与 22% 垂直定位提前裁切，不保留原图中不会显示的区域。两张合计约296KB。转换脚本为 `scripts/convert-messenger-art.mjs`，可传入保留的PNG源目录重新制作；项目资源目录不再保留PNG。

背包格子改为1:1，取消格子中的物品名称与名称底条，保留数量与选择框；顶部“背包”标题不变。背包和支付卡片统一通过项目的 `itemIcon` 查找真实物品素材，六种食品直接复用 `src/assets/道具/临期食品/` 的既有WebP，其他物品也沿用游戏中的真实美术映射。此前生成的面板专用食品插画不再使用，已从项目资源目录清理。SVG继续作为矢量部件使用，不转换成位图。

支付卡片去除左上和右下额外的内角装饰线，只保留外框与圆环。底部取消和确认投递直接复用野餐入口所用的 `ExploreActionButton`，采用标准216×58尺寸和交互动效，取消使用青色语义，确认使用野餐同款暖金色语义；移除面板自定义操作按钮样式。

进一步收紧布局：移除整个底部说明区域，把按钮放入支付食品区底部；左右区域外边界继续等高，食品卡片按按钮上方剩余高度均分，两行卡片每张至少220px，避免压缩过度。已选投递件数移至背包标题旁，已有包裹入口移至支付区。标准行动按钮增加可选 centered 参数，仅信使面板启用，让图标和文字整体居中。

面板复用锻造师事件的共享 panel-reveal 与 panel-bar 动画及时间变量，打开从中央亮线展开，关闭先收拢再通知父组件卸载。关闭、取消、按退出键、确认投递统一经过关闭动画；退场期间阻止重复操作，定时器在组件卸载时清理。本轮没有执行测试或构建。

信使按钮启用标准按钮的 fitLabel 可选参数，根据中文标签字数、图标和留白计算宽度，取消约102px、确认投递约144px；SVG牌面同步使用计算后的宽度。其他调用默认继续使用原尺寸。

背包格子移除左上勾选框（含SVG中预绘制的方框），普通状态为紫色边框，已选状态为亮青色边框与青色光晕；悬浮只提亮紫色，避免与已选状态混淆。仍保留 aria-pressed 及选择状态描述。

最新按钮风格调整：信使面板改用独立 `MessengerActionButton`，紫色单层细框、左上右下切角、深蓝紫渐变内底。取消采用低亮度灰紫，确认采用亮紫边框和紫色内光；取消叉号和投递羽翼都使用协调的单色图标。按钮高52px，宽度由中文文案自然撑开，图文整体居中。保留支付校验、禁用状态和退场流程，其他面板的标准按钮不变。

最终配色与对齐：底部按钮在支付区靠右排列，取消为灰紫色，确认投递为青蓝色，图文继续整体居中。食品加减改为36×36细框切角按钮，减号为低亮度灰紫，加号为淡紫色，采用细线图标和轻微悬浮反馈，移除原八角按钮与厚重霓虹外光；禁用时统一使用暗灰色。
