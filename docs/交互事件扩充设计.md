# 交互事件扩充设计（总纲）

> 2026-10-09。现状数据见 `docs/交互物与事件奖励清单.md`；每个设施的选项、数值、界面与代码落点见 `docs/交互事件设施详案.md`。
> 本文只放**方向与已定决策**，数值以详案为准。

---

## 一、目标

1. **统一美术**：20～30 个通用交互物素材 + 每个地区 4～6 个独有素材，覆盖全部交互事件；一个素材对应一种明确功能，告别「一图多用、名不副实」。
2. **统一插图**：所有交互事件沿用事件面板现有的 7 张主题插图，按功能分配主题。
3. **提高背包利用率**：让玩家在地图里就能消化背包——合成、出售换经验、赌一把，而不是一路捡满 24 格、回城一键卖掉。
4. **整理现有事件**：合并重复、修正错配、给每个旧事件一个归宿。

## 三、现状诊断（摘要）

1. **玩法同质化**：约三分之二的交互物都是「花粒子 → 掷隐性失败率 → 拿奖励池物品」。
2. **背包没有出口**：钱币、材料、水晶都是一个占一格，每占 2 格还会扣命中 / 精准 / 闪避；但它们在地图里几乎没有用处。真正在地图里流通的「货币」是六种临期食品。
3. **美术错配**：熔合用的是织梦机图、模组宝匣用的是织梦机图、神龛图被 4 种事件共用、陷阱沿用旧科技风；岔路牌开出道具、留声机开出食品，实物暗示的功能与实际不符。

## 四、功能族

| 功能族 | 玩家拿背包做什么 | 规则口径 | 设施 |
| --- | --- | --- | --- |
| 搜刮 | 拿东西 | 隐性失败率，吃物件等级 | 旅行布袋、探险箱、委托柜、机械宝匣、寄存邮筒、遗物宝库 |
| 合成 | 低档压成高档，腾格子 | 明码、等值、只向上、每次 3 食品 | 金铃兑币机、琉璃炼金炉、星屑研钵 |
| 献祭 | 出售物品换经验 | 明码、按稀有度折算经验、有次数 | 记忆萤火坛 |
| 赌运 | 押上东西博一把 | 不显示概率、可血本无归、有次数 | 潮汐祈愿门、糖果扭蛋树、三杯戏法桌、月鲸留声机 |
| 构筑服务 | 改装备 / 遗物 / 卡组 | 明码 | 织梦机、鉴宝镜台、赤铜锻造台、祈愿神龛、锻造师 |
| 队伍状态 | 生命 / 体力极限 / 污染 / 粒子 | 隐性失败率 | 调药台、焙茶台、小憩床、充能座 |
| 信息 | 看地图 | 明码 | 橡叶岔路牌、星盘望远镜 |
| 交易 / 寄送 | NPC | 维持现状 | 流浪货商、羽翼信使 |
| 陷阱 | 进房强制 | 维持现状 | 通用 1 种 + 地区独有 |

**新分类 `convert`**：合成、献祭、赌运三族统称，交互消耗 2 粒子。

## 五、三层结构：功能模板 × 美术皮肤 × 地区

- **功能模板**：规则只写一次（输入、输出、次数、是否失败）。
- **美术皮肤**：素材 + 名称 + 文案 + 插图主题，分配表沿用 `commonPropArt.ts` 的做法。
- **地区加料**：地区独有设施要么是全新模板，要么是通用模板的「地区皮 + 额外配方」，并尽量吃 / 产地区材料。
