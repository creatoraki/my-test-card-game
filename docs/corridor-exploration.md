# 横向场景探索初版

## 操作

严格侧视横向行走，镜头跟随“玩家”探索者。探索者是统一的提灯角色，实际战斗仍由已编成的小队参加。

| 输入 | 行为 |
| --- | --- |
| 左右方向键、A / D | 左右行走 |
| 上下方向键、W / S | 循环选择交互范围内的物件 |
| 空格、回车 | 操作当前目标 |
| 点击附近物件或中央提示 | 打开对应交互面板 |
| 按住底部左右箭头 | 用鼠标或触摸行走 |
| 退出键 | 关闭背包、角色详情，或取消尚未结算的物件交互 |

物件必须在 190 设计像素以内才能打开。远处物件只展示外形和名称，搜寻后的物件变暗，无法重复领取。第一层第三、第四个物件相邻，可以使用上下键切换目标。

## 初版物件

| 物件 | 功能 |
| --- | --- |
| 遗留物资箱 | 补给或居民积分 |
| 应急医疗柜 | 全队治疗或取走医疗包 |
| 破损数据终端 | 全队经验或随机模组 |
| 故障售货机 | 食品或付出粒子换医疗包 |
| 残存净化罐 | 回收粒子或降低队员污染 |
| 废弃零件堆 | 安全回收积分或承受伤害获取装备 |
| 安全投递柜 | 开启背包寄件流程 |
| 遗落营地 | 恢复体力极限与生命，或回收粒子 |

物件可以跳过或稍后回来处理。选项确认后才扣粒子、发放奖励并标记已使用；基础消耗沿用 `energyCostAt`，额外消耗由选项配置。奖励先进入现有拾取框和待办队列，处理完毕才能继续。

## 遭遇与返回

每层走廊宽 5600 设计像素。中段和末端的黑斑会阻挡通行，进入感知范围后自动触发约 1.85 秒的破地、升起、亮眼和画面压暗动画，再进入现有裂纹战斗转场。敌人使用统一程序化黑影，不依赖敌人的完整模型。

中途战斗胜利后，保留玩家位置、朝向和物件状态，并将该黑影标记为已击败；终点战斗胜利后按地图层数生成下一层，最后一层胜利通关。战败、战斗撤离和主动撤离仍走原有远征结算。

打开物件、背包、角色档案、野餐或奖励面板时停止行走。失焦、切到后台、松开按键或取消触摸会清理输入。位置只在停步和交互前提交，会话不会因移动逐帧深拷贝。

## 模块与素材

- `src/explore/corridor/`：纯探索逻辑与状态定义。
- `src/store/exploreCorridor.ts`：状态提交与战斗衔接。
- `src/data/corridorCurios.ts`：物件定义。
- `src/ui/explore/CorridorScene/`：场景、移动、图集和黑影动画。
- `src/ui/explore/ExploreScreen/`：界面、物件弹窗、背包及队伍编排。
- `src/assets/explore-corridor/`：内置 imagegen 生成的走廊和透明图集；最终提示词记录在该目录的说明中。

界面沿用 1920×1080 设计画布，新组件的文字最小为 18px。旧路线事件和桥接组件保留在工程中，当前远征不再经过其限时记忆流程。不处理旧存档迁移；本次未运行游戏、测试或构建，交由用户验证。
