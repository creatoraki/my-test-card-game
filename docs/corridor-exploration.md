# 房间探索

## 一张地图 = 一张房间图

一趟远征只有一张图，**没有「层」的概念**：地图的 `roomCount` 就是这张图的庞大程度（新手关卡 6 间，废弃楼层 12 间）。房间在网格上连通，每个房间最多连通上下左右 4 个房间，也就是一屋最多 4 座传送门。

- 近景素材宽高按原始尺寸的 2 倍绘制；除远景外的世界层（近景、角色、物件、传送门与黑影）以地面线为锚统一缩放至 0.7，房间宽度仍按未缩放世界 px 计算，场景高度仍为 1080。镜头在 1920×1080 的可视区域内按等效 2743 世界 px 宽度跟随玩家居中移动，并在房间两端夹紧。
- 房间普通随机物件以 1–3 件为目标，成长／治疗／风险配额优先且可超过此数量（起始房固定安全投递柜、临时祝福匣和食品箱，BOSS 房同样参与配额与随机投放）；普通房额外投放 1–2 个流浪货商。传送门优先占据左右两端；超过两扇时，多出的门、BOSS 红门与物件使用按房间宽度换算、跳过正中位置的 8 个中段槽位，因此不会互相叠住。
- 图由生成树加少量环路长成，所以会出现回环与近路；BOSS 房是离起点最深的那间死胡同。
- 战斗房按比例随机投放（至少 1 间），进房立刻起黑影；BOSS 房不生成黑影，只生成一扇可交互红门。

## 操作

严格侧视横向行走，镜头随探索者移动并在房间边缘停住。探索者是统一的提灯角色，实际战斗仍由已编成的小队参加。

| 输入 | 行为 |
| --- | --- |
| 左右方向键、A / D | 左右行走 |
| 上方向键、W、空格、回车 | 交互（脚下有传送门时即为「确认传送」） |
| 下方向键、S | 循环选择交互范围内的物件 |
| 点击附近物件或传送门 | 直接操作该目标 |
| 按住底部左右箭头 | 用鼠标或触摸行走 |
| 退出键 | 关闭背包、角色详情，或取消尚未结算的物件交互 |

物件必须在 190 设计像素以内才能打开，传送门的判定半径是 120。远处物件只展示外形和名称，搜寻后的物件变暗，无法重复领取。战斗房进房后黑影立即在玩家身前破地；自由行走时每累计 2 秒检查一次暗雷，战斗结束后的净化粒子消耗从上一场战斗结束时重新累计。

## 传送门与小地图

**四个方向的传送门外观完全一致**，场景里读不出它通往哪边——这是刻意的：方向只能从小地图读出。

1. 走到传送门上 → 小地图上该门通往的房间**亮起**（位置已知、内容仍未知），场景里给出「空格传送 · 粒子 −5」提示。
2. 再按一次交互键（或点击传送门）才真的过去，此时扣 5 点净化粒子。
3. 可以逐个踩过四座门，先把周围侦察清楚再决定走哪边——侦察本身不要钱。

小地图（右上角常驻）有三种格子：

| 状态 | 画法 |
| --- | --- |
| 已访问 | 实心亮格 + 房间序号；全部可交互物处理完且黑影已清后加 ✓ 角标并降饱和（**已探索**） |
| 已点亮 | 琥珀色虚框 + 「?」——被某座传送门照出过位置 |
| 已知邻接 | 暗色虚框 + 淡「?」——与某个已访问房相连，但还没被点亮 |

角标另有：☗ BOSS 房、▲ 未清场的战斗房。聆听神谕后会揭示完整地图，并为所有战斗房/BOSS 房显示角标；此时所有连线改为虚线。

## 净化粒子

整套只有三项消耗：

| 行为 | 消耗 |
| --- | --- |
| 移动一个房间 | −5 |
| 交互一个事件 | −2（外加该选项自身的增减；「隐匿通道」可免除基础那一份） |
| 战斗每经过一个回合 | −1（战斗结算时按实际回合数一次性扣，BOSS 战豁免） |

## 成长投放

卡牌交互统一由每图一位的锻造师提供，四种服务随机展示两种，任选一种使用一次。具体费用及新手蓝图见[探索锻造师](blacksmith-services.md)；装备和遗物规则见[探索成长投放](exploration-growth-balance.md)。

## 物件

物件种类、功能与投放规则以 [交互物现状说明](交互物现状说明.md) 为准。全部物件素材都存放在 `src/assets/explore-corridor/通用交互物/`，素材登记在 `ui/art/corridor/commonPropAssets.ts`，种类到素材的分配在 `ui/art/corridor/commonPropArt.ts`，游戏内缩放倍率与上下偏移在 `ui/art/corridor/commonPropTuning.ts`。

物件可以跳过或稍后回来处理（但回头要再付一次移动的 5 点粒子）。选项确认后才扣粒子、发放奖励并标记已使用；奖励先进入现有拾取框和待办队列，处理完毕才能继续，也才能再次传送。

## 战斗

黑斑在进入战斗房时立刻在玩家朝房间中央的身前破地升起，播约 1.85 秒的演出后接入现有裂纹战斗转场。敌人使用统一程序化黑影，不依赖敌人的完整模型。BOSS 房的红门使用传送门素材的红色变体，首次进入判定范围会自动打开首领事件面板，关闭后原地不重复弹出；离开再回来会再次触发，点击或按交互键仍可手动打开。

- **战斗房**：档位按当前房间的深度在 `battleTierWeights` 里抽（越深越难）。胜利后黑影清场、通行恢复，玩家留在原房间继续搜。
- **暗雷**：上一场战斗后的累计净化粒子低于 20 时不会遭遇；20 点起每 2 秒按 5% 线性提升至 39 点约 35%，达到 40 点时下一次检查必定遭遇。杂兵按 t1 80% / t2 20% 权重抽取，胜利后移除暗雷并留在原房间原位置。
- **BOSS 房**：先处理房间物件，再开启红门选择「挑战首领」。挑战后固定 t5，面板保持开启并从点击位置播放裂纹转场；战斗胜利即通关整趟远征——房间制没有「下一层」。
- BOSS 战失败或在战斗中撤退按「撤离副本」结算，背包和积分照常带回；普通战斗战败仍按团灭处理，战斗撤离和主动撤离仍走原有远征结算。

挑战契约的倒计时改按**战斗场次**走（接下后再打赢 N 场即结算），战斗房与 BOSS 房同权。

## 模块与素材

- `src/explore/dungeon/`：房间图类型、生成器与换房间逻辑。
- `src/explore/corridor/`：单个房间内的场景状态与交互判定。
- `src/explore/corridor/ambush.ts`：暗雷累计、概率、位置和杂兵节点的纯逻辑。
- `src/store/exploreCorridor.ts`：状态提交与战斗衔接（只克隆与提交，不含规则）。
- `src/data/curios/`：物件定义、机械小生物食品、奖励池与货商定价。
- `src/explore/curio/`：物件可见性、放入匹配、风险结算、熔铸、换宝、揭示和货商逻辑。
- `src/ui/explore/CorridorScene/`：房间场景、移动、传送门、BOSS 红门、图集和黑影动画。
- `src/ui/explore/CorridorScene/corridorTriggers.ts`：红门进入范围与行走周期暗雷触发器。
- `src/ui/explore/Minimap/`：房间小地图。
- `src/ui/explore/ExploreScreen/`：界面、物件弹窗、背包及队伍编排。
- `src/assets/explore-corridor/`：内置 imagegen 生成的走廊、传送门和透明图集。

界面沿用 1920×1080 设计画布，新组件的文字最小为 18px。旧路线事件与桥接规则（`route.ts` / `generateRouteRound`）仍保留在引擎测试与数据兼容范围内，当前远征不再经过它们。不处理旧存档迁移。
