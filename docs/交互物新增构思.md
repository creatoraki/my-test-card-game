# 交互物新增构思

> 2026-10-10 头脑风暴整理。标「采用」的 6 项（1 钱币兑换、2 经验转换、3 路牌、4 传送雕像、9 拆解回收机、12 霓虹游艺摊）已于同日实现，
> 最终规则以 `docs/交互物现状说明.md` 为准；本文只保留构思过程。

---

## 一、设计约束（沿用现状）

1. 没有等级，一套数值通用全图。
2. 有多类产出时沿用「交互时 roll」思路，结算后才揭晓。
3. 失败率隐藏，只体现在结算文案里。
4. 素材优先用 `通用交互物/` 里还没分配的 7 件：全息许愿泉、自助驿站终端、霓虹游艺摊、星象观测台、月光能量盆、鲸纹留声机、橡叶岔路牌。
5. 价格参照：搜刮 4 粒子、恢复 3 粒子、服务 2 粒子；NPC 免费。

### 可利用的现有事实

| 事实 | 出处 | 对新物件的意义 |
| --- | --- | --- |
| 铜币 50 / 银币 200 / 金币 500（回收价） | `data/items/catalog/scrap.ts` | 币值比例 铜:银 = 4:1，银:金 = 5:2 |
| 钱币 `maxStack: 1`，每枚占一格 | 同上 | 背包只有 12×2 格，**合成钱币的真正价值是省格子** |
| 普通难度不出金币 | `mapDifficulty.ts` | 合成服务能让普通难度也拿到金币，需要决定是否允许 |
| 枝序谱系树已有「付食品换全队经验」 | 生态方舟 | 经验转换服务要和它拉开差异 |

## 二、已定想法（用户提出）

### 1. 钱币兑换台 采用

| 项 | 内容 |
| --- | --- |
| 素材 | 自助驿站终端 |
| 分类 | 服务，2 粒子 + 3 食品 |
| 作用 | 打开兑换界面，自由合成钱币，一次付费可兑换多次 |
| 常驻 | 建议常驻（用完不消失），付费一次后本次打开内无限兑换 |

**待定**

- 兑换方向： A
  - A. 只能向上合（铜→银→金）
  - B. 上合下拆都可以（拆分能凑零钱付费）
- 兑换比例： A
  - A. 等值：4 铜 = 1 银，5 银 = 2 金
  - B. 带损耗：5 铜 = 1 银，3 银 = 1 金（鼓励在城里卖而不是在副本里换）
- 普通难度能否合出金币： B
  - A. 可以
  - B. 不可以，上限到银币

### 2. 经验转换服务 采用

| 项 | 内容 |
| --- | --- |
| 素材 | 自助驿站终端（与兑换台二选一）或 鲸纹留声机 |
| 分类 | 服务，2 粒子 + 2 食品 |
| 作用 | 玩家从背包选物品投入，按价值折算成全队经验 |
| 与谱系树的区别 | 谱系树花**食品**换经验；这里花**物品**换经验，给背包里的杂物一个出口 |

**待定**

- 折算方式： B
  - A. 按回收价折算（如 每 10 回收价 = 1 经验）
  - B. 按品类给固定值（材料 / 钱币 / 模组 / 装备各一档）
- 可投入的物品范围：B
  - A. 所有物品
  - B. 排除装备和遗物，只收消耗品、材料、钱币
- 单次投入上限：不限 / 最多 6 件 不限

### 3. 路牌 采用

| 项 | 内容 |
| --- | --- |
| 素材 | 橡叶岔路牌 |
| 分类 | 服务 |
| 作用 | 揭示与本房相连的所有房间的具体类型（战斗 / 陷阱 / 商店 / 首领……） |
| 实现 | 复用 `REVEAL_MAP`，加「只揭示相邻房间」的范围参数 |

**待定**

- 价格：B
  - A. 免费
  - B. 1 粒子
- 是否计入清房条件： A
  - A. 不计入（建议：避免变成「必须点一下才算清房」的负担）
  - B. 计入

### 4. 传送雕像（成对） 采用

| 项 | 内容 |
| --- | --- |
| 素材 | 月光能量盆 ×2（同一素材，点亮态用发光动效区分） |
| 分类 | 服务，常驻 |
| 点亮 | 每座交互一次即点亮，点亮本身花 2 粒子（待定） |
| 传送 | 两座都点亮后，在任一座处交互可传送到另一座所在房间，每次 2 粒子 |
| 投放 | 每图最多一对，两座放在不同房间，且房间距离尽量远（如 ≥ 4 步） |
| 小地图 | 点亮第一座后，在小地图上标出另一座的位置 |

**待定**

- 投放频率：B
  - A. 每图必有一对
  - B. 50% 概率出现
- 点亮是否花粒子：花 2 粒子 / 免费 -2粒子
- 是否计入清房条件：建议不计入（常驻物件）-不计入

## 三、新增构思

### A. 情报 / 导航

#### 5. 星象观测台 否认

| 项 | 内容 |
| --- | --- |
| 素材 | 星象观测台 |
| 分类 | 服务，2 粒子 |
| 作用 | 3 选 1 |
| 选项 ① | 查看本层首领的招式表（首领战前就能看到） |
| 选项 ② | 首领战开场时首领带「易伤」2 回合 |
| 选项 ③ | 在小地图上标出本层价值最高的交互物所在房间 |
| 定位 | 路牌看相邻房，观测台看远处的目标 |

#### 6. 上锁的宝库 + 门禁卡（跨房间联动）否认

| 项 | 内容 |
| --- | --- |
| 素材 | 密码寄存柜（换皮）或新素材 |
| 分类 | 搜刮，4 粒子 |
| 作用 | 宝库房里有一个打不开的储物柜；同层另一个随机搜刮物结算时额外掉一张「门禁卡」（任务物品）；拿着卡回来开柜，保底稀有产出 |
| 投放 | 每图至多 1 组；门禁卡挂在离宝库 ≥ 3 步的搜刮物上 |
| 配合 | 每日固定骨架下，玩家会主动规划回头路线 |
| 无卡时 | 可选「撬锁」：60% 失败，失败触发守卫战（复用 `ALARM_BATTLE`） |

### B. 经济 / 资源

#### 7. 全息许愿泉（延迟兑现）否认

| 项 | 内容 |
| --- | --- |
| 素材 | 全息许愿泉 |
| 分类 | 服务，2 粒子 |
| 作用 | 投 1 枚铜 / 银 / 金币许愿，当下什么都不给；再清 3 间房后兑现，按投入价值的 1.5～2 倍发放奖励（roll 钱币 / 模组 / 装备） |
| 定位 | 与神龛「投币降污染」区分：这里是理财，赌自己能走到第 3 间房 |
| 团灭 | 未兑现的愿望作废 |

#### 8. 月光能量盆：粒子存储罐（与传送雕像争用素材） 否认

| 项 | 内容 |
| --- | --- |
| 素材 | 月光能量盆（若已给传送雕像，则需新素材） |
| 分类 | 服务，免费，常驻 |
| 作用 | 存入任意数量粒子；之后每清一间房利息 +10%（上限 +50%）；回到这里一次性取出 |
| 定位 | 粒子紧张时的取舍：现在用，还是存起来 |

#### 9. 拆解回收机 采用

| 项 | 内容 |
| --- | --- |
| 素材 | 新素材 |
| 分类 | 服务，2 粒子 |
| 作用 | 把装备或模组拆成材料 / 水晶，按稀有度和完美度折算 |
| 备注 | 如果商店卖出已经能处理废装备，这条优先级最低 |

### C. 增益 / 契约

#### 10. 鲸纹留声机（点歌换增益） 否认

| 项 | 内容 |
| --- | --- |
| 素材 | 鲸纹留声机 |
| 分类 | 服务，2 粒子 + 2 食品 |
| 作用 | 交互时 roll 3 首曲子，选 1 首；效果持续接下来 2 场战斗，作用于全队 |
| 曲目候选 | 开场全队护盾 / 第一回合多抽 1 张 / 敌人先手行动点 −5 / 每回合首张卡费用 −1 / 战斗胜利额外掉落 1 件材料 |
| 定位 | 恢复类是单人效果，这里是全队增益 |
| 表现 | 增益期间在探索底栏显示「乐曲」图标和剩余场次 |

#### 11. 悬赏告示板（接委托）否认

| 项 | 内容 |
| --- | --- |
| 素材 | 新素材（或霓虹游艺摊换皮） |
| 分类 | 服务，免费 |
| 作用 | 交互时 roll 3 个委托，选 1 个接取；完成后自动领奖，失败无惩罚 |
| 委托候选 | 接下来 2 场战斗无人倒下 / 清 3 间房不用恢复类物件 / 一场战斗在 4 回合内结束 / 一场战斗中打出 3 张同羁绊系别的卡 |
| 奖励 | roll 高价值钱币 / 模组 / 一次性遗物 |
| 同时进行 | 同一时间最多 1 个委托 |
| 定位 | 把战斗变成支线目标，补上交互物和卡牌战斗的联系 |

#### 12. 霓虹游艺摊（押注战斗）采用,但改为押注下一次战斗玩家能完成多少个挑战,押注成功则钱币升级,最多押注3枚钱币

## 四、实现评估

| 编号 | 名称 | 能复用的现有效果 | 需要新增 |
| --- | --- | --- | --- |
| 1 | 钱币兑换台 | `foodCost` | 兑换界面、`EXCHANGE_COINS` 效果 |
| 2 | 经验转换 | `select` 选物、给经验效果 | 物品 → 经验折算规则 |
| 3 | 路牌 | `REVEAL_MAP` | 「仅相邻」范围参数 |
| 4 | 传送雕像 | `persistent` | 成对投放、点亮状态、传送移动、小地图标记 |
| 5 | 星象观测台 | `REVEAL_MAP` | 首领招式预览、首领战开场状态 |
| 6 | 宝库 + 门禁卡 | `GAIN_POOL_ITEM`、`ALARM_BATTLE`、`withItem` 门槛 | 跨物件绑定投放、任务物品 |
| 7 | 许愿泉 | `CONSUME_ITEM` | 延迟兑现计数器（按清房计） |
| 8 | 粒子存储罐 | — | 存取界面、按清房计息 |
| 9 | 拆解回收机 | `select` 选物 | 拆解折算规则 |
| 10 | 鲸纹留声机 | `ROLL_EFFECTS` | 按场次计数的全队战斗增益 |
| 11 | 悬赏告示板 | `ROLL_EFFECTS` | 委托系统：进度追踪、完成判定、自动发奖 |
| 12 | 霓虹游艺摊 | `CONSUME_ITEM` | 战斗表现统计、赔率结算 |
| 13 | 污染虹吸器 | `ADJUST_POLLUTION`、`GAIN_POOL_ITEM` | 无（纯配置） |
| 14 | 血契祭坛 | `DAMAGE_MEMBER_PERCENT`、给遗物 / 装备 | 无或很少（纯配置） |
| 15 | 重启装置 | — | 房内物件复位 |
| 16 | 机械小生物 | `feed` | 跟随状态、进房自动掉落 |

**共用的底层能力**：10、11、12 都需要「跨战斗计数 / 统计」，7、8 都需要「按清房计数」。如果一起做，可以先做这两套通用计数器，再挂具体物件。

## 六、素材分配冲突

7 件未用素材对应的候选：

| 素材 | 候选物件 |
| --- | --- |
| 橡叶岔路牌 | 3 路牌 |
| 自助驿站终端 | 1 钱币兑换台 / 2 经验转换（二者可合并成一个「驿站终端」，两个选项） |

| 全息许愿泉 | 7 许愿泉 |
| 星象观测台 | 5 星象观测台 |
