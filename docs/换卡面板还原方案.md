# 换卡面板还原方案（方案四 · 苔绿工业温室）

## 目标与范围

- 参考图：`生图模型输出目录/换卡面板_方案四_苔绿工业温室_透明背景_无关闭按钮.png`，原图 1672×941（RGBA，背景已透明），换算到 1920×1080 设计画布的系数为 **×1.148**。
- 改造对象：`src/ui/explore/CardReplace/DeckServiceModal`（换牌 / 删牌 / 复制共用的卡组面板），演示入口是 `src/dev/TestScreen/cardReplace/CardReplacePreview.tsx`。
- 卡面继续复用 `HandCard`（220×308，1:1.4），**不按设计图的近方形卡面重画**；设计图的卡位、舱体窗口尺寸都要按 HandCard 比例重新落位（见第三节）。
- 只换视觉与布局，不改服务逻辑：选卡 → 放入舱位 → 确认 → 写 result → 演出 → 「完成」由调用方收尾；`onConfirm` 返回 false 时保持打开。

结论先行：和卡牌三选一不同，这张图的质感主要来自**锈蚀旧钢板、黄铜切角、线缆、藤蔓、玻璃培养舱**，SVG/CSS 画不出来，所以**外壳和舱体必须用位图**。好在舞台是固定 1920×1080 画布，外壳可以整张按 1:1 像素贴，不存在拉伸问题。
所有文字、图标、卡面、选中框、状态光效仍由代码绘制，不烘焙进图。

## 四、美术素材清单（需要生图模型生成）

存放目录：`src/assets/换卡面板/`，生成 PNG 后转 webp，文件名必须与下表一致。原始 PNG 与提示词存 `生图模型输出目录/换卡面板/`。
代码用 `import.meta.glob` 可选加载，素材未放入时退回简易深色底，不影响构建；放入后自动生效。

| 编号 | 文件名 | 输出尺寸 | 透明 | 优先级 | 用途 |
|---|---|---|---|---|---|
| 01 | `面板外壳.webp` | 1920×1080 | 是 | **高** | 整个面板外框 + 内部所有空底板（卡组柜、页签轨道、舱位标题条、信息表底板、底栏提示条、按钮凹槽），按画布坐标 1:1 贴 |
| 02 | `重换舱.webp` | 1056×920（2 倍，落位 528×460） | 是 | **高** | 培养舱完整舱体，舱内**空置**、无卡 |
| 02b | `重换舱_前层.webp` | 同 02 | 是 | 中 | 从 02 原图切出的前景件（上环下沿、底座前唇、玻璃前反光），压在卡面上方制造「卡在舱内」的层次；**不单独生成** |
| 03 | `页签_常态.webp` | 480×114（2 倍） | 是 | 中 | 页签底板，CSS `border-image` 三段拉伸，中段必须是可横向平铺的均匀材质 |
| 04 | `页签_激活.webp` | 480×114（2 倍） | 是 | 中 | 同上，翠绿激活态 |
| 05 | `按钮_放弃.webp` | 448×134（2 倍） | 是 | 中 | 次按钮底板 |
| 06 | `按钮_确认.webp` | 544×164（2 倍） | 是 | 中 | 主按钮底板（含外发光，四周需留发光余量） |
| 07 | `面板发光层.webp` | 1920×1080 | 是 | 低（可选） | 只含外框上的翠绿导光槽亮光，与 01 同坐标，代码做呼吸闪烁；不做则导光槽为静态 |

确认按钮禁用态用 CSS（去饱和 + 压暗 + 去发光）从 06 派生，不另出图；悬停态用亮度提升 + 扫光。

**不需要生成的**：卡牌与卡框（HandCard）、选中金框（SVG）、职业图标（`CrewClassGlyph`）、舱位准星图标 / 勾选图标 / 「!」提示图标 / 双箭头（内联 SVG）、所有文字、滚动条、页眉小标签底与斜杠、底座光晕 / 扫描线 / 气泡等动态光效（CSS 或 GLSL）、面板背后的背景（沿用现有遮罩，设计图本就是透明底）。

### 生成方法建议

1. **素材 01 不要从零生成**：从零生成无法与已测量的坐标对齐。用参考图做**局部擦除重绘**：保留外框、线缆、藤蔓、所有底板，抹掉全部文字、卡牌、页签、按钮、培养舱、图标、滚动条，抹掉处补成与周边一致的空底板。再超分到 1920×1080（建议先超到 3840×2160 再缩小，避免发糊）。
2. **素材 02 舱窗比例按 HandCard**：设计图里舱内卡是近方形，HandCard 是 1:1.4，生成时必须把可视窗口做成竖长约 280×410（1 倍尺寸），否则卡面会顶出玻璃。
3. **透明背景**：如果生图工具不能直接出透明图，用纯品红 `#FF00FF` 底再抠图（面板大量绿光，不能用绿幕）。
4. **02b 前层**：在 02 原图上用蒙版切出上环下沿、底座前唇两段，玻璃前反光可直接用 CSS 渐变代替，不强求。

### 01 面板外壳 — 提示词（局部重绘用）

> 以输入图为底，保持画面构图、外框形状、尺寸、透视、光照、材质完全不变，只做擦除：去掉所有文字（标题、说明、小标签、页签文字、计数、信息表文字、底栏提示、按钮文字）、所有卡牌、三枚角色页签、两枚按钮、右侧的玻璃培养舱及其两侧玻璃管和植物、所有图标、竖向滚动条、斜杠装饰。擦除后的区域补成与周围一致的深色旧钢板凹槽底板、深色玻璃信息面板、暗色按钮凹槽，保留原有的磨损、细划痕与微弱绿色反光。保留外框的黑钢、古铜切角、铆钉、翠绿导光槽、左上角件、右上线缆束和边缘藤蔓。背景保持透明。不要新增任何文字、图标、人物、卡牌。

### 02 重换舱 — 提示词

> 透明背景，正视角，二次元工业科幻游戏界面道具，单个「绿色玻璃重构培养舱」，竖版构图。中央是一座竖直的圆柱形玻璃舱，舱内**空置**，内壁是深青黑色半透明玻璃，透出极淡的薄荷绿雾光，可视窗口为竖长矩形区域、宽高比约 2:3，窗口内部必须足够暗且干净（会放一张卡牌在里面）。玻璃舱上下各有一圈厚重的古铜与黑钢金属环，上环带一圈翠绿发光灯带，下方是嵌入式精密平台底座，底座边缘有柔和薄荷绿光环。舱体左右两侧各有一根细长玻璃管，管内有翠绿植物叶片和少量气泡，外侧是带指示灯的黑钢金属边柱，少量电缆与藤蔓缠绕边柱。舱体背后是朦胧的工业温室工坊剪影，暖琥珀检修灯点缀，整体压暗。材质：深色旧钢板、古铜切角、低饱和翠绿导光，真实微磨损但不破烂。不要卡牌、不要文字、不要人物、不要界面边框。主体占画布约 90%，四周留安全边不裁切。

### 03 / 04 页签 — 提示词

> 透明背景，正视角，二次元工业科幻游戏界面按钮底板，横向长条页签，宽高比约 4.2:1，左上与右下切角。材质为黑色阳极氧化钢板，细古铜描边，表面细微拉丝与轻微磨损，内侧有一道暗色倒角。左右两端各有一小段古铜护角，中间区域材质均匀、没有任何独立装饰（需要横向拉伸）。不要文字、不要图标。
> 激活态追加：底板转为深翠绿金属，描边变为亮翠绿发光细线，上沿有一道柔和翠绿高光，整体微微外发光。

### 05 放弃按钮 — 提示词

> 透明背景，正视角，二次元工业科幻游戏界面次级按钮底板，横向，宽高比约 3.3:1，四角切角。深黑钢厚板，古铜细边框，边框四角有小铆钉，表面细拉丝与微磨损，内侧暗色倒角，中央平整留空用于放文字。克制、无发光。不要文字、不要图标。

### 06 确认按钮 — 提示词

> 透明背景，正视角，二次元工业科幻游戏界面主按钮底板，横向，宽高比约 3.3:1，四角切角。亮翠绿发光装甲按钮：表面是由亮翠绿到深绿的纵向渐变金属板，上半部有玻璃质高光，边缘是近白的翠绿亮线，外圈有一层黑钢加古铜的托框，整体向外散发柔和翠绿光晕（四周留足发光余量，不要被裁切）。中央平整留空用于放文字，左右两端留出放箭头的空位。不要文字、不要箭头、不要图标。

### 07 面板发光层（可选）— 提示词

> 以素材 01 为底，只保留外框上所有翠绿导光槽与指示灯的发光部分，其余全部变为透明；发光部分提亮到最亮状态。

## 五、技术分配

|---|---|---|

| 动效 | CSS | 入场：遮罩淡入 → 外壳上浮淡入 → 页签 / 卡牌依次上浮 → 舱体底光亮起 |

## 六、已确认决策（2026-10-09）

| 编号 | 事项 | 结论 |
|---|---|---|
| 1 | 改造范围 | 直接改正式的 `DeckServiceModal`，锻造师、置换终端、战斗奖励换牌同步换新 |
| 2 | 删牌 / 复制的舱体 | 三种服务共用绿色培养舱，只换文案，不加素材 |
| 3 | 结果演出 | 在培养舱内原地进行：原卡溶解 → 新卡在舱内成形；左侧卡组柜在演出收束前保持结算前快照，收束时同步并闪亮新卡位 |
| 4 | 演出光效技术 | GLSL（共享 `GlslSprite` 宿主） |
| 5 | 卡组超过 8 张 | 竖向滚动 |
| 6 | 素材 07 发光层 | 先不做，导光槽静态（代码未预留加载位） |

演出分镜（`useReplaceSequence.chamberTimeline`）：

| 服务 | 分镜 |
|---|---|
| 换牌 | 扫描 700ms → 原卡溶解 1000ms → 新卡成形 1100ms → 收束 520ms |

## 八、验收标准

1. 1920×1080 画布下与参考图叠图，外壳、舱位、按钮、页签行位置偏差 ≤ 10px（卡位按 HandCard 重排，不参与比对）。
2. 所有中文正文 ≥ 18px，界面无英文。
3. 未选 / 悬停 / 选中三态可区分；未选中时确认按钮为禁用态；舱位状态「等待放入 / 已放入」随之切换。
4. 卡面在培养舱内完整可读，不被玻璃反光遮挡、不顶出舱窗。
5. 换卡 / 删卡 / 复制三种模式都正常，锁定角色时显示单页签。
6. 战斗手牌、牌堆、据点卡组、卡牌三选一的卡面不受影响。
7. 新增 / 修改文件均不超过 500 行，无原生 `title` 属性。
