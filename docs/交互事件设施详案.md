# 交互事件设施详案

> 2026-10-09。方向与已定决策见 `docs/交互事件扩充设计.md`（下称「总纲」），本文写到能直接开工的粒度：每个设施的选项、数值、次数、隐性门槛、界面流程与代码落点。
> 数值全部是**草案**；第八章为已确认问题的记录。

---

## 一、通用规则

### 1. 分类与粒子

| 分类 | 包含 | 每次交互粒子 | 失败机制 |
| --- | --- | --- | --- |
| loot 搜刮 | 6 种搜刮 | 4 | 隐性失败率 |
| heal 状态 | 调药台、焙茶台、小憩床、充能座 | 3 | 隐性失败率 |
| service 服务 | 构筑、信息、NPC | 2 | 多数无失败 |
| **convert 转化（新）** | 合成、献祭、赌运 | **2** | 合成 / 献祭无失败；赌运结果本身就是风险 |
| trap 陷阱 | — | 0（强制触发） | 现状 |

### 2. 次数

- **不限次**：兑币机、炼金炉、研钵的合成配方。每打开一次档案执行一次操作（单次或一键）扣 2 粒子。
- **有次数**：萤火坛 3 次、祈愿门 2 次、扭蛋树 3 次、戏法桌 2 次、锻造台拆解 2 次。次数用完后物件变成「已处理」。
- **小地图判定**：有次数或不限次的设施，交互过一次就算这间房「已处理」，但仍可以继续用。

### 3. 合成通用口径（总纲决策 1、5、6）

- **等值**：钱币按回收价（铜 50 / 银 200 / 金 500）；材料与水晶按「档值」，普通 1、较好 3、最好 9。
- **只向上**：没有任何拆分配方。
- **手续费**：每执行一次配方收 3 份临期食品，六种可混付，沿用 `payServiceFood` 的固定扣款顺序。
- **选择投入物**：输入物可以混搭的配方（炼金炉）由玩家**手动点选**具体投入哪几件；输入物只有一种的配方（钱币、水晶）不需要点选（已定）。
- **一键全部**：只有钱币与水晶配方提供（炼金炉不提供，已定）。按当前背包算出最多能合成几次，总手续费 = 次数 × 3。食品不够付总额时按钮置灰，显示「还差 N 份食品」，**不会自动降成部分兑换**。
- **产出直接进背包**：所有配方都是多换少，产出一定放得下，不走待拾取框。
- **隐性门槛减免手续费的方式**：界面上永远显示 3 份；门槛生效时在**结算后返还** 1 份，结算文案里写一句，事前不暴露（总纲决策 8）。

### 4. 赌运通用口径（总纲决策 10）

- 描述文案只写定性提示（「也可能一无所获」），**不显示具体概率**。
- 落空就是什么都不给，押上的东西全部没收。
- 押注品必须在背包里；押注品在结算前就扣除。

## 二、合成族

### 2.1 金铃兑币机　`coinMint`（新）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 矿石 |
| 投放 | 配额设施（见第六章），不限次 |
| 描述 | 挂满小金铃的投币机。零钱从上面塞进去，叮当几声，整枚的硬币从下面滚出来。它只认一种小费：临期食品。 |

| 选项 | 消耗 | 结果 | 失败 |
| --- | --- | --- | --- |
| 铜币换银币 | 4 铜 + 3 食品 | 1 银 | 无 |
| 银币换金币 | 5 银 + 3 食品 | 2 金 | 无 |
| 全部兑换 | 先把铜全换成银，再把银全换成金；总手续费按总次数 | 一次结算 | 无 |

- 隐性门槛：**精算师**执行 → 每次结算返还 1 份食品（一键全部也只返还 1 份）。
- 例：背包有 9 铜 3 银。全部兑换 = 铜换银 2 次（剩 1 铜，银变 5）→ 银换金 1 次 = 3 次 × 3 = 9 份食品；结果 1 铜 + 2 金，腾出 9 格。

### 2.2 琉璃炼金炉　`compactor`（改造）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 矿石 |
| 投放 | 配额设施，不限次 |
| 描述 | 琉璃炉腔里的液体会把投进去的零件熔成一团，再凝成一块更精密的部件。 |

| 选项 | 消耗 | 结果 | 失败 |
| --- | --- | --- | --- |
| 炼成弹簧 | 任意 3 个普通档材料（魔方 / 齿轮 / 电池，可混）+ 3 食品 | 弹簧 ×1 | 无 |
| 炼成磁铁 | 同上 | 磁铁 ×1 | 无 |

- **消耗哪些具体材料**：玩家在配方板的背包区里手动点选 3 件普通档材料，选满才能点「炼成」（已定）。
- **不提供「全部炼成」**（已定），每次只炼一件。
- 地区配方（预留）：3 个较好档材料 → 1 个当前地区低档材料（废弃楼层 = 霓虹灯管）。地区材料的档值没定，先不开放。
- 隐性门槛：**炼金术士**执行 → 每次结算返还 1 份食品。

### 2.3 星屑研钵　`crystalMortar`（新，吸收雷萤晶石座）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 矿石 |
| 投放 | 配额设施；合成不限次，研磨晶簇每座 1 次 |
| 描述 | 石研钵旁堆着一簇半透明的晶体。细碎的星屑落进钵底，会自己聚成更纯的结晶。 |

| 选项 | 消耗 | 结果 | 失败（概率 → 惩罚） |
| --- | --- | --- | --- |
| 研磨晶簇（原雷萤晶石座） | 无 | 水晶奖励池 ×1（吃物件等级） | 50% → 执行者污染 +12 |
| 喂鼹鼠 ×1 后研磨（原晶石座） | 鼹鼠食物 | 水晶奖励池 ×3 + 霓虹灯管 | 同上 |
| 提纯蓝色水晶 | 3 绿 + 3 食品 | 1 蓝 | 无 |
| 提纯红色水晶 | 3 蓝 + 3 食品 | 1 红 | 无 |
| 全部提纯 | 先绿后蓝 | — | 无 |

- 隐性门槛（研磨晶簇，沿用晶石座）：**植物学家**失败率 −35%，追加全队污染 −10；**圣水**失败率 −30%。
- 隐性门槛（提纯）：**炼金术士**执行 → 每次结算返还 1 份食品。
- 研磨晶簇有失败率，按 convert 计价只收 2 粒子，比原来的搜刮价 4 便宜。可接受，因为研钵是配额设施，每图只有约 1 座。

## 三、献祭族

### 3.1 记忆萤火坛　`memoryLantern`（新）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 神龛 |
| 投放 | 配额设施，每座 3 次 |
| 描述 | 坛里的萤火会吞下旧物，把物件里残存的记忆还给放下它的人。 |

**选项：献上旧物**——一次最多放入 6 件，选择经验给谁，确认后物品消失、经验到账。无失败。

**经验只看物品稀有度**（已定），与回收价、物品类别无关：

| 稀有度 | 普通 | 精良 | 稀有 | 史诗 | 传说 |
| --- | --- | --- | --- | --- | --- |
| 每件经验（草案） | 5 | 15 | 40 | 100 | 250 |

按现有物品的稀有度，常见物品折算如下：

| 物品 | 稀有度 | 经验 |
| --- | --- | --- |
| 铜币 / 银币 / 金币 | 普通 / 精良 / 稀有 | 5 / 15 / 40 |
| 通用材料（五种都是普通） | 普通 | 5 |
| 模组（目前都是精良） | 精良 | 15 |
| 装备、祝福遗物 | 按自身稀有度 | 5～250 |

> 注意：按稀有度算，4 铜（20）比 1 银（15）多、5 银（75）比 2 金（80）略少——先合成还是直接献祭，结果会略有不同，可以接受。

**不可献出**：水晶（据点建设资源）、临期食品、消耗品、诅咒遗物（去神龛解咒）、一次性遗物、地区材料、不可丢弃物品。界面上置灰。

**经验给谁**：

| 方式 | 结果 |
| --- | --- |
| 指定一名队员 | 该队员获得 100% |
| 全队 | 每名存活队员各得 40%（合计 120%） |

- 隐性门槛：**预言家**执行 → 本次经验 +25%。
- ⚠ 每档经验数需要对照战斗经验口径校准（普通敌人约 20 经验、首领 124，卡组第一级 100），规则统一写在一张「稀有度 → 经验」表里，调平衡只改这一处。

## 四、赌运族

### 4.1 潮汐祈愿门　`wishGate`（新素材已有）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 神龛 |
| 投放 | 随机池，每座 2 次 |
| 描述 | 潮水在拱门里来回翻涌。投进去的硬币会被带走——有时候潮水会还回点什么，有时候不会。 |

| 选项 | 押注 | 结果（草案概率） |
| --- | --- | --- |
| 投下铜币 | 1 铜 | 45% 落空；30% 基础食品 ×2；20% 通用材料 ×2；5% 银币 ×1 |
| 投下银币 | 1 银 | 35% 落空；30% 应急道具 ×2；25% 1 阶模组 ×1；10% 金币 ×1 |
| 投下金币 | 1 金 | 30% 落空；30% 装备 ×1；30% 祝福遗物三选一；10% 祝福遗物三选一 + 退回金币 |

- 物件等级越高，非落空结果里越偏向后面的档（与奖励池同口径）。
- 隐性门槛：**预言家**执行 → 落空概率减半，减掉的部分并入第一档奖励。
- 期望略低于投入的积分价值，但产出全是地图里能用的东西，这正是「钱在地图里有用了」的体现。

### 4.2 糖果扭蛋树　`gachaTree`（新）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 神龛 |
| 投放 | 随机池，每座 3 次 |
| 描述 | 树枝上挂满彩色扭蛋。把一样东西塞进树洞，树会摇下一颗扭蛋——里面可能是更好的东西，也可能只是一张糖纸。 |

**选项：塞进树洞**——放入 1 件物品，摇出 1 颗扭蛋：

| 结果 | 概率 |
| --- | --- |
| 糖纸（物品没了） | 35% |
| 同类同档的另一件 | 45% |
| 同类高一档 | 15% |
| 同类高两档 | 5% |

**同类阶梯**：

| 类别 | 阶梯 | 到顶后的「更高档」 |
| --- | --- | --- |
| 通用材料 | 普通（魔方/齿轮/电池）→ 较好（弹簧/磁铁） | 数量 ×2 |
| 水晶 | 绿 → 蓝 → 红 | 数量 ×2 |
| 临期食品（1 份） | 牛奶/面包/可乐 → 汉堡/炸鸡/披萨 | 数量 ×2 |
| 应急道具 | 糖块 → 圣水 → 医疗包 | 数量 ×2 |
| 模组 | 1 阶模组之间互换 | 数量 ×2 |

- **不收**：钱币（钱币有祈愿门和戏法桌）、装备、遗物、地区材料、不可丢弃物品。
- 隐性门槛：**植物学家**执行 → 糖纸概率降到 20%。

### 4.3 三杯戏法桌　`shellGame`（新）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 危险 |
| 投放 | 随机池，每座 2 次 |
| 描述 | 三只倒扣的茶杯在桌面上飞快地换位。押上硬币，猜一只杯子。 |

**流程**：选 1～3 枚**同种**钱币押注 → 三杯洗牌演出（约 2 秒）→ 玩家点一只杯子 → 翻开。

| 杯底 | 概率 | 结果 |
| --- | --- | --- |
| 双份 | 1/3 | 退回押注并再给同样数量 |
| 原样 | 1/3 | 退回押注 |
| 空杯 | 1/3 | 押注全部没收 |

- 期望正好持平，纯方差。赢来的钱币背包放不下时进待拾取框。
- 杯子结果在洗牌前就已确定，玩家点哪只都一样，选杯只是演出。
- 隐性门槛：**精算师**执行 → 空杯时退回一半押注（向下取整）。

### 4.4 月鲸留声机　`vending`（改造）

| 项 | 内容 |
| --- | --- |
| 分类 / 主题 | convert / 神龛（原物资） |
| 投放 | 随机池，每座 1 次 |
| 描述 | 鲸形喇叭里还卡着三张唱片。放哪一张，全凭运气。 |

**选项：放一张唱片**——三张背面朝上的唱片，翻一张：

| 唱片 | 概率 | 结果 |
| --- | --- | --- |
| 祝福曲 | 50% | 一次性祝福遗物 ×1 |
| 安眠曲 | 25% | 全队治疗 15% |
| 走调曲 | 25% | 全队污染 +8 |

- 隐性门槛：携带**牛奶**→ 自动消耗 1 个，走调曲改为安眠曲。
- 原来「翻找唱片匣 → 基础食品」的选项删除。

## 六、投放

### 1. 配额设施

每张普通地图（非新手关）在生成房间图时固定放：

| 配额 | 内容 |
| --- | --- |
| 合成 ×1 | 兑币机 50% / 炼金炉 25% / 研钵 25% |
| 献祭 ×1 | 记忆萤火坛 |

- 计入所在房间的物件数上限（每房 1～2），优先放主路中段的房间，避开起点、首领、陷阱房。
- 配额设施不再进入随机池，避免一图出现 3 台兑币机。

### 2. 随机池权重（草案）

| 族 | 设施 : 权重 |
| --- | --- |
| 搜刮 | 旅行布袋 22、探险箱 12、委托柜 12、潮汐宝匣 8、寄存邮筒 6、遗物宝库 2 |
| 赌运 | 留声机 5、祈愿门 4、扭蛋树 3、戏法桌 3 |
| 构筑 | 赤铜锻造台 4、织梦机 2、神龛 2、鉴宝镜台 1 |
| 信息 | 岔路牌 5、望远镜 3 |

- 治疗池（每房 20% 投放 1 个）：调药台、焙茶台、小憩床、充能座。
- 方舟在此基础上按现有 `curioPool.weights` 合并地区物件。

所有新界面都挂在事件档案（EventDossier）的选项区里，不另开全屏面板。最小字号 18px，全部中文，悬浮提示用组件不用原生 title。

### 1. 合成配方板（兑币机 / 炼金炉 / 研钵共用）

```
┌───────────────────────────────────────────────────┐
│ [铜][铜][铜][铜]  →  [银]      手续费 3 食品   可合成 2 次 │
│                          [ 合成一次 ]  [ 全部合成 ]    │
├───────────────────────────────────────────────────┤
│ [银][银][银][银][银] → [金][金]  手续费 3 食品   材料不足    │
├───────────────────────────────────────────────────┤
│ 全部兑换：共 3 次，手续费 9 食品（持有 7）  还差 2 份食品    │
└───────────────────────────────────────────────────┘
```

- 每行一个配方：输入图标（背包里够数的亮、不够的暗）→ 输出图标 → 手续费 → 可合成次数。
- 不可用原因直接写在行尾：「材料不足」「还差 N 份食品」。
- 炼金炉没有「全部合成」按钮；它的配方板上方多一排背包里的普通档材料，玩家点选 3 件放进输入格（再点取回），选满后「炼成弹簧」「炼成磁铁」两个按钮才亮。
- 合成演出：输入图标依次飞进设施图标，短暂闪光后输出图标落进背包格（BackpackBar 对应格高亮一下）。
