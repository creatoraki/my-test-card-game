## 一、这 10 件为什么不合格

对照合格素材（眠猫金库、锈蜗储物壳、星砂沙漏等），不合格的 10 件共同问题：

| # | 问题 | 典型 |
| --- | --- | --- |
| 1 | **主体不唯一**：一件里塞了三四个设备，剪影是一团 | 鉴定铁砧（砧 + 放大镜 + 色卡 + 宝石托盘 + 水桶 + 锤）、霓虹游艺摊（帐篷 + 玻璃罩 + 唱片 + 音箱 + 画板） |
| 2 | **白瓷 + 藏蓝 + 金边 + 青灯带**科幻皮，和其他物件串色 | 萤光记忆坛、雷萤灯柱、机械许愿树 |
| 3 | **前景是填空道具**：方箱、礼盒、罐子、电源箱 | 萤光记忆坛的礼盒、雷萤灯柱的电源箱、许愿树的扭蛋机 |
| 4 | **主题是功能名 + 设备**，画面讲不出事件故事 | 药剂调配台、自助驿站终端、战术背包 |
| 5 | 底部是碎石堆、圆台，底边不平 | 鉴定铁砧、萤光记忆坛 |

所以新主题一律是「**一个有生命感或有奇观的主体** + 一块长方体基座 + 最多两件故事小物」。

## 三、事件包装（功能数值不动）

### 1. 半张的珠母巨蚌（relicCache · 搜刮）

- **动词**：撬取
- **描述**：巨蚌的壳只张开一道缝，珍珠层里裹着一件遗物，壳缝里还卡着前人留下的撬棍。撬开它就能取走遗物，只是蚌壳里积着陈年的黑水。
- **选项**：撬开蚌壳取出遗物 → 「蚌壳被撬棍一点点顶开，裹着珍珠层的遗物被送入待拾取框。」
- **失败（20%，执行者污染）**：蚌壳猛地合拢，喷出的黑水溅了执行者一身。

### 2. 吱呀转动的水车磨石（perfectnessWorkbench · 装备调校）

- **动词**：重磨
- **描述**：老水车带着砂岩磨轮吱呀转动。把装备架上磨石重磨一遍，消耗任意临期食品共 N 份，重新随机装备完美度；磨得好还是磨崩了口，全看这块老磨石的脾气。保留羁绊与负面代价，选择装备后才扣款。
- **选项**：选择装备架上磨石 → 「水车吱呀转起，磨轮贴上了刃口，等待小队指定目标。」

### 3. 等人下注的发条擂台（neonArcade · 押注）

- **动词**：押注
- **描述**：擂台上两个铁皮骑士拧紧了发条，台前三个投币槽等着押注。投进最多 N 枚钱币，赌小队下一场战斗完成的挑战数：押中钱币升级，押不中就被擂台吞掉。同一时间只能有一笔押注。
- **选项**：沿用「押注：至少完成 1 个挑战」「押注：2 个挑战全部完成」。
- **战斗内挑战词条悬浮提示**：「游艺摊」字样改为「发条擂台」。

### 4. 无主的拼甲人台（modBench · 熔合）/ 训练拼甲台（tutorialModBench）

- **动词**：缝合
- **描述**：裁缝不在，人台上那件拼起来的护甲还差最后几针。挑三件装备挂上人台，发光的缝线会把它们最好的部分缝成一件新的装备。
- **选项**：选择三件装备挂上人台。
- **新手关**：名称「训练拼甲台」，描述「训练用的拼甲人台上已备好一枚攻击力模组与三份临期食品，可用于体验锻造师服务。」

### 5. 噼啪作响的雷劈树桩（collapsedCeiling · 陷阱）

- **描述**：刚踏进房间，插在焦黑树桩里的铜钱剑就炸出一串电光，电弧顺着地面朝队伍乱窜。
- **选项**（效果不变）：
  - 全队压低身形冲过
  - 由执行者拔出铜钱剑（成功时拆下剑上的铜钱 → 钱币）
  - 消耗粒子撑起绝缘屏障

### 6. 驮着地图的负图老龟（arkGeneConsole · 方舟服务）

- **动词**：请教
- **描述**：方舟最老的住户。龟甲上的纹路记着整座方舟的路线和每一只守卫的去向。可以请它亮出龟甲上的地图，也能喂它一份临期食品，听它讲讲守卫们的老习惯。
- **选项**：
  - 读取龟甲上的路线与威胁 → 「老龟伸了个懒腰，甲纹一格格亮起，拼成一张完整的区域图。」
  - 喂食并聆听往事（1 食品）→ 「老龟慢吞吞嚼完食物，讲起守卫们的老习惯，全队获得卡组经验。」

### 7. 一触即喷的鼓囊菇（arkSporeVent · 方舟陷阱）

- **描述**：房门开启的一瞬间，栽培箱里的鼓囊菇猛地胀大，顶上的气孔对准了小队，随时会把一肚子孢子喷出来。
- **选项**：
  - 消耗净化粒子让菇球休眠 → 「净化膜裹住了菇球，气孔慢慢合上，鼓胀的菌球瘪了下去。」
  - 掩住口鼻迅速通过 → 「小队穿过了黄绿色的孢子雾，每个人都沾上了一点孢子。」
  - 由执行者砍断菌柄 → 「执行者一刀砍断了菌柄，手臂被喷出的孢子灼出一道浅口。」

### 8. 叼牌的三尾灵狐（新增事件 · 服务）

> 自助驿站终端原本闲置，按确认结果配新事件。用现有效果 `FORGE_DRAW_TAINTED`（contaminate 0），不新增效果类型。

- **代号**：`fortuneFox`（新增 `CurioKind`），role = service，交互 2 粒子，一次性。
- **投放**：进 `RANDOM_CURIO_WEIGHTS`，权重 2（与织梦机、貘龛同档）。
- **动词**：求牌
- **描述**：朱漆台上的三尾狐叼着一张牌，摊开的牌阵等人来抽。奉上 2 份临期食品当供品，它会从牌阵里叼出三张，让小队挑走一张。
- **选项**：奉上供品求牌（`foodCost: 2`）→ `FORGE_DRAW_TAINTED contaminate 0`：卡牌三选一。story：「灵狐吃完供品，摇着三条尾巴从牌阵里叼出三张牌。」

### 9. 捣药的玉兔（tutorialMedical · 新手关）

- **动词**：治疗
- **描述**：青玉兔子一下一下地捣着药，臼里的药泥已经发出翠光。它会为所有存活成员恢复生命，并清除一部分污染。
- **选项**：请玉兔分药。

### 10. 磕裂的陶猪扑满（tutorialCashBox · 新手关）

- **描述**：不知是谁落下的陶猪扑满磕裂了肚子，裂口里露出几枚旧铜币。
- **选项**：收走铜币。

## 五、四宫格通用开头

每批完整提示词 = **通用开头** + **本批四格描述**，整段复制，不要删减。

> 用途：stylized-concept，中文奇幻卡牌游戏的可切分四宫格道具素材图集。
> 只生成一张正方形高清四宫格透明PNG，尽量 1536×1536，2行×2列，恰好4个不同的完整道具，按下方指定位置各占一个象限，互不连接；无分格线、无边框、无标签。
> 排版硬性要求：左侧两件只能位于画布横向4%到46%范围，右侧两件只能位于54%到96%范围；上排两件只能位于画布纵向4%到44%范围，下排两件只能位于54%到94%范围。正中竖直46%到54%的通道和水平44%到54%的通道必须完全透明，任何部件、描边、光晕都不能进入。每件在本象限内水平居中，大小尽量饱满，完整呈现不裁切；四件大小可以不同，保持比例不拉伸。
> 贴地硬性要求：每件道具最底部都是一块正对画面的长方体基座，基座底边是一条贯穿左右的笔直水平线，不能是圆形或椭圆形底座，不能用碎石堆、岩石堆垫底。上排两件最下方可见实体像素严格落在整图高度44%处的同一水平线上；下排两件严格落在94%处的同一水平线上。每件的前景小物底部与本件基座底边齐平，任何垂挂物、根须、尾巴、碎片和光效都不能低于底线。不画对齐线，不画地面、地板、投影椭圆或漂浮底座。
> 背景：真正的RGBA全透明alpha背景，物件之间、轮廓外与内部空隙都透明；绝不画白底、灰底、黑底、棋盘格、场景或背景渐变；轮廓外不留杂色残边和脏边。
> 画风：精致的2D手绘游戏道具，略Q版、厚实圆润比例，干净的深色轮廓，赛璐璐明暗加精细局部材质与发光，像有真实体积的高级奇幻道具插画，绝不能像平面图标。统一正面略俯视视角：基座正面正对画面，只露出顶面一条窄边和少量右侧面；统一左上主光。
> 主体唯一：每件只有一个主体，占本格60%以上，把它单独涂黑也能一眼认出是什么；不要把几台设备拼在一起。
> 纵深：每件由后景、主体、前景三层具有真实厚度的部件构成并互相遮挡。后景只有一件，比主体高或宽，从主体背后露出轮廓，整体压暗一档、饱和度略低，只画大形和少量纹理；主体细节最密、最亮；前景最多两件矮小的故事道具，压住主体底部左前或右前，描边略粗。
> 材质：每件按描述使用有来历的材质，画出磨损、锈迹、划痕、掉漆、裂纹等使用痕迹；绝不使用白色瓷质面板、藏蓝装甲板、金色包边加青色灯带的科幻风格。
> 发光：每件只有一个主发光色，发光点不超过三处，集中在描述指定的位置；发光受控，不以雾气遮盖结构，光晕不连接四格。
> 静态：这是静态素材，不画飞行中的生物、飘散的烟雾和孢子、飞溅的水珠、下落中的硬币、漂浮的碎片和花瓣、四散的电火花、速度线、动态模糊；需要表现动作时画成定格瞬间，需要表现流动时用凝固形态或封在容器里。
> 禁止：画面绝无任何文字、数字、字母、符号标签、招牌、签名、水印；不出现人物，不增加描述以外的道具，不重复物品，不画方形储物箱、手提箱、电源箱、软管、礼盒、杂乱瓶罐、宝石托盘。

## 六、各批四格描述

### 第一批：珠母巨蚌 · 发条擂台 · 水车磨石 · 拼甲人台

## 七、交付与验收

### 1. 存放位置

```
生图模型输出目录/交互物/不合格重做/第N批/
├─ 四宫格_首轮.png          每轮一张，后续轮次按「四宫格_改动说明.png」命名
├─ 提示词_首轮.txt          该轮实际使用的完整提示词
├─ 切图结果/                确认后由脚本导出
├─ 终稿/                    确认采用的独立 PNG
└─ 交付记录.md              四宫格顺序、各轮改动、采用版本
```

### 2. 总图验收清单

1. 四件都在各自象限里，十字通道完全透明，没有部件、光晕跨格。
2. 上排两件底边在同一条线上，下排两件在另一条线上；每件底边平直，前景小物不低于基座。
3. 没有圆形 / 椭圆底座、碎石堆垫底，没有垂过底线的根须、尾巴、绳子。
4. **主体唯一**：每件涂黑后能一眼认出（蚌、擂台、水车、人台、树桩、狐、龟、菇、兔、猪）。
5. 没有白瓷 + 藏蓝 + 金边 + 青灯带，没有方箱、电源箱、礼盒、宝石托盘。
6. 没有文字、字母、数字（重点看擂台布幕、灵狐牌背、老龟石板）。
7. 没有飘散的孢子、电火花、水花、火星、下落的硬币。
8. 每件的「故事点」画出来了：蚌壳里的撬棍与唯一遗物、擂台前三个投币槽（两满一空）、剑刃一半雪亮一半崩口、护甲三块拼缝、铜钱剑插在树桩裂口、狐狸嘴里叼着牌、龟甲上的房间格、菌柄被砍开一半、兔子举杵、扑满裂口里的铜币。

不合格时优先**编辑当前总图**修正出问题的那一格；整件跑偏才放进第三批补位重画。

### 3. 切图与转换（回复「采用，切图」之后）

```powershell
node scripts/extract-curio-sheet.mjs --input "生图模型输出目录/交互物/不合格重做/第一批/四宫格_首轮.png" --output "生图模型输出目录/交互物/不合格重做/第一批/切图结果" --names "珠母巨蚌,发条擂台,水车磨石,拼甲人台" --padding 8
node scripts/extract-curio-sheet.mjs --input "生图模型输出目录/交互物/不合格重做/第二批/四宫格_首轮.png" --output "生图模型输出目录/交互物/不合格重做/第二批/切图结果" --names "雷劈钱剑桩,叼牌灵狐,负图老龟,鼓囊菇" --padding 8
node scripts/extract-curio-sheet.mjs --input "生图模型输出目录/交互物/不合格重做/第三批/四宫格_首轮.png" --output "生图模型输出目录/交互物/不合格重做/第三批/切图结果" --names "玉兔药臼,陶猪扑满,补位名1,补位名2" --padding 8
node scripts/convert-curio-art.mjs "生图模型输出目录/交互物/不合格重做/第N批/终稿"
```

- `--names` 严格按左上、右上、左下、右下顺序，必须正好 4 个不同的名字；补位版名字加后缀（如「发条擂台补位版」）避免和首版重名。
- 切图逐张检查没有邻格残片后再复制到 `终稿/` 转 WebP。
