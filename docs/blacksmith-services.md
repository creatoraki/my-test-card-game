# 探索锻造师

每张地图固定一位锻造师，占用一个交互物名额。普通地图优先投放在无货商的普通房间；没有合适房间时依次使用其他普通房、战斗房、陷阱房、首领房。教学地图固定在第三间房。

首次打开事件时，从抽牌、换牌、删牌、复制四种服务中等概率、不重复地抽出两种。每位锻造师只允许任选一种使用一次。随机服务、付费抽牌的候选和最终结果保存在房间状态中，关闭、重返和会话恢复不会刷新。

| 服务 | 任意临期食品费用 | 结算规则 |
| --- | ---: | --- |
| 三选一抽牌 | 1 | 选择存活角色后，确认生成候选即扣款并锁定；必须完成选牌。候选不足三张时展示现有合法候选。 |
| 换牌 | 3 | 确认有效卡牌后，替换为该角色随机不同的普通卡，原卡及模组移除。 |
| 删牌 | 2 | 所有难度开放；删除卡牌及模组，不能低于角色最小卡组张数。 |
| 卡牌复制 | 3 | 新增干净的同名卡，不继承模组、污染、升级或其他实例状态；保留原卡，遵守现有数量限制。 |

食品允许混付；打开和离开不消耗粒子。取消选择或服务失败不扣款，不消耗使用机会；无合法目标时显示禁用原因，不重抽服务。锻造师不阻碍房间已探索判定，使用后仍可查看事件结果。

旧打印、训练、置换、删卡终端及训练附带经验已移除；方舟枝序档案台保留经验服务与地图揭示，移除抽牌。战斗奖励、货商售卡和据点功能保留。教学训练模组台固定提供三份临期面包，供后续收费服务使用。

场景立绘使用512×768透明WebP，可见主体高度约260设计像素；独立事件页使用专属锻造师插画，高度904像素。两份原始素材保留在“处理后的WebP素材/已确认”中。

入口：`src/explore/curio/blacksmithTypes.ts`定义规则和状态，`src/store/explore/blacksmithRules.ts`统一资格判断，`blacksmithActions.ts`结算，`src/ui/explore/Blacksmith/`提供事件页、目标选择与结果页。
