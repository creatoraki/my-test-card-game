# 《霓虹都市》试玩体验评审

## 评审结论

项目目前属于“视觉完成度较高、内容与引导仍在原型阶段”的状态。美术包装明显高于功能完整度，据点、商店、战斗和场景氛围已经形成较完整的产品雏形，但探索教学、成长闭环、地图内容和空状态仍需要继续开发。

## 试玩范围

试玩路径：

`开始游戏 → 据点 → 编队 → 工房 → 医疗室 → 商店 → 档案机 → 研究中心 → 出击准备 → 升降机 → 探索 → 野餐 → 角色档案 → 战斗界面`

说明：探索移动的键盘事件在无头浏览器自动化环境中未能正常驱动，因此战斗界面通过页面运行时切入已加载的真实战斗状态进行观察，没有修改业务源码。

## 视觉表现很棒

- 主菜单城市背景、标题霓虹灯牌和开始按钮融合得很好，第一印象很强。
- 据点全景辨识度高，六个设施的场景切换统一，空间站氛围成立。
- 编队界面的角色立绘质量高，角色卡边框颜色能清晰区分人物。
- 商店、档案机、研究中心拥有独立配色，界面框体和场景美术统一。
- 出击准备页的仓库、补给货架和背包区域层次清楚。
- 战斗场景的霓虹城市、敌人立绘、血条和回合信息视觉冲击力不错。
- 野餐面板和角色档案已经具备较完整的功能界面形态。

## 视觉上较弱、需要优化

### 1. 全站视觉过载

- 发光、描边、斜切框使用过多，工房和研究中心容易出现光污染。
- 边框的视觉权重经常高于文字，导致内容层级不够突出。
- 部分说明文字太小、太暗，商店和研究中心的长文本阅读压力较大。

### 2. 空状态像半成品

- 工房没有装备时，左侧空列表、中间空区域、右侧空区域同时出现，页面显得非常空。
- 博物馆默认有大量问号格，整体像未完成的占位界面。
- 编队顶部徽章区域很宽，但内容较少，“未启用徽章”显得突兀。
- 医疗室初始几乎都是空状态，缺少演示数据或新手任务。

### 3. 个别页面信息关联不够直观

- 研究中心的材料数字与素材图标关联不够清晰，更像数据表而不是制造界面。
- 探索页底部队伍、背包、技能和撤离按钮堆叠较重，信息密度偏高。
- 宽屏视口下两侧黑边明显。固定 16:9 画布策略保证了构图统一，但空间利用率较低。

### 4. 文字规范问题

- 编队副标题、出击准备页等位置仍有英文展示文本。
- 项目整体要求中文展示，后续应清理 `SQUAD MANAGEMENT`、`CAPACITY`、`SECTOR-03 // INVENTORY TERMINAL` 等英文 UI 文案。

### 5. 战斗过场需要确认

战斗入场截图中，探索页旧画面会从圆形战斗遮罩边缘露出，观感像过场尚未完全收干净。需要确认这是刻意设计，还是过渡时长、层级或裁切范围问题。

## 功能不完整与需要新开发的内容

### 最高优先级

- 增加明确的新手教学，告诉玩家如何移动、靠近物件、交互和使用传送门。
- 探索页目前高度依赖键盘操作，缺少醒目的操作说明，首次进入容易不知道下一步做什么。
- 出击前缺少小队徽章时，会弹出“未处理编排”确认框，但没有足够引导玩家完成徽章配置。
- “撤离远征”属于高风险操作，建议增加二次确认。
- 完整验证并串通房间推进、物件交互、战斗房触发、战斗胜利后回到房间、首领房和通关结算流程。

### 成长与内容系统

- 工房已有装备升阶和羁绊重铸入口，但初始没有装备，核心玩法几乎无法体验。
- 编队页显示“暂无羁绊词条”，但没有告诉玩家如何形成羁绊。
- 医疗室的复苏舱、疗养舱和圣水池初始基本为空，缺少可体验的演示流程。
- 博物馆怪物图鉴为 `0/10`，需要补充怪物解锁、展示和详情内容。
- 研究中心已有模组装配、模组制造和科技树，但资源不足时缺少资源获取指引。
- 室内花园、天空列车、玻璃栈道、城市天顶尚未配置完整事件和怪物内容。
- 继续补充更多房间事件、战斗遭遇、首领、掉落和奖励闭环。

### 体验优化

- 首次进入需要预加载大量美术资源，建议增加更有信息量的加载提示。
- 为工房、医疗室、博物馆等页面设计专门空状态，不要只显示空白区域或问号。
- 预备队员的“上阵”按钮禁用时，应明确提示“队伍已满”。
- 野餐需要加强配方发现、试错反馈和奖励反馈。
- 战斗卡牌效果文字较压缩，应进一步强化悬停详情、费用说明和目标预览。

## 建议开发优先级

### P0：影响首次可玩性

1. 探索操作教学与新手引导。
2. 房间探索到战斗、奖励、回城的完整闭环。
3. 撤离操作二次确认。
4. 首局可体验的徽章、装备、羁绊和医疗流程。

### P1：影响内容完整度

1. 补全未开放地图的事件、怪物、首领和奖励。
2. 补充工房、医疗室、博物馆的有效空状态。
3. 完善羁绊、模组、科技树和资源获取说明。
4. 补全怪物图鉴、卡牌图鉴和装备图鉴内容。

### P2：影响视觉和长期体验

1. 降低全站发光与边框噪声，强化文字层级。
2. 优化探索页底部 HUD 信息密度。
3. 统一清理英文展示文案。
4. 复核战斗入场遮罩与宽屏黑边表现。
