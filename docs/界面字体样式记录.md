# 界面字体样式记录

本文记录据点全景中建筑广告牌与左上角信息牌使用的字体和视觉样式，后续新增类似界面文字时优先参考本规范。

## 字体来源

全局字体变量位于 `src/styles/tokens.css`：

```css
--font-family: "BebasNeue", "SourceHanSansSC", "Microsoft YaHei", sans-serif;
```

字体文件位于 `src/styles/base.css`：

```css
@font-face {
  font-family: "SourceHanSansSC";
  src: url("../assets/fonts/SourceHanSansSC-Bold-2.woff2") format("woff2");
  font-style: normal;
  font-weight: 400 900;
  font-display: swap;
}
```

中文文字会从 `BebasNeue` 回退到项目内置的 `SourceHanSansSC`。实际观感是偏厚、规整、清晰的现代中文黑体。

## 建筑广告牌文字

实现位置：

- 结构：`src/ui/town/TownScreen/StationLayer/StationLayer.tsx`
- 样式：`src/ui/town/TownScreen/StationLayer/StationLayer.module.css`

### 文字样式

```css
.signName {
  fill: #e1fff4;
  font-size: 25px;
  font-weight: 600;
  font-family: var(--font-family);
  filter: drop-shadow(0 0 5px #74ffcc66);
}
```

### 排版方式

- 每个汉字单独放进一个 `<tspan>`。
- 所有字符使用相同的 `x` 坐标，实现竖排。
- 字符的 `y` 坐标每次增加 `32px`。
- 文字字号为 `25px`，因此每个字之间约有 `7px` 的呼吸空间。
- 广告牌顶部的编号单独使用 `11px` 等宽字体，并保留 `3px` 字间距。

### 配套视觉效果

```css
.signPanel {
  fill: #071d21ed;
  stroke: #79e5cc;
  stroke-width: 1;
  filter: drop-shadow(0 4px 6px #001512b3);
}

.signRail {
  stroke: #b3ffe8;
  stroke-width: 3;
  filter: drop-shadow(0 0 4px #4effc4);
}
```

整体使用深青黑底、青绿色边框和淡青白文字，文字只保留轻微柔光，避免发光过强影响识别度。

## 左上角信息牌文字

实现位置：`src/ui/town/TownScreen/StationHud/StationHud.module.css`

信息牌沿用广告牌的字体、字重和青绿色柔光，但保留原有字号和信息层级：

```css
.label {
  color: #c5e8df;
  font-size: 18px;
  font-family: var(--font-family);
  font-weight: 600;
  letter-spacing: 2px;
  text-shadow: 0 0 5px #74ffcc66;
}

.value {
  color: #e1fff4;
  font-family: var(--font-family);
  font-size: 20px;
  font-weight: 600;
  letter-spacing: 2px;
  text-shadow: 0 0 5px #74ffcc66;
}
```

### 使用原则

- 标签字号固定为 `18px`，不要为了套用广告牌而改成 `25px`。
- 数值字号固定为 `20px`，保持信息牌现有高度和布局稳定。
- 标签使用稍暗的青白色，数值使用更亮的淡青白色，维持阅读层级。
- 普通 HTML 文字使用 `text-shadow`；SVG 文字使用 `filter: drop-shadow`，两者保持相同的 `0 0 5px #74ffcc66` 柔光参数。
- 新增据点状态、建筑标签或类似终端文字时，优先使用 `var(--font-family)` 与 `font-weight: 600`。
