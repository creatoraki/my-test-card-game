# 界面字体样式记录

本文记录据点广告牌与左上角信息牌确立的文字观感，后续新增类似界面文字时以此为唯一参考。

## 字体来源

全局字体变量位于 `src/styles/tokens.css`：

```css
--font-family: "BebasNeue", "SourceHanSansSC", "Microsoft YaHei", sans-serif;
--font-num: "SourceHanSansSC", "Microsoft YaHei", sans-serif;
```

项目内字体文件及实际覆盖范围如下：

- `BebasNeue.woff2`：英数字体，作为 `--font-family` 的首选字体。
- `SourceHanSansSC-Bold-2.woff2`：文件名虽写着思源黑体，但实际 cmap 只有全角拉丁字母，没有汉字；不能作为中文字体依据。
- `PingFangSC-Medium.woff2`：包含中文字符，但当前项目没有为它声明 `@font-face`，因此不参与渲染。

中文实际由系统回退字体微软雅黑（`Microsoft YaHei`）渲染。本规范不引入或启用新的字体文件；好看的关键在文字的配色、字重、字距与柔光，而不是更换中文字体。

## 终端文字令牌

令牌集中在 `src/styles/tokens.css`，来源是据点信息牌的标签与数值样式：

```css
/* 终端文字（据点信息牌确立的基调，见 docs/界面字体样式记录.md）。
   只用于 HUD 标签 / 面板标题 / 数值 / 按钮 / tab 这类“终端文字”；
   卡面说明、事件正文这类长文保持 var(--text) 且不发光。 */
--ui-label: #c5e8df;                              /* 标签：稍暗青白 */
--ui-value: #e1fff4;                              /* 数值 / 标题：亮青白 */
--ui-weight: 600;
--ui-tracking: 2px;
--ui-glow-color: #74ffcc66;                       /* 域内主题色不同时只覆盖这一个 */
--ui-glow: 0 0 5px var(--ui-glow-color);          /* HTML：text-shadow */
--ui-glow-svg: drop-shadow(0 0 5px var(--ui-glow-color)); /* SVG：filter */
```

标签使用稍暗的青白色，数值和标题使用更亮的淡青白色；终端文字统一使用 `600` 字重与 `2px` 字距。普通 HTML 文字使用 `text-shadow`，SVG 文字使用 `filter`：

```css
/* 标签 */
color: var(--ui-label);
font-weight: var(--ui-weight);
letter-spacing: var(--ui-tracking);
text-shadow: var(--ui-glow);

/* SVG 文字 */
fill: var(--ui-value);
filter: var(--ui-glow-svg);
```

青白配色与青绿柔光只用于 HUD 标签、面板标题/副标、数值、按钮文字、tab 和状态文字。卡面说明、事件正文、物品描述等长文保持 `var(--text)`，不使用柔光。物品稀有度、探索事件类型、增益/减益、危险色和卡牌稀有度等语义色也保持各自令牌。

## 建筑广告牌

实现位置：

- 结构：`src/ui/town/TownScreen/StationLayer/StationLayer.tsx`
- 样式：`src/ui/town/TownScreen/StationLayer/StationLayer.module.css`

广告牌文字使用 `var(--ui-value)`、`var(--ui-weight)` 和 `var(--ui-glow-svg)`。每个汉字单独放进 `<tspan>`，共用 `x` 坐标实现竖排，`y` 坐标每次增加 `32px`；编号属于辅助读数，保留等宽字体与原有紧凑排版。

## 左上角信息牌

实现位置：`src/ui/town/TownScreen/StationHud/StationHud.module.css`

信息牌沿用广告牌的文字层级：标签使用 `var(--ui-label)`，数值使用 `var(--ui-value)`，两者都使用 `var(--ui-weight)`、`var(--ui-tracking)` 与 `var(--ui-glow)`。标签保持 `18px`，数值保持 `20px`，以免改变信息牌的现有高度。
