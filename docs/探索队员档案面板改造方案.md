# 探索队员档案面板改造方案（琥珀工业）

## 一、目标与范围

- 参考图：`生图模型输出目录/方案二_琥珀工业.png`（1672×941）。
- 改造对象：探索场景的队员档案 `src/ui/explore/PartyDossier/`（底栏点立绘 / 背包点「装备」打开）。
- 原则：除场景插图类素材外，外框、按钮、角标、图标、进度条、文字全部用 CSS / SVG 实现；业务逻辑（换装、预览差值、页签、切换队员）不动，只换视觉与布局。
- 卡组页设计图没有画，沿用同一套内容面板与配色重新换皮。

## 六、各模块改造说明

### 1. 外壳 `PartyDossier.tsx / .module.css`

- 宽度 1600 → 1700；`--k` 从 `DOSSIER_ACCENT`（青）改为琥珀，作为本面板私有常量。
- 背景：新增 `parts/DossierBackdrop.tsx`，照搬事件档案 `.art + .shade` 的做法：场景图按高度铺满，渐变层负责「右侧内容区压暗 + 底部压暗 + 左侧立绘区保留光感」。可选前景植物层放在立绘之上、名牌之下。
- 页眉：删除「档案」标签与英文装饰；保留「远征小队 · 队员档案」，标题后接三道琥珀斜杠（CSS 重复渐变），下划线左段琥珀右段渐隐。
- 主体由 `grid 470px + 1fr` 改为绝对定位两栏（左栏 810 宽，右栏从 x=808 开始），因为立绘要跨越栏界。
- 左栏去掉 `DossierSection` 包裹（设计图左侧无框）；右栏 `03 队员配置` 分区改为「页签栏 + 内容面板」。
- 新增 `parts/DossierFrameDecor.tsx`：左上 / 右下角琥珀亮段、右下切角辉光、页眉斜杠等纯装饰层，不接收指针。
- 文件估算：`PartyDossier.tsx` 改后约 200 行，`.module.css` 约 200 行，不超限。

### 2. 左栏 `MemberStage`

- 去掉 `.stage` 的边框、底色、斜纹；立绘放大（`--bust-zoom` 调大），顶部可超出页眉线，底部由背景暗部与前景植物吃掉。
- 名牌：职业徽记（SVG）+ 名字 52px 粗体 + 下方细线；细线下「03 / 03」与签名笔画（SVG 路径，纯装饰）。
- 序号目前在 `DossierSection` 的 `extra` 里，移入名牌区。
- 生命：沿用 `HpBar`（`flush` + `animated={false}`），外层包一层定位容器，在条内右侧叠「64/65」读数；条高 24、去切角，配色覆盖为青色。
- 污染：沿用 `PollutionMeter`（自带条内数字与悬浮说明），用 `className` 覆盖为橄榄色、尺寸与生命条一致。

### 3. 队员切换 `MemberSwitcher`

## 七、需要生图模型生成的素材

全部只生成图片本体：**不要文字、数字、界面、边框、按钮、水印**。输出先放 `生图模型输出目录/队员档案素材/`，接入时转 WebP 放到 `src/assets/队员档案/`。

| 编号 | 文件名 | 建议尺寸 | 透明 | 是否必需 | 用途 |
|---|---|---|---|---|---|
| 01 | `场景背景.png` | 2048×1088（约 1.88:1，对应面板 1700×904） | 否 | **必需** | 整个面板的铺底场景 |
| 02 | `前景植物.png` | 1024×640 | 是 | 可选 | 压在立绘腿部与左下角的虚化叶片 |
| 03 | `部位剪影_武器.png` / `_防具.png` / `_饰品.png` | 各 256×256 | 是 | 可选 | 空装备格内的立体金属剪影；不生成则用现有 SVG |

不需要生成的：角色立绘（沿用 `src/assets/人物立绘/` 现有 1152×2048 透明立绘）、缩略图（由立绘裁切）、所有图标、外框、按钮、进度条、签名笔画、斜杠装饰。

### 01 场景背景（必需）

> 生成一张横向游戏界面背景插画，宽高比约 1.88:1。场景：废弃工业厂房改造的植物温室工坊，室内无人。左侧和中部是视觉重心：高大的工业格窗透进温暖的金色午后光线，光束中有漂浮的微尘；窗下有木质栽培架、盆栽、悬垂的藤蔓与蕨类、金属工具箱和一盏亮着暖黄光的工业吊灯。右侧三分之一是贴满植物素描图纸的墙面与几盏小型暖光壁灯，整体比左侧更暗、更低对比，便于叠放界面面板。画面底部较暗，前景有轻微虚化的植物叶片。色调：炭灰、深棕、暖琥珀橙，少量偏灰的橄榄绿，不要高饱和的绿色和任何紫色。电影感光影，柔和景深，二次元游戏背景美术风格，细节精致。画面中不要出现人物、动物、文字、可读的标牌、界面元素、边框和水印。中心偏左区域要留出空间，因为会叠放一个角色半身立绘。

### 02 前景植物（可选）

> 生成透明背景的前景植物装饰层，横向构图约 1.6:1。内容：一丛从画面下边缘向上生长的宽叶热带植物与蕨类叶片，集中在画面左下到中下方，右侧和上方逐渐稀疏直至留空。叶片暗绿偏橄榄色，边缘受暖琥珀色逆光照亮，整体带明显的景深虚化（作为离镜头很近的前景）。风格与温室工坊场景一致的二次元游戏美术。只保留植物本体，背景完全透明，不要花盆、地面、人物、文字和边框；叶片不要被画布裁切成生硬直线，下边缘允许出血。

### 03 部位剪影（可选，三张同批生成）

> 生成透明背景的游戏装备图标，三张风格统一：① 一把紧凑的机械复合弩，斜向放置，弩头朝右上；② 一件战术护甲背心，正面视角；③ 一枚带宝石托的机械指环，三分之四视角。统一材质：冷灰色磨砂金属，低饱和，几乎单色，边缘有细微的高光，整体像未点亮的空槽占位剪影，不要琥珀色和其他鲜艳色。物体居中，占画布约 70%，边缘完整不裁切。不要背景、阴影、文字、边框、发光特效。

## 八、需要你确认的点
