# 卡牌三选一面板还原方案

## 目标与范围

- 参考图：`生图模型输出目录/三选一卡牌_方案一_全息锻造台.png`，原图 1672×941，换算到 1920×1080 设计画布的系数为 **×1.148**。
- 改造对象：`src/ui/common/card/CardRewardPicker/`（战斗胜利额外卡牌奖励、探索事件卡牌奖励共用的三选一弹窗）。
- 只改视觉与布局，**不改**选卡交互逻辑：悬停 → 点击选中（可改选）→ 点「确认选择」领取；「放弃」语义由调用方决定；`onConfirm` 返回 false 时保持打开。
- 卡面继续复用 `HandCard`（全游戏唯一卡面），不另做一套奖励专用卡面。参考图卡面结构（左上费用、方形配图、贴图卡名压条＋归属色竖标、下方说明区）与现有 HandCard 一致。

结论先行：**整块面板 95% 以上用 SVG + CSS 即可还原**，因为舞台是固定 1920×1080 画布，外框可以按精确像素直接画 SVG 路径，不存在拉伸变形问题。美术素材为全息卡牌投影与面板内景两张，见「美术素材清单」。

## 四、技术分配：每个部件用什么做

| 部件 | 技术 | 说明 |
|---|---|---|
| 外框轮廓 + 面板底 | **SVG `<path>`** | viewBox 固定 1400×916，按上表坐标写死路径；底色用 `<linearGradient>` 填充；替代现在 `::before/::after + clip-path` 的做法（clip-path 只能做规则切角，做不出页签台阶和右下外扩） |
| 外框双层描边 | SVG 两条 path | 外层主线 + 内缩 8px 暗线，`vector-effect` 不需要（不缩放） |
| 高亮折角段 + 外发光 | SVG path + `filter: drop-shadow` | 只对折角段那一个 `<g>` 加滤镜，不对整面板加，避免卡面辉光被重采样发糊（现有代码已有此约束） |
| 左侧竖向刻度 | SVG 或 CSS `repeating-linear-gradient` | 沿用现有 `.rail` 思路 |
| 面板科技网格 | CSS 渐变网格 + `mask-image` | 沿用现有 `.grid`，色调改紫蓝 |
| 面板内部背景 | CSS 背景图 + 渐变压暗 + `backdrop-filter` | 复用锻造师事件背景；裁剪用与外框同一组顶点生成的 `clip-path: polygon()` |
| 「额外奖励」箭头 | 内联 SVG | `━━»` 造型，紫色 |
| 主标题渐变字 | CSS `background-clip: text` + `text-shadow` 替代方案 | 渐变字不能直接 text-shadow，外发光用伪元素复制一层模糊文字或 `filter: drop-shadow`（仅作用于标题元素） |
| 职业图标 | **复用** `src/ui/character/glyphs/CrewClassGlyph.tsx` | 线条走 currentColor，染成 `owner.color`；参考图是填充图标，现有为线框图标，风格可接受；如需填充感可加 `fill` 半透明 |
| 卡面 | **复用 HandCard** | 需给 HandCard 增加尺寸钩子，见「已确认决策 1」 |
| 选中卡霓虹框 | **SVG**（新组件，替代当前 L 型四角 InteractiveHint） | 双描边切角矩形 + 左右中段短亮条 + 底部小三角；外发光用 `drop-shadow`；呼吸动画用 CSS `@keyframes` 改 opacity |
| 选中连接线 | **SVG `<polyline>`** | 起点 x 由选中下标计算（列中心固定：284 / 680 / 1076）；切换时用 `stroke-dashoffset` 做描线动画 |
| 提示图标 (i) | 内联 SVG | |
| 双箭头 `»` 图标 | 内联 SVG | |
| 两个按钮 | CSS `clip-path` 切角 + 内层 SVG 描边 | clip-path 会裁掉 border，描边与右上亮边用按钮内绝对定位的 SVG 画；主按钮外发光放在按钮外层包裹元素上（否则被 clip 掉） |
| 按钮悬停扫光 | CSS 伪元素 + `@keyframes` | 斜向高光条一次性扫过 |
| 入场/退场动画 | CSS | 沿用现有 `pickLayerIn / pickFrameIn / pickSlotIn`，外框 SVG 可加描线入场 |
| 全息卡牌投影 | **美术素材** | 见下节 |
| 所有文字 | 真实中文文字 | 不烘焙进任何图片；最小字号 18px |

| 编号 | 文件名 | 尺寸 | 透明 | 优先级 | 用途 |

| 01 | `全息卡牌投影.webp` | 768×1024 | 是 | 中 | 面板右外侧漂浮装饰（画布约 x 1614–1914、y 198–598），低透明度叠加 |

### 01 全息卡牌投影 — 提示词

> 透明背景。两张漂浮的全息投影卡牌，竖版长方形，前后错开叠放、各自倾斜约 15°～25°，呈三分之四透视。卡牌只有发光线框：外圈切角边框、中央一个由同心圆与放射刻度组成的符文圆盘、下方两三条短横线示意文字行（不要任何可读文字）。颜色为蓝紫与冰青霓虹，线条半透明，边缘有扫描线与轻微色散，周围点缀少量漂浮光点。不要实体背景、不要人物、不要文字、不要界面边框。主体占画布约 80%，四周留安全边，不裁切。

### 02 面板内景 — 提示词

> 横版 1440×940，二次元游戏场景原画风格，夜晚的蒸汽朋克锻造工业城市远景。画面右上三分之一是视觉重心：高耸的钢铁锻造塔、悬挂的粗重铁链、吊臂与齿轮结构，熔炉口透出橙红色的火光与飞溅火星；中景是一排带栏杆的钢铁天桥与工厂剪影，窗户点缀少量蓝紫霓虹灯；远景是层叠的高楼与淡紫色雾气。整体主色为深蓝紫（#1a1f4a～#3b2c9e），只用橙红火光做点缀对比。画面左侧三分之一与下半部分要明显更暗、细节更少（这些区域会被卡牌和文字覆盖）。景深感强，远处轻微虚化。不要人物、不要文字、不要界面元素、不要边框、不要大型单体机器人或特写主体。

接入后的表现：代码检测到 `面板内景.webp` 时，内景层不再做紫蓝拉色与模糊，只保留左侧与下方的压暗渐变（见 `parts/PickFrame.module.css` 的 `.art[data-scene]`）。

| 6 | 主题色 | 按设计图固定紫 + 冰青 |

## 九、验收标准

1. 在 1920×1080 画布下与参考图叠图对比，面板轮廓、卡片位置、按钮位置偏差在 10px 以内。
2. 所有中文正文 ≥ 18px，界面无英文。
3. 三种状态可区分：未选、悬停、选中；未选中时确认按钮为禁用态。
4. 改选时选中框与连接线正确跟随。
5. 战斗手牌、牌堆弹窗、据点卡组的卡面表现不受影响。
6. 新增/修改文件均不超过 500 行，无原生 `title` 属性。
