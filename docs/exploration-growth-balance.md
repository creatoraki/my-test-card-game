# 探索成长投放

目标是让基础装备和卡组构筑快速成形，长期追求留给装备完美度、羁绊搭配和卡上模组组合。这里的“升级卡牌”沿用现有的卡组经验成长，不新增单张卡牌等级。

## 装备来源

- 完整探索一张地图，固定提供两次无需物资的装备领取机会。
- 击杀敌人的首次战斗胜利保证一个装备箱。后续战斗仍按敌人掉率与掉落系数抽取，每场最多一箱，整趟战斗最多三箱；玩家主动放弃仍算已投放。
- 因此拾取与战斗合计提供 3–5 件装备。主动购买、通关奖励、装备熔铸等额外来源不计入此口径。
- 小怪装备箱基础概率从 10% 提高到 18%。品质、地图稀有度上限和装备完美度生成分布保持原规则。

## 地图配额

随机地图先分配成长、治疗和风险配额，再填充普通随机物件。配额按深度分散，并优先放入物件较少的房间。

| 内容 | 随机地图配额 |
| --- | --- |
| 起始房 | 安全投递柜、临时祝福匣、食品补给箱各一件 |
| 装备箱 | 两件 |
| 战术训练终端 | 每四间房一件，向上取整，至少两件 |
| 卡牌置换终端 | 一件，不进入普通随机池 |
| 羁绊重铸台 | 每六间房一件，向下取整，至少一件 |
| 精密校准台 | 一件 |
| 途中临时祝福匣 | 一件 |

废弃楼层共十二间房，训练终端保底三件。每个终端给予存活成员各 60 点卡组经验和一次免费角色抽卡；经验沿用会话暂存与结算流程。普通随机池额外提高训练终端、卡牌打印终端和食品补给箱权重。小怪战后卡牌奖励基础概率提高到 40%，精英提高到 65%，每场最多一组候选。

新手六房蓝图单独登记：起始房保留训练装备并加入临时遗物与食品；第二个装备箱和两个训练终端沿途投放；同样提供一次换卡、一次羁绊重铸和一次完美度重置。原有医疗站与永久遗物候选箱保留。

## 服务和价值

| 服务 | 任意临期食品总份数 |
| --- | --- |
| 卡牌打印（无污染三选一） | 1 |
| 重铸装备羁绊 | 1 |
| 换卡（随机不同的普通卡） | 3 |
| 重置装备完美度 | 4 |

以上服务允许六种临期食品混付。抽卡在打印时付款；换卡、装备服务在确认有效目标后付款，取消不扣食品。开启物件仍消耗统一的两点交互粒子，取消已开启的奖励不会恢复物件次数。

换卡会替换原卡及其模组，遵循普通卡限携，并排除原卡模板，避免付费后换回同一张。重铸只改变随机羁绊，保证换为不同羁绊，保留属性与完美度。完美度重置沿原生成分布重掷预算，保留羁绊和负面代价，在原有属性方向上增减数值；结果可能升降，并在奖励面板展示前后装备。

流浪货商仍只收各自选中的两种食品，单件商品价格分级为：换金物 1、材料 2、装备／模组 3、永久遗物 5。卡牌和普通消耗品为 1。旧交易终端的同类商品同步此价格层级。

新手地图与普通难度不投放删卡服务，困难及深渊才允许。物件、旧交易终端、事件选项和奖励效果均执行该门槛。

## 一次性遗物

临时祝福匣从普通祝福及野餐遗物中随机选择一件，排除本趟背包和待领取中的同款。实例带一次性标记，不能寄回，远征结束过滤销毁；神龛升级也保留一次性标记。该补给不降低永久遗物的购买价值。
