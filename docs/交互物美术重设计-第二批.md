## 一、为什么第一批看起来更精美

把两批图并排看，差距集中在五点：

| # | 第一批（精美） | 这一批（普通） |
| --- | --- | --- |
| 1 | **一个强主体**，剪影一眼认得：圆滚的猫团、螺旋蜗壳、竖立的沙漏 | **组合摆件**：主机 + 箱子 + 线缆 + 小盒，剪影是一团方块 |
| 2 | **有来历的材质**：铸铁、铜锈、乌木、象牙石，表面有磨损和使用痕迹 | **同一套科幻皮**：白瓷面板 + 藏蓝 + 金边 + 青色灯带，12 件里有 10 件是这套 |
| 3 | **专属配色**：每件一套，放在一起不撞 | 配色互相雷同，放进同一个房间分不出谁是谁 |
| 4 | **前景是故事道具**：倒下的金币、等待拆解的旧头盔 | **前景是填空道具**：方箱、手提箱、软管、礼盒、罐子 |
| 5 | 主题是**意象 + 物件**，物件的状态讲出功能 | 主题偏**功能名 + 设备**（调配台、终端、游艺摊、灯柱），只能靠堆零件说明用途 |

所以这批要做的不是修图，而是**每件换成一个有生命感或有奇观的主体**，材质和配色各自专属，前景只放跟故事有关的小物。

## 四、通用出图规范

沿用第一批「三、通用出图规范」的全部条目（画风、静态、视角、底线、背景、画布、无文字、前中后三层），这里只写**本批新增的要求**。

**出图方式**：4 件一批拼成 2×2 四宫格出图，共 4 组；分组、四宫格提示词、验收清单和切图命令见 [交互物美术重设计-第二批-出图批次](交互物美术重设计-第二批-出图批次.md)。下面「五」里的单件提示词用于单独重画某一件。

### 1. 精美度要求（本批重点）

| 项 | 要求 |
| --- | --- |
| 主体 | 一个**有剪影辨识度**的主体占画面 60% 以上；把主体单独涂黑也能认出是什么 |
| 材质 | 每件指定 1～2 种**有来历的材质**（铸铁、青铜、蜂蜡、藤编、乌木…），画出磨损、锈迹、划痕、补丁等使用痕迹；**禁止白瓷面板 + 藏蓝 + 金边 + 青色灯带**这套科幻皮 |
| 发光 | 发光点不超过 3 处，集中在主体的「故事位置」上；不画装饰性灯带 |
| 前景 | 前景只放**和故事有关**的小物，**禁止方箱、手提箱、软管、礼盒、罐子**等填空道具 |
| 细节密度 | 主体细节最密，后景只画大形和少量纹理，前景中等；不要每处都一样满 |

### 2. 底线写法

第一批第一轮失败的 4 件都栽在底线上，所以本批每件的主体**都自带一块正对画面的长方体基座**（石台、木箱、栽培槽、货板…），在提示词里直接写明，不再靠事后加后缀。

### 3. 统一提示词后缀（本批）

每段提示词末尾都已带上，单独使用时可直接复制：

> 静态画面，画面由后景、主体、前景三层元素相互遮挡构成纵深，后景略暗；物件最底部是一块正对画面的长方体基座，基座底边是一条贯穿左右的笔直水平线，所有元素的底部都落在这条线上，任何垂挂物、藤蔓、碎石、火焰、水花都不能低于它；不画透视地面和椭圆阴影，透明背景。

### 4. 通用负面提示词（本批）

> 文字，数字，字母，水印，签名，边框，背景，透视地面，椭圆形地面阴影，倾斜的底边，弧形的底边，圆形底座，椭圆形底座，垂到底座以下的装饰，底部的碎石堆，悬空的物体，漂浮的碎片，飘散的烟雾，飞溅的水珠，飞行中的昆虫，速度线，动态模糊，人物，白色瓷质面板，藏蓝色装甲板，青色灯带，科幻控制台，屏幕，方形储物箱，手提箱，软管，礼盒，杂乱的瓶罐，裁切不完整

## 五、逐个主题

### 1. 荆棘玫瑰匣（替换 环锁密匣 · relicCache）

**功能对应**：固定开出 1 件永久遗物（稀有）；20% 失败执行者污染。
**画面故事**：只有一朵花的荆棘丛——遗物稀有，所以整只匣子只开了一朵玫瑰，花心托着那件遗物。伸手去摘就要穿过荆棘，**失败是被刺扎破，黑色的刺汁渗进伤口**，正好对上污染。

**轮廓**：一团向上收拢的荆棘，顶上一朵花，身后一扇尖拱铁栅。宽高约 1:1。

**层次**：
- 后景：匣子身后半扇哥特尖拱铁栅栏，顶端几根铁矛尖高过玫瑰，略暗。
- 主体：古银长方圣匣 + 裹住它的黑荆棘 + 顶上的血红玫瑰。
- 前景：左前一只掉落的旧皮手套，指尖被刺破；右前几片凋落的深红花瓣贴在一块小方石上。

**主体细节**：
- 圣匣是古银铸的长方匣，正对画面，正面浮雕褪色的天使翼纹；匣子本身就是基座，底边平直。
- 乌黑的荆棘从匣子四角长出，交叉缠紧整只匣子，刺尖带一点暗紫光泽，有几根刺尖挂着凝住的黑色汁珠。
- 匣盖正中，荆棘向上收拢成一根花茎，顶上开着唯一一朵血红玫瑰；花心托着一枚发光的白金色遗物徽印。
- 荆棘缝隙里能看见匣盖上一圈旧环锁，已经锈死。

**发光点**：玫瑰花心的遗物徽印、玫瑰花瓣边缘的微光。
**不要**：多朵花、绿色叶子茂盛的玫瑰丛、宝箱造型、科幻面板、飘落的花瓣。

**提示词**：
> 2D 游戏道具插画，略 Q 版圆润厚实比例，深色干净描边，赛璐璐阴影，正视略带俯角。一只被荆棘吞没的玫瑰圣匣：主体是一只正对画面的古银长方圣匣，正面浮雕褪色的天使翼纹，匣盖上一圈旧环锁已经锈死；乌黑的荆棘从匣子四角长出，交叉缠紧整只匣子，刺尖带暗紫光泽，几根刺尖挂着凝住的黑色汁珠；匣盖正中的荆棘向上收拢成一根花茎，顶端开着唯一一朵血红玫瑰，花心托着一枚发光的白金色遗物徽印。后景是匣子身后半扇哥特尖拱铁栅栏，顶端几根铁矛尖高过玫瑰。前景左侧是一只指尖被刺破的旧皮手套，右侧是一块小方石，上面贴着几片凋落的深红花瓣。配色：乌黑荆棘、血玫红、古银，白金色光。静态画面，画面由后景、主体、前景三层元素相互遮挡构成纵深，后景略暗；物件最底部是一块正对画面的长方体基座，基座底边是一条贯穿左右的笔直水平线，所有元素的底部都落在这条线上，任何垂挂物、藤蔓、碎石、火焰、水花都不能低于它；不画透视地面和椭圆阴影，透明背景。

### 2. 琉璃万花筒（替换 萤光记忆坛 · perfectnessWorkbench）

**功能对应**：付食品，重新随机装备完美度（可能变好也可能变差）。
**画面故事**：把装备放在筒口下的托盘上，转一圈曲柄，彩窗里的碎玻璃就重新拼一次花样——**完美度重掷 = 万花筒再转一次**，好看还是难看全凭运气。

**轮廓**：一根斜向上的粗筒，筒口一面大圆彩窗，身后一个立着的圆形转盘架。宽高约 5:4。

**层次**：
- 后景：一面竖立的胡桃木大齿轮（像磨坊水车），被万花筒挡住下半，略暗。
- 主体：斜架在胡桃木台座上的黄铜大万花筒。
- 前景：左前一只盛着几块彩色碎玻璃的浅木碗；右前一只立着的旧护手，表面映着彩色光斑。

**主体细节**：
- 台座是正对画面的胡桃木长方台，正面镶两块小彩窗玻璃，底边平直。
- 黄铜万花筒约 30° 斜向右上，筒身刻花、包着几道皮革箍，有磨亮的握痕。
- 筒口是一面大圆彩窗：红、蓝、绿、紫四色碎玻璃拼成对称花样，花样一半已经拼好、一半正在错开（错开的碎片仍嵌在彩窗框里，不飞出）。
- 筒身侧面一只黄铜曲柄，筒下方一只小托盘里放着一件短剑，剑身映着彩窗的光。

**发光点**：筒口彩窗、托盘短剑上的彩色反光。

## 六、落地时的代码改动（出图验收后再做）

1. 新素材按新文件名放进 `src/assets/explore-corridor/通用交互物/`，删除被替换的旧图；运行 `scripts/convert-curio-art.mjs` 后在 `commonPropAssets.ts` 登记（资源 id 改名），在 `commonPropArt.ts` 改分配。
2. `data/curios/defs/` 里对应物件的名称、描述、交互动词、选项与结算文案按新主题重写，数值规则不动。例如：
   - 环锁密匣「开启」→ 玫瑰匣「摘花」，失败文案改成「被荆棘刺破」；
   - 留声机「播放」→ 蜂巢「投喂」，「读成旋律」改成「酿成蜂蜜」；
   - 游艺摊「霓虹灯牌写着赌下一场战斗」→ 金蟾「把钱币放进它背上的凹槽」；
   - 雷萤灯柱「拔断供电线」→ 雷鳗「拔掉缸后电缆、捞走缸底硬币」；
   - 铃鼓架「砸停铃架 / 投币静音 / 拆下鼓芯」→ 喇叭藤「砸烂花藤 / 往花口塞币 / 摘下共鸣芯」；
   - 格栅藤蔓「砍断主藤」保留，「孢子」改成「孢子囊」；
   - 货商、信使按「三、3」的选择决定是否连面板标题一起改。
3. `curioTheme.ts` 视情况换事件档案主题；`docs/交互物现状说明.md` 同步素材列和名称。
4. 新图先进缩放预览页「待调素材」，调好倍率和偏移后录入 `commonPropTuning.ts`。
