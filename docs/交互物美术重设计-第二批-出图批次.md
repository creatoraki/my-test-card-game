## 二、四宫格通用开头

每组的完整提示词 = **下面这段通用开头** + **本组四格描述**（见「三」）。整段复制，不要删减。

> 用途：stylized-concept，中文奇幻卡牌游戏的可切分四宫格道具素材图集。
> 只生成一张正方形高清四宫格透明PNG，尽量 1536×1536，2行×2列，恰好4个不同的完整道具，按下方指定位置各占一个象限，互不连接；无分格线、无边框、无标签。
> 排版硬性要求：左侧两件只能位于画布横向4%到46%范围，右侧两件只能位于54%到96%范围；上排两件只能位于画布纵向4%到44%范围，下排两件只能位于54%到94%范围。正中竖直46%到54%的通道和水平44%到54%的通道必须完全透明，任何部件、描边、光晕都不能进入。每件在本象限内水平居中，大小尽量饱满，完整呈现不裁切；四件大小可以不同，保持比例不拉伸。
> 贴地硬性要求：每件道具最底部都是一块正对画面的长方体基座，基座底边是一条贯穿左右的笔直水平线，不能是圆形或椭圆形底座。上排两件最下方可见实体像素严格落在整图高度44%处的同一水平线上；下排两件严格落在94%处的同一水平线上。每件的前景小物底部与本件基座底边齐平，任何垂挂物、藤蔓、稻草、碎片、火焰、水花和光效都不能低于底线。不画对齐线，不画地面、地板、投影椭圆或漂浮底座。
> 背景：真正的RGBA全透明alpha背景，物件之间、轮廓外与内部空隙都透明；绝不画白底、灰底、黑底、棋盘格、场景或背景渐变；轮廓外不留杂色残边和脏边。
> 画风：精致的2D手绘游戏道具，略Q版、厚实圆润比例，干净的深色轮廓，赛璐璐明暗加精细局部材质与发光，像有真实体积的高级奇幻道具插画，绝不能像平面图标。统一正面略俯视视角：基座正面正对画面，只露出顶面一条窄边和少量右侧面；统一左上主光。
> 纵深是重要要求：每件由后景、主体、前景三层具有真实厚度的部件构成并互相遮挡。后景部件比主体高或宽，从主体背后露出轮廓，整体压暗一档、饱和度略低；主体占本格60%以上，细节最密、最亮；前景是一两件矮小的故事道具，压住主体底部左前或右前，描边略粗。可见顶面、正面和侧面，有厚边、倒角、凹槽、接缝和内腔阴影。
> 材质：每件按描述使用有来历的材质，画出磨损、锈迹、划痕、掉漆、补丁等使用痕迹；绝不使用白色瓷质面板、藏蓝装甲板、金色包边加青色灯带的科幻风格。
> 发光：每件只有一个主发光色，发光点不超过三处，集中在描述指定的位置；发光受控，不以雾气遮盖结构，光晕不连接四格。
> 静态：这是静态素材，不画飞行中的昆虫、飘散的烟雾、飞溅的水珠、下落中的硬币、漂浮的碎片和花瓣、速度线、动态模糊；需要表现流动时用凝固形态或封在容器里。
> 禁止：画面绝无任何文字、数字、字母、符号标签、招牌、签名、水印；不出现人物，不增加描述以外的道具，不重复物品，不画方形储物箱、手提箱、软管、礼盒、杂乱瓶罐，不画成柜子或桌子。

## 三、各组四格描述

### 第一组：三足青鼎 · 荆棘玫瑰匣 · 衔币金蟾 · 窥路葵

> 左上【三足青鼎】：后层是鼎后一面立着的青铜大圆镜，背面朝外刻蟠龙纹，比鼎高，压暗。中层是灰白长方石台，正面刻云雷纹，台上立着一口厚重圆腹青铜鼎，三只足都踩在石台上，前两足等高，满布绿锈，腹部铸饕餮纹，局部磨出金铜色；鼎沿等距排着虎、牛、羊三只兽首，分别衔着一把短剑、一只护手、一顶头盔，装备下半截没入鼎内；鼎腹正面一扇小炉门半开，门内燃着冷青色火焰；鼎口冷青色熔液中央一件新装备的轮廓正在凝成，被一圈朱砂红光环绕。前层左侧一把小青铜钳靠在一块方石上，右侧一只小木架搭着一卷朱砂红布条。青铜绿锈、冷青、朱砂红；主发光冷青。不要铁砧、放大镜、宝石托盘、橙红火焰。
>
> 右上【荆棘玫瑰匣】：后层是匣子身后半扇哥特尖拱铁栅栏，顶端几根铁矛尖高过玫瑰，压暗。中层是一只正对画面的古银长方圣匣，匣子本身就是基座，正面浮雕褪色天使翼纹，匣盖上一圈旧环锁已经锈死；乌黑荆棘从匣子四角长出，交叉缠紧整只匣子，刺尖带暗紫光泽，几根刺尖挂着凝住的黑色汁珠；匣盖正中荆棘向上收拢成一根花茎，顶端开着唯一一朵血红玫瑰，花心托着一枚发光的白金色遗物徽印。前层左侧一只指尖被刺破的旧皮手套，右侧一块小方石上贴着几片凋落的深红花瓣。乌黑、血玫红、古银；主发光白金。不要多朵花、茂盛绿叶、宝箱造型、飘落的花瓣。
>
> 左下【衔币金蟾】：后层是蟾身后一根细木杆，杆顶横挂一串红绳穿起的方孔钱，钱串末端远高于石台，压暗。中层是青石长方台，正面刻一圈回纹，台面铺薄薄一层钱币；台上蹲坐一只赤金铸造的三足蟾蜍，前两腿后一腿，肚皮圆鼓，有磨亮高光和几处暗沉铜绿；宽嘴衔着一枚系朱红绳的大方孔钱；一对鼓起的墨绿琉璃眼半眯；背上三个排成一列的圆形凹槽，两个放着微微发光的铜币，第三个空着。前层左侧一只翻倒的小竹筒，筒口露出两枚铜币，右侧一只小石碟里一颗朱红骰子，骰面只画圆点。赤金、墨绿、朱红；主发光暖金。不要霓虹灯牌、帐篷、游戏机、飞出的硬币。
>
> 右下【窥路葵】：后层是一扇只剩门框的旧木门，比葵花矮一截，门框上挂着半截藤，压暗。中层是黄铜长方花盆，正面錾葵花纹，盆里长出一根带关节的黄铜管茎和两片带铜绿的铸铜大叶；顶端大花盘向右侧转约二十度，中心是一块深褐圆形凸透镜，像一只眼睛；花盘外圈一圈小圆镜花瓣，镜面冷银色，每面镜子里映着一个简单剪影：一把剑、一只宝箱、一个骷髅、一只锅、一只钱袋、一扇门，另有两三面蒙着雾；花瓣背面刷葵花黄漆，边缘剥落。前层左侧一只倒扣的小喷壶，右侧一块小方石上放着一片掉落的镜面花瓣。葵花黄、黄铜、冷银；主发光冷银白。不要路牌、箭头、木牌、灯笼、太阳。

### 第二组：琉璃万花筒 · 蜜蜡蜂巢 · 寄居蟹货郎 · 邮差鹈鹕

> 左上【琉璃万花筒】：后层是一面竖立的胡桃木大齿轮，像磨坊水车，被万花筒挡住下半，压暗。中层是胡桃木长方台座，正面镶两块小彩窗玻璃；台上斜架一根向右上方约三十度的黄铜大万花筒，筒身刻花，包几道皮革箍，有磨亮握痕，侧面一只黄铜曲柄；筒口是一面大圆彩窗，红、蓝、绿、紫碎玻璃拼成对称花样，一半拼好、一半正在错开，错开的碎片仍嵌在彩窗框内；筒下方一只小托盘放着一把短剑，剑身映着彩窗的光。前层左侧一只盛几块彩色碎玻璃的浅木碗，右侧一只立着的旧护手，表面映着彩色光斑。胡桃木、黄铜、彩窗宝石色；主发光彩窗透光。不要水晶球、法阵、圆形坛座、飞出的玻璃。

>
> 左下【寄居蟹货郎】：后层是壳顶竖着的一根细木杆，挂一面空白三角小旗和一盏纸灯笼，压暗。中层是长方木货板，下面垫两根横木，蟹腿全部收在货板上方；珊瑚红铁皮机械寄居蟹，带铆钉，左钳托一杆小秤，右钳朝前摊开像在招呼客人，一对长柄眼的眼珠是暖黄小灯；背上的奶白大海螺壳开出一面两行三列六格木货架，格子里分别放一把短剑、一面小盾、一叠卡牌、一只药瓶、一块面包、一枚发光芯片；螺壳顶撑一顶薄荷绿与奶白相间的条纹遮阳篷，篷檐一排短流苏。前层左侧一只半开的小布包露出一张卡牌背面，右侧一只小木凳摞着两罐罐头。珊瑚红、薄荷绿、奶白；主发光暖黄。不要机器人、圆球机身、屏幕、招牌、购物车图标。

### 第三组：雷鳗水缸 · 铜喇叭藤 · 嫁接百果树 · 巨口猪笼草

> 左上【雷鳗水缸】：后层是缸后一截歪斜的木电线杆，挂几只白瓷绝缘子，一根粗电缆从杆上垂下插进缸后，压暗。中层是正对画面的铁框长方玻璃水缸，铁框铆钉粗大带锈，正面玻璃从左上角裂出一道闪电形裂纹，裂纹发柠檬黄电光，水没有漏出；缸里深海青色的水中，一条乌黑分节机械电鳗盘成圆圈，节缝亮着柠檬黄电纹，鳗头朝外张嘴露出一排细牙，眼睛是两点白光，几道锯齿电弧贴着身体连到缸壁；缸底铺砂石和几枚硬币；缸后电缆接口一圈焦黑。前层左侧一张小木凳搭着一双指尖烧焦的橡胶手套，右侧一块崩落的缸壁玻璃靠在一块方石边。铁灰、柠檬黄、深海青；主发光柠檬黄。不要路灯、球形灯泡、漏到地上的水、四散的电火花。
>
> 右上【铜喇叭藤】：后层是一座木条小格子拱架，藤蔓从上面攀出，压暗。中层是灰石长方花槽，正面刻卷草纹，粗壮绿色藤茎从槽里长出缠成一团，心形叶片，所有藤梢收在槽沿以上；藤上开着七八朵大小不一的黄铜喇叭花，花口朝左、右、前方张开，边缘像花瓣一样翻卷，花喉内侧一圈品红；正中最大一朵正对画面，花喉深处一颗发光的品红共鸣芯，周围一圈细密铜丝花蕊；喇叭口周围几圈像浮雕一样贴着的同心声波纹。前层左侧一朵被砸扁的小喇叭花和一把木槌，右侧一只小木碟盛两枚铜币。黄铜、藤绿、品红；主发光品红。不要铃铛、鼓、音箱、飘出的音符、扩散的声波。
>
> 左下【嫁接百果树】：后层是一扇拱形温室铁窗框，只有框和几格玻璃，比树冠略高，压暗。中层是铁角包边的长方木栽培箱，正面嵌一块长方玻璃窗，窗里盘绕的树根发淡绿光，交织成房间网格一样的图案；箱里长出一棵粗短的树，树干上五六处嫁接口，各用铜箍箍住、缠麻绳和空白小木标签；每根枝条叶形不同（桃叶、枫叶、银杏叶、橡叶），各结一种果：粉桃、紫李、橙橘、青梨、金杏，其中几颗微微发光。前层左侧一只装肥料的小麻袋，袋口插一把小铲，右侧一只编织果篮放着两颗刚摘的果子。树皮灰褐、桃粉、李紫、柑橙；主发光淡绿（根系）。不要玻璃球吊坠、水晶、扭蛋机、漂浮的光球。
>
> 右下【巨口猪笼草】：后层是一根插在槽里的竹支架，顶端绑一圈麻绳，主藤绕着它攀上去，压暗。中层是陶土长方花槽，正面几道裂纹和白色水渍，所有藤和捕虫瓶都在槽沿以上；槽里升起一根带酒红斑点的粗壮青柠绿主藤，顶端挂一只大捕虫瓶，瓶身青柠绿带酒红斑纹，瓶口一圈肋状酒红唇缘，瓶盖半掀，瓶里盛着发光的淡紫黏液，没有溢出；两侧弯藤各挂一只瓶盖紧闭的小捕虫瓶；主藤上鼓着几只半透明孢子囊，里面封着淡紫孢子雾。前层左侧一把卡在藤上的弯柄镰刀，藤被砍开一半，右侧两只鼓胀的绿色孢子囊落在一块小方石上。酒红、青柠绿、淡紫；主发光淡紫。不要铁格栅、金属管道、飘出的孢子和雾、流到地上的黏液。

### 第四组：披甲稻草人 · 悬壶药藤 · 坠落气球篮 · 补位

> 左上【披甲稻草人】：后层是稻草人身后一块立着的草编圆箭靶，插着两支箭，比稻草人肩膀略高，压暗。中层是铁箍加固的长方木桩座，一根木杆从座里立起，横杆撑开双臂；身体是粗麻布扎着金黄稻草，袖口领口支棱出少量草茎；头上扣一顶有凹痕的铁头盔，脸是缝两颗纽扣眼睛的麻布袋，表情憨厚，脖子系一条茜红围巾；胸前套一件铁胸甲，胸甲上一枚发光小徽记，左手戴一只微微发光的铁护手，右手挂一面小圆盾。前层左侧一把倒放的木训练剑，右侧一只装着几束稻草的小木桶。稻草金黄、粗麻米色、铁灰、茜红；主发光暖白（护手与徽记）。不要恐怖的脸、乌鸦、邮筒、蘑菇。
>
> 右上【悬壶药藤】：后层是棚后一面半卷的竹帘，压暗。中层是长方木台，台上立着竹子搭成的方形小棚架，葫芦藤爬满棚顶，垂下五只大小不一的黄褐色葫芦，每只腰上系红绳，葫芦口木塞半开，透过葫芦上的小琉璃窗能看到翠绿、琥珀、玫红三种发光药液；所有葫芦末端都高于木台台面。前层左侧一只石药碾子，右侧一只竹篮放着两只小葫芦。竹青、葫芦黄褐；主发光翠绿。不要冒出的热气、调配台、瓶罐架。
>
> 左下【坠落气球篮】：后层是瘪下来的茜红与奶白条纹气球布，松松地搭在一根断石柱上，比吊篮高出一大截，压暗。中层是正对画面的方形藤编吊篮，底部一块平直木底板，篮沿包皮革，四角麻绳向上连到身后的气球布；篮里露出一只敞口旧皮钱袋，几枚铜币从袋口露出，旁边插着一张卷起的地图；篮身一侧挂一盏熄灭的小油灯，灯底高于篮底。前层左侧一只麻布沙袋，右侧一只翻倒的黄铜望远镜。藤编棕、茜红奶白条纹、麻绳米色；主发光很弱，只有钱袋口铜币的暖光。不要背包、方箱、飘在空中的气球。
>
> 右下【补位：素材名】：照抄该素材在本文第一到三组里的整段描述，只把位置改成「右下」。

## 四、每组的交付与验收

### 1. 存放位置

```
生图模型输出目录/交互物/重设计第二批/第N组/
├─ 四宫格_首轮.png          每轮一张，后续轮次按「四宫格_改动说明.png」命名
├─ 提示词_首轮.txt          该轮实际使用的完整提示词
├─ 切图结果/                确认后由脚本导出
├─ 终稿/                    确认采用的独立 PNG
└─ 交付记录.md              四宫格顺序、各轮改动、采用版本
```

### 2. 总图验收清单（逐项看完再说「采用」）

1. 四件都在各自象限里，十字通道完全透明，没有部件、光晕跨格。
2. 上排两件底边在同一条线上，下排两件在另一条线上；每件底边平直，前景小物不低于基座。
3. 没有圆形 / 椭圆底座，没有垂过底线的流苏、藤梢、稻草、吊牌。
4. 没有白瓷面板 + 藏蓝 + 金边 + 青灯带的科幻皮，没有方箱、软管、礼盒。
5. 没有文字、字母、数字、招牌（重点看货郎、窥路葵的镜面、金蟾的骰子）。
6. 没有飞行的蜜蜂、飘散的孢子 / 烟 / 水珠 / 花瓣 / 电火花。
7. 每件的「故事点」画出来了：鼎沿三件装备、玫瑰只有一朵、金蟾背上三个凹槽、窥路葵镜中剪影、万花筒半拼的花样、蜂巢的一线蜜、货郎的六格货架、鹈鹕喉囊里的火漆包裹、雷鳗缸底硬币和电缆、喇叭藤中心共鸣芯、百果树的根系地图、猪笼草的孢子囊。

不合格时优先**编辑当前总图**修正（只改出问题的那一格或排版），整件跑偏才把它放进第四组补位重画。

### 3. 切图与登记（用户回复「采用，切图」之后）

```powershell
node scripts/extract-curio-sheet.mjs --input "生图模型输出目录/交互物/重设计第二批/第一组/四宫格_首轮.png" --output "生图模型输出目录/交互物/重设计第二批/第一组/切图结果" --names "三足青鼎,荆棘玫瑰匣,衔币金蟾,窥路葵" --padding 8
node scripts/convert-curio-art.mjs "生图模型输出目录/交互物/重设计第二批/第一组/终稿"
```

- `--names` 严格按左上、右上、左下、右下顺序，必须正好 4 个不同的名字。
- 切图逐张检查没有邻格残片后，复制到 `终稿/` 再转 WebP。
- WebP 放进 `src/assets/explore-corridor/通用交互物/` 后，在 `commonPropAssets.ts` 登记尺寸和主体边界，加进缩放预览页「待调素材」；代码与文案改动见主文档「六」。
