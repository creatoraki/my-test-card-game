## 使用规则

- 先读本索引，再按任务选择 1 个模块说明；只有跨模块修改时才追加相关模块。
- 规则真相点、状态边界和资源登记表优先于组件实现。
- 需要精确到单个文件时，再打开对应模块说明中的文件链接。
- 设计文档与代码不一致时，以当前任务要求和实际代码为准，并在修改后同步相关文档。
