# 攻击特效演示集

五类各两种特效，均由 `AttackArtsFx` 按 `art.id` 分发绘制。

- `catalog.ts`：十个特效的名称、配色、命中时刻、总时长。
- `paint.ts`：固定种子的粒子几何、光晕、轨迹、冲击环等绘制工具。
- `slash.ts` / `arrow.ts` / `poison.ts` / `fire.ts` / `oracle.ts`：各类型的独立动作。
- `AttackArtsFx.tsx`：画布和播放生命周期，不负责背景、伤害结算、震屏。

坐标以目标中心为原点，使用 1200×900 设计像素透明画布。挂载即播放，改变 React key 重播，卸载时清理动画帧。`rate` 可显式传入，否则读取祖先的 `--fx-rate`，最低四分之一速。绘制只依赖时间与固定几何，重播布局保持一致。

尚未替换正式卡牌动画。正式接入时需登记动画类型与 `HitFxLayer` 映射，并让演出保留时长覆盖 `durationMs`。星雨箭阵的七次命中为 `impactMs + 序号 × 78` 毫秒，其余特效以 `impactMs` 为主爆点；演示目标只显示主爆点反馈。
