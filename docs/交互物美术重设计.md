## 一、主题方向

参考你认可的 4 张：**封印能量柱、紫晶织梦机、月光能量盆、神龛**。它们好在**名字一念出来就有画面**：

- 一个具体、可想象的**主体**（锁链缠住的晶柱、织梦的弧形织机、盛满月光的高脚盆、长苔的石祠）；
- 一个**故事状态**（被封印、织到一半、盛满月光、被岁月遗忘）；
- 一套**专属配色**。

旧的 6 个主题问题在于都是「功能名 + 设备」（工作站、寄存柜、实验台），读起来像说明书，画出来自然是一堆柜子和桌子。
新主题全部改成**「意象 + 物件」**：拟物、带生命感或带奇观，功能通过画面里物件的状态讲出来。

## 三、通用出图规范

### 1. 基本要求

| 项 | 要求 |
| --- | --- |
| 画风 | 与现有通用交互物一致：2D 游戏道具插画，略 Q 版的圆润厚实比例，深色干净描边，赛璐璐阴影 + 局部发光 |
| 静态 | 素材是一张静态图，游戏内不播动画。画面要**停下来也成立**：不画半空下落的硬币、飘散的烟丝、飞溅的水珠、脱离主体漂浮的花瓣与光点、速度线、动态模糊。需要表现「流动」时，用凝固的形态（沙漏里连续的一线细沙、凝成螺旋的水柱）或容器内的状态（罐里的雾、瓶里的云） |
| 视角 | 正视略带俯角（约 15°），能看到物体顶面和一点侧面，形成体积感；**底部不画透视地面** |
| 底线 | **所有元素的底部落在同一条水平直线上**，底边平直、左右齐平；没有任何部分低于这条线，也没有悬空不着地的底座。游戏内按这条线贴到 2D 地面上 |
| 背景 | 纯透明，不带场景、不带椭圆地面阴影；元素之间的接触阴影可以画在底线以上 |
| 画布 | 建议 1024×1024，主体占满画布约 90%，底线贴近画布下缘（留 2～4% 透明边） |
| 文字 | 画面内不出现任何文字、数字、字母 |

### 2. 纵深构建：前、中、后三层

每件素材由**后景、主体、前景**三层元素叠出立体感，三层的底部都在同一条底线上，纵深只靠**遮挡、大小和明暗**表现，不靠上下错位。

```
        ┌───────────┐
        │  后景元素  │  高、窄，比主体暗一档、饱和度略低，被主体遮住一部分
     ┌──┴───────────┴──┐
     │     主  体      │  最大、最亮、细节最密，发光集中在这里
   ┌─┴──┐         ┌───┴┐
   │前景│         │前景 │  矮小，压住主体底部的左右两角，颜色最深、描边最粗
═══╧════╧═════════╧════╧═══  ← 同一条水平底线
```

- **后景**：1 件，比主体高或宽，从主体背后露出轮廓，负责撑起画面高度、交代环境。
- **主体**：占画面 60% 以上，故事和功能都在它身上。
- **前景**：1～2 件小物，站在主体底部左前或右前，遮住主体底边的一部分，制造「站在前面」的距离感。
- 层与层之间要有明显的**互相遮挡**；后景整体压暗一档，前景描边略粗，拉开前后。
- 元素总数控制在 3～4 件，不要回到「一堆杂物」的老问题。

### 3. 统一提示词后缀

每段提示词末尾都已经带上这段，单独使用时也可以直接复制：

> 静态画面，画面由后景、主体、前景三层元素相互遮挡构成纵深，后景略暗；所有元素的底部落在同一条水平直线上，底边平直，不画透视地面和椭圆阴影，透明背景。

### 4. 底线常见失败与加强后缀

第一轮不合格的 4 件都是底边不平，原因集中在四类：

1. **圆形底座被俯视**：圆台、圆池在俯角下变成椭圆，底边成了弧线。→ 底座一律改成**正对画面的长方体**，正面是一个矩形，顶面只露出一条窄边。
2. **下垂装饰越过底边**：流苏、吊牌、垂绳挂得太低。→ 所有垂挂物的末端必须**高于底座底边**。
3. **用不规则形状当底**：波浪荷叶边、碎石堆、火焰、水花垫在最底下。→ 最底下只能是**一条笔直的基座边**，装饰全部放在基座以上。
4. **斜放导致脚高低不一**：托架、桌脚跟着物体转角度。→ 支撑结构**正对画面**，左右等高，最好在底部加一条贯通左右的横板。

**底线加强后缀**（重新出图时追加在提示词末尾）：

> 物件最底部是一块正对画面的长方体基座，基座底边是一条贯穿左右的笔直水平线，像正视图里放在桌面上的物体；基座不能是圆形或椭圆形；任何流苏、吊牌、垂绳、碎石、火焰、水花都不能低于这条底线。

**通用负面提示词**：文字，数字，字母，水印，签名，边框，背景，透视地面，椭圆形地面阴影，倾斜的底边，弧形的底边，圆形底座，椭圆形底座，垂到底座以下的流苏和吊牌，底部的碎石堆，悬空的物体，漂浮的碎片，飘散的烟雾，飞溅的水珠，下落中的硬币，速度线，动态模糊，人物，纸箱堆，书堆，杂乱的瓶罐，裁切不完整

### 3. 星砂沙漏（顶替 星象观测台 · salvager）

**功能对应**：放入装备 / 模组，拆成通用材料与水晶。
**画面故事**：时间会把一切磨成沙——把装备放进上瓶，它就碎成星砂落下，到了下瓶已经分成了晶粒和零件。**「拆解」就是沙漏的上下两半**。

**轮廓**：竖直的沙漏，身后一面大刻度圆盘。宽高约 3:4。

**层次**：
- 后景：沙漏后方立着一面大号黄铜刻度圆盘（像没有指针的钟面），比沙漏宽，被沙漏遮住中间，略暗。
- 主体：乌木框架的大沙漏。
- 前景：左前一只小黄铜托盘盛着几颗晶粒；右前斜靠一只等待拆解的旧头盔。

**主体细节**：
- 框架是左右两根乌木立柱 + 黄铜顶盖和底座，底座方正厚实，直接落在底线上。
- 上瓶里斜插着一把旧剑，剑身下半截已经碎成闪烁的银白星砂，堆在上瓶底部。
- 细腰处一线连续的细沙连通上下两瓶（凝固的细线，不画飞散的沙粒）。
