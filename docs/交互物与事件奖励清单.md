## 一、通用说明

### 1. 奖励池（`GAIN_POOL_ITEM` 抽取范围）

物件等级（1～5，玩家不可见）越高，越偏向较好/最好档的条目。

| 奖励池 | 中文含义 | 可能产出 |
| --- | --- | --- |
| generalMaterial | 通用材料 | 魔方、齿轮、电池、弹簧*、磁铁* |
| generalMaterialOrScrap | 材料或钱币 | 上述材料 + 铜币、银币*、金币** |
| scrap | 钱币 | 铜币、银币*、金币** |
| premiumScrap | 高价值钱币 | 铜币、银币*、金币**（偏向银金） |
| crystal | 水晶 | 绿色水晶、蓝色水晶*、红色水晶** |
| basicFood | 基础食品 | 牛奶、面包、可乐 |
| food | 食品 | 牛奶、面包、可乐、汉堡*、炸鸡*、披萨* |
| highFood | 高级食品 | 汉堡、炸鸡、披萨（目前无物件使用） |
| consumable | 应急道具 | 糖块、医疗包*、圣水* |
| module | 1 阶模组 | 攻击力、治愈力、穿甲*、暴击*、精准*、淬毒*、燃烧* 模组 |

`*` 较好档，`**` 最好档。

### 2. 其他奖励 / 惩罚类型

| 效果 | 含义 |
| --- | --- |
| 装备 | 一件完整装备进入待拾取框，品质由当前地图决定 |
| 随机遗物 | 一件随机永久遗物 |
| 一次性遗物 | 仅本次探索生效的祝福遗物，离开远征消失 |
| 单人治疗 X% | 选一名队员回复 X% 生命 |
| 全队治疗 X% | 全队回复 X% 生命 |
| 修复体力极限 | 选一名队员修复体力极限 |
| 净化粒子 ±X | 探索能量（粒子）增减 |
| 污染 ±X | 执行者 / 全队污染值增减 |
| 揭示地图 | 显示未知房间；「含威胁」时同时显示战斗与陷阱位置 |
| 全队经验 | 全队卡组经验 |
| 警报战斗 | 失败时引来守卫，进入战斗（档位按物件等级） |
| 受伤 X% | 执行者 / 全队按最大生命百分比扣血 |

### 3. 隐性门槛

- **职业**：剑士、精算师、植物学家、预言家、炼金术士。作为执行者时降低失败率、追加奖励，或把失败转为正面结果。
- **携带物品**：背包内有指定物品时自动消耗 1 个生效（圣水、医疗包、可乐、牛奶、齿轮、霓虹灯管、沉重的负担、诅咒遗物等）。
- **喂养机械小生物**：背包里有足够的对应食品时才出现额外选项，选择后自动扣除。
  - 甲虫：面包 / 牛奶
  - 鼹鼠：汉堡 / 炸鸡
  - 清扫虫：可乐 / 披萨
