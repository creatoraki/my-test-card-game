# 奇物四宫格切图

> 整理更新：第 1—24 项最终切图已集中到奇物目录下的「切图结果」，见 [最终素材汇总](../生图模型输出目录/奇物/切图结果/整理说明.md)。原批次和过程版本保留。以下命令为原批次切图方式，重新切图请指定其他输出目录，避免覆盖汇总清单。

执行：

```powershell
node scripts/extract-curio-sheet.mjs
```

默认读取已确认的 `生图模型输出目录/奇物/通用素材_前四个_四宫格_精致手游版_平底修正版.png`，导出到 `生图模型输出目录/奇物/切图结果`：旅人战术背包、空投补给舱、密码寄存柜、环锁密匣，各一张透明 PNG，另附 `切图清单.json`。

脚本先以透明度至少 64/255 的像素识别四个主体，再从主体向外分配透明度至少 8/255 的半透明边缘。相邻物件之间的低透明度桥接不会导致主体合并。每个像素只属于一组，导出使用独立像素遮罩，即使裁切包围框交叠也不会带入其他组的物件。

保留原始像素尺寸、颜色与有效透明边缘，不缩放；裁紧主体后四周各加 8 像素透明留白。透明度低于 8/255 的噪点、未与主体连接的孤立碎点不导出。若物件实际遮挡重叠，或无法识别四个独立主体，脚本会停止；此脚本无法恢复被遮挡的原图内容。顺序固定为左上、右上、左下、右下，适用于这张原图。

重新导出：

```powershell
node scripts/extract-curio-sheet.mjs --overwrite
```

指定输入、输出以及透明留白：

```powershell
node scripts/extract-curio-sheet.mjs --input "原图.png" --output "输出目录" --padding 8
```

默认拒绝覆盖已有同名文件。透明留白设为 `0` 时输出最紧包围框。

后续批次通过 `--names` 指定四个不带扩展名的素材名称，按左上、右上、左下、右下排列，以逗号分隔。不同批次使用独立输出目录：

```powershell
node scripts/extract-curio-sheet.mjs --input "生图模型输出目录/奇物/第5-8项/四宫格_门锁修正版.png" --output "生图模型输出目录/奇物/第5-8项/切图结果" --names "蝶纹合金闸门,自助驿站终端,合成实验台,金铃兑币终端" --padding 8
```

若有后续修正版，输入路径改为最终使用的图片。仅指定新图片不会自动改变默认的前四项名称。
