# 四宫格独立透明素材

背景使用内置生图模型抠除。请把模型输出的真实透明 PNG，按原图文件名保存到 `生图模型输出目录/切图目录/模型抠图原图`。不要把浅色底原图放进这个目录，脚本只负责拆分和排版。

默认执行：

```powershell
node scripts/extract-generated-props.mjs
```

输出到 `生图模型输出目录/切图目录`，每张四宫格导出四件独立 PNG，名称包含来源及左上、右上、左下、右下位置。处理目录中的直属图片，不扫描其他子目录。

默认画布为 768×768。所有物体保持比例，在画布中水平居中；底部到最下方可见像素固定为 36 像素。留白比例是用户指定的 12/256，上方及两侧至少保留同等留白。

脚本识别透明图中的完整连通主体，不直接按几何中线四等分，所以宽物体越过中线也能保持完整。四个最大的主体按上下两行、每行左右顺序归类，附近的独立装饰一并保留，远离主体的零碎噪点舍弃。输入需包含四件互不连接的完整物体。

排版前后只清理透明度低于 8/255（约 3%）的透明噪点，避免模型在主体远处残留的近乎不可见像素拉大边界。不根据颜色抠图，正常半透明边缘和物体材质使用模型输出的原始透明通道。

输出 256×256，底部留白 12 像素：

```powershell
node scripts/extract-generated-props.mjs --size 256 --overwrite
```

更改输入、输出目录：

```powershell
node scripts/extract-generated-props.mjs --input "透明四宫格目录" --output "独立素材目录" --size 768
```

已有同名文件时停止。重新导出需要显式添加 `--overwrite`，只覆盖本次导出的同名文件，不删除其他素材。原始浅色底四宫格保持在原目录。

只处理指定批次，例如“奇幻第二批”：

```powershell
node scripts/extract-generated-props.mjs --batch "奇幻第二批"
```

`--batch` 按模型透明原图的文件名筛选，并保存带批次名称的切图清单和说明，便于继续追加素材。

输出附有 `切图清单.json` 和 `切图说明.md`，记录来源、位置、原图主体边界、输出主体边界及统一底部留白。模型抠图提示词保存在输出目录的 `模型抠图提示词.txt`。
