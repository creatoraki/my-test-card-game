# 《霓虹都市》· 废弃楼层敌人 UI 美术提示词

> **适用范围**：废弃楼层战斗中的小怪立绘、敌人头像和战斗 UI 敌方单位素材。
>
> **本次覆盖**：废品机器人、电线杆机器人、收音机机器人、清扫无人机、维修蜘蛛。
>
> **统一方向**：沿用物品提示词总览中的“软萌拟物·末世补给”作为主风格。五种敌人都属于同一座仍在运行的无人城市，必须像旧工单驱动的自治机械；在圆润、亲和、易读的二次元拟物造型中保留功能逻辑和敌人压迫感，而不是来自不同作品的怪物。

## 一、共用 UI 规范

以下内容应固定加入每个怪物提示词：

- 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，完整全身或完整主体沿画面纵向位于中央。
- 主体正面朝向观者，功能面、头部或主要识别结构面朝画面；采用有纵深感的透视构图，通过近大远小、前后错层和明确的空间收束表现体积，允许轻微转体但不能让主体侧面对或背对观者。
- 主体纵向占画布约 70%~85%，轮廓外留出稳定安全边距，不能被画面边缘裁切；姿势与透视方向一致，前景部件、支撑结构和后方部件要有清楚的前后关系。
- 二次元游戏敌人 UI 立绘，轻度软萌拟物风格，圆润但有功能逻辑的敌人轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给品和旧设备的设计元素，少量磨损与贴纸形状装饰，但不出现人物表情和拟人化五官；造型亲和、有记忆点，轮廓缩小后仍然容易辨认。
- 废弃楼层的未来办公设施与维护设备来源，保留轻微灰尘、划痕、褪色、氧化和维修痕迹，但不能脏到遮挡结构。
- 使用一个主色、一个辅助色和一个能源强调色；电子光只集中在传感器、接口、线路或功能核心，不要变成满屏技能特效。
- 透明背景；如果模型不支持透明背景，使用干净深灰蓝纯色背景或极简柔和光晕，不生成场景。
- 不生成文字、数字、品牌 logo、可读标签、对白气泡、战斗 UI、血条、技能图标、卡牌、地面、房间、传送带、人物、人物手部或多个怪物。

## 二、敌人提示词

### 1. 废品机器人

**视觉定位**：基础清运单位，体型低矮厚重，像一台把办公废品分类、搬运并压缩的旧式移动回收设备。它的轮廓应该最朴素、最容易批量出现，同时保留“把人类识别为高价值废品”的荒诞感。

**可直接复制的提示词：**

> 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的废品机器人全身，沿画面纵向位于中央，正面朝向观者，采用低机位的纵深透视构图：前侧履带、机械臂和夹钳略大，机体后侧的压缩结构向后收束，形成明确的近大远小和前后层次；主体纵向占画布约 78%，四周留有均匀安全边距，透明背景或干净深灰蓝背景，不生成场景。
>
> 二次元游戏敌人 UI 立绘，软萌拟物·末世补给风格，轻度软萌拟物造型，圆润但有功能逻辑的废品机器人轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给设备和旧维护机械的设计元素，少量磨损与贴纸形状装饰，不出现人物表情和拟人化五官；金属与工程塑料保留清楚的材质差异，电子光克制地集中在功能部件，整体亲和、易读、有记忆点。
>
> 主体是一台基础清运用废品机器人，整体为低矮厚实的圆角矩形机体，像一只缩短的移动回收箱，底部有两条宽大的履带或低矮滚轮，左右各有一支粗短的分类机械臂；两支机械臂都朝向观者展开，一侧夹钳略微前伸，另一侧压平板稍后收，利用前后距离差表现透视。机械臂末端是夹钳与压平板的组合；正面嵌入一块深色矩形识别面板，面板中央只有一个冷黄色扫描光点和少量不可读几何标记，顶部有小型回收入口，背部露出简单的压缩机构。
>
> 主色为旧工程白与垃圾桶灰，辅助色为深石墨黑，强调色为识别黄，局部加入少量电光青接口光；可加入一两处小面积贴纸形状装饰，但不能遮挡功能结构。姿势要像正面迎向观者并缓慢压近，体型保持重量感、功能感和圆润钝角，不要生成文字、数字、logo、完整垃圾堆、传送带或多个机器人。

### 2. 电线杆机器人

**视觉定位**：重载小怪，细长高耸，负责电力维护和吊装。它与废品机器人同属旧式自治机械，但必须通过“电线杆般的纵向剪影、支架和高压绝缘结构”一眼区分。

**可直接复制的提示词：**

> 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的电线杆机器人全身，沿画面纵向位于中央，正面朝向观者，采用略低机位的仰视纵深透视构图：底部加固支架和前方稳定脚略大，分节躯干与顶部横担向上、向后收束，形成高耸而有空间距离的纵向透视；主体高度占画布约 86%，宽度保持细长，顶部与底部留出安全边距，透明背景或干净深灰蓝背景，不生成场景。
>
> 二次元游戏敌人 UI 立绘，软萌拟物·末世补给风格，轻度软萌拟物造型，将高挑结构处理成圆润、简洁、容易辨认的功能性轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给设备和旧维护机械的设计元素，少量锈蚀与贴纸形状装饰，不出现人物表情和拟人化五官；金属、绝缘橡胶、陶瓷和透明能源管保留清楚的材质对比，整体亲和但保留重载设备感。
>
> 主体是一台高挑的重载电力维护机器人，中央是一根由分节金属柱和厚实绝缘套组成的垂直躯干，顶部展开两侧不对称但边缘圆润的短横担与高压接线夹，肩部连接可伸缩的维修臂；两条维修臂正面朝向观者，一条吊装夹具向画面前方伸出，另一条向后错开，末端为钩状吊装夹具，底部是三点式加固支架与短粗的稳定脚；机体中段有一枚窄长的橙色过载指示灯，绝缘节缝隙中有极少量受控的蓝色电弧。
>
> 主色为深铁灰，辅助色为旧铜橙与暗红警示色，强调色为电弧蓝，局部可加入少量贴纸形状警示装饰。姿势要像一座正面压向观者、正在执行吊装的城市电力设施，重而高但不尖锐，不要生成电缆堆、闪电场景、文字、数字、logo 或其他单位。

### 3. 收音机机器人

**视觉定位**：巡回与侦测单位，外形接近旧式广播设备和移动信标。它应当比废品机器人轻巧，比电线杆机器人更集中，核心识别点是圆形扬声器面、旋钮和短天线，而不是夸张声波特效。

**可直接复制的提示词：**

> 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的收音机机器人全身，沿画面纵向位于中央，正面朝向观者，采用近大远小的纵深透视构图：圆形扬声器面和前方旋钮作为近景略微放大，广播机身与后方天线向后收束，主体占画布约 76%，四周留出安全边距，透明背景或干净深灰蓝背景，不生成场景。
>
> 二次元游戏敌人 UI 立绘，软萌拟物·末世补给风格，轻度软萌拟物造型，圆润但有功能逻辑的旧广播机械轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给设备和旧维护机械的设计元素，少量氧化、灰尘、划痕与贴纸形状装饰，不出现人物表情和拟人化五官；金属外壳、深色扬声器网、玻璃刻度窗和橡胶旋钮具有清楚的材质差异，整体亲和、易读、有记忆点。
>
> 主体是一台近方形的巡回收音机机器人，圆角广播机身正面朝向观者并略微前倾，正面中央是一枚大而清晰的圆形扬声器网，扬声器周围有一圈暗金色调谐环，右侧排列两枚粗短旋钮和一个不可读的几何频率指示窗；顶部伸出一根向后上方延伸的短天线与小型信号灯，下方连接两条短而灵活、前后错开的机械腿或滚轮足，侧面探测臂向画面前方伸出，用于扫描维修轨道。
>
> 主色为收音机棕与暗铜色，辅助色为炭黑和旧米白，强调色为频率青，电子光集中在调谐环、天线端和扫描窗。姿势要像正面锁定观者并向前探测，利用扬声器面、探测臂和后方天线的距离差表现空间深度。只表现少量贴近机体的细窄信号光，不生成巨大声波、广播塔、音符、文字、数字、logo、人物或多个机器人，不要画成普通家用收音机。

### 4. 清扫无人机

**视觉定位**：轻型机动小怪，负责骚扰和补充数量。它的轮廓要轻、薄、快，核心识别点是圆角清扫壳体、折叠吸尘口和微尘过滤网，避免做成军用无人机或普通飞行器。

**可直接复制的提示词：**

> 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的清扫无人机，悬浮在画面中央，正面朝向观者，采用由前向后的纵深透视构图：前方吸尘口、短刷片和污染扫描镜略微放大，扁平机壳与后方过滤仓向后收束，主体纵向占画布约 74%，四周留有稳定安全边距，透明背景或干净深灰蓝背景，不生成场景。
>
> 二次元游戏敌人 UI 立绘，软萌拟物·末世补给风格，轻度软萌拟物造型，扁平圆润但有功能逻辑的清扫设备轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给设备和旧维护机械的设计元素，少量灰尘、碰撞擦痕与贴纸形状装饰，不出现人物表情和拟人化五官；轻量化工程塑料、磨砂金属、透明过滤网和柔性软管具有清楚的材质差异，整体轻快、亲和、易读、有记忆点。
>
> 主体是一台轻型清扫无人机，整体为扁平圆角六边形机壳，机身正面朝向观者并略微前倾，底部前方有一个明显的可伸缩吸尘口与短刷片，左右展开两片前后错开的折叠稳定翼，后侧安装一块可以看见网格结构的微尘过滤仓，顶部有一个小型圆形污染扫描镜；机身下方悬挂两条短而柔韧、向画面前方伸出的清扫软管，但不能形成杂乱线团。
>
> 主色为雾灰白，辅助色为深灰蓝，强调色为净化绿与少量警示橙，局部可加入贴纸形状的简洁装饰。整体姿势要轻巧、低空悬浮并带有正面向观者冲刺的纵深动势，前端更近、后端更远，但主体必须完整且清楚，不生成喷气战斗机、武器、螺旋桨、灰尘云、清扫场景、文字、数字、logo 或多个无人机。

### 5. 维修蜘蛛

**视觉定位**：支援型小怪，负责在天花板和维修管线之间移动。它需要有蜘蛛般的多足剪影，但本质是城市维护设备；关键识别点是八条细长机械腿、背部维修舱和自动焊接工具，避免出现真实昆虫的眼睛和生物质感。

**可直接复制的提示词：**

> 9:16 竖幅游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的维修蜘蛛机械体，沿画面纵向位于中央，维修舱正面朝向观者，采用接近正面视线的轻微高机位纵深透视构图：前方两条机械腿、夹持臂和维修舱略大，后方六条机械腿向后收束，八条机械腿完整展开但不被边缘裁切，主体纵向占画布约 80%，轮廓外留有安全边距，透明背景或干净深灰蓝背景，不生成场景。
>
> 二次元游戏敌人 UI 立绘，软萌拟物·末世补给风格，轻度软萌拟物造型，圆润但有功能逻辑的机械蜘蛛轮廓，干净线稿，简洁厚涂，柔和阴影与小面积高光，鲜明而克制的配色，带有未来城市补给设备和旧维护机械的设计元素，少量油污、刮擦、补焊痕迹与贴纸形状装饰，不出现人物表情和拟人化五官；金属关节、工程陶瓷外壳、柔性维修管线和透明焊接仓具有清楚的材质差异，整体亲和、易读、有记忆点。
>
> 主体是一只城市设施维护用的机械蜘蛛，中央为扁圆的深灰维修舱，正面有一枚朝向观者的圆角透明观察窗，窗内可见短小的自动焊接头与卷收焊丝；八条细长但结实的机械腿从躯干四周展开，每条腿由三段圆润关节组成，前方两条腿向画面前方撑开并改装成细小的夹持臂和低温焊接工具，后方六条腿以前后错层的姿势支撑身体，末端是可吸附墙面的软胶维修脚；侧面有几段整齐收束的柔性导管。
>
> 主色为深石墨灰，辅助色为旧铜与陶瓷米白，强调色为熔融橙和少量维修青，局部可加入少量贴纸形状维修标记。姿态要像正面锁定观者并准备向前修补故障，利用腿部的前伸、回收和高低层次表现空间深度，不能生成真实昆虫、毛发、血肉、蜘蛛网、巨大焊接火焰、维修车间、文字、数字、logo 或其他机械。

## 三、统一验收要点

- 适配 9:16 竖幅战斗 UI 后，缩小到敌人头像或小型立绘仍能只凭剪影区分五种敌人。
- 五张图都以正面朝向观者为基础，并通过近大远小、前后错层和姿势方向形成清楚的纵深透视，而不是平面正投影或侧面展示。
- 废品机器人最厚重朴素；电线杆机器人最细高；收音机机器人最圆；清扫无人机最轻薄；维修蜘蛛的多足结构最醒目。
- 五张图都只有一个完整主体，没有战斗背景、地面、人物、文字和额外单位。
- 机械都保留轻微旧化，但主色、功能部件和能源强调色仍然清楚，不被灰尘、锈蚀或发光效果淹没。
- 电子光只强调功能部件：废品机器人是识别面板，电线杆机器人是绝缘节与过载灯，收音机机器人是调谐环，清扫无人机是净化扫描镜，维修蜘蛛是焊接仓。
- 五种敌人共享同一套 9:16 竖幅比例、正面朝向、纵深透视、方案 E 软萌拟物线稿、光照、材质和背景规则，放入战斗页面后应像同一座废弃大厦的自治设备。
