# 废弃楼层敌人立绘提示词规范（清洁重设计版）

> 本文以“收音机机器人”`idle.png`为标准敌人立绘参考，记录废弃楼层机械敌人的统一画风、材质语言和构图规则。新版的重点不是把敌人画得更破，而是让它们像被城市长期维护、仍在稳定工作的旧设备：外形干净、结构有设计、损耗集中且可读。后续敌人可以替换主体设备和工作机构，但应保持同一套视觉基准。

## 一、统一画风

- 高细节、偏写实的科幻机械生物角色立绘，重点是“旧设备被重新赋予了生物般的工作姿态”，不是产品展示图、三维模型渲染图或工业设计效果图；不使用扁平插画、像素画或纯卡通玩具风。
- 保留日系二次元游戏素材的清晰剪影、干净分区和强识别设计，结合旧家电、城市维护机械与赛博朋克废土语言；允许结构夸张、错位和荒诞，但第一眼必须能读出一个完整角色，而不是零件堆。
- 机械设计遵循“三个大形体 + 一个工作动作”：主体设备、连接核心、工作机构先形成大轮廓，再用少量转轴、线缆和接缝补充可信度。细节服从剪影，不用密集小零件填空。
- 旧化采用“干净使用痕迹”而不是“满身脏污”：保留一到三处明确的掉漆、边缘氧化、局部焦痕或维修补片，其余表面保持完整、清爽、可辨认。旧化面积建议不超过主体表面的 15%。
- 材质表现以大块平整色面、清楚的明暗分区和少量手绘纹理为主；主色使用雾银、暖灰、深石墨、冷青灰或褪色的旧铜色，避免整张图被铁锈棕和脏黑占满。
- 发光部件只保留一处主光源和一处辅助光源，例如电压槽、绝缘接口或扫描线；发光嵌入结构，边缘干净，不用全身霓虹、烟雾、火花和光污染掩盖轮廓。
- 线稿边缘清楚，轮廓略厚但不发白溢出；用干净的白色或浅青色抠图边缘保证敌人在战斗背景中醒目，阴影保持透明背景，不绘制地面接触影。
- 整体气质表现为“仍在执行旧职责的城市维护生命”：危险、笨重、古怪，但不是腐烂和肮脏。保留收音机机器人的核心感觉，却不强制每个敌人都长出相同的多足结构。

### 清洁度控制

- 画面材质比例建议为：约 70% 干净基础色面、约 20% 结构明暗与边缘细节、约 10% 集中的使用痕迹和发光信息。
- 旧化词每次提示词最多选择三种，并明确位置，例如“右上角掉漆、底部一条焦痕、左侧维修补片”；不要同时堆叠锈蚀、污渍、积尘、油污、烧灼、氧化、刮擦等词。
- 正向加入：`clean surface separation`、`controlled wear`、`clear graphic shapes`、`readable silhouette`、`freshly serviced old machine`对应的中文语义；负向加入：`muddy texture`、`dirty gray filter`、`rust covering the whole body`对应的中文语义。
- 如果生成结果仍然发脏，优先删掉材质形容词并强化“完整外壳、平整色块、局部磨损、清爽边缘”，不要继续增加“高细节”。

## 二、标准立绘的构图特色

- 使用透明背景的单体敌人角色立绘，禁止把完整场景、地面、建筑或复杂环境绘入角色素材；地面接触阴影由战斗场景 UI 单独处理。画面应像一个完整的游戏角色，不像拆开的机械零件陈列或工程设备产品图。
- 采用正面展示为主、略带三分之四透视的视角，让敌人的正面识别面完整可见，同时通过侧面厚度和结构错位体现立体感。
- 敌人主体置于画布中央，占画布约 72% 至 84%，根据造型选择纵向、横向或环形构图；四周保留均匀安全边距，不能裁切任何外伸结构。
- 第一视觉焦点是一个明确的大形状，第二视觉焦点是一个正在执行工作的机构，第三视觉焦点才是连接细节。不要让显示槽、绝缘子、夹具和线缆同时争夺中心。
- 每个方案只使用两到五个主要支撑点或肢体，并让它们具有不同长度、方向和功能；避免默认生成六条相似机械腿、蜘蛛网状腿群或规则对称栅格。
- `idle`不是僵硬站立，而是“动作暂停的一帧”：至少有一个夹具正在夹持、一个环体正在偏转、一个支架正在承重或一个工作臂处于半展开状态。动作要能解释角色的职业，不要摆成人形战斗姿势。
- 通过一处偏心重心、一个折叠结构或一条有方向性的线缆制造不对称；不对称服务于姿态和识别，不用随机零件和满身破损制造混乱。
- 轮廓先于细节：缩小到卡牌尺寸后，仍应只凭外形分辨三种方案；正面工作面清晰，后续可以沿用同一结构制作攻击、受击和死亡变体。
- 画面内不放置名称、属性数字、技能文字、血条、徽章、logo、水印或其他 UI 元素。

## 三、机械设计关键词

可根据具体敌人的职责替换主体设备，但建议从以下方向组合：

`旧式电力维护设备`、`清爽的大色块材质`、`完整外壳`、`一个明确工作机构`、`偏心重心`、`可见铰链与转轴`、`少量整齐线缆`、`角色化夸张结构`、`局部可控磨损`、`干净轮廓`、`单一冷色光源`、`仍在执行旧工单的自动机械`、`废土赛博朋克游戏角色立绘`。

## 五、制作检查清单

- [ ] 一眼能看出敌人的主要工作设备和所属机械职责。
- [ ] 正面识别面完整，侧面厚度和三维结构清楚。
- [ ] 旧化痕迹集中且克制，大部分外壳干净完整，颜色没有变成单一脏黑。
- [ ] 发光部件只有一个主焦点和一个辅助焦点，主要用于强调功能接口和危险感。
- [ ] 工作机构承担明确动作，支撑结构数量有限且方向有变化，轮廓没有严重重叠。
- [ ] 透明背景干净，主体没有被画布边缘裁切，也没有混入场景和 UI。
- [ ] 待机姿态像动作暂停的一帧，稳定、可读，后续可以沿用同一结构制作攻击、受击和死亡动作。

## 六、电线杆机器人：三种全新造型方案

以下三种方案共享本文件前述的画风、材质、透明背景和清洁度规范，但不再共享“设备盒子 + 多条机械腿”的固定模板。它们分别使用“承重支架、折叠工作翼、滚动磁环”作为身体语言；每种方案只有一个主要工作动作和一个主识别形状。电力职责通过绝缘件、夹持结构、导线接口和姿态表达，不通过堆满电线和零件表达。

### 方案一：绝缘冠架型

**造型定位：** 一只高耸、偏斜、像旧电力设备长出骨架的承线机械生物，负责把主干高压线固定在楼层结构上，并持续吸收线路拉力。

**轮廓特色：** 主体是一枚完整的竖向六边形继电器外壳，顶部不是横担，而是两片向外张开的奶白色绝缘冠片，形成清晰的开口 V 形剪影；底部只有三根粗短的折叠承重支架，像三枚正在撑住身体的脚。主体微微向一侧倾斜，一根前置承线臂向外伸出并夹住单条导线，整体像一座会移动的偏斜高压标记塔，而不是人形或真实电塔。

**功能细节：** 正面只保留一块竖向深色检修窗、一条细窄的冷青电压光带和一枚偏心圆形锁止盘；绝缘冠片分成两到三节，表面完整光滑，只在一片边缘有细小裂纹。三根支架长度不同，后方两根负责承重，前方一根向前弯曲形成动作；承线臂夹住一条短而整齐的电缆，不生成巨大电缆网。主体使用雾银、暖灰、深石墨，加入右上角一小块掉漆和底部一条焦痕即可。

单体敌人角色立绘，透明背景，废弃楼层的绝缘冠架型电线杆机器人，负责固定主干高压线路，仍在执行旧工单。主体完整位于画布中央，正面略带三分之四视角，纵向构图，身体微微向右倾斜，主体占画布约 78%，绝缘冠片、承线臂和三根支架全部位于安全边距内，不裁切任何结构。

### 方案二：折翼桥架型

**造型定位：** 一只贴着电缆桥架侧面爬行的横向维修机械生物，负责展开绝缘护翼、夹紧松脱的线路接口并完成短距离巡检。

**轮廓特色：** 主体是一枚宽而薄的椭圆终端舱，左右各连一片折叠绝缘翼，像一只收拢中的机械蝠翼，但没有羽毛和装饰翅膀。左翼完全展开并夹住线路，右翼折叠到身体侧后方，形成一开一合的强烈不对称。底部不是腿群，而是两条短促的弧形桥架滑靴和一个向前探出的三节探针，角色像在桥架上“侧身刹住”而不是站立。

**功能细节：** 终端舱正面是一条横向扫描面板和三枚不同大小的状态指示孔，不画成眼睛或脸；两片绝缘翼由宽大的陶瓷片和金属铰链组成，内侧各有一条整齐导线槽。左翼末端的夹爪正夹住一枚绝缘接口，前方探针略微抬起像在读取线路。颜色以浅灰、雾银、深石墨和褪色青绿为主，磨损只放在展开翼的折角和底部滑靴。

### 方案三：磁环摆渡型

**造型定位：** 一只围绕线路接口滚动巡检的圆环机械生物，负责把高压绝缘环和短接线送到维修位置，并将异常接口暂时隔离。

**轮廓特色：** 主体是一个不规则的厚重 C 形磁力绝缘环，环体不是完美圆形，而是上宽下窄，内部悬着一枚小型发光接线核心。两侧各有一条半圆轨足，像环自己长出的滚动支撑；一条短小的偏心夹臂从环内穿出，夹着一枚明亮的白色绝缘环。整体形成“圆环包住核心、向前滚动”的单一剪影，不像车辆、炮塔或普通电缆卷盘。

**功能细节：** C 形环体由三块完整的雾银绝缘外壳拼接而成，接缝清楚，内圈有一条冷蓝导向光；内部核心只显示一条竖向红紫状态线，不能画成眼睛。两条半圆轨足一前一后错开，前足已经滚过一个角度，后足仍在承重，形成动态待机姿势。偏心夹臂把绝缘环送到环体前方，动作简单但职业明确。磨损只放在内圈接触边一条焦痕和左下方一块维修补片，绝不覆盖整个圆环。
