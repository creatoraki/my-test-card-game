# 《霓虹都市》· 废弃楼层敌人 UI 美术提示词

> **适用范围**：废弃楼层战斗中的小怪立绘、敌人头像和战斗 UI 敌方单位素材。
>
> **本次覆盖**：废品机器人、电线杆机器人、收音机机器人、清扫无人机、维修蜘蛛。
>
> **统一方向**：沿用物品提示词总览中的“霓虹废土·高光道具卡”作为主风格，并吸收“未来工业·设定感图标”的结构逻辑。五种敌人都属于同一座仍在运行的无人城市，必须像旧工单驱动的自治机械，而不是来自不同作品的怪物。

## 一、共用 UI 规范

以下内容应固定加入每个怪物提示词：

- 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，完整全身或完整主体位于画面中央。
- 正面或轻微 3/4 视角，主体占画布约 70%~85%，轮廓外留出稳定安全边距，不能被画面边缘裁切。
- 日系二次元科幻游戏原画，半厚涂与清晰轮廓线结合，造型适度夸张，材质结构可信，轮廓缩小后仍然容易辨认。
- 废弃楼层的未来办公设施与维护设备来源，保留轻微灰尘、划痕、褪色、氧化和维修痕迹，但不能脏到遮挡结构。
- 使用一个主色、一个辅助色和一个能源强调色；电子光只集中在传感器、接口、线路或功能核心，不要变成满屏技能特效。
- 透明背景；如果模型不支持透明背景，使用干净深灰蓝纯色背景或极简柔和光晕，不生成场景。
- 不生成文字、数字、品牌 logo、可读标签、对白气泡、战斗 UI、血条、技能图标、卡牌、地面、房间、传送带、人物、人物手部或多个怪物。

## 二、敌人提示词

### 1. 废品机器人

**视觉定位**：基础清运单位，体型低矮厚重，像一台把办公废品分类、搬运并压缩的旧式移动回收设备。它的轮廓应该最朴素、最容易批量出现，同时保留“把人类识别为高价值废品”的荒诞感。

**可直接复制的提示词：**

> 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的废品机器人全身，位于画面中央，正面偏右的 3/4 视角，主体占画布约 78%，四周留有均匀安全边距，透明背景或干净深灰蓝背景，不生成场景。日系二次元科幻游戏敌人原画，霓虹废土·高光道具卡风格，半厚涂，清晰而有力度的轮廓线，未来工业结构可信，金属与工程塑料材质对比，冷色环境光与少量电子边缘光，轻微灰尘、划痕、掉漆和维修痕迹。主体是一台基础清运用废品机器人，整体为低矮厚实的圆角矩形机体，像一只缩短的移动回收箱，底部有两条宽大的履带或低矮滚轮，左右各有一支粗短的分类机械臂，机械臂末端是夹钳与压平板的组合；正面嵌入一块深色矩形识别面板，面板中央只有一个冷黄色扫描光点和少量不可读几何标记，顶部有小型回收入口，背部露出简单的压缩机构。主色为旧工程白与垃圾桶灰，辅助色为深石墨黑，强调色为识别黄，局部加入少量电光青接口光。体型要有重量感、功能感和旧设备的圆润钝角，不要拟人化五官，不要画成可爱的机器人角色，不要生成文字、数字、logo、完整垃圾堆、传送带或多个机器人。

### 2. 电线杆机器人

**视觉定位**：重载小怪，细长高耸，负责电力维护和吊装。它与废品机器人同属旧式自治机械，但必须通过“电线杆般的纵向剪影、支架和高压绝缘结构”一眼区分。

**可直接复制的提示词：**

> 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的电线杆机器人全身，位于画面中央，近正面轻微 3/4 视角，主体高度占画布约 86%，宽度保持细长，顶部与底部留出安全边距，透明背景或干净深灰蓝背景，不生成场景。日系二次元科幻游戏敌人原画，霓虹废土·高光道具卡与未来工业设定感结合，半厚涂，结构分层清楚，细长轮廓有强烈剪影识别度，金属、绝缘橡胶、陶瓷和透明能源管的材质对比明确，冷白光与少量电弧蓝边缘光，轻微锈蚀、焦痕和高处风压磨损。主体是一台高挑的重载电力维护机器人，中央是一根由分节金属柱和厚实绝缘套组成的垂直躯干，顶部展开两侧不对称的短横担与高压接线夹，肩部连接可伸缩的维修臂，末端为钩状吊装夹具，底部是三点式加固支架与短粗的稳定脚；机体中段有一枚窄长的橙色过载指示灯，绝缘节缝隙中有极少量受控的蓝色电弧。主色为深铁灰，辅助色为旧铜橙与暗红警示色，强调色为电弧蓝。造型要像会缓慢移动的城市电力设施，重而高、略微向一侧倾斜，不能变成普通电线杆、昆虫、长枪、炮塔或带人物脸部的机器人，不要生成电缆堆、闪电场景、文字、数字、logo 或其他单位。

### 3. 收音机机器人

**视觉定位**：巡回与侦测单位，外形接近旧式广播设备和移动信标。它应当比废品机器人轻巧，比电线杆机器人更集中，核心识别点是圆形扬声器面、旋钮和短天线，而不是夸张声波特效。

**可直接复制的提示词：**

> 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的收音机机器人全身，位于画面中央，略微向左旋转的正面 3/4 视角，主体占画布约 76%，四周留出安全边距，透明背景或干净深灰蓝背景，不生成场景。日系二次元科幻游戏敌人原画，霓虹废土·高光道具卡风格，半厚涂，圆润但结构可信的旧广播机械，清晰轮廓，金属外壳、深色扬声器网、玻璃刻度窗和橡胶旋钮具有明显材质差异，冷色环境光与克制的频率青边缘光，轻微氧化、灰尘、划痕和旋钮磨损。主体是一台近方形的巡回收音机机器人，圆角广播机身略微前倾，正面中央是一枚大而清晰的圆形扬声器网，扬声器周围有一圈暗金色调谐环，右侧排列两枚粗短旋钮和一个不可读的几何频率指示窗，顶部伸出一根短天线与小型信号灯；下方连接两条短而灵活的机械腿或滚轮足，侧面有一支用于扫描维修轨道的细小探测臂。主色为收音机棕与暗铜色，辅助色为炭黑和旧米白，强调色为频率青，电子光集中在调谐环、天线端和扫描窗。只表现少量贴近机体的细窄信号光，不生成巨大声波、广播塔、音符、文字、数字、logo、人物或多个机器人，不要画成普通家用收音机。

### 4. 清扫无人机

**视觉定位**：轻型机动小怪，负责骚扰和补充数量。它的轮廓要轻、薄、快，核心识别点是圆角清扫壳体、折叠吸尘口和微尘过滤网，避免做成军用无人机或普通飞行器。

**可直接复制的提示词：**

> 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的清扫无人机，悬浮在画面中央，略微向右上方倾斜的 3/4 视角，主体占画布约 74%，四周留出稳定安全边距，透明背景或干净深灰蓝背景，不生成场景。日系二次元科幻游戏敌人原画，明快赛璐璐与未来工业设定感结合，清晰干净的外轮廓，轻量化工程塑料、磨砂金属、透明过滤网和柔性软管材质对比明确，少量薄荷绿净化指示光，轻微灰尘积累、碰撞擦痕和旧清扫设备磨损。主体是一台轻型清扫无人机，整体为扁平圆角六边形机壳，底部有一个明显的可伸缩吸尘口与短刷片，左右展开两片小型折叠稳定翼，后侧安装一块可以看见网格结构的微尘过滤仓，顶部有一个小型圆形污染扫描镜；机身下方悬挂两条短而柔韧的清扫软管，但不能形成杂乱线团。主色为雾灰白，辅助色为深灰蓝，强调色为净化绿与少量警示橙。整体轻巧、偏低空悬浮、带有向前冲刺的动势，但主体必须完整且清楚，不生成喷气战斗机、武器、螺旋桨、灰尘云、清扫场景、文字、数字、logo 或多个无人机。

### 5. 维修蜘蛛

**视觉定位**：支援型小怪，负责在天花板和维修管线之间移动。它需要有蜘蛛般的多足剪影，但本质是城市维护设备；关键识别点是八条细长机械腿、背部维修舱和自动焊接工具，避免出现真实昆虫的眼睛和生物质感。

**可直接复制的提示词：**

> 1:1 正方形游戏敌人 UI 立绘，单个怪物独立展示，主体是完整的维修蜘蛛机械体，位于画面中央，采用略微俯视的 3/4 视角，八条机械腿完整展开但不被边缘裁切，主体占画布约 80%，轮廓外留有安全边距，透明背景或干净深灰蓝背景，不生成场景。日系二次元科幻游戏敌人原画，霓虹废土·高光道具卡与未来工业设定感结合，半厚涂，清晰细线与圆润硬表面结构结合，金属关节、工程陶瓷外壳、柔性维修管线和透明焊接仓具有明确材质对比，冷白环境光、少量熔融橙功能高光，轻微油污、刮擦和反复维修留下的补焊痕迹。主体是一只城市设施维护用的机械蜘蛛，中央为扁圆的深灰维修舱，背部有一枚圆角透明观察窗，窗内可见短小的自动焊接头与卷收焊丝；八条细长但结实的机械腿从躯干四周对称伸出，每条腿由三段圆润关节组成，末端是可吸附墙面的软胶维修脚；前方两条腿改装成细小的夹持臂和低温焊接工具，侧面有几段整齐收束的柔性导管。主色为深石墨灰，辅助色为旧铜与陶瓷米白，强调色为熔融橙和少量维修青。姿态要像正在锁定一处故障、准备修补设备，不能生成真实昆虫、毛发、血肉、蜘蛛网、巨大焊接火焰、维修车间、文字、数字、logo 或其他机械。

## 三、统一验收要点

- 缩小到战斗 UI 中的敌人头像或小型立绘后，仍能只凭剪影区分五种敌人。
- 废品机器人最厚重朴素；电线杆机器人最细高；收音机机器人最圆；清扫无人机最轻薄；维修蜘蛛的多足结构最醒目。
- 五张图都只有一个完整主体，没有战斗背景、地面、人物、文字和额外单位。
- 机械都保留轻微旧化，但主色、功能部件和能源强调色仍然清楚，不被灰尘、锈蚀或发光效果淹没。
- 电子光只强调功能部件：废品机器人是识别面板，电线杆机器人是绝缘节与过载灯，收音机机器人是调谐环，清扫无人机是净化扫描镜，维修蜘蛛是焊接仓。
- 五种敌人共享同一套线稿、光照、材质和背景规则，放入战斗页面后应像同一座废弃大厦的自治设备。
