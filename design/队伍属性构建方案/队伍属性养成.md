# 队伍属性养成

> **状态**：方案记录，具体数值与天赋节点成本待平衡。

## 一、设计目标

队伍的初始手牌数量、抽牌数、换牌次数、待机次数、每回合费用上限和手牌上限，不通过装备或单一羁绊直接决定，而是由玩家根据当前队伍的个人卡组计划进行分配。

玩家应当能够围绕自己的牌组选择队伍特长，同时因为训练点有限而自然形成短板：

- 高费用牌组可以优先投资费用上限，但抽牌与手牌空间的成长会变慢。
- 速攻、弃牌或循环牌组可以优先投资抽牌与换牌，但费用上限不会同步提高。
- 需要囤牌、依赖弃牌数量或手牌数量的牌组可以优先投资手牌上限，但其他资源项目会被挤占。
- 依赖开局组件或前期铺场的牌组可以优先投资初始手牌数量，但后续每回合的补牌能力不会同步提高。

这种短板主要来自训练点的机会成本，不额外给天赋强行附加负面属性。

队伍属性构建分成两层：

1. **核心方向**：选择一个与当前牌组相符的小队徽章，决定队伍的基础属性改造和可用天赋树。
2. **训练点分配**：使用上阵角色卡组等级提供的训练点，在当前徽章的专属天赋树中继续定制队伍资源曲线。

核心方向不是羁绊，也不是装备词条；它描述的是这套牌组准备怎样运转。

## 二、训练点来源

每名角色根据自己的个人卡组等级获得训练点：

```text
角色训练点 = 该角色当前个人卡组等级
```

当前上阵队伍的总训练点为：

```text
小队训练点 = Σ 上阵角色的个人卡组等级
```

例如：

| 角色 | 个人卡组等级 | 提供训练点 |
|---|---:|---:|
| A 角色 | 2 | 2 |
| B 角色 | 3 | 3 |
| C 角色 | 1 | 1 |
| **小队合计** |  | **6** |

规则边界：

- 训练点来自个人卡组等级，而不是角色等级；本作角色本体仍然不设等级和属性点。
- 只计算当前上阵角色，未上阵角色不提供本次队伍的训练点。
- 训练点是当前队伍可分配的额度，不是消耗后永久减少的货币。
- 更换上阵角色后，队伍可用训练点随队伍构成变化。
- 个人卡组等级仍然承担提高卡牌获取稀有度概率的职责；训练点是它对队伍资源结构的第二层作用。

## 三、核心方向与小队徽章

### 3.1 核心方向的定位

玩家在据点的小队天赋页面中，为当前队伍选择一个「核心方向」。核心方向以一个**小队徽章**的形式展示，也可以被称为天赋树名称或基础方案名称。

小队徽章不是一件装备，不占装备槽；也不是羁绊，不参与装备羁绊计数。它是当前队伍对战斗牌组的整体运行方案。

每个小队徽章包含三部分：

| 组成 | 作用 |
|---|---|
| 基础改造 | 徽章激活后立即改变一至两项牌组基础属性，建立该方向的初始优势和限制 |
| 专属天赋树 | 该徽章独有的训练点投资路线，不同徽章不能共用同一棵完整天赋树 |
| 牌组适配条件 | 用来判断当前牌组是否真的属于该方向，避免任意牌组无条件获得强力方案 |

基础改造应当主要作用于以下队伍资源：初始手牌数量、抽牌数、换牌次数、待机次数、每回合费用上限和手牌上限。第一期不直接提高角色的 HP、攻击力、防御力等个人战斗属性，也不直接提高单张卡牌的伤害倍率。

### 3.2 选择与适配

核心方向由玩家手动选择，不由系统根据牌组自动替换。系统可以根据牌组中的卡牌类型、费用、效果和关键词统计出适配提示，但最终选择权交给玩家。

建议采用以下规则：

- 当前队伍只能激活一个小队徽章，避免多个基础方案的初始改造叠加。
- 每个徽章有一个基础适配条件，例如速攻牌、弃牌牌、高费牌或待机相关牌达到指定数量。
- 牌组不满足适配条件时，该徽章不能确认，或只能使用不完整的预览状态。
- 至少保留一个不要求特殊牌组条件的「均衡」徽章，避免混合牌组或新队伍没有可用方案。
- 徽章可以在据点重新选择；进入远征后锁定，不能在战斗前根据敌人临时更换。
- 更换徽章后，原徽章的训练点分配全部退回，再按照新徽章的专属天赋树重新分配。

这样玩家不是先拿一套固定数值，再被动接受系统判断，而是主动选择方向、调整牌组、满足适配条件，并在专属树中继续塑造特长。

### 3.3 徽章示例

以下名称和数值只用于说明结构，具体数值待平衡：

| 小队徽章 | 适配牌组 | 基础改造示例 | 专属天赋树示例 |
|---|---|---|---|
| **疾行徽章** | 速攻、低费、抽牌和费用恢复较多 | 抽牌数提高，手牌上限略受限制 | 预读、换牌、速攻循环 |
| **重载徽章** | 2 至 3 费牌、高倍率牌和终结牌较多 | 费用上限提高，抽牌或换牌效率受限制 | 蓄能、费用压缩、高费牌运转 |
| **储备徽章** | 弃牌、回收、保留手牌和手牌数量收益较多 | 手牌上限提高，基础抽牌速度较慢 | 扩容、回收、弃牌批次 |
| **观测徽章** | 待机、敌方意图、延迟触发和节奏牌较多 | 待机次数提高，直接费用爆发较弱 | 观测、等待、时刻调整 |
| **均衡徽章** | 没有明显单一方向的混合牌组 | 不提供明显初始偏向 | 六类资源的低阶混合路线 |

徽章的基础改造不必全部使用单纯的正负数。它也可以改变资源的获得顺序或某类牌的使用条件，但第一期应优先使用玩家能直接读懂的六项队伍资源，避免基础方案变成难以解释的隐藏规则。

## 四、小队天赋页面与专属天赋树

据点中增加「小队天赋」页面。页面展示当前上阵角色、各自卡组等级、训练点来源、当前小队徽章和队伍属性预览，并允许玩家分配训练点。

页面流程为：

1. 查看当前牌组的核心标签和可用小队徽章。
2. 选择一个小队徽章，查看它的基础属性改造与适配条件。
3. 进入该徽章专属天赋树，使用训练点解锁节点。
4. 在右侧预览最终的初始手牌、抽牌、换牌、待机、费用和手牌上限。
5. 确认后将方案锁定到当前远征；回到据点后才能重新选择和分配。

不同徽章的天赋树应当有不同的节点排列、前置关系和侧重点。即使两个徽章都存在“抽牌 +1”节点，它们的出现位置、训练点成本、前置条件和相邻节点也可以不同，不能只是换一个标题的同一棵树。

## 五、天赋节点规则

每棵专属天赋树由多个递进节点和分支组成。解锁节点后获得对应的牌组基础属性改造，后续节点需要额外训练点；具体节点数量、每级成本和最终上限待平衡。

建议每棵树至少包含：

| 结构 | 作用 |
|---|---|
| 核心节点 | 强化该徽章最主要的资源方向，例如疾行徽章的抽牌或重载徽章的费用上限 |
| 辅助分支 | 强化与核心方向配套的属性，例如抽牌配换牌、费用配手牌上限 |
| 取舍节点 | 在两个不同资源方向中选择一个，防止一棵树同时覆盖所有优势 |
| 终端节点 | 消耗较多训练点，形成明显的牌组特长；不应让所有终端同时可得 |

节点效果可以包括：

| 节点类型 | 示例效果 | 设计注意事项 |
|---|---|---|
| 初始手牌节点 | 战斗开始时初始手牌数量 `+1` | 只影响战斗开始，不影响后续每回合抽牌；成本应接近抽牌节点 |
| 抽牌节点 | 每回合基础抽牌数 `+1` | 强度较高，成本通常高于手牌扩容 |
| 换牌节点 | 每回合换牌次数 `+1` | 提高稳定性，应与抽牌节点区分成本 |
| 待机节点 | 每回合待机次数 `+1` | 增加节奏控制空间，不直接增加伤害 |
| 费用节点 | 每回合费用上限 `+1` | 最强资源节点，应后置或设置较高成本 |
| 手牌节点 | 手牌上限 `+1` | 作为较平滑的储备成长 |

建议天赋节点采用递增成本，而不是每个节点固定 1 点。例如同一分支的第二、第三个节点应比第一个节点昂贵；终端节点还需要前置节点或牌组适配条件，使玩家必须在“多个方向各拿一点”和“集中形成明显特长”之间做选择。

训练点只在当前徽章的天赋树中生效。它不是一套所有徽章共用的万能加点表，因此换徽章时会产生真正的构筑差异：同样拥有 6 点训练点，疾行徽章的 6 点和储备徽章的 6 点不会得到相同的队伍属性。

## 五、属性计算口径

小队天赋只提供全队基础修正，其他系统的效果仍按各自职责叠加：

```text
小队初始手牌数量 = 基础初始手牌数量(4) + 小队天赋初始手牌修正 + 其他合法全队修正
小队每回合抽牌数 = 基础抽牌数 + 小队天赋抽牌修正 + 其他合法全队修正
小队换牌次数 = 基础换牌次数 + 小队天赋换牌修正 + 其他合法修正
小队待机次数 = 基础待机次数 + 小队天赋待机修正 + 其他合法修正
小队费用上限 = 基础费用上限 + 小队天赋费用修正 + 战斗内合法修正
小队手牌上限 = 基础手牌上限 + 小队天赋手牌修正 + 其他合法全队修正
```

训练点分配不改变角色的 HP、攻击力、防御力、命中率、暴击率等个人战斗面板。

## 六、与现有系统的职责边界

| 系统 | 负责内容 |
|---|---|
| 个人卡组等级 | 提高该角色后续卡牌获取质量，并按等级提供小队训练点 |
| 小队天赋 | 把训练点转换为初始手牌、抽牌、换牌、待机、费用和手牌资源能力 |
| 装备 | 提供角色战斗属性与装备羁绊，不承担小队资源成长的主要来源 |
| 羁绊 | 提供装备构筑形成的队伍特色效果；不能垄断抽牌等基础资源入口 |
| 卡牌与关键词 | 提供战斗内的抽牌、弃牌、回收、费用恢复和临时资源变化 |

「愚者」羁绊可以继续强化抽牌方向，但不再是玩家获得额外抽牌的唯一途径。玩家即使选择其他羁绊，也能通过小队天赋投资抽牌；选择愚者则代表进一步强化抽牌构筑，而不是被迫支付抽牌的唯一门票。

## 七、典型构筑方向

以下只描述构筑逻辑，不锁定最终数值：

### 1. 高费爆发

优先投资费用回路，围绕 2 费、3 费和高倍率终结牌构筑。

- 优势：一回合能打出更重的牌，费用转化效率高。
- 短板：训练点不足以同时提高抽牌、换牌和手牌上限，关键牌不一定及时出现。

### 2. 高速循环

优先投资抽牌训练和换牌训练，围绕速攻、抽牌、弃牌触发和连续出牌构筑。

- 优势：更容易找到需要的牌，回合内行动选择更多。
- 短板：费用上限较低，手牌空间有限时容易出现抽到但无法全部利用的情况。

### 3. 储牌弃牌

优先投资手牌扩容，搭配弃牌、回收、手牌数量和弃牌批次相关卡牌。

- 优势：可以保留更多牌，等待费用、目标或弃牌条件成熟后集中爆发。
- 短板：抽牌和费用成长较慢，若没有有效的弃牌或回收手段，扩大的手牌空间不能自动转化为战力。

### 4. 节奏控制

优先投资待机训练，并搭配观察敌方行动、等待时刻或依赖回合条件的卡牌。

- 优势：拥有更多等待和调整节奏的机会，可以减少被迫提前结束回合的情况。
- 短板：待机本身不产生牌和费用，过度投资会牺牲直接资源能力。

### 5. 起手构筑

优先投资初始手牌训练，围绕需要尽早建立的组件、低费铺场牌和开局触发牌构筑。

- 优势：战斗开始时更容易同时拿到核心组件，减少前几轮完全无法展开的情况。
- 短板：初始手牌只在战斗开始生效，不能替代后续每回合抽牌；过度投资会牺牲持续运转能力。
