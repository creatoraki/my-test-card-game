# 初心者徽章

## 一、徽章基础属性

初心者徽章激活后立即获得以下固定属性，不消耗训练点：

| 属性 | 徽章基础加成 |
| --- | ---: |
| 初始手牌数量 | `+1` |
| 每回合基础抽牌数 | `+0` |
| 每回合换牌次数 | `+0` |
| 每回合待机次数 | `+0` |
| 每回合费用上限 | `+0` |
| 手牌上限 | `+0` |

初始手牌数量的系统基础值为 `4`，激活徽章后为 `5`。

## 二、训练方向

每个方向的节点数量和节点成本独立配置，不要求所有方向使用相同的节点数量。下表中的成本按节点顺序填写。

| 训练方向 | 提升属性 | 节点数量 | 各节点消耗训练点 |
| --- | --- | ---: | --- |
| 手牌扩容 | 手牌上限每节点 `+1` | 3 | `1、3、5` |
| 换牌训练 | 每回合换牌次数每节点 `+1` | 3 | `1、2、3` |
| 待机训练 | 每回合待机次数每节点 `+1` | 5 | `1、1、2、2、2` |
| 费用训练 | 每回合费用上限每节点 `+1` | 5 | `5、5、5` |
| 抽牌训练 | 每回合基础抽牌数每节点 `+1` | 3 | `3、4、5` |
| 起手训练 | 初始手牌数量每个节点 `+1` | 3 | `1、2、3` |

## 三、节点解锁与退还

以上节点在界面中排布为一棵以徽章为核心、六条方向链向外发散的**天赋树**（树形布局只为表达节点间的空间关系，不影响上表的数值与成本）：

- **链式前置解锁**：每条方向链的节点按顺序逐颗点亮 —— 首节点无前置、直接可点，其余节点必须已点亮其前一个节点才能投资。
- **单点退还**：已激活的节点可通过右键 / `Alt`+左键（键盘为 `Delete` / `Backspace`）退还其训练点；只有当退还后其余已激活节点仍满足前置依赖时才允许退还（即只能从链尾逐颗往回退）。
- **整树重置与切换徽章**：「重置分配」返还全部训练点并保留当前徽章；切换徽章会清空当前徽章的全部分配（训练点全部回到池子）。
- 进入远征后整棵树锁定为只读，返回据点才恢复分配。
