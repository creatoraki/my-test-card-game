# 装备与角色属性重构方案

> **状态：本轮已落地**
>
> 本文记录基础属性、战斗公式和装备随机模型的最终口径及实现边界。

---

## 一、目标与范围

本轮调整包括：

1. 将角色基础攻击力从 20 调整到 100，并保持 1.0 倍攻击牌约造成 20 点伤害。
2. 将角色基础防御力从 10 调整到 0，并重设防御减伤曲线。
3. 将装备从“每个稀有度固定一组属性”调整为“装备模型 + 随机模型值分配”。
4. 为装备建立五个升阶区间，并使每次升阶获得 4-5 点模型值。
5. 所有模型值分配使用整数；先手允许按半点模型值换算为 `0.5` 点属性，其余当前装备属性仍使用整数换算。

本轮不改变角色等级规则、卡组等级规则、卡牌固定伤害规则、装备槽位规则和装备羁绊规则。

### 1.4 模型值换算表

1 模型点约等于 1% 期望输出，换算系数以整数为主；先手按 2 点模型值换算为 1 点属性：

| 属性 | 每 1 模型点 | 结果单位 |
| --- | ---: | --- |
| 最大生命 `maxHp` | +1 | 固定值 |
| 攻击力 `attack` | +1 | 固定值 |
| 治愈力 `healPower` | +1 | 固定值 |
| 暴击率 `critRate` | +2 | 百分点 |
| 爆伤 `critDamage` | +2 | 百分点 |
| 命中率 `hitRate` | +1 | 百分点 |
| 精准 `precision` | +2 | 百分点 |
| 穿甲 `armorPen` | +1 | 固定值 |
| 防御力 `defense` | +1 | 固定值 |
| 先手 `initiative` | +0.5 | 固定值 |

其中最大生命和防御力按 1:1 换算：角色基础最大生命 50、防御常量 50 时，模型点对有效生命的影响量级约为 2%，与其他固定属性的强度口径一致。治愈力、格挡、闪避等属性留到防具和饰品重新上线后再定。

## 三、攻击力与伤害公式

### 3.1 推荐公式

攻击倍率类效果使用：

$$
D_{raw} = \frac{A}{5} \times M
$$

其中：

- $A$ 为攻击者最终攻击力；
- $M$ 为卡牌或技能声明的攻击倍率；
- $D_{raw}$ 为进入命中、暴击、防御和格挡流程前的伤害。

当角色攻击力为 100、卡牌倍率为 1.0 时：

$$
100 \div 5 \times 1.0 = 20
$$

因此，“1AP = 20 点伤害”应理解为 **1AP、1.0 倍攻击牌的基准伤害为 20**。低于 1.0 倍的牌仍可低于 20 点，高于 1.0 倍的牌仍可高于 20 点。

推荐保留现有结算顺序：

```text
状态修正 → 命中 → 暴击 → 防御 → 格挡 → 护盾 → HP
```

伤害在完整管线结束前允许保留小数，最终落地前继续统一使用 `Math.round`。模型值和装备面板不允许使用小数，不等于战斗中间值不能出现小数。

### 3.2 固定伤害与倍率伤害的边界

- `multiplier` 伤害使用 `攻击力 ÷ 5 × 倍率`。
- `amount` 固定伤害不使用攻击力，仍然跳过防御和格挡，但仍可被护盾吸收。
- 暴击仍然在命中后判定；暴击倍率仍读取最终爆伤。
- 卡牌升级、弱化、锋利、易伤等现有伤害修正的职责不变。

### 3.3 与现有卡牌文档的冲突

当前卡牌数值文档写过“1AP 标准为 90%”，而本方案把“1AP = 20”对应到 1.0 倍攻击牌。两种口径不能同时作为同一个基准：

- **方案 A，推荐**：保留 `攻击力 ÷ 5`，把 1.0 倍定义为 1AP 的 20 点标准；0.9 倍牌就是约 18 点。
- **方案 B**：坚持 0.9 倍就是 1AP 标准 20 点，则公式应改为 `攻击力 ÷ 4.5 × 倍率`，与本轮提出的“攻击/5”不一致。

当前草案按方案 A 记录。

## 四、防御力与减伤公式

### 4.1 推荐公式

先计算穿甲后的有效防御力：

$$
X = \max(0,\text{目标防御力} - \text{攻击者穿甲})
$$

防御减伤比例为：

$$
R_{def} = \frac{X}{X+50}
$$

最终承伤倍率为：

$$
M_{def} = 1-R_{def}=\frac{50}{X+50}
$$

这个公式在基础防御力为 0 时不会凭空减伤，并且随着防御增加逐步递减收益。

### 4.2 减伤示例

| 有效防御力 X | 减伤比例 | 承伤倍率 |
| ---: | ---: | ---: |
| 0 | 0% | 100% |
| 10 | 16.7% | 83.3% |
| 25 | 33.3% | 66.7% |
| 50 | 50% | 50% |
| 100 | 66.7% | 33.3% |

防御力仍然只影响非固定伤害；固定伤害继续跳过防御和格挡。穿甲仍然只抵扣防御，不会把防御转化为负数。

### 4.3 防御装备的影响

防御常量从 30 改为 50 后，旧装备中的防御数值不能直接视为平衡完成。例如：

- 防御力 +5 时，减伤约为 9.1%；
- 防御力 +10 时，减伤约为 16.7%；
- 防御力 +20 时，减伤约为 28.6%。

因此，防具和带防御词条的饰品需要在模型值换算表确定后重新评估，不能只把角色基础防御从 10 改成 0 而保留全部旧装备数值。

## 五、装备随机模型

### 5.1 三层结构

建议把装备拆成三层：

1. **装备模型 `familyId`**：确定名称、装备槽、可出现的词条、词条方向和各阶的模型值容量。
2. **装备阶位**：确定模型值总量区间。建议直接复用现有五档物品稀有度：一阶对应普通，二阶对应精良，三阶对应稀有，四阶对应史诗，五阶对应传说。
3. **装备实例随机结果**：记录这件具体装备实际获得的总模型值、各词条分配值和换算后的最终属性。

`ItemDef` 继续描述静态模型；随机结果必须保存到 `ItemStack` 或与其等价的装备实例数据中。不能只在 `ItemDef` 上记录随机属性，否则同一模型的所有装备会共享同一组数值。

### 5.2 模型值区间

| 阶位 | 建议代码映射 | 模型值总量 |
| ---: | --- | ---: |
| 一阶 | `common` | 5-10 |
| 二阶 | `fine` | 9-15 |
| 三阶 | `rare` | 13-20 |
| 四阶 | `epic` | 17-25 |
| 五阶 | `legendary` | 21-30 |

初次生成装备时，在对应区间内等概率抽取一个整数 $M$：

$$
M \in [M_{min},M_{max}] \cap \mathbb{Z}
$$

### 5.3 升阶规则

推荐升阶时保留原有词条分配，只增加模型值：

$$
M_{next}=M_{current}+\operatorname{randomInt}(4,5)
$$

这会自然得到以下区间：

- 一阶 5-10 升二阶后为 9-15；
- 二阶 9-15 升三阶后为 13-20；
- 三阶 13-20 升四阶后为 17-25；
- 四阶 17-25 升五阶后为 21-30。

推荐每次升阶只把新增的 4 或 5 点随机分配给该模型允许的词条，已有词条不会被随机扣除。这样升阶一定是变强，装备仍然保留刷词条分布的价值。

为了保证追加分配始终有位置，各阶的词条上限必须随阶位提高。模板设计时应满足：

```text
该阶所有词条最低分配值之和 ≤ 该阶模型值下限
该阶所有词条最高分配值之和 ≥ 该阶模型值上限
下一阶的可用容量足以容纳当前分配 + 4-5 点
```

不推荐升阶时把全部词条重新随机：那会导致升阶后某个已满意的词条变差，玩家难以判断升级收益。

### 5.4 整数模型点分配规则

设装备模型允许的词条为 $i=1...n$，每个词条的模型分配值为 $p_i$：

$$
\sum_{i=1}^{n}p_i=M
$$

并满足：

$$
 p_i\in\mathbb{Z}_{\ge 0}
$$

词条换算为实际属性时使用换算系数 $k_i$：

$$
 v_i=p_i\times k_i
$$

模型点 $p_i$ 始终为整数；当前只有先手使用 `0.5` 换算系数，因此奇数模型点可能产生 `0.5` 点先手，其余属性仍保持整数。需要更细的平衡粒度时，优先扩大模型总量或把属性单位改成更小的整数单位。

### 5.4.1 词条权重与块状投放

三条词条按声明顺序使用主词条、副词条、第三词条的权重 `3 / 2 / 1`。每次投放只从尚未达到上限的词条中按权重抽取，因此主词条的期望分配高于副词条，副词条又高于第三词条；权重不会改变模型总预算。

模型值不再逐点投放，而是按块投放。第 `index` 阶的块大小为 `randomInt(2, 2 + index)`，最后一块不足时取剩余值。这样高阶装备的分配次数更少、单次波动更大，同时仍满足：

```text
所有词条模型值之和 = 装备实例的正向模型值总量
每条词条模型值不低于模板下限且不超过模板上限
```

普通武器的词条上限按位阶使用主 `5 + 3·index`、副 `4 + 2·index`、第三 `3 + index`。极端武器使用更宽的主 `6 + 4·index`、副 `5 + 3·index`、第三 `3 + 2·index`，用于容纳代价返还后的正向预算。升阶沿用同一套块状投放函数，不重新随机已有正向分配；基础追加为 4-5 点，另加新旧返还值的差额。

### 5.4.2 代价词条预算返还

极端武器的代价词条按阶提供固定正数代价点 `c`，写入装备实例时以负数保存；正向可分配预算为：

$$
M = randomInt(M_{min}, M_{max}) + r
$$

其中 `r` 为按阶固定的返还模型值。一至二阶为 `2`，三至四阶为 `3`，五阶为 `4`。装备详情展示代价点总量与实际返还点数。升阶会把负面词条重置为新阶固定代价，并将返还差额与追加的 4-5 点一起分配到正向词条。

代价属性必须通过代码白名单校验，只允许 `maxHp`、`initiative`、`healPower`、`critDamage`、`hitRate`。防御、闪避、格挡和精准等属性在当前公式中存在 `Math.max(0, …)` 截断或不具备足够的正向基础值，做成负向代价可能不会产生实际损失，却会错误返还预算；模板声明这些代价时必须直接报错。

### 5.5 模型值换算实现

| 实际属性 | 每 1 点模型值换算 | 结果单位 |
| --- | ---: | --- |
| 最大生命 `maxHp` | 1 | 最大生命 +1 |
| 攻击力 `attack` | 1 | 攻击力 +1 |
| 治愈力 `healPower` | 1 | 治愈力 +1 |
| 暴击率 `critRate` | 2 | 暴击率 +2 个百分点 |
| 爆伤 `critDamage` | 2 | 爆伤 +2 个百分点 |
| 命中率 `hitRate` | 1 | 命中率 +1 个百分点 |
| 精准 `precision` | 2 | 精准 +2 个百分点 |
| 穿甲 `armorPen` | 1 | 穿甲 +1 |
| 防御力 `defense` | 1 | 防御力 +1 |
| 先手 `initiative` | 0.5 | 先手 +0.5 |

所有概率类属性仍使用百分点存储，例如命中率 +6 表示 +6%，而不是 0.06。

### 5.6 五个正向武器族的词条分配

五个纯正向武器族均使用三条词条，顺序为主词条、副词条、第三词条，权重为 `3 / 2 / 1`；每阶最低分配为 `2 / 2 / 1`，上限按词条位阶分化：主 `5 + 3·index`、副 `4 + 2·index`、第三 `3 + index`。拳套的第三词条为治愈力，用于让武器承担低配额的续航构筑。

| 族 | 名称 | 主词条 | 副词条 | 第三词条 |
| --- | --- | --- | --- | --- |
| `deflection-blade` | 太刀 | 攻击力 | 命中率 | 暴击率 |
| `armor-piercing-crossbow` | 穿甲弩 | 攻击力 | 穿甲 | 命中率 |
| `quickstrike-gauntlet` | 拳套 | 攻击力 | 先手 | 治愈力 |
| `hunting-rifle` | 狙击枪 | 暴击率 | 攻击力 | 爆伤 |
| `hunter-longbow` | 弓箭 | 穿甲 | 暴击率 | 攻击力 |

### 5.7 太刀示例：三条词条与分配约束

太刀使用三条词条，并把示例数值理解为“一阶各词条允许分配的模型值范围”：

```text
攻击力 [2-5]
命中率 [2-5]
暴击率 [1-3]
```

一阶最低分配值为 `2 + 2 + 1 = 5`，正好对应一阶模型值下限；一阶最高容量为 `5 + 5 + 3 = 13`，可以容纳一阶最多 10 点模型值。实际生成时仍以装备总模型值为准，不会因为三个词条都达到上限而超过 10 点。

高阶不应继续使用一阶的固定上限。可以沿用相同的最低分配值，并逐阶扩大上限，例如：

| 阶位 | 攻击力模型值 | 命中率模型值 | 暴击率模型值 | 词条容量合计 | 总模型值 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 一阶 | 2-5 | 2-5 | 1-3 | 5-13 | 5-10 |
| 二阶 | 2-8 | 2-6 | 1-4 | 5-18 | 9-15 |
| 三阶 | 2-11 | 2-8 | 1-5 | 5-24 | 13-20 |
| 四阶 | 2-14 | 2-10 | 1-6 | 5-30 | 17-25 |
| 五阶 | 2-17 | 2-12 | 1-7 | 5-36 | 21-30 |

这里的范围是模型点分配范围，不是最终属性范围。比如一件一阶太刀随机到 8 点模型值，可以分配为：

```text
攻击力 3 点模型值 → 攻击力 +3
命中率 3 点模型值 → 命中率 +3 个百分点
暴击率 2 点模型值 → 暴击率 +4 个百分点
```

三条词条并不是额外赠送的属性；每增加一条词条，都会分走同一笔模型预算。其他武器也可以使用两条、三条或更多词条，但必须通过同样的最低值、最大容量和升阶容量校验。

## 六、装备刷取与随机性的建议边界

### 6.1 随机发生的时机

- 装备掉落、商店生成或其他产生新装备实例时，第一次生成随机模型值和词条分配。
- 装备进入背包或仓库后，随机结果固定，并随实例持久化。
- 战斗中穿戴同一件装备时只读取已经保存的属性，不重新随机。
- 探索中的可复现掉落应使用探索 RNG；商店如果继续沿用独立随机，则装备随机也应遵循商店现有随机边界。

### 6.2 刷取价值

随机性应主要带来“同一模型的分布差异”，而不是让低阶装备无条件超过高阶装备。建议满足：

- 高阶装备的模型值总量区间整体向上，但允许与相邻阶位少量重叠；
- 装备模型决定可用词条，随机结果不能引入模型未声明的属性；
- 升阶不会减少已有词条；
- 词条最终属性全部可读、可比较，并在装备详情中显示模型值分配；
- 同一装备模型的随机结果不改变装备名称、槽位和羁绊归属。

### 6.3 极端加成型装备

极端武器与普通武器一样使用装备模型和随机实例，但额外声明一条代价词条。三族的正向词条分别为：匕首“暴击率 / 攻击力 / 命中率”，火炮“攻击力 / 穿甲 / 爆伤”，盾斧“生命上限 / 治愈力 / 攻击力”。代价分别为：匕首生命上限，火炮命中率，盾斧先手。

单条代价词条在一至五阶固定为 `3 / 3 / 4 / 4 / 5`，对应固定返还模型值 `2 / 2 / 3 / 3 / 4`。正向词条使用更宽的上限：主 `6 / 10 / 14 / 18 / 22`，副 `5 / 8 / 11 / 14 / 17`，第三 `3 / 5 / 7 / 9 / 11`。

代价以负数写入实例，正向模型值再按 `基础预算 + 固定返还` 计算。升阶将负面词条更新为新阶代价，返还差额与 4-5 点正向模型值一并追加。原有固定 `mods` 数值整体移除，不与新模型并存。

- [x] 五阶模型值区间为 5-10、9-15、13-20、17-25、21-30。
- [x] 升阶每次增加 4-5 点模型值。
- [x] 模型分配必须是整数。
- [x] 攻击力 1 模型值换算为攻击力 +1。
- [x] 暴击率和爆伤 1 模型值分别换算为 +2 个百分点。

### 7.2 已定稿

1. 1AP 的标准攻击倍率定为 1.0；0.9 倍攻击牌按约 18 点基准伤害结算。
2. 五个纯正向武器族各使用三条词条，具体分配见 §5.6；拳套第三词条为治愈力。
3. 升阶保留已有分配，并随机追加 4 或 5 点模型值。
4. 本轮登记攻击力、暴击率、爆伤、命中率、精准、穿甲和先手的换算系数，见 §1.4。
5. 随机装备固定三条词条，最低分配为 `2 / 2 / 1`，不允许 0 点词条。
6. 普通武器各阶上限使用主 `5 + 3·index`、副 `4 + 2·index`、第三 `3 + index`，并按 `3 / 2 / 1` 权重块状投放。
7. 极端武器使用独立的加宽正向上限与按阶固定的代价返还，负面词条每件最多一条。
8. 直接复用现有五档稀有度作为一至五阶，不新增独立阶位字段。
