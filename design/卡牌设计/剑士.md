# 剑士卡牌设计

> **状态**：弃牌与速攻的卡牌功能模型草案。
>
> 本文只记录剑士的卡牌功能、关键词和个人卡池方向。角色属性、卡组等级、稀有度限携与养成边界见 [角色养成设计.md](../角色养成设计.md)。

## 一、角色关键词

剑士同时使用“弃牌”和“速攻”两个关键词，但卡牌分为两种模型：

1. **单机制模型**：一张牌只服务弃牌或速攻其中一个机制，负责提供稳定的基础功能。
2. **混合机制模型**：一张牌让弃牌与速攻产生明确的因果关系，负责提供构筑上限。

两者的典型循环是：**速攻启动 → 主动弃掉低模牌 → 弃牌触发自动攻击 → 用普通牌完成追击**。玩家需要在“现在打出这张牌”和“先把它弃掉触发额外价值”之间做选择。

### 1.1 速攻

速攻负责在敌人行动前制造低承诺动作。速攻牌不推进时刻，但不能默认等价于“免费高效率牌”；它应通过低倍率、弃牌代价、目标限制或一次性效果承担机会成本。

### 1.2 弃牌

弃牌不是“卡牌离开手牌时触发一次效果”，而是一整套围绕手牌与弃牌堆展开的操作语言。它可以是支付成本、主动动作、手牌整理、牌库筛选、弃牌堆资源、战斗历史、临时状态、风险选择或牌型转换。被弃置时触发特效只是其中一种表现，剑士的卡牌还应大量利用“为什么弃、弃什么、从哪里弃、弃到哪里、弃完之后改变什么”。

## 二、弃牌触发规则

“进入弃牌堆”与“被弃置”必须区分，否则所有普通攻击都会在打出后再次触发，关键词会退化为无条件额外伤害。

这里的规则只定义“被弃置时触发”这一条子机制，不代表所有弃牌卡都需要监听弃牌事件。主动弃牌、弃牌作为费用、查看后选择弃牌、操作弃牌堆、读取本回合弃牌历史等功能，都可以独立成立。

| 事件 | 是否触发“被弃置时” | 说明 |
| --- | --- | --- |
| 玩家主动点击弃牌 | 是 | 最明确的主动决策，触发弃牌牌的完整效果。 |
| 重抽一张牌导致原牌进入弃牌堆 | 否 | 重抽是剑士的重要启动窗口；每回合重抽次数仍受全局规则限制。 |
| 其他卡牌或效果指定弃置 | 是 | 这是弃牌启动器的主要用途。 |
| 回合结束自动清空手牌 | 否，仅限明确标注可触发 | 默认牌不因回合清手触发；卡牌可写“回合清手也触发”作为额外标签。 |
| 普通打出后进入弃牌堆 | 否 | 这是打出后的归堆，不是被弃置，防止攻击牌无条件双倍结算。 |
| 打出后进入消耗堆（`exhaust`） | 否 | 消耗堆与弃牌堆不同；除非卡牌另写“消耗时触发”。 |
| 弃牌堆洗回抽牌堆 | 否 | 洗牌只改变区域，不产生新的弃牌决策。 |

弃牌触发牌的默认结算规则：

- 触发效果不消耗法力、不额外推进时刻，但伤害仍走正常的命中、暴击、防御、格挡与护盾管线。
- 自动使用必须声明目标策略。默认使用 `randomFoe`，避免玩家在弃牌动作中还要额外点选目标；高稀有度牌可以写“上一次速攻命中的目标”或“最低生命敌人”。
- 同一张卡牌实例在同一个弃牌事件中最多触发一次；自动使用自身不会再次触发自身的弃牌效果。一个弃牌效果可以继续弃置其他牌，但每张牌仍按各自实例各触发一次。
- 弃牌触发发生在卡牌离开手牌并登记到弃牌堆时。触发前先标记该卡已处理，防止触发过程中重复访问再次结算。
- 自动使用的效果应短、单一、可预期。普通牌优先只提供一次攻击或一次小型资源转换，不在同一张普通牌上叠加大量抽牌、增伤和连锁弃牌。

## 三、单机制模型

单机制牌只围绕一个关键词提供输入、输出或回报，不要求玩家同时满足另一个关键词。它们是卡组的基础骨架，抽到时即使没有配套牌也能正常工作。

| 单机制分支 | 典型职责 | 推荐牌型 | 首版模型预算 |
| --- | --- | --- | --- |
| **单弃牌** | 让一张牌被弃置时产生独立价值，或主动弃牌换取抽牌、资源、护盾。 | 普通牌为主 | 弃牌载荷手动约 `0.65~0.85` 倍攻击，被弃置时追加约 `0.35~0.60` 倍攻击；弃牌启动器的附加收益只取抽牌、资源、护盾其中一项。 |
| **单速攻** | 提供不推进时刻的小攻击、短时增益或防御窗口。 | 速攻牌 | `0~1` 费、约 `0.30~0.70` 倍攻击，或一次小额增益；不读取弃牌数量、不要求本回合已经弃牌。 |

单机制牌的设计原则：

- 单弃牌牌即使本回合没有速攻牌，也应能通过主动弃牌、重抽或普通弃牌按钮发挥作用。
- 单速攻牌即使卡组没有任何弃牌牌，也应能凭“不推进时刻”提供合理但有限的价值。
- 单机制牌可以是低模攻击、抽牌、资源或小额防御，但不能在描述中偷偷同时读取两个关键词；否则应归入混合机制模型。
- “略微亏模普通攻击，被舍弃时自动使用”属于**单弃牌模型**，因为它只关心这张牌是否被弃置，不要求先打出速攻，也不改变速攻状态。

## 四、混合机制模型

混合机制牌必须让弃牌和速攻互相产生明确的因果关系，而不是简单地同时写上两个标签。它们负责提供构筑上限，通常放在罕见和稀有卡池中。

| 混合方向 | 典型职责 | 推荐牌型 | 首版模型预算 |
| --- | --- | --- | --- |
| **速攻 → 弃牌** | 用不推进时刻的动作主动弃置载荷牌，立即触发弃牌收益。 | 速攻牌 | `0~1` 费，弃置 1 张指定手牌；附带抽 1 或小额攻击，不再额外给高额增伤。 |
| **弃牌 → 速攻** | 弃牌后让下一张速攻获得强化、返还资源或追加攻击。 | 速攻/普通均可 | 每回合首次弃牌只强化下一张速攻一次，例如伤害 `+20%`、获得 `1` 点资源或追加 `0.25~0.40` 倍攻击。 |
| **双关键词终结** | 先用速攻和弃牌完成准备，再把两者累计值转为一次终结攻击。 | 稀有普通牌 | `2~3` 费、基础约 `1.6~2.0` 倍攻击；按本回合弃牌数或速攻次数取较低者计算，最多计 3~4 次。 |

混合机制牌必须满足以下限制：

- 文本中要能读出哪个动作触发哪个收益，不能只写“弃牌时获得速攻效果”这类无法判断顺序的描述。
- 混合牌的基础效果应略低于同费用单机制牌；完整价值来自玩家确实完成了另一关键词的前置动作。
- 同一张牌最多承担一条主要转化链，例如“速攻后弃牌并触发”可以成立，但不再同时叠加“弃牌后抽牌、加暴击、再返还费用”。
- 混合牌不应成为单机制牌的替代品。单机制牌负责稳定性，混合机制牌负责上限；两者都需要出现在同一套剑士卡池中。

剑士的少量生存功能也遵循这两个模型：单机制生存牌可以是“速攻后获得小额护盾”或“弃牌后获得一次格挡”；混合机制生存牌才可以写成“速攻弃牌后获得护盾”。不建议加入与两个关键词都无关的纯护盾、纯治疗牌。

## 五、首版个人卡池配额

沿用当前剑士专属卡池的 **普通 6 / 罕见 2 / 稀有 1** 规模，同时保证单机制与混合机制都能被抽到：

| 稀有度 | 建议槽位 | 模型职责 |
| --- | ---: | --- |
| 普通 | 6 | 单机制 4 张：单弃牌 2 张、单速攻 2 张；混合机制 2 张：速攻 → 弃牌 1 张、弃牌 → 速攻 1 张。 |
| 罕见 | 2 | 混合机制 1 张：强化速攻 → 弃牌；单机制或混合机制 1 张：强化下一张速攻或弃牌回报。 |
| 稀有 | 1 | 双关键词终结 1 张：同时读取本回合的弃牌数与速攻次数，并使用较低值计数。 |

当前已有卡牌可以按这个二分模型重新定位：`quick-slash` 是单速攻基准；`battle-cry` 可以改成单速攻增益或弃牌 → 速攻的混合牌；`guard-stance`、`shield-bash`、`second-wind` 至少应有一张改成单弃牌生存牌、一张改成混合机制生存牌，剩余卡位再补足单机制攻击，避免剑士卡池回到通用防御牌集合。

## 六、功能可能性模板

以下内容只讨论“卡牌可以提供什么功能”和“玩家会面对什么选择”，不是最终卡名、卡面文本或数值定稿。费用、伤害倍率、抽牌量、资源量、持续时间、触发上限、稀有度与是否消耗，都应在功能方向确定后再单独平衡。

### 6.1 弃牌关键词的功能维度

设计弃牌卡时，先确定卡牌使用的是哪一种“弃牌语义”，再决定它是否需要被弃置触发。下面的维度可以单独使用，也可以在高复杂度卡牌中组合，但一张牌仍应有清晰的主要决策。

| 弃牌语义 | 卡牌功能可能性 | 玩家真正做出的选择 |
| --- | --- | --- |
| 弃牌作为支付成本 | **断价**：支付资源之外，还必须牺牲手牌来换取强力攻击、防御或特殊行动。 | 保留手牌质量，还是把手牌当作当前回合的行动成本。 |
| 弃牌作为主动动作 | **弃锋**：卡牌的主要效果就是让玩家选择手牌并将其弃置，然后执行抽换、移动、攻击或防御。 | 选择弃掉哪张牌，而不是等待某张牌被动触发。 |
| 弃牌作为条件开关 | **开刃**：只要发生过符合条件的弃牌，某类卡牌就改变形态、目标或使用方式。 | 先弃牌准备状态，还是直接保留当前资源完成别的动作。 |
| 弃牌作为战斗历史 | **留痕**：记录本次战斗弃过的牌的类型、来源、目标或顺序，供后续卡牌读取。 | 弃牌不再只是瞬时收益，而是会影响整场战斗的路线。 |
| 弃牌作为数量压力 | **堆势**：弃牌越多，后续效果越偏向攻击、抽换、防御或终结。 | 是集中弃牌快速进入高收益状态，还是分散弃牌维持手牌质量。 |
| 弃牌作为类型筛选 | **择刃**：根据攻击牌、防御牌、速攻牌、临时牌、诅咒牌等类型决定弃牌后的结果。 | 选择牌的功能类别，而不只是选择一张当前价值最低的牌。 |
| 弃牌作为属性筛选 | **断弱**：依据费用、稀有度、标签、强化状态、临时状态或来源筛选可弃牌对象。 | 牺牲低质量牌、未完成牌或高价值牌，换取不同层级的收益。 |
| 弃牌作为牌库操作 | **洗锋**：从牌库查看、抽取、替换、过滤或安排牌，然后把不需要的部分送入弃牌堆。 | 用弃牌主动塑造接下来会抽到的内容，降低随机性。 |
| 弃牌作为手牌整理 | **整列**：弃掉不适合当前局面的牌，再补充、重排或交换手牌。 | 在即时战斗价值与未来抽牌质量之间取舍。 |
| 弃牌作为弃牌堆操作 | **回刃**：从弃牌堆选择牌、调整顺序、标记牌、移除牌或把牌送回其他区域。 | 弃牌堆成为可经营的资源区，而不是单纯的回收终点。 |
| 弃牌作为牌型转换 | **炼形**：弃掉一张牌后，把它转化为速攻、普通攻击、防御、临时牌或另一种标签。 | 决定一张牌在当前战斗中应该保持原本功能，还是转成急需的功能。 |
| 弃牌作为效果转移 | **借锋**：弃掉的牌不结算自身效果，而是把攻击、护盾、标记、抽换等性质转移给另一张牌或下一次行动。 | 让低价值牌成为高价值牌的强化材料。 |
| 弃牌作为临时资源 | **余势**：弃牌后留下可被后续卡牌消耗的势、印记、战意或行动窗口。 | 选择立即兑现弃牌收益，还是储存成更强的后续行动。 |
| 弃牌作为随机风险 | **乱刃**：随机弃牌换取范围攻击、异常效果或不可预测的战术收益。 | 以手牌确定性换取爆发上限；随机规则必须让玩家能预估风险范围。 |
| 弃牌作为定向风险 | **孤锋**：玩家主动选择高价值牌作为牺牲品，换取稳定且明确的强力效果。 | 不是被系统随机惩罚，而是由玩家决定愿意付出什么代价。 |
| 弃牌作为时机动作 | **抢鞘**：在敌人行动前、受到攻击后、敌人获得增益时或回合收束时进行弃牌，产生不同结果。 | 同一张牌的价值取决于弃牌时机，而不是只取决于牌面强度。 |
| 弃牌作为顺序系统 | **连断**：弃牌的先后顺序会影响准备、结算、目标或下一张牌的性质。 | 安排弃牌顺序，避免把所有弃牌动作压缩成没有差别的按钮。 |
| 弃牌作为区域选择 | **落点**：选择把牌送入弃牌堆、消耗堆、牌库、手牌或特殊区域，不同去处对应不同后续价值。 | 决定这张牌是暂时离场、永久移除，还是为后续循环保留入口。 |
| 弃牌作为手牌上限处理 | **卸载**：手牌过满、抽牌过量或获得临时牌时，将多余牌转为资源、防御或牌库整理。 | 将“手牌溢出”从纯损失变成可利用的剑士节奏。 |
| 弃牌作为失败保护 | **留退**：攻击未命中、目标消失、效果被抵抗或敌人提前死亡时，把原本的行动转化为弃牌收益。 | 降低速攻和弃牌连锁在特殊战况下完全落空的挫败感。 |
| 弃牌作为对手干扰 | **夺意**：在满足战斗条件时迫使敌人放弃增益、取消准备、丢失行动选项或改变意图。 | 让“弃牌”概念可以延伸为剥夺对手选择，但需要和玩家弃牌使用明确区分。 |

因此，卡牌文案中的“弃牌”至少可以对应以下不同动词：**支付、选择、筛选、抽换、堆积、记录、回收、转化、转移、储存、排序、落区、溢出处理与干扰**。只有其中明确写出“被弃置时”的卡牌，才属于弃牌触发牌。

### 6.2 单机制：围绕弃牌运作

这类卡牌不要求玩家先使用速攻，也不改变速攻状态。它们可以主动制造弃牌、把弃牌当成成本、管理弃牌堆、读取弃牌历史，或者在被弃置时触发效果；“手动使用与被弃置之间的取舍”只是其中一种设计。

| 功能方向 | 卡牌可能性 | 玩家选择与可玩空间 |
| --- | --- | --- |
| 弃牌自动攻击 | **残锋**：手动使用时是偏低承诺的普通攻击；被弃置时自动攻击敌人。 | 玩家可以把它当作普通攻击，也可以把它留在手中等待弃牌收益；目标可以是原目标、随机敌人、生命最低敌人或最近一次被速攻命中的敌人。 |
| 弃牌追击 | **回鞘**：被弃置时攻击最近受到剑士伤害的敌人，或对带有剑士标记的敌人追加效果。 | 让弃牌动作具有追踪感，减少随机目标带来的失控，同时鼓励玩家安排攻击顺序。 |
| 弃牌施加状态 | **裂痕**：被弃置时给敌人施加破甲、易伤、流血、标记或削弱攻击的状态。 | 不直接追求伤害，而是把暂时打不出的牌转成后续回合的战术铺垫。 |
| 弃牌提供防御 | **藏锋**：被弃置时获得格挡、护盾、闪避窗口或降低下一次受到的伤害。 | 让弃牌成为防御按钮，玩家需要在保留攻击手段和提前处理危险之间取舍。 |
| 弃牌提供资源 | **蓄势**：被弃置时恢复资源、减少后续牌的使用负担，或为下一次普通攻击积累力量。 | 适合构成“主动弃掉亏模牌，换取高质量回合”的资源循环。 |
| 弃牌改变抽牌 | **断念**：被弃置时补充手牌，或让下一次抽牌优先抽取速攻牌、攻击牌或特定标签牌。 | 让玩家通过弃牌整理手牌，而不是单纯等待随机抽牌。 |
| 弃牌回收 | **归刃**：被弃置时把另一张牌送回手牌、抽牌堆顶或可再次使用的区域。 | 可以保护关键牌，也可以把低价值牌当作回收链的入口；需要谨慎处理循环触发。 |
| 弃牌换目标 | **引锋**：被弃置时改变敌人的锁定、攻击意图或仇恨目标，或迫使敌人暴露弱点。 | 把弃牌从输出行为扩展为战场控制，给剑士处理高威胁敌人的非伤害手段。 |
| 特定条件弃牌 | **断势**：只有在手牌满足某种状态、敌人处于某种状态或自身濒危时，被弃置效果才完全展开。 | 形成“现在弃掉还是继续保留”的判断，而不是所有弃牌时机都等价。 |
| 弃牌后的替代使用 | **空手式**：被弃置时不攻击，而是把这次弃牌转化为一次特殊动作，例如移动、净化自身状态或取消敌人的强化。 | 让弃牌牌不被固定成自动伤害，扩大剑士的战术表达。 |

### 6.3 单机制：只提供速攻

这类卡牌只利用“不推进时刻”的价值，不读取弃牌数量、不要求手里有弃牌载荷，也不因为弃牌而变强。它们是剑士在敌人行动前争取主动权的基础工具。

| 功能方向 | 卡牌可能性 | 玩家选择与可玩空间 |
| --- | --- | --- |
| 速攻直伤 | **疾刺**：对单个目标进行快速攻击，重点是抢在敌人行动前处理威胁。 | 可以作为稳定的补刀手段，也可以用来触发敌人的受击反应或维持攻击节奏。 |
| 速攻多目标 | **横断**：快速攻击多个敌人，或让玩家在多个目标之间分配攻击。 | 适合处理群体敌人，但单个目标的压制力应由其他牌承担。 |
| 速攻补刀 | **追命**：只对低生命、带有负面状态或刚刚受到伤害的敌人发挥完整效果。 | 鼓励玩家先用普通牌或弃牌触发牌制造条件，再用速攻完成收尾。 |
| 速攻防御 | **掠身**：速攻后获得闪避、格挡、护盾，或降低敌人下一次攻击的威胁。 | 让速攻不只是攻击效率，也能在敌人即将行动时提供防御窗口。 |
| 速攻扰乱 | **截势**：速攻后削弱敌人意图、延后其强化、打断蓄力或移除一个增益。 | 适合面对拥有明确行动预告的敌人，强调读局而不是单纯堆伤害。 |
| 速攻标记 | **点名**：速攻后给目标施加标记，后续攻击、自动使用或特定牌优先处理该目标。 | 为剑士建立稳定的目标选择语言，也能解决自动攻击完全随机的问题。 |
| 速攻抽换 | **换手**：速攻后整理手牌，例如抽取、替换、查看牌堆顶或调整牌的顺序。 | 让速攻承担手牌修整职能，但本身不依赖弃牌机制。 |
| 速攻蓄力 | **前踏**：速攻后为后续普通攻击、重击或防御动作留下准备状态。 | 提供“先快后重”的节奏，不直接读取弃牌，却能成为混合机制的前置动作。 |
| 速攻反应 | **听风**：在敌人满足特定行动条件时可以速攻响应，例如敌人蓄力、获得增益或准备攻击时。 | 将速攻从主动按钮延伸为时机牌，增加对敌人行为的观察价值。 |
| 速攻位移 | **踏步**：速攻后改变自身站位、目标距离或队伍中的保护关系。 | 为未来的阵型、前后排或场景互动留下功能空间，不强行绑定弃牌。 |

### 6.4 混合机制：速攻驱动弃牌

这里的因果顺序是“先使用速攻，再由速攻动作选择或制造弃牌”。弃牌不是附带文字，而是速攻牌的主要决策成本或主要收益来源。

| 功能方向 | 卡牌可能性 | 玩家选择与可玩空间 |
| --- | --- | --- |
| 速攻主动弃牌 | **借势**：速攻时选择手牌中的弃牌载荷，使其立即进入弃牌结算。 | 玩家要判断该牌现在适合被弃掉，还是应该保留到更好的时机手动使用。 |
| 速攻攻击后弃牌 | **破阵**：先对目标进行速攻，再根据命中结果选择弃牌；命中、暴击或击破可以影响可弃牌的来源。 | 形成“先确认攻击结果，再决定牺牲什么”的即时判断。 |
| 速攻弃牌并追击 | **借刃**：速攻选择弃牌后，让被弃置牌的效果结算，并追加一次与弃牌结果相关的追击。 | 重点是串联两个效果，但追击应保持短小，避免一张牌包办整套循环。 |
| 速攻筛选弃牌 | **择锋**：速攻时查看手牌或牌堆中的候选牌，只把符合条件的牌送入弃牌堆。 | 玩家可以主动寻找攻击载荷、防御载荷或资源载荷，构筑方向更清晰。 |
| 速攻弃掉负面牌 | **卸甲**：速攻动作要求弃掉诅咒、临时牌、低价值牌或特定标签牌，并从清理中获得收益。 | 让弃牌机制承担牌组清理功能，避免所有弃牌都要求牺牲高价值牌。 |
| 速攻转化弃牌 | **炼锋**：速攻把被弃置的牌转化为临时攻击、防御、资源或特殊状态，而非直接触发原牌效果。 | 可以处理不适合当前战斗的牌，也能限制原牌效果过度连锁。 |
| 速攻弃牌改变目标 | **引杀**：速攻弃牌后，让弃牌载荷锁定速攻目标、敌人弱点或即将行动的敌人。 | 将目标选择纳入连锁过程，强化“先点名、后弃牌、再追击”的操作感。 |
| 速攻弃牌制造防线 | **回身**：速攻弃牌后，弃牌载荷提供保护，让剑士可以在主动进攻后承受敌方反击。 | 让攻击型和防御型弃牌载荷都能被速攻启动。 |
| 速攻弃牌改变时刻 | **抢拍**：速攻弃牌后影响行动顺序、敌人行动预告或下一次时刻推进方式。 | 这是高风险的节奏功能，应明确是改变顺序还是延迟危险，避免与免费出牌混淆。 |
| 速攻连续转火 | **逐风**：速攻弃牌结算后，根据命中目标状态决定是否将后续动作转向另一名敌人。 | 适合表现剑士的连斩感，但需要限制目标规则，避免随机连锁失去可读性。 |

### 6.5 混合机制：弃牌强化速攻

这里的因果顺序是“先发生弃牌，再让后续速攻获得变化”。强化不必只表现为伤害提高，也可以改变目标、时机、费用、效果形态或使用条件。

| 功能方向 | 卡牌可能性 | 玩家选择与可玩空间 |
| --- | --- | --- |
| 弃牌强化速攻伤害 | **踏刃**：发生弃牌后，后续速攻获得更强的攻击表现。 | 这是最容易理解的基础方向，但应避免所有混合牌都只变成伤害放大器。 |
| 弃牌强化速攻目标 | **追猎**：弃牌后，速攻可以无视普通目标限制，优先攻击被标记、即将行动或生命最低的敌人。 | 将弃牌转化为精准打击能力，适合处理复杂敌方阵容。 |
| 弃牌强化速攻范围 | **回旋**：弃牌后，速攻从单体动作变为穿透、溅射、反弹或连续转火。 | 让玩家在单体压制与群体清理之间切换。 |
| 弃牌返还速攻资源 | **快拔**：弃牌后让速攻获得资源返还、使用条件放宽或再次进入可用状态。 | 形成“弃牌换节奏”的循环，但需要和真正的无限重复使用区分。 |
| 弃牌复制速攻性质 | **借名**：弃牌后让普通攻击获得速攻属性，或让速攻暂时继承普通攻击的附加效果。 | 通过改变卡牌性质制造构筑变化，而不是简单叠加面板数值。 |
| 弃牌改变速攻效果 | **变式**：弃牌后让下一次速攻在攻击、护盾、打断、抽换或标记之间选择一种形态。 | 玩家根据敌人行动选择功能，增加牌的决策密度。 |
| 弃牌储存速攻 | **藏雷**：弃牌后留下一个待触发的速攻动作，在敌人满足条件或玩家打出相关牌时释放。 | 把速攻从即时动作转成延迟威胁，适合设计伏击和反应玩法。 |
| 弃牌回收速攻 | **返锋**：弃牌后从牌堆、弃牌堆或特殊区域寻找速攻牌，或让已使用的速攻牌回到可用状态。 | 形成速攻构筑的稳定性来源，但应避免牌组只重复同一张速攻。 |
| 弃牌改变速攻消耗 | **轻身**：弃牌后让后续速攻减少资源负担、绕过某种限制或获得临时免费条件。 | 强调弃牌带来的行动权，而不是直接提高攻击数字。 |
| 弃牌触发速攻反击 | **听刃**：弃牌后记录敌人的下一次行动，并在其攻击、强化或移动时自动进行速攻反应。 | 让玩家主动弃牌布置反击，适合与敌人意图系统结合。 |

### 6.6 混合机制：双关键词终结与构筑上限

终结牌同时读取弃牌与速攻，但不应只把两种次数相加。更有趣的方向是让两种关键词决定终结牌的形态、目标、代价和后续状态。

| 功能方向 | 卡牌可能性 | 玩家选择与可玩空间 |
| --- | --- | --- |
| 双关键词爆发攻击 | **百炼归鞘**：完成弃牌与速攻的准备后，将积累的战斗节奏转成一次高承诺终结动作。 | 重点是判断何时结束循环，而不是无条件等待最大收益。 |
| 双关键词分支终结 | **两断**：根据此前更偏向弃牌还是更偏向速攻，终结时分别呈现不同效果。 | 同一张稀有牌可以服务两种构筑，不要求所有卡组都用同一种顺序。 |
| 双关键词取短板 | **齐锋**：只有弃牌和速攻都完成准备时才完整发挥，任何一边不足都会改变终结形态。 | 防止只堆单一关键词获得完整上限，同时保留未完成时的基础用途。 |
| 双关键词生成牌 | **剑雨**：终结后生成一组与本回合行为相关的临时牌，可能偏向速攻、弃牌或防御。 | 将本回合的构筑选择延伸到下一回合，形成战斗节奏的回响。 |
| 双关键词重置 | **归鞘**：终结时清除部分临时状态、回收部分牌或重整手牌，然后重新开始下一轮循环。 | 终结不只负责造成伤害，也负责整理已经变得混乱的资源。 |
| 双关键词防守反转 | **守中带攻**：完成双关键词准备后，终结动作同时处理敌方威胁并建立防线。 | 让剑士在危险回合也有“准备终结”的理由，而不是只能纯输出。 |
| 双关键词目标控制 | **定军**：终结前锁定关键敌人，终结后改变敌方行动顺序、攻击目标或增益状态。 | 将速攻提供的先手和弃牌提供的资源都转成战场控制。 |
| 双关键词牌型转换 | **无式**：终结根据已完成的条件，把手牌、弃牌堆或临时牌转换成另一种牌型。 | 适合作为构筑的转折点，让玩家从速攻循环切换到重击或防守循环。 |
| 双关键词风险赌注 | **孤注**：终结消耗当前积累的弃牌与速攻成果，并在成功后获得明显的后续优势；失败或时机不对则损失循环资源。 | 提供高波动路线，但结果必须可预判，不能依赖纯随机。 |
| 双关键词团队协作 | **领锋**：弃牌负责为队友或全队准备状态，速攻负责把状态转成全队行动或保护。 | 如果未来支持队伍联动，可让剑士成为以节奏带动队伍的角色。 |

### 6.7 需要继续探索的特殊方向

以下方向可以作为后续扩展，不必在首版全部加入：

- **弃牌堆作为第二手牌**：卡牌被弃置后并非消失，而是允许通过特定速攻牌从弃牌堆选择并转化使用。
- **主动弃牌与被动弃牌分层**：玩家主动选择弃置时触发完整效果，重抽、回合清手或系统清理时只触发较弱的替代效果。
- **弃牌顺序产生差异**：先弃掉的牌负责准备，后弃掉的牌负责结算，鼓励玩家安排弃牌顺序。
- **弃牌类型产生差异**：攻击牌、防御牌、速攻牌、临时牌或诅咒牌被弃置时分别提供不同方向的收益。
- **速攻目标产生差异**：速攻敌人、速攻队友、速攻自己或速攻场景目标时，触发不同的后续效果。
- **速攻失败也有价值**：未命中、被格挡或目标消失时，仍然完成标记、弃牌或位置调整，避免速攻牌在特殊局面完全失效。
- **主动结束循环**：玩家可以用终结牌提前结束弃牌与速攻准备，换取稳定收益；也可以继续贪取更多准备，承担敌人反击风险。
- **反向构筑**：让某些牌希望被打出，让另一些牌希望被弃置，玩家围绕“这张牌当前应该处于哪个区域”进行组牌。

这些模板只确定功能方向，不确定最终数值。后续应先从中挑选能组成清晰循环的功能，再分别为基础牌、构筑牌和终结牌补充费用、伤害、资源、持续时间与触发限制。模板中的“自动使用”仍不是第二次打出卡牌：它不重新要求玩家选择主目标，但可以记录独立的命中、伤害、状态和目标结果。
