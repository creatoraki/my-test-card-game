# 精算师改版方案 · 机制与状态

> 本文件统一精算师改版涉及的关键词、规则术语、状态与初始卡组口径。标记说明：`已有` = 代码中已实装；`校准` = 已实装，但文档口径需要对齐代码；`新设` = 本方案新增。
>
> 本文中“保险 X%”“回复 X%”“护盾 X%”均指**精算师治愈力 X% 换算出的点数**（治愈力 ÷ 5 × X%，与普通治疗同一口径）；“伤害 X%”指精算师攻击力 X%。未注明时持续 2 回合。

---

## 一、已有机制的口径校准（以代码为准）

### 1.1 保险（已有 · 校准）

| 规则 | 口径 |
| --- | --- |
| 层数 | 层数 = 治愈力 ÷ 5 × 卡面百分比，**四舍五入**。1 层 = 1 点回复量。 |
| 增值 | 保险存续期间，持有者每次受到**敌方直接攻击**，层数变为 `floor(层数 × 1.2)`。中毒、灼烧等持续伤害不触发。 |
| 到期 | 保险到期时**理赔**：回复持有者等同于当前层数的生命，然后移除。 |
| 叠加 | 同一目标身上只有一份保险：层数相加，剩余回合取较大值。 |
| 持续 | 默认 2 回合，**含施加当回合**（施加后本回合结束算 1 回合）。 |

> 《实际卡牌》原文“向下取整”与代码不一致，以代码的四舍五入为准。

### 1.2 回响（已有 · 校准）

| 规则 | 口径 |
| --- | --- |
| 挂号 | 回响牌结算完毕后，**主目标**获得回响 BUFF。 |
| 持续 | 回响 BUFF 持续 1 回合，**含施加当回合**——也就是只在本回合内有效。 |
| 新增上限 | 每回合最多新增 1 名回响角色；已经带有回响的主目标可以刷新持续时间。 |
| 同步 | 回响牌的**基础效果**按 `100%` 对所有其他存活且带有回响的队友重放一次；不重放关键词效果，不重放“出牌时属性加成”。 |

**实际玩法**：每回合第一张回响牌的主目标成为“挂号人”；之后本回合打出的每一张回响牌，在作用于自己的主目标之外，还会同步作用于挂号人。小队上限 3 人，所以常规情况下回响 = “一张牌管两个人”。

本方案只有两张牌能突破这一规则：

- 《团体保单》：所有回响持续 `+1` 回合 → 挂号人留到下一回合，下一回合还能再挂一个新人，网络扩到 3 人。
- 《共保体》：本场战斗回响新增人数不受限制 → 每张回响牌的主目标都会入网。

### 1.3 急诊（已有 · 校准）

| 规则 | 口径 |
| --- | --- |
| 判定 | 目标在本回合内被敌方攻击命中过，或带有【假装受伤】时，结算急诊分支；否则只结算普通分支。 |
| 记录 | 攻击命中我方单位时记录该单位，回合开始时清空；持续伤害不记录。 |
| 奖励口径（新设） | 急诊分支必须让牌**换一种工作方式**：变即时、变群体、不扣层数、改持续时间、集中后立即兑现……不给单纯的数值提升。起始卡《首期保费》例外。 |

**实际玩法**：急诊牌要在敌人出手之后打，因此精算师的急诊牌大多是速攻——等时刻推进、敌人动手之后再插进来，不额外推进时刻。

### 1.4 免赔（已有 · 校准）

- 受到的伤害降低 `20%`，独立持续 2 回合。
- 《实际卡牌》原文写“该保险存续期间”，代码中免赔是独立状态，**不会**因保险被提前理赔而移除。以代码为准，卡面文本对齐为“持续 2 回合”。

## 二、理赔与溢额（新设）

### 2.1 理赔

**理赔**是“保险转为治疗”的统称。以下情况都算一次理赔：

| 来源 | 是否移除保险 |
| --- | --- |
| 保险自然到期 | 移除 |
| 提前理赔 | 移除 |
| 分期赔付 | 扣除一半层数（急诊时不扣） |
| 保单转让（急诊） | 转入的部分理赔，原有部分保留 |
| 止损协议 | 不扣层数 |
| 终身寿险（免死触发） | 移除 |
| 灾后核保（急诊） | 本回合末到期，按“自然到期”处理 |

不算理赔的：急诊拨付的急诊分支（它从未成为保险）、足额赔付（即时治疗）、保单质押与现金价值（消耗保险，但不回复生命）。

### 2.2 溢额

> **溢额** = 本次理赔的回复量 − 实际回复的生命（即超过持有者已损失生命的部分）。

溢额按以下顺序处理：

1. 若有队友带有【受益人】，且溢额来自**其他**队友：溢额改为回复受益人。
2. 仍有剩余：按 `50%` 计入精算师的**盈余**（《偿付能力》生效时改为 `100%`），向下取整。
3. 盈余已满时，超出上限的部分作废。

> 即时治疗（足额赔付、急诊拨付等）的溢出**不是溢额**，不计入盈余。足额赔付自己会把溢出转为保险，再由之后的理赔产生溢额。

## 三、盈余（新设）

| 规则 | 口径 |
| --- | --- |
| 持有者 | 精算师自身的资源状态，显示在精算师身上。 |
| 来源 | 理赔溢额（见 2.2）；《佣金》。没有任何牌能直接获得盈余。 |
| 上限 | 精算师治愈力 `100%` 换算的点数；《偿付能力》生效时翻倍。 |
| 持续 | 本场战斗，不可驱散。精算师阵亡时清空。 |
| 出口 | 分红（全队护盾）、再保险（保险）、清算（伤害）。三张出口牌都是“消耗全部盈余”。 |

**设计意图**：以前队伍健康时，精算师的保险会成批地空转到期；现在溢出的一半会记进账本。盈余的折算率只有 `50%`，它是**止损**而不是收益来源——专门为满血队友投保去刷盈余，效率远低于直接把保险给受伤的人。

## 四、状态

### 4.1 精算师自身

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |
| --- | --- | --- | --- | --- |
| 盈余 | 新设 | 见第三节。 | 按点数累计，有上限。本场战斗。 | 理赔溢额、佣金 |
| 共保体 | 新设 | 回响每回合新增人数不受限制。 | 本场战斗，不可叠加，不可驱散。 | 共保体 |
| 偿付能力 | 新设 | 溢额 `100%` 计入盈余；盈余上限翻倍。 | 本场战斗，不可叠加，不可驱散。 | 偿付能力 |

### 4.2 队友

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |
| --- | --- | --- | --- | --- |
| 保险 | 已有 | 见 1.1。新增内部记录“存续期间是否受到过敌方直接攻击”，供《无赔优待》读取；合并时只要任意一份被打过即记为“受过攻击”。 | 见 1.1。 | 大多数治疗牌 |
| 回响 | 已有 | 见 1.2。 | 1 回合（含当回合）。 | 回响牌 |
| 免赔 | 已有 | 受到的伤害降低 `20%`。 | 2 回合。 | 免赔条款 |
| 假装受伤 | 已有 | 本回合视为已受到攻击，可触发急诊；**不**触发保险增值、风险准备金。 | 1 回合（含当回合）。 | 急诊模组；分诊 |
| 嘲讽 | 已有 | 敌方单体攻击优先指向持有者。 | 按卡面。 | 风险敞口 |
| 止损 | 新设 | 下一次受到敌方直接攻击后（先结算保险增值），回复等同于当前保险层数的生命，不扣层数，然后移除止损。没有保险时不回复。 | 不可叠加，1 回合（含当回合）。 | 止损协议 |
| 寿险 | 新设 | 持有者受到致命伤害时，生命保留为 1，并立即理赔全部保险，回复量 ×2，然后移除寿险。保险被移除时寿险一并移除。 | 随保险存续；每名队友每场战斗只能触发 1 次。 | 终身寿险 |
| 受益人 | 新设 | 其他队友理赔产生的溢额，改为回复持有者（见 2.2）。同时只能有 1 名受益人，新的顶替旧的。 | 2 回合。 | 受益人 |

### 4.3 小队状态

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |
| --- | --- | --- | --- | --- |
| 共同海损 | 新设 | 我方任一单位受到敌方直接攻击时，最终伤害平均分摊给所有存活队友（向上取整）；每名分摊到伤害的队友都视为受到一次直接攻击（触发保险增值与急诊记录，不触发风险准备金与高风险）。 | 本回合。 | 共同海损 |

### 4.4 敌方

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |
| --- | --- | --- | --- | --- |
| 高风险 | 新设 | 持有者的直接攻击命中我方时：被攻击者的保险增值改为 ×1.5（不与 ×1.2 叠乘）；被攻击者没有保险时，改为获得保险 `15%`（2 回合）。 | 不可叠加，2 回合。 | 风险评估 |

## 五、初始卡组

| 卡牌 | 来源 | 作用 |
| --- | --- | --- |
| 基础攻击 | 通用 | 输出 |
| 基础治疗 | 通用 | 即时回复 |
| 基础防护 | 通用 | 护盾 |
| 首期保费 | 普通卡 | 铺保；急诊教学 |
| 急诊拨付 | 普通卡 | 急诊时保险变即时治疗 |
| 提前理赔 | 普通卡 | 主动兑现；急诊时连带理赔 |

与现状一致，不做改动。第一回合的标准打法：首期保费给前排投保 → 推进时刻、等敌人出手 → 急诊拨付救被打的人（即时回复 + 抽牌）→ 提前理赔（速攻）把前排已增值的保险当场兑现，或者留到下回合继续养。

## 六、引擎改动清单（供后续实装参考）

| 改动 | 涉及卡牌 | 说明 |
| --- | --- | --- |
| 盈余 | 规则；分红、再保险、清算、佣金、偿付能力 | 精算师自身新状态。`settleInsurance` 需要读取 `ops.heal` 的实际回复量，求出溢额后按 2.2 的顺序处理。 |
| 理赔事件 | 佣金、受益人、无赔优待 | 所有理赔路径（到期、提前、部分、止损、寿险）统一走一个入口，派发“理赔量 / 实际回复 / 溢额”。 |
| 部分理赔 | 分期赔付 | `SETTLE_INSURANCE` 增加“按比例理赔”“理赔后不扣层数”两个参数。 |
| 保险转移 | 保单转让 | 把其他队友的保险合并到目标身上（层数相加、回合取大），并能只理赔“转入的部分”。可评估复用 `TRANSFER_STATUS`。 |
| 保险延期上限 | 保单展期 | 剩余回合 `+1`，上限 3。可复用 `EXTEND_STATUS` 并补上上限参数。 |
| 保险补足 | 灾后核保 | 新效果：层数提高到“已损失生命”，本次增量有上限。 |
| 增值倍率改写 | 风险评估 | `growInsurance` 接收倍率参数；攻击者带有【高风险】时用 ×1.5。 |
| 存续期间受击记录 | 无赔优待 | 保险实例上记录是否受过敌方直接攻击。 |
| 止损 | 止损协议 | 受击后钩子，读取增值后的保险层数。 |
| 致命伤害拦截 | 终身寿险 | 在单位阵亡判定前拦截，保留 1 点生命并理赔。 |
| 伤害分摊 | 共同海损 | 我方受击时把最终伤害平均分给存活队友，并逐人派发“视为受击”。 |
| 回响新增上限 | 共保体 | 检查共保体状态后跳过 `echoGainedThisRound` 限制。 |
| 回响延长 | 团体保单 | 对所有带回响的队友延长回响 1 回合。 |
| 急诊判定改写 | 应急预案 | 持有该被动时，`targetAttackedThisRound` 改为“本回合任一队友受过攻击”。 |
| 溢额改道 | 受益人 | 见 2.2 第 1 步。 |

可以复用的现有实现：

- `SETTLE_INSURANCE`：提前理赔已有写法，分期赔付、保单转让在此基础上加参数。
- `CONSUME_STATUS` + `lastConsumedStatusStacks`：保单质押已有写法，现金价值、分红、再保险、清算都按“消耗量”结算。
- `partyInsuranceStacks` 计数：代位求偿继续沿用。
- `targetAttackedThisRound` / `targetNotAttackedThisRound` 条件与【假装受伤】：急诊牌与分诊直接沿用。
- 嘲讽状态：风险敞口直接沿用。
