# 植物学家实际卡牌

## 一、关键词口径

- **瞄准**：使用带有瞄准的卡牌攻击没有被瞄准的目标时，为目标附加被瞄准；下次使用瞄准卡牌攻击该目标时，移除被瞄准并触发本卡的额外效果。
- **培育 N**：卡牌在手牌中经过 N 个回合后，触发培育后的额外效果。卡牌每回合开始时减少 1 层培育计数；计数归零后，卡面效果升级。

- **费用**：1 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：一名敌人
- **效果**：造成 80% 攻击力的伤害；瞄准：额外攻击一次。
- **卡面文本**：造成 `{0}` 点伤害。瞄准：额外攻击一次。
