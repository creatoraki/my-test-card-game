# 植物学家实际卡牌

> 与 `src/data/cards/botanist/` 保持一致：按支柱拆为 `bow.ts`（弓）、`venom.ts`（毒）、`garden.ts`（园·治疗）、`support.ts`（园·辅助）、`passive.ts`、`temporary.ts`。设计来源见《改版方案/二次改版》目录，缺失素材见其中的《05-缺失美术素材.md》。
>
> 数值口径：攻击倍率与中毒层数按植物学家攻击力计算，治疗倍率与护盾按治愈力计算；攻击力 `90` 时 `100%` = 18 点伤害，治愈力 `100` 时 `100%` = 20 点生命。

## 一、关键词口径

- **穿孔 N**：为敌人附加 N 层穿孔；每层使其受到的伤害提高 2%，最多 10 层。穿孔不放大中毒伤害。
- **毒箭 N**：为目标附加 N 层穿孔；目标在命中前带有中毒（任意来源）时改为 2N 层。多段逐段判定；满弓目标不附加。棘冠、花粉施加的毒箭按施加时目标是否中毒判定。
- **满弓 N**：打出时检查目标穿孔，达到 N 层的目标移除所需层数并触发满弓效果；本次触发满弓的目标不会再被本卡附加穿孔。群体牌逐个目标判定。
- **采收**：出牌结算前读取主目标全部穿孔层数 X，本卡按 X 强化；本卡效果全部结算完后移除这 X 层。伤害仍吃到这 X 层的增伤；X = 0 时只结算基础部分。
- **毒发**：立即按目标当前中毒层数结算一拍中毒伤害，不减少层数，不消耗持续拍数。
- **菌毒**：一段特殊的中毒，每结算一次（包括毒发）层数 +1。
- **培育 N**：进入手牌时有 N 层，每回合开始减 1；归零即成熟，打出时追加成熟效果（标注“替换”时替换基础效果）。
- **成熟 → 枯萎**：成熟维持 2 个回合，第 2 个回合卡面提示“即将枯萎”；该回合结束仍在手牌中，本牌移出本场战斗，原位置替换为 1 张枯萎的果实。被催熟提前成熟的牌同样维持到下一个回合结束。
- **催熟 N**：连续选择 N 次手牌中**生长中**的培育牌，每次推进 1 层；成熟牌不可选。
- **嫁接**：其他角色的一张手牌获得培育 1；成熟后打出时，该牌所属角色在本次结算中攻击力 +40%、治愈力 +40%；不会枯萎；打出或离开手牌后移除。
- **盛放**：本回合打出成熟牌时成熟效果额外结算一次；嫁接加成按两次计算（+80%）。

## 七、临时卡（2 张）

- **枯萎的果实**：0 费，任意一名角色。敌人：附加 25% 中毒 2 拍；队友：恢复 30% 生命。消耗。
- **双生花·子株**：1 费，为一名队友恢复 40% 生命；消耗。
