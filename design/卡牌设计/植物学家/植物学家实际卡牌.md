# 植物学家实际卡牌

> 与 `src/data/cards/botanist/` 保持一致：按支柱拆为 `bow.ts`（弓）、`venom.ts`（毒）、`garden.ts`（园）、`support.ts`（愈）、`passive.ts`、`temporary.ts`。设计来源见《改版方案》目录。

## 一、关键词口径

- **穿孔 N**：为敌人附加 N 层穿孔；每层使其受到的伤害提高 2%，最多 10 层。穿孔不放大中毒伤害。
- **满弓 N**：打出带满弓的牌时检查目标当前穿孔。达到 N 层的目标移除所需层数并触发满弓效果；本次触发满弓的目标不会再被本卡附加穿孔。群体牌逐个目标判定。
- **毒箭 N**：本卡的攻击每次命中时，若目标在命中前带有中毒（任意来源），额外附加穿孔 N。多段逐段判定；满弓目标不附加。
- **毒发 N**：立即按目标当前中毒层数结算 N 次中毒伤害，不减少层数，不消耗持续回合。
- **培育 N**：牌进入手牌时有 N 层培育；每回合开始减少 1 层。归零为成熟，打出时追加培育效果（标注“替换”时替换基础效果）。
- **过熟**：成熟牌在手牌中再经过 1 回合后进入过熟；打出时用过熟效果替换基础效果和培育效果。本回合结束仍在手牌中会转化为腐烂的果实。
- **催熟 N**：玩家连续选择 N 次手牌中的生长中或成熟培育牌，每次推进 1 层；成熟牌可以被推进为过熟。过熟牌、常青牌与嫁接牌的成熟态不可选。
- **常青**：成熟后不会过熟，也不能被催熟；仍在手牌中时每回合开始结算常青效果。
- **嫁接**：其他角色的一张手牌获得培育 1；成熟后本牌伤害、治疗、护盾与中毒数值 +40%，不会过熟；打出或离开手牌后移除。
- **盛放**：本回合打出成熟牌时培育效果额外结算一次；打出过熟牌时过熟效果额外结算一次；嫁接加成按两次计算（+80%）。

## 七、临时卡（2 张）

- **腐烂的果实**：1 费，一名敌人，附加 70% 中毒 2 回合；消耗。
- **双生花·子株**：1 费，为一名队友恢复 40% 生命；消耗。
