# 植物学家改版方案 · 机制与状态

> 本文件统一植物学家改版涉及的持续伤害口径、关键词、角色状态、卡牌状态和临时卡。标记说明：`已有` = 代码中已实装；`改` = 已有但规则需调整；`新设` = 本方案新增。

---

## 一、持续伤害统一口径（中毒 = 灼烧）

中毒与灼烧**使用同一套扣血规则**，不再有“中毒永久”“烧伤逐回合减半”之类的专属机制：

| 规则 | 口径 |
| --- | --- |
| 结构 | 层数 + 持续回合。每次施加形成独立的一段，各段分别计时，到期的一段自行移除。 |
| 扣血 | 每拍每层扣 1 点生命。 |
| 护盾 | 无视护盾。 |
| 体力极限 | 不降低体力极限。 |
| 穿孔 | 不放大持续伤害。 |
| 持续回合 | 由卡面决定，默认 `2` 回合。 |
| 数值基准 | 1 AP 单体 ≈ 攻击力 `40%` 层 × 2 回合，与现有代码中《引火试剂》《毒蘑菇孢子》一致；群体每个目标按单体的 `0.6` ~ `0.75` 倍计算。 |

**两者的区别只体现在卡牌交互上**：

| 状态 | 施加者 | 专属交互 |
| --- | --- | --- |
| 灼烧 | 炼金术士 | 易燃（灼烧伤害翻倍）、火转盾、永燃炉芯延长持续 |
| 中毒 | 炼金术士、植物学家 | 毒箭、毒发、箭毒木、菌丝网络、恒温坩埚增殖、催化引爆转成灼烧 |

> 这与代码现状一致：`src/engine/statuses/dot.ts` 中 `poison` 与 `burn` 的扣血实现相同，唯一差别是灼烧读取易燃。需要调整的只是炼金术士那几张“永久中毒”牌，它们要补上持续回合（见第七节）。

## 二、关键词口径

### 2.1 弓：穿孔 / 满弓（已有，不改）

| 关键词 | 口径 |
| --- | --- |
| 穿孔 N | 为敌人附加 N 层穿孔；每层使其受到的伤害提高 `2%`，最多 `10` 层。 |
| 满弓 N | 打出带满弓的牌时检查目标当前穿孔。达到 N 层的目标移除所需层数并触发满弓效果；本次触发满弓的目标不会再被本卡附加穿孔。群体牌逐个目标判定。 |

本方案还会用到两种不属于满弓的穿孔读取方式，它们不移除穿孔，除非卡面写明：

- **读取层数**：按目标当前穿孔层数结算（缠根绊索、乱刺散射）。
- **满层判定**：目标穿孔已达上限 `10` 层（蒺藜箭）。满层判定在本卡附加穿孔**之前**进行。

### 2.2 毒：毒箭 / 毒发（新设）

| 关键词 | 口径 |
| --- | --- |
| 毒箭 N | 本卡的攻击每次命中时，若目标带有中毒，额外为其附加 N 层穿孔。多段攻击逐段判定。判定时读取**命中前**的中毒，本卡自己附加的中毒不计入。 |
| 毒发 N | 立即按目标当前中毒层数结算 N 次中毒伤害。不减少层数，不消耗持续回合。伤害与中毒完全相同：无视护盾、不受穿孔加成。 |

- 毒箭与毒发都读取**任意来源**的中毒，包括炼金术士施加的中毒。
- 毒箭附加的穿孔属于本卡的穿孔。如果本卡对该目标触发了满弓，按满弓规则不再附加。
- 毒发不是攻击，不会触发“被攻击”类效果。

### 2.3 园：培育 / 成熟 / 过熟 / 催熟（已有，不改）

| 关键词 | 口径 |
| --- | --- |
| 培育 N | 牌进入手牌时有 N 层培育；每回合开始减少 1 层。归零为成熟，打出时追加培育效果；标注“替换”的培育效果会替换基础效果。 |
| 过熟 | 成熟牌在手牌中再经过 1 回合后进入过熟；打出时用过熟效果替换基础效果和培育效果。本回合结束仍在手牌中会转化为《腐烂的果实》。 |
| 催熟 N | 玩家连续选择 N 次手牌中的生长中或成熟培育牌，每次推进 1 层；成熟牌可以被推进为过熟，过熟牌不可选。 |

本方案新增两个培育修饰：

- **常青**（千年古树）：本牌成熟后不会进入过熟，催熟也无法把它推进为过熟。
- **嫁接**（卡牌状态，见第五节）：让没有培育的牌获得培育 1。

## 五、卡牌状态

| 状态 | 标记 | 效果 | 来源 |
| --- | --- | --- | --- |
| 嫁接 | 新设 | 本牌获得培育 1（立即开始计时）。成熟后，本牌的伤害、治疗、护盾与中毒数值 `+40%`。嫁接牌可以被催熟、会触发根系网络，但**不会过熟**，也不会变成腐烂的果实。本牌被打出后移除嫁接。 | 嫁接 |
| 常青 | 新设（写在卡面上的规则，不是可附加的状态） | 本牌不会过熟；成熟后只要仍在手牌中，每回合开始结算卡面写明的常青效果。 | 千年古树 |

**嫁接的限制**：

1. 只能选择**其他角色**的牌；已有培育或已被嫁接的牌不可选。
2. 被动牌、临时卡不可选。
3. 嫁接只改变数值，不改变牌的所属角色和费用。

## 七、引擎改动清单（供后续实装参考）

| 改动 | 涉及卡牌 | 说明 |
| --- | --- | --- |
| 炼金术士中毒补上持续回合 | 腐骨酸雨、终末合剂、恒温坩埚、过量催化 | 目前这几张牌施加的中毒没有 `duration`，统一口径后需要补上（默认 2 回合）；数值调整见《炼金术士改版方案.md》。 |
| 毒箭 | 连续射击、藤蔓缠绕 | 伤害效果增加“命中中毒目标时额外穿孔 N”的参数，逐段判定，读取命中前的状态。可参照现有的 `pierceOnHit`。 |
| 毒发 | 毒刺箭、孢子云雾、菌丝网络 | 按目标当前中毒层数立即结算 N 次，不减少持续。已有的 `TICK_STATUS`（恒温坩埚丢弃效果）与 `tickNow`（孢子云雾过熟）可以直接复用。 |
| 读取中毒剩余回合 | 箭毒木 | 取目标身上所有中毒分段中剩余回合的最大值。 |
| 中毒结算事件 | 菌丝网络 | 中毒每次扣血（包括毒发）派发事件，状态监听后附加穿孔，并按敌人计数“每回合最多 2 层”。 |
| 满层判定 | 蒺藜箭 | 新条件“目标穿孔已达上限”，需要在本卡附加穿孔之前判定。 |
| 移除穿孔并计数 | 树脂护甲 | 移除指定敌人至多 N 层穿孔，把实际移除层数传给后续护盾效果。 |
| 捕虫夹 | 食虫陷阱 | 在敌人招式结算前插入一次伤害结算；击杀时取消该招式并回复法力。 |
| 迟滞 | 缠根绊索 | 状态模板中已有设计，需要实装；与现有的招式时刻读取对接。 |
| 花粉 | 授粉 | 攻击命中钩子，按“每张牌”计数上限；可参照已有的龙舌花信 `agaveBloom`。 |
| 嫁接 | 嫁接 | 让任意牌挂上培育计时；成熟后给牌的数值效果乘 `1.4`；禁止过熟。 |
| 常青 | 千年古树 | 培育配置增加“不会过熟”的开关；手牌中成熟时在回合开始结算常青效果。 |
| 盛放 | 花期 | 出牌结算时检查盛放状态，决定培育效果结算次数与过熟三段结算。 |
| 目标中毒条件 | 汲血蔓 | 现有的 `targetHasStatus` 可以复用。 |

可以复用的现有实现：

- `src/engine/statuses/dot.ts`：中毒与灼烧的统一扣血实现。
- `src/engine/deck/cultivate.ts` 中的 `advanceCultivate` / `cultivateStage`：嫁接、常青、花期都基于它扩展。
- `src/engine/statuses/botanist.ts` 中的 `onCultivateStage` 钩子（根系网络）与 `onAfterAttack` 钩子（龙舌花信）：分别是嫁接联动根系网络、花粉的参照写法。
- 已有的 `halfDraw`（半熟保鲜）、`SPREAD_STATUS`（毒蘑菇孢子传染）、`damageBonus.perStatusStack`（乱刺散射）继续沿用。
