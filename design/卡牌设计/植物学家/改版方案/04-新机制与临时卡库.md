# 新机制与临时卡库

> 三套改版方案共用的新 BUFF、新动词和临时果实卡，这里统一口径，方便混搭。
>
> 「来源」列标明该机制出自哪套方案：A = 生长统一论，B = 养分循环，C = 花果与嫁接。

## 一、机制总表

| 名称 | 类型 | 来源 | 口径 |
| --- | --- | --- | --- |
| 寄生种子 | 敌人减益 | A | 取代被瞄准。分幼苗、成株、盛放 3 阶；每个敌方回合结束时 +1 阶；每名敌人最多 1 颗。 |
| 播种 / 收割 | 瞄准的结算 | A | 瞄准牌命中没有种子的敌人时播种；命中有种子的敌人时，移除种子，并按阶段结算。 |
| 移植 | 动词 | A | 不移除种子，而是转移给另一名没有种子的敌人；算作一次瞄准触发。 |
| 催生 N | 动词 | A | 获得 N 点生长，逐点分配给种子（+1 阶）或未成熟的培育牌（计数 −1）。 |
| 锚定 | 自身增益 | A / B / C | 本回合第一次收割时，保留标记（方案 A 中，种子阶段 −1）。沿用现有机制。 |
| 过熟 | 手牌状态 | A / B | 培育牌成熟后，在手牌中再经过 1 回合即变为过熟；培育分支替换为「过熟」分支。 |
| 养分 | 自身资源 | B | 植物学家的个人状态，上限 5；任何角色每收割一个被瞄准，植物学家获得 1 点。 |
| 汲取 X | 条件词 | B | 打出时，若养分 ≥ X，自动消耗 X 点，并结算汲取分支；可与培育分支同时结算。 |
| 施肥 N | 动词 | B | 消耗至多 N 点养分，每点令一张未成熟的培育牌计数 −1。 |
| 开花选择 | 培育的结算 | C | 成熟牌打出时，选择【花】（培育分支）、【果】（生成果实卡）或【根】（回到牌堆顶，保持成熟）。 |
| 瞄准·择 | 瞄准的变体 | C | 收割时二选一：【收】结算「1 + 深根」次；【养】不移除标记，深根 +1。 |
| 深根 | 敌人减益层数 | C | 依附于被瞄准，最多 2 层；随标记一起转移或传播，标记移除时清空。 |
| 嫁接 / 嫁穗 | 关键词 / 队友增益 | C | 消耗一张培育牌，使一名队友的下一张牌额外结算其培育分支；未成熟时数值减半。持续到触发，或持续到下回合结束。 |
| 扦插 | 动词 | C | 复制一张培育牌；复制品计数重置，带有“消耗”。 |
| 已萌发 | 卡牌标识 | C | 带有此标识的培育牌被抽到时，直接成熟。 |

### 过熟的补充规则

- 卡面在培育分支后追加「过熟：…」。没有过熟分支的牌不会过熟，成熟后可以一直保持成熟。
- 过熟状态不会再继续恶化。是否加入“枯枝”，见总览中的待确认问题 2。
- 过熟分支的设计原则是**换一种收益，而不是变弱**：
  - 单体变群体；
  - 效果变果实卡；
  - 治疗变催生或养分；
  - 伤害变铺标记。

## 二、果实卡通用规则

- 果实卡是**临时卡**：费用为 0，打出后消耗，战斗结束后消失，不进入个人卡组。
- 果实卡属于植物学家；如果被嫁接，或者效果写明“队友”，可以作用于其他角色。
- 数值以植物学家当前的攻击力或治愈力为基准，**在生成时锁定**。
- 手牌已满时的处理方式待确认，见总览中的待确认问题 3。

## 三、果实卡一览

| 果实卡 | 来源卡牌 | 目标 | 效果 | 设计方向 |
| --- | --- | --- | --- | --- |
| 浆果 | 双生花（B 过熟）；果园随机 | 一名队友 | 恢复 20% 治愈力的生命。 | 零碎治疗 |
| 双子果 | 双生花（C 果） | 两名队友 | 为生命最低的 2 名队友各恢复 25% 治愈力的生命。 | 分散治疗 |
| 刺果 | 仙人掌护甲（B 过熟）；乱刺散射（C 果）；果园随机 | 一名敌人 | 造成 30% 攻击力的伤害；若目标未被瞄准，为其附加被瞄准。 | 培育→瞄准 |
| 光合果 | 光合储能（B 过熟）；果园随机 | 自身 | 获得 1 点法力。 | 节奏 |
| 龙舌兰酒 | 龙舌兰（C 果） | 一名队友 | 该队友下一张攻击牌伤害 +30%。 | 队友增益 |
| 仙人掌果 | 仙人掌护甲（C 果） | 一名队友 | 附加 25% 治愈力的护盾，并附加仙人掌反伤，持续 1 回合。 | 防御缩小版 |
| 常春藤籽 | 常春藤庇护（C 果） | 一名敌人 | 为目标附加被瞄准；已被瞄准时，改为获得 1 层深根。 | 培育→瞄准 |
| 甘露滴 | 净化甘露（C 果） | 一名队友 | 移除 1 个负面状态；若成功移除，令一张培育牌计数 −1。 | 驱散 + 培育 |
| 盐晶 | 盐青苔（C 果） | 自身 | 获得锚定。 | 瞄准资源 |
| 血藤果 | 汲血蔓（C 果） | 一名队友 | 该队友下一次触发瞄准时，恢复其造成伤害 50% 的生命。 | 队友增益 + 瞄准 |
| 孢子囊 | 孢子云雾（C 果） | 所有被瞄准的敌人 | 各附加 2 层中毒（持续 2 回合）。 | 读取标记 |

### 在方案 A 中使用果实卡的改写

如果混合路线采用方案 A 的种子体系，以下果实卡需要改写：

| 果实卡 | 改写后效果 |
| --- | --- |
| 刺果 | 造成 30% 攻击力的伤害；为目标播种，已有种子则阶段 +1。 |
| 常春藤籽 | 催生 1，只能分配给种子。 |
| 孢子囊 | 所有带种子的敌人，各附加「阶段」层中毒。 |
| 血藤果 | 该队友下一次收割时，恢复「阶段 × 15%」治愈力的生命。 |
| 盐晶 | 获得锚定。不变。 |
