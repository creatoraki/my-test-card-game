# 方案 B：养分循环

> 改动中等。瞄准和培育的触发规则保持不变，新增植物学家的个人资源**养分**，把两个关键词串成“产出 → 消耗”的链条。
>
> 过熟、果实卡的完整口径见 [04-新机制与临时卡库.md](04-新机制与临时卡库.md)。

## 一、关键词口径

### 瞄准 / 培育 N（保留）

- 与 [植物学家实际卡牌.md](../植物学家实际卡牌.md) 的口径一致，包括锚定。

### 养分（新增 BUFF）

- 植物学家的个人状态，永久存在，默认上限 **5 层**。
- **通用产出**：任何角色的瞄准牌每收割一个被瞄准，植物学家获得 1 点养分。收割者不一定是植物学家本人，装有瞄准模组的队友收割也算。
- 部分卡牌有额外的产出途径，见卡表。
- 养分已满时，新获得的养分作废。部分稀有卡会把溢出的养分转化为其他收益。

### 汲取 X（新增条件词）

- 打出时，若养分 ≥ X，自动消耗 X 点养分，并结算「汲取」分支。
- 养分不足时，不消耗养分，也不结算汲取分支。
- 同一张牌同时满足培育和汲取时，**两个分支都会结算**。这就是培育和瞄准交汇的地方。

### 施肥（新增动词）

- 「施肥 N」：消耗至多 N 点养分，每消耗 1 点，就令一张未成熟的培育牌计数 −1。可以把多点养分集中投在同一张牌上。所有未成熟的培育牌都成熟后，停止消耗养分。

### 过熟（新增）

- 成熟后在手牌中再经过 1 回合即变为过熟。
- 过熟后，培育分支替换为「过熟」分支。本方案中，过熟分支统一为**转换型**：生成果实卡或产出养分。

## 二、设计意图

| 旧问题 | 方案 B 的回应 |
| --- | --- |
| 瞄准无法推动培育 | 收割产出养分 → 施肥、汲取，让培育更快或更强 |
| 培育无法推动瞄准 | 丰收祭、刺果、孢子云雾，把养分和成熟度转回被瞄准 |
| 奖励方向单一 | 汲取分支是另一条独立的奖励线；过熟分支生成果实卡 |
| 成熟后没有决策 | 立即打出拿培育分支，或留到过熟换果实卡或养分 |
| 缺少构筑核心 | 丰收祭（爆发出口）、果园（果实引擎）、根瘤菌（养分上限与溢出） |

**与方案 A 的差异**：方案 B 不改变敌人身上的标记，玩家只需要多盯一个数字，理解成本更低；代价是联动集中在“养分”这一个节点上，形状比较单一。

## 四、联动关系

```
  瞄准收割（任何角色） ──+1──┐
  食虫陷阱击杀 ──────────+2──┤
  枯萎孢子 / 汲血蔓 ────────+─┤
  净化甘露 / 新叶萌发 ──────+─┤           ┌─▶ 汲取：回收射击、藤蔓缠绕、龙舌兰、根系联结、常春藤庇护…
  光合储能 / 乱刺散射过熟 ──+─┼─▶【养分 0~5】┼─▶ 施肥 / 堆肥：培育牌计数下降
                              │           ├─▶ 丰收祭：转化为伤害，并重新附加被瞄准（回到左侧）
                              │           └─▶ 根瘤菌：溢出部分转化为培育进度
  培育牌过熟 ─▶ 果实卡（浆果、刺果、光合果）─▶ 刺果附加被瞄准（回到左侧）
```

## 五、典型回合示例

**配置**：养分 2，法力 3。手牌为食虫陷阱、藤蔓缠绕、根系联结（培育 1）、堆肥。敌人甲已被瞄准，且只剩少量生命。

| 操作 | 养分 | 说明 |
| --- | ---: | --- |
| 食虫陷阱 → 甲（2 费） | 2 → 3 → 5 | 收割得 1 点，击杀得 2 点 |
| 堆肥（1 费） | 5 → 0 | 施肥 1，根系联结成熟；剩余 4 点，抽 2 张牌 |

另一条路线：不打堆肥，保留 5 点养分。下回合根系联结自然成熟，打出时同时结算培育和汲取 3，获得持续 3 回合的根系联结，养分还剩 2 点。

**体现的决策**：养分拿来换抽牌和节奏，还是存起来换一次强化版的核心牌。

## 七、风险与待确认

1. **养分沦为数值堆叠**：汲取分支如果都是“+X%”，就会重回奖励单一的老问题。本方案中，汲取分支已尽量写成“延长 / 扩大范围 / 抽牌”，后续新增时也需要守住这一点。
2. **通用产出的归属**：队友收割也给植物学家养分，能鼓励配合；但如果队伍里没有植物学家，养分就没有意义，需要确认模组的描述方式。
3. **汲取是否可选**：当前为“满足条件就自动消耗”。如果玩家想存养分却被自动扣掉，会产生挫败感。备选方案是在打出时弹出开关，但会增加操作。
4. **上限 5 是否偏低**：果园、根瘤菌都围绕上限设计，数值需要验证。
