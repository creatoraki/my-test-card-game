## 一、问题诊断

### 1.1 逐卡标注

标注说明：

- **奖励类型**：瞄准或培育触发后，奖励属于哪一类。
- **联动方向**：
  - 瞄准→瞄准：只服务瞄准；
  - 培育→瞄准：培育后产出标记；
  - 培育→培育：加速其他培育牌；
  - 无：与另一关键词没有关系。

| 卡牌 | 关键词 | 奖励类型 | 联动方向 |
| --- | --- | --- | --- |
| 连续射击 | 瞄准 | 数值提升（追加伤害）+ 重新附加标记 | 瞄准→瞄准 |
| 回收射击 | 瞄准 | 资源（法力、抽牌） | 无 |
| 荆棘鞭击 | 瞄准 | 减益 + 转移标记 | 瞄准→瞄准 |
| 藤蔓缠绕 | 瞄准 | 控制 | 无 |
| 食虫陷阱 | 瞄准 | 数值提升 + 击杀后传播标记 | 瞄准→瞄准 |
| 毒蘑菇孢子 | 瞄准 | 数值提升（中毒翻倍） | 无 |
| 枯萎孢子 | 瞄准 | 数值提升（多一层减益） | 无 |
| 双生花 | 培育 | 延迟治疗 | 无 |
| 龙舌兰 | 培育 | 增益 | 无 |
| 光合储能 | 培育 | 抽牌 + 加速培育 | 培育→培育 |
| 仙人掌护甲 | 培育 | 反伤 | 无 |
| 根系联结 | 培育 | 治疗分摊 | 无 |
| 汲血蔓 | 培育 | 溢出治疗转移 | 无 |
| 孢子云雾 | 培育 | 读取标记后传播中毒 | 培育→瞄准（读取） |
| 盐青苔 | 培育 | 全体附加标记 + 锚定 | 培育→瞄准 |
| 常春藤庇护 | 培育 | 被动附加标记 | 培育→瞄准 |
| 引路棘冠 | 培育 | 被动附加标记 | 培育→瞄准 |
| 净化甘露 | 培育 | 加速培育 | 培育→培育 |
| 新叶萌发 | 培育 | 加速培育 | 培育→培育 |
| 乱刺散射 | 培育 | 数值提升 + 可指定目标 | 无 |

### 1.2 结论

1. **两个关键词互不相通**
   - 瞄准全部在攻击牌上，培育全部在治疗/功能牌上，没有一张牌同时带两个关键词。
   - 跨关键词联动只有“培育→瞄准”这一个方向，共 4 张。**没有一张牌能让瞄准反过来推动培育。**
2. **标记是二元的**
   - 被瞄准只有“有/没有”两种状态，不会成长，也不能叠加。
   - 玩家对标记的操作只有“挂上”和“收掉”，缺少“养大再收”的决策。
3. **缺少构筑核心**
   - 没有牌会读取“场上有几个标记”或“手里有几张成熟牌”。
   - 没有稀有卡，卡池缺少能撑起构筑的核心牌。
4. **奖励方向单一**
   - 7 张瞄准牌里有 4 张的奖励是“本卡数值更高”。
   - 培育的奖励全部是“等一等，本卡变强”。
5. **培育几乎没有决策**
   - 等待的唯一代价是占一格手牌，所以玩家总是“能等就等”，成熟之后也没有理由再继续留着。
6. **奖励都在当下结算完毕**
   - 奖励几乎不会转化成未来的卡牌、牌堆位置、队友收益或长期资源。

### 1.3 改版目标

| 目标 | 衡量方式 |
| --- | --- |
| 双向联动 | 每套方案至少有 6 张“瞄准→培育”或“双关键词”卡 |
| 奖励多样 | “本卡数值提升”类奖励占比不超过 1/3 |
| 持有决策 | 培育牌成熟后，“继续持有”要有代价或另一种回报 |
| 构筑核心 | 每套方案至少 2 张稀有卡，能读取关键词状态并放大收益 |

## 二、三套方案对比

| 维度 | 方案 A：生长统一论 | 方案 B：养分循环 | 方案 C：花果与嫁接 |
| --- | --- | --- | --- |
| 改动幅度 | 大：重写被瞄准 | 中：新增一种资源 | 小：只改奖励结构 |
| 联动方式 | 种子阶段 × 手牌培育，通过“催生”双向互推 | 瞄准产出养分，培育与汲取消耗养分 | 花果选择、嫁接给队友、深根叠加 |
| 新增概念 | 种子阶段、催生、过熟 | 养分、汲取、过熟、果实卡 | 开花三选一、果实卡、嫁接、瞄准·择、深根、扦插 |
| 主要奖励方向 | 分档控制、阶段倍率、加速培育、移植 | 资源转换、卡牌生成、延迟爆发 | 卡牌生成、队友增益、牌堆操作、风险叠加 |
| 策略深度来源 | 什么时候收割、先收哪颗种子 | 养分花在哪里 | 每次成熟时的分支选择 |
| 理解成本 | 高：玩家需要追踪每颗种子的阶段 | 中：需要看一个资源数字 | 中：主要是选择界面 |
| 界面需求 | 敌人身上显示种子阶段 | 角色身上显示养分层数 | 选择弹窗 + 队友嫁接标识 |
| 与现有卡的继承度 | 约 50% | 约 75% | 约 80% |
| 主要风险 | 种子自然生长会让“挂上就不管”变成最优解 | 养分容易变成单纯的数值堆叠 | 选择过多会拖慢出牌节奏 |

## 三、推荐混合路线

**骨架：方案 A 的种子阶段 + 催生。**
这是对“联动少”改善最直接的方案。两个关键词都在说“生长”，自然会出现双向卡。

在骨架上叠加两块内容：

1. **方案 C 的果实卡与嫁接**
   - 果实卡给培育提供“成熟后转化成别的卡”的奖励方向。
   - 嫁接把植物学家的培育分支送到队友的牌上，承担队友联动。
2. **方案 A/B 共有的过熟**
   - 让“成熟后继续持有”变成真正的决策，而不是单纯拖延。

**剔除：**

- **方案 B 的养分**：养分和“催生”都在做“把瞄准收益转化为培育进度”，混合时二选一。推荐保留催生，因为它不需要额外的资源 UI。
- **方案 C 的深根**：深根和种子阶段都在做“标记会成长”，混合时由种子阶段取代。

混合后建议的卡池结构（约 20 张）：

| 类别 | 数量 | 说明 |
| --- | ---: | --- |
| 纯瞄准牌 | 6 | 其中 2 张按阶段分档，1 张移植 |
| 纯培育牌 | 5 | 其中 3 张有过熟分支，2 张可结出果实 |
| 双关键词牌 | 4 | 瞄准 + 培育，承担双向循环 |
| 催生与牌堆操作 | 3 | 光合储能、嫁接刀、种子袋 |
| 稀有核心 | 2 | 收获镰、温室 |

## 四、对关键词模组的影响

依据：[角色关键词模组设计.md](../../../物品设计/角色关键词模组设计.md)。当前两个模组如下：

- **瞄准模组**：附加瞄准；目标已有被瞄准时，本卡本次数值 +30%。
- **催熟模组**：打出后，随机令一张培育层数大于 0 的手牌减少 1 层。

| 方案 | 瞄准模组 | 催熟模组 |
| --- | --- | --- |
| A | 附加瞄准；收割时，本卡本次数值按种子阶段 +10% / +20% / +30% | 改名为“催生模组”：打出后催生 1 |
| B | 保持不变；收割时植物学家额外获得 1 点养分 | 打出后，植物学家获得 1 点养分；若养分已满，则改为随机一张培育牌 −1 |
| C | 附加瞄准·择 | 保持不变；新增“嫁接模组”：被嫁接的分支在本卡上额外结算一次 |
| 混合 | 同 A | 同 A |

说明：

- 方案 A 中，其他角色通过瞄准模组也能播种和收割，因此种子会成为全队共享的资源，跨角色联动比现在更强。
- 方案 C 的嫁接本身就是“植物学家把效果交给队友”，因此不依赖模组也能产生跨角色联动。

## 五、待确认问题

1. 种子自然生长的时机：敌方回合结束时，还是我方回合开始时？这会影响“当回合挂、下回合收”能否直接拿到 2 阶。
2. 过熟后是否还会继续恶化，例如过熟两回合后变成“枯枝”废牌？
3. 果实卡是否占用手牌上限？手牌已满时，果实卡是直接销毁，还是置于牌堆顶？
4. 嫁接的目标是“指定队友的下一张牌”，还是“下一张不属于植物学家的牌”？手牌由全队共享，这两种口径在实际体验上差别很大。
5. 稀有卡的定位：稀有卡是否允许有“本场战斗持续生效”的能力类效果（如温室、百花园、果园）？
6. 混合路线里，能否接受“被瞄准”这个名字改为“寄生种子”？如果不改名，可以保留“被瞄准”，只增加阶段数字。
