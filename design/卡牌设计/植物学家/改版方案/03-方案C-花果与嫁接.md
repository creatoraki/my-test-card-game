# 方案 C：花果与嫁接

> 改动较小。瞄准和培育的**触发方式不变**，重点改造**奖励结构**：成熟时要做选择，收割时要做选择，培育分支可以送给队友，培育牌可以在牌堆里流转。
>
> 果实卡、深根等共用口径见 [04-新机制与临时卡库.md](04-新机制与临时卡库.md)。

## 一、关键词口径

### 培育 N · 开花选择（改写）

- 计数规则不变。成熟的培育牌打出时，先结算基础效果，再从本卡提供的选项中**选择一项**：

| 选项 | 效果 | 出现范围 |
| --- | --- | --- |
| 【花】 | 结算本卡的培育分支，也就是现有效果 | 所有培育牌 |
| 【果】 | 放弃培育分支，生成本卡专属的果实卡，加入手牌 | 卡面标注了「果：××」的牌 |
| 【根】 | 放弃培育分支，本卡结算后置于抽牌堆顶，并保持成熟 | 卡面标注了「根」的牌 |

- 未成熟时打出，只结算基础效果，不做选择。
- **设计意图**：
  - 【花】是即时收益；
  - 【果】把收益拆成一张 0 费牌，换取出牌节奏和灵活性；
  - 【根】是牌堆操作，让核心牌下回合必定再抽到。

### 瞄准（保留）与 瞄准·择（新增）

- 普通瞄准牌的口径不变。
- 标注「瞄准·择」的牌命中已被瞄准的敌人时，二选一：
  - 【收】：移除被瞄准，结算瞄准效果「1 + 深根层数」次。
  - 【养】：不移除被瞄准，改为使其获得 1 层**深根**（最多 2 层），不结算瞄准效果。
- 深根跟随被瞄准一起转移、传播；被瞄准被移除时，深根也随之清空。
- **设计意图**：现在兑现，还是继续投资。连续【养】两次后，下一次【收】会结算 3 次瞄准效果，但前提是目标要活到那时，并且不能被其他牌提前收割。

### 嫁接（新增关键词）

- 「嫁接」：选择一张手牌中的培育牌（成熟与否均可）将其消耗，再选择一名队友，该队友获得「嫁穗」状态。
- **嫁穗**：该队友的下一张卡牌结算后，额外结算被嫁接牌的**培育分支**（即【花】的效果）。
  - 若被嫁接的牌尚未成熟，分支数值减半；
  - 分支的目标优先沿用队友那张牌的目标，目标类型不符时，按分支原本的规则选择目标。
- 嫁穗持续到被触发为止，或持续到下回合结束。
- **设计意图**：把植物学家的培育收益交给其他角色，形成队友联动；同时让“等不及成熟”的培育牌有了另一条出路。

### 扦插、种子袋（新增动作，写在具体卡上）

- **扦插**：复制一张手牌中的培育牌。复制品的计数重置为卡面初始值，并带有“消耗”。
- **种子袋**：把手牌中的培育牌洗回抽牌堆。这些牌带上「已萌发」标识，下次被抽到时直接成熟。

## 二、设计意图

| 旧问题 | 方案 C 的回应 |
| --- | --- |
| 奖励方向单一 | 同一张牌可以在花、果、根之间选择，奖励方向分别是即时效果、0 费牌和牌堆位置 |
| 成熟后没有决策 | 每次成熟都要选；百花园会进一步改变选择规则 |
| 标记是二元的 | 深根让被瞄准可以累积 |
| 瞄准无法推动培育 | 猎人藤、四季轮转：收割时推进培育 |
| 培育无法推动瞄准 | 常春藤籽、盐晶、四季轮转：成熟时附加标记或深根 |
| 缺少队友联动 | 嫁接刀、龙舌兰酒、血藤果 |

- 连续射击：满深根【收】时，额外伤害结算 3 次，合计 280%。
- 食虫陷阱：满深根【收】时，+60% 结算 3 次，合计 280%。
- 两者都需要 3 回合的投资，数值上限可以接受。

## 四、联动关系

```
  瞄准·择【养】──▶ 深根 ──▶【收】时效果翻倍（连续射击、食虫陷阱、猎人藤）
        ▲                          │
        │                          ├─▶ 猎人藤 / 四季轮转：推进手牌培育
        │                          ▼
  常春藤籽、盐晶、引路棘冠      培育牌成熟 ──▶【花】即时效果
  四季轮转：附加标记或深根 ◀──┤            ├─▶【果】果实卡（0 费，可交给队友的节奏）
                              │            └─▶【根】回到牌堆顶，下回合再抽到
                              │
  嫁接刀：消耗培育牌 ──▶ 队友的嫁穗 ──▶ 队友的下一张牌额外结算培育分支
  扦插 / 种子袋：复制培育牌，或洗回牌堆后以成熟状态重新抽到
```

## 五、典型回合示例

**配置**：法力 4（例如上回合回收射击多拿了 1 点）。手牌为猎人藤、龙舌兰（成熟）、嫁接刀、双生花（培育 2，刚抽到）、剑士的一张 2 费攻击牌。敌人甲已被瞄准，有 1 层深根。

| 操作 | 结果 |
| --- | --- |
| 嫁接刀（1 费）：嫁接双生花 → 剑士 | 抽 1 张牌；剑士获得嫁穗，因双生花未成熟，数值减半 |
| 猎人藤 → 甲（1 费），选【收】 | 瞄准效果结算 2 次：抽 2 张牌，两张培育牌计数各 −1 |
| 龙舌兰（成熟）→ 剑士，选【果】 | 恢复生命，并获得 0 费的龙舌兰酒 |
| 龙舌兰酒 → 剑士（0 费） | 剑士下一张攻击牌伤害 +30% |
| 下回合：剑士打出攻击牌 | 伤害 +30%，同时结算减半的双生花分支，治疗生命最低的队友 |

**体现的决策**：

- 双生花是等两回合再打，还是现在嫁接出去；
- 猎人藤是现在收，还是再养一层；
- 龙舌兰选花拿即时攻击力，还是选果把增益留到队友的关键攻击上。

## 七、风险与待确认

1. **选择疲劳**：每张成熟牌都弹出选择，会拖慢节奏。建议记住上次的选择作为默认值，或者只让一部分牌拥有果和根。
2. **嫁接的目标规则**：手牌由全队共享，“某队友的下一张牌”需要依据卡牌归属判断，归属需要在卡面上清楚标识。
3. **深根和其他角色**：装有瞄准模组的队友收割时，是否也按「1 + 深根」结算？建议不按，只移除深根，保证植物学家的独占性。
4. **种子袋过强**：0 费、抽牌还带成熟，可能需要改为 1 费，或限制最多洗回 2 张。
5. **果实卡数量**：果实卡会塞满手牌，需要确认手牌上限的处理方式，见总览中的待确认问题 3。
