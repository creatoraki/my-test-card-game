## 零、为什么有方案 D

- 00 中的诊断大体成立，主要问题有四个：
  - 两个关键词互不相通；
  - 被瞄准只有“有 / 没有”两种状态；
  - 缺少构筑核心；
  - 奖励方向单一。
- 方案 A、B、C 的共同问题是**新增概念太多**，上手成本偏高：
  - 方案 A 引入了种子阶段、催生；
  - 方案 C 引入了开花三选一、嫁接、深根、扦插。
- 方案 D 的原则：
  1. 被瞄准改为可叠层的《穿孔》，只用两个词：**穿孔 → 满弓**。
  2. 培育加入过熟和《腐烂的果实》，让培育有取舍，但词条总量仍然克制。

### 已确认的设计决策

| 问题 | 结论 |
| --- | --- |
| 系列词命名 | 穿孔（动词兼状态，负责积累）/ 满弓（负责消耗）；不再使用“瞄准” |
| 攻击牌结构 | 每张攻击牌都有基础效果 + 满弓 + 穿孔；触发满弓时，本次不附加穿孔 |
| 穿孔是否有被动效果 | 有，每层带来小幅易伤 |
| 满弓的触发方式 | 层数足够时自动触发 |
| 穿孔是否衰减 | 不衰减 |
| 过熟 | 每张培育牌都有独立的过熟分支，定位是侧向替代，不强于成熟；过熟当回合结束时仍在手牌中，就会烂掉 |
| 腐烂的果实 | 临时卡，1 AP，抽 1 张牌；允许少量卡牌读取或消耗它 |
| 基础卡规模 | 20 张，沿用现有卡名与素材 |

## 一、穿孔系：穿孔 → 满弓

### 1.1 穿孔（敌人身上的减益，取代“被瞄准”）

- **层数**：可以叠加，上限 10 层。
- **被动效果**：每层使目标受到的伤害提高约 2%，满层时约提高 20%。
  - 这个加成对全队的伤害都生效。
  - 具体数值待平衡。
- **不会衰减**：只有被满弓消耗、被转移，或者敌人死亡时，穿孔才会消失。
- **满层之后**：继续附加的穿孔直接作废，不会引爆。
- **定位**：穿孔就像挂在敌人身上的“存款”：
  - 存着有利息，也就是易伤；
  - 取出来有本金，也就是满弓收益。
  - 玩家要决定：继续叠层，还是现在拉满弓。

### 1.2 两个动词

| 动词 | 口径 | 常用数值 |
| --- | --- | --- |
| **穿孔 N** | 为目标附加 N 层穿孔 | 单体 1～3 层；群体 1～2 层 |
| **满弓 N：效果** | 打出时，如果目标穿孔 ≥ N，自动移除 N 层并结算效果；层数不足时，不扣层，也不结算效果 | 分为两档，见下表 |

**攻击牌的统一结构**：

- 每张攻击牌都由三部分组成：
  - 基础效果；
  - 满弓 N；
  - 穿孔 M。
- 基础效果（伤害等）不依赖满弓，每次都会结算。卡牌不能做成“不满弓就没用”。

**结算顺序（统一规则）**：

1. 打出时，先判定满弓：层数足够就扣层，并结算满弓效果。
2. 结算基础效果。
3. 最后结算穿孔。**如果本次已经触发满弓，就跳过穿孔。**

因此：

- 一张牌无法用自己附加的层数来支付自己的满弓；
- 每次打出，只会在“收获”（满弓）和“积累”（穿孔）中选一个。

**群体牌**：

- 逐个敌人判定满弓；
- 触发满弓的敌人，本次不附加穿孔；
- 没有触发满弓的敌人，正常附加穿孔。

**满弓的两档阈值**：

| 档位 | 层数 | 收益定位 |
| --- | --- | --- |
| 小额 | 2～3 层 | 顺手收益：催熟、扩散、治疗转化、抽牌 |
| 中额 | 4～6 层 | 质变收益：眩晕、回复 AP |

- 稀有牌《回收射击》采用特殊写法：满弓 4 触发后，移除该敌人的**全部**穿孔，而不只是 4 层。

**穿孔牌**：带有“穿孔 N”或“满弓 N”的攻击牌，统称为穿孔牌，供模组、图鉴和筛选使用。

**删除的旧概念**：

- **瞄准**：它只是“附加穿孔”的别名，已并入“穿孔 N”。
- **满弓全部**：已删除，改为回收射击卡面上的特殊写法。
- **锚定**：不再作为规则词。只有盐青苔的过熟分支保留一次性的“半保鲜”效果。
- **转移 / 传播**：不再作为规则词，改为直接写在卡面上。

## 二、培育系：培育 → 成熟 → 过熟 → 腐烂

### 2.1 生长时间线

- **培育 N**：卡牌在手牌中每经过 1 个回合，计数 −1；计数归零后，这张牌成熟，打出时结算培育分支。
- **过熟**：成熟后，在手牌中再经过 1 个回合就会变为过熟。
  - 过熟后打出，结算本卡的**过熟分支**，并**替换**培育分支。
- **腐烂**：过熟当回合结束时，如果这张牌仍在手牌中：
  - 原卡在本场战斗中被移除；
  - 原位置替换为一张《腐烂的果实》。
  - 替换发生在原卡的位置上，因此不受手牌上限影响。

**示例**：第 1 回合抽到一张“培育 2”的牌。

| 回合 | 状态 |
| --- | --- |
| 第 1 回合 | 培育 2 |
| 第 2 回合 | 培育 1 |
| 第 3 回合 | 成熟 |
| 第 4 回合 | 过熟；回合结束时如果还没打出，就烂掉 |

**玩家的三段取舍**：

1. 立刻打出，只拿基础效果；
2. 等到成熟，拿培育分支；
3. 留到过熟，换一种形态的过熟分支，以适配当前局面；但错过就会烂掉。

### 2.2 过熟分支的设计原则

过熟分支是成熟分支的**侧向替代**，而不是升级：

- **总价值**：约为成熟分支的 80%～100%，不能比成熟分支强。
- **作用**：只改变效果的形态。常见方向：
  - 单体变群体，但单体数值更低；
  - 防御变输出，但防御值更低；
  - 持续效果变即时效果，但总量更少；
  - 放弃自身收益，换来穿孔积累或负面状态转移。
- **设计意图**：玩家不会为了“更强”去等过熟。过熟只是“成熟后没来得及打出”的补救，或者“局面刚好需要这种形态”时的选择。

### 2.3 《腐烂的果实》（临时卡）

| 项目 | 口径 |
| --- | --- |
| 费用 | 1 AP |
| 效果 | 抽 1 张牌 |
| 其他 | 打出后消耗；属于植物学家；战斗结束后消失 |

- 腐烂的果实本身是一种轻度惩罚：花 1 AP 换一张牌。
- 少数卡牌会读取或消耗它，例如孢子云雾、新叶萌发，让“放烂了”也能有一点回报。

### 2.4 催熟 N（动词）

- **效果**：选择一张培育牌，使它的生长**推进 N 步**：
  - 未成熟的牌，计数 −1；
  - 已成熟的牌，直接变为过熟。
- **设计意图**：
  - 主要用来加快未成熟的牌；
  - 也可以主动把一张成熟牌推到过熟，在本回合换成过熟形态。
- **代价**：推进后的过熟牌如果没在本回合打出，同样会在回合结束时烂掉。

## 三、角色词条预算

植物学家最终共有 5 个概念，不再增加。

| 概念 | 类型 | 状态 |
| --- | --- | --- |
| 穿孔 / 穿孔 N | 敌人减益，兼作动词 | 新增，取代被瞄准；动词用法取代原来的“附加被瞄准” |
| 满弓 N | 条件词 | 新增 |
| 培育 N | 条件词 | 保留 |
| 过熟 | 卡牌状态 | 新增，腐烂的果实作为它的附属结果 |
| 催熟 N | 动词 | 由现有效果正式化 |

**卡面复杂度红线**：

- 一张牌最多有 2 段关键词文本。
- 同一培育段落中的“培育 / 过熟”算作 1 段。

## 四、两个系怎样互通

| 方向 | 做法 |
| --- | --- |
| 穿孔 → 培育 | 满弓的收益是催熟，把敌人身上的存款换成手牌的生长进度 |
| 培育 → 穿孔 | 培育或过熟分支负责群体穿孔、让队友的攻击附带穿孔，或持续产出穿孔 |
| 腐烂 → 其他 | 腐烂的果实可以被读取或消耗，失败的培育也能换来一点收益 |
| 读取 | 少数牌会读取穿孔层数，或敌人身上负面状态的数量，但不消耗 |
| 队友 | 穿孔的易伤对全队生效；龙舌兰过熟后，队友的下一次攻击也能附加穿孔 |

## 五、卡池设计约束

- **模型唯一**：每张牌的“触发 → 收益”模型必须独特。
  - 广义上同类的模型只能出现一次。
  - 例如“满弓后追加伤害”只能出现一次，连击、提高倍率都算同类。
  - 卡表中的“模型”一列用来查重。
- **奖励方向**：“本卡数值提升”类奖励，不超过全部奖励的 1/3。
- **稀有核心**：共 2 张。
  - 一张负责全场满弓收尾；
  - 一张负责“生长 → 穿孔”的持续引擎。

## 六、对关键词模组的影响

| 模组 | 调整方向 |
| --- | --- |
| 穿孔模组 | 满弓 3：本卡本次数值 +30%；否则穿孔 1（遵循统一结算顺序） |
| 催熟模组 | 效果不变，文本统一为“催熟 1” |

- 模组只使用小额档，避免队友“抢收”植物学家辛苦叠起的穿孔。
- 模组里的“满弓后本卡数值提升”属于模组专属模型，不计入植物学家卡池的查重。

## 七、待确认问题与风险

1. **易伤数值**
   - 每层 2%，满层 +20%，而且对全队输出都生效。
   - 需要结合敌人血量验证是否偏高。
2. **敌人死亡时穿孔直接消失**
   - 目前只有食虫陷阱能在击杀后转移穿孔。
   - 是否需要一条通用的保底规则？当前倾向：不需要。
3. **腐烂后原卡从本场战斗移除，等于自动精简卡组**
   - 需要观察是否会被玩家当作收益，故意把牌放烂。
4. **催熟的操作次数**
   - 催熟由玩家手动选择目标，操作次数会增加，需要实际体验来验证。
5. **过熟分支与“烂掉”的平衡**
   - 过熟已定为侧向替代，不强于成熟，所以玩家不会为了收益去等过熟。
   - 风险是过熟太弱，会让玩家觉得“成熟后必须立刻打出”。好在烂掉本身就是代价，过熟分支主要作为补救，并在特定局面下提供不同形态。
6. **攻击牌的“收获 / 积累”二选一**
   - 触发满弓后不附加穿孔，连续打同一名敌人时会形成交替节奏。
   - 需要验证满弓后穿孔归零，是否会让易伤收益过低。
