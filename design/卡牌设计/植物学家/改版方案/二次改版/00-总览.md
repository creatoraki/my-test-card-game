## 一、问题诊断

数值取自 `battleRules.ts`、`characters.ts` 与植物学家卡牌数据：攻击力 `90`，`100%` 攻击倍率 = 18 点伤害；治愈力 `100`，`100%` 治疗倍率 = 20 点生命；中毒层数 = 攻击力 ÷ 5 × 倍率。

| 问题 | 原因 |
| --- | --- |
| 满弓与穿孔联动弱 | 全队共用 3 点法力，植物学家每回合约出 1 张牌；穿孔每层只有 `+2%`；满弓扣掉层数后多数只换来抽 1 张、催熟 1 这类小奖励；穿孔缺少终点。 |
| 培育拖慢节奏 | 培育 2 ~ 3 回合；成熟后再放 1 回合会过熟，过熟效果多数比成熟更弱；成熟收益不明显，留牌感觉不到变强。 |
| 只想拿毒卡 | 中毒无视防御、格挡、护盾；毒牌拿来就能打，不需要植物或弓；腐烂的果实 1 费 `70%` 中毒，性价比过高。 |
| 治疗没有特色 | 治疗牌的成熟收益零散，没有群体治疗，也没有体力极限修复。 |
| 卡牌词条过多 | 一张攻击牌常常同时写着伤害、穿孔、毒箭、满弓，读起来负担大。 |

## 二、角色定位

**一句话定位：会治病也会下毒的植物学家，用成熟的草药托住全队，用淬毒的荆棘拆掉首领。**

植物学家是**奶 / 毒 / 首领单体输出**三位一体的角色，三项能力按卡池张数大致均衡：

| 支柱 | 负责什么 | 核心关键词 | 张数 |
| --- | --- | --- | ---: |
| 奶（园） | 治疗牌成熟后，除了治疗还附带强力且各不相同的增益；全游戏唯一以**群体治疗**和**体力极限修复**为特色的角色 | 培育、成熟、枯萎 | 13 |
| 毒 | 毒从植物里来；读取中毒来治疗、延长、毒发 | 中毒、毒发 | 7 |
| 弓（首领单体） | 在单个目标身上叠穿孔，用满弓和采收兑现 | 毒箭、满弓、采收 | 10 |

### 2.1 三条支柱如何咬合

| 方向 | 实现方式 | 代表卡牌 |
| --- | --- | --- |
| 毒 → 弓 | **毒箭 N**：附加 N 层穿孔，目标中毒时改为 2N 层 | 连续射击、荆棘鞭击、蒺藜箭、引路棘冠、授粉 |
| 弓 → 毒 | 满弓毒发；采收延长中毒持续 | 毒刺箭、箭毒木 |
| 弓 → 奶 | 采收换群体治疗；满弓催熟治疗植物 | 愈创木、荆棘鞭击 |
| 毒 → 奶 | 读取中毒为全队吸血；中毒敌人的攻击被削弱；枯萎的果实可以喂给队友 | 汲血蔓、孢子云雾、枯萎孢子 |
| 奶 → 毒 / 弓 | 治疗植物成熟后的增益让队友的攻击也能上毒、叠穿孔、提高攻击力 | 夹竹桃、授粉、龙舌兰 |

### 2.2 满弓与采收：每张都是不同的策略选择

审批意见第 4 条指出采收 / 满弓的效果单薄。本版 8 张兑现牌，每张兑现的方向都不同：

| 卡牌 | 稀有度 | 兑现方式 | 兑现成什么 | 策略点 |
| --- | --- | --- | --- | --- |
| 荆棘鞭击 | 普通 | 满弓 2 | 催熟 2 | 让治疗植物提前成熟，**下一张牌**就能拿到成熟增益 |
| 毒刺箭 | 普通 | 满弓 2 | 毒发 | 立刻兑现一拍毒伤 |
| 藤蔓缠绕 | 罕见 | 满弓 3 | 眩晕 | 跳过一名敌人的回合 |
| 棘刺绽放 | 普通 | 采收 | 每层本卡攻击力 `+10` | 纯爆发，首领斩杀 |
| 缠根绊索 | 普通 | 采收 | 每 3 层迟滞 1（持续 2 拍） | 把首领的大招往后推，连续两招都推 |
| 愈创木 | 普通 | 采收 | 每层全队治疗倍率 `+5%` | 把伤口换成全队治疗，进攻资源转防守 |
| 箭毒木 | 罕见 | 采收 | 每 2 层中毒持续 `+1` 拍 | 把一次性爆发换成长期毒伤，适合长线首领战 |
| 回收射击 | 稀有 | 采收 | 每 3 层全队锋芒（攻击力 `+20%`）1 回合，最多 3 回合 | 把首领身上的增伤“拔下来”，变成全队的爆发窗口 |

同一份穿孔可以拿去打伤害、推大招、奶全队、延长毒、开爆发窗口——**用在哪里才是策略**。

### 2.3 设计红线

1. **一张牌最多 2 个关键词**（培育计为 1 个）。带毒箭的牌不再写穿孔。
2. **所有加成写成属性或倍率**：攻击力 / 治愈力是角色**属性**，可以写 `+N` 或 `+X%`；攻击倍率 / 治疗倍率是卡牌**系数**，写 `+X%`。属性与倍率不互相换算。禁止“本卡伤害 `+X%`”。
3. **毒发不带数字**，固定为立即结算一拍毒伤。
4. **培育 → 成熟 → 枯萎的果实**：删除过熟，不引入落果。
5. **体力极限修复只给小额固定值**（2 ~ 3 点），参照预言家《紧急医疗》（瀑布：恢复 5 点体力极限）。
6. **穿孔上限 10 层、每层 `+2%` 不变**；穿孔不放大中毒。

## 四、培育节奏示意

> 培育 1 的牌，第 1 回合抽到：

| 回合 | 状态 | 打出得到 |
| ---: | --- | --- |
| 1 | 生长中（培育 1） | 基础效果 |
| 2 | **成熟** | 基础效果 + 成熟效果（治疗牌带增益） |
| 3 | **成熟**（卡面提示“即将枯萎”） | 基础效果 + 成熟效果 |
| 3 回合结束 | 仍在手中 → **枯萎**：本牌移出本场战斗，替换为 1 张《枯萎的果实》 | — |

- 和旧版相比：删除了“过熟”这一档（旧版第 3 回合会变成更弱的过熟效果），成熟窗口完整保留 2 个回合。
- 枯萎不是纯惩罚：《枯萎的果实》是 0 费临时卡，可以给敌人上毒，也可以给队友治疗；枯萎孢子会一次吃掉所有果实，换取群体上毒 + 群体治疗。是否故意让植物枯萎，是一个可选的策略。

## 五、首领战节奏示意

> 攻击力 `90`、治愈力 `100`，单个首领，省略队友。

| 回合 | 操作 | 结果 |
| ---: | --- | --- |
| 1 | 打出毒蘑菇孢子（未成熟），手中留下夹竹桃（培育 1） | 首领中毒 5 层 × 2 拍 |
| 2 | 夹竹桃成熟，打出：治疗剑士 `40%`，剑士获得淬毒 | 剑士之后的攻击会给首领续毒 |
| 3 | 打出连续射击：首领中毒，每段毒箭 1 → 2 层 × 2 段 | 首领穿孔 4 |
| 4 | 打出蒺藜箭：首领中毒，毒箭 2 → 4 层 | 首领穿孔 8 |
| 5 | 视局势三选一：棘刺绽放（约 36 点伤害）、缠根绊索（迟滞 2，首领接下来两招各推迟 2 时刻）、愈创木（全队各恢复 `50%`） | 穿孔清零，重新开始叠层 |

## 六、审批意见对照

| # | 审批意见 | 修订 |
| ---: | --- | --- |
| 1 | 词条过多；毒箭改为升级版穿孔 | 毒箭 N = 附加 N 层穿孔，目标中毒时改为 2N 层；带毒箭的牌不再写穿孔。一张牌最多 2 个关键词。 |
| 2 | 毒发去掉数字 | 毒发固定为“立即结算一拍毒伤”，所有卡面只写“毒发”。 |
| 3 | 禁止“本卡伤害 +X%” | 全部改为攻击力 / 治愈力（属性，`+N` 或 `+X%`）或攻击倍率 / 治疗倍率（系数）；蒺藜箭满层写作“攻击倍率改为 `170%`”。 |
| 4 | 采收 / 满弓效果单薄 | 8 张兑现牌各自兑现成不同资源（见 2.2）；删除“兑现成抽牌”的设计。 |
| 5 | 不要落果，保留培育 → 成熟 → 枯萎的果实 | 落果整体删除；删除过熟，成熟维持 2 回合后枯萎为《枯萎的果实》；枯萎的果实改为 0 费双用途，并有枯萎孢子、根系联结两张读取枯萎的牌。 |
| 6 | 单体毒 / 群体毒模型重合 | 毒蘑菇孢子 = 单体成长毒；孢子云雾 = 群体薄毒 + 成熟后全队对中毒敌人减伤；枯萎孢子 = 消耗果实的群体毒 + 群体奶。三者模型不同。 |

## 七、待确认问题

1. **毒发的“一回合毒伤”**：本版按“一拍”结算（按当前层数结算 1 次）。敌人一回合通常不止行动一次，所以如果“一回合”是指“该敌人本回合会行动的次数”，毒发的强度会翻倍。是否按一拍处理？
2. **迟滞“持续 2 拍”**：本版理解为“对接下来 2 次招式都生效，每层每次推迟 1 时刻”。另一种理解是“每层一次推迟 2 时刻，只影响 1 次招式”。用哪种？
3. **成熟窗口**：本版沿用旧版时长，成熟维持 2 个回合后枯萎。如果希望节奏更快，可以缩短为 1 个回合（成熟当回合不打就枯萎）。
4. **枯萎的果实**：本版改为 0 费，可以对敌人（上毒）或队友（治疗）使用。需要引擎新增“任意角色”的目标类型。如果不想加，可以拆成“对敌人上毒”一种用途。
5. **群体治疗的独特性**：预言家《太阳风》已经是全队 `25%` 治疗，炼金术士的组装奖励卡也有全队 `60%` 治疗。本版植物学家的群体奶都附带成熟增益、读取穿孔或读取中毒，以示区分。是否需要把太阳风调整为非群体？
6. **移出的 4 张卡**：乱刺散射、光合储能、常春藤庇护有美术，是否保留到备选池？
