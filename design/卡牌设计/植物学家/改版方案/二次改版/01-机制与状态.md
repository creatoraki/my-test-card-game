# 植物学家二次改版 · 机制与状态（审批修订版）

> 标记说明：`沿用` = 与当前实装相同；`改` = 已有但规则调整；`新设` = 本轮新增；`删除` = 本轮移除。
>
> 数值口径：攻击倍率与中毒层数均指植物学家攻击力，治疗倍率与护盾均指植物学家治愈力。攻击力 `90` 时 `100%` = 18 点伤害、`10%` 中毒 ≈ 2 层；治愈力 `100` 时 `100%` = 20 点生命。

---

## 一、关键词总览

| 关键词 | 标记 | 口径 |
| --- | --- | --- |
| 穿孔 N | 沿用 | 为敌人附加 N 层穿孔；每层使其受到的伤害提高 `2%`，最多 10 层，永久保留直到被移除。不放大中毒。 |
| **毒箭 N** | 改 | 为目标附加 N 层穿孔；目标**命中前**带有中毒时，改为附加 2N 层。带毒箭的牌不再另写穿孔。 |
| 满弓 N | 沿用 | 打出时检查目标穿孔，达到 N 层则移除 N 层并触发满弓效果；本次触发满弓的目标不会再被本卡附加穿孔。 |
| **采收** | 新设 | 终结技。读取目标全部穿孔层数，按层数强化本卡，结算后清空这些穿孔。 |
| 中毒 | 沿用 | 层数 + 持续拍数，分段计时；每拍每层扣 1 点，无视护盾，不降低体力极限。 |
| **毒发** | 改 | 立即按目标当前中毒层数结算一拍毒伤。不带数字，不减少层数，不消耗持续拍数。 |
| 培育 N | 改 | 进入手牌时有 N 层培育，每回合开始减 1；归零即成熟。本轮除千年古树（培育 2）外均为培育 1。 |
| 成熟 | 改 | 打出时追加成熟效果（标注“替换”的会替换基础效果）。成熟维持 2 个回合。 |
| **枯萎** | 改（取代过熟与腐烂） | 成熟后第 2 个回合结束时仍在手中，本牌移出本场战斗，替换为 1 张《枯萎的果实》。 |
| 催熟 N | 改 | 连续选择 N 次手牌中**生长中**的培育牌，每次推进 1 层。成熟牌不可选。 |
| 嫁接 | 改（写法） | 其他角色的一张手牌获得培育 1；成熟后打出时，所属角色在本次结算中攻击力 `+40%`、治愈力 `+40%`；嫁接牌不会枯萎。 |
| ~~过熟~~ | 删除 | 由枯萎取代。 |
| ~~常青~~ | 删除 | 千年古树改为普通培育牌。 |

**卡面写法约定**（审批意见第 1、3 条）：

1. 一张牌最多 2 个关键词，培育计为 1 个。
2. 加成只能写在**属性**或**倍率**上，不写“本卡伤害 `+X%`”：
   - 属性：攻击力、治愈力是角色属性，可以写 `+N`（如“本卡攻击力 `+10`”）或 `+X%`（如“攻击力 `+20%`”）。
   - 倍率：攻击倍率、治疗倍率是卡牌系数，写 `+X%` 或“改为 `X%`”。
   - 属性与倍率**不互相换算**。伤害 = 攻击力 ÷ 5 × 攻击倍率，治疗 = 治愈力 ÷ 5 × 治疗倍率（`RULES.combat.attackDivisor` / `healDivisor`）。
3. 增益 / 减益的效果是固定的，卡牌只能改变它的层数或持续回合，不能改变它的数值（如锋芒固定为攻击力 `+20%`）。

## 二、弓：毒箭 / 满弓 / 采收

### 2.1 毒箭 N（改）

| 项目 | 口径 |
| --- | --- |
| 基础 | 为目标附加 N 层穿孔。 |
| 中毒加倍 | 目标在本卡命中前带有中毒（任意来源，包括炼金术士）时，改为附加 2N 层。本卡自己附加的中毒不计入。 |
| 多段 | 卡面写“每段命中：毒箭 N”时逐段判定；否则一张牌只结算一次。 |
| 非攻击来源 | 棘冠、花粉等状态也可以“施加毒箭 N”，判定口径相同。 |
| 满弓目标 | 沿用满弓规则：本次触发满弓的目标不附加。 |

### 2.2 满弓 N（沿用）

规则不变。本轮满弓只出现在 3 张牌上，而且这 3 张牌的兑现方向各不相同：催熟（荆棘鞭击）、毒发（毒刺箭）、眩晕（藤蔓缠绕）。

### 2.3 采收（新设）

| 项目 | 口径 |
| --- | --- |
| 文本格式 | `采收：每层穿孔，<效果>。` 或 `采收：每 N 层穿孔，<效果>。` |
| 读取 | 出牌结算开始时读取目标当前**全部**穿孔层数，记为 X。 |
| 结算顺序 | ① 读取 X → ② 按 X 结算本卡效果（伤害仍然吃到这 X 层穿孔的增伤）→ ③ 移除目标的 X 层穿孔。 |
| X = 0 | 只结算本卡的基础部分，本卡永远不会是废牌。 |
| 击杀 | 目标在第 ② 步死亡时，X 仍按读取值计算。 |
| 与满弓 | 采收不是满弓，不触发满弓效果；同一张牌不会同时带有采收和满弓。 |
| 治疗类采收 | 愈创木以一名敌人为采收目标，治疗作用于全队。 |

**采收的兑现方向**：

| 卡牌 | 每层 / 每 N 层 | 10 层时 |
| --- | --- | --- |
| 棘刺绽放 | 每层本卡攻击力 `+10` | 攻击力 `190` ÷ 5 × `90%` ≈ 34 点，再 × 1.2 穿孔增伤 ≈ 41 点 |
| 缠根绊索 | 每 3 层迟滞 1，最多 2 层 | 迟滞 2（9 层以上的余数浪费） |
| 愈创木 | 每层治疗倍率 `+5%` | 全队各 `60%`（各 12 点） |
| 箭毒木 | 每 2 层中毒持续 `+1` 拍，最多 `+4` 拍 | 中毒持续 `+4` 拍（8 层以上的余数浪费） |
| 回收射击 | 每 3 层全队锋芒 1 回合，最多 3 回合 | 全队锋芒（攻击力 `+20%`）3 回合 |

> 棘刺绽放的 `+10` 加在攻击力属性上，只在本卡结算时生效，攻击倍率始终是 `90%`。

## 三、毒：中毒 / 毒发

### 3.1 中毒来源约束

植物学家施加中毒的效果只出现在**培育牌**、**读取枯萎的牌**或**枯萎的果实**上：毒蘑菇孢子、孢子云雾、枯萎孢子、夹竹桃（成熟后借队友的攻击上毒）、枯萎的果实。弓牌只读取中毒，不施加中毒。

### 3.2 毒发（改）

| 项目 | 口径 |
| --- | --- |
| 效果 | 立即按目标当前中毒层数（所有分段之和）结算一次中毒伤害，等同于多走一拍。 |
| 不消耗 | 不减少层数，不消耗持续拍数。 |
| 性质 | 不是攻击，不触发“被攻击”类效果；不吃穿孔增伤。 |
| 卡面 | 只写“毒发”，不带数字。需要多次时由卡面写“毒发，然后再毒发”这类明确文字（本轮没有）。 |

本轮来源：毒刺箭（满弓 2）、菌丝网络。

## 四、园：培育 / 成熟 / 枯萎

### 4.1 生命周期

| 阶段 | 判定（以培育 1 为例，第 1 回合抽到） | 打出时 |
| --- | --- | --- |
| 生长中 | 第 1 回合 | 只结算基础效果 |
| 成熟 | 第 2 回合开始 | 基础效果 + 成熟效果 |
| 成熟（即将枯萎） | 第 3 回合开始，卡面高亮提示 | 基础效果 + 成熟效果，**和第 2 回合完全相同** |
| 枯萎 | 第 3 回合结束仍在手中 | 本牌移出本场战斗，原位置替换为 1 张《枯萎的果实》 |

- 与旧版相比：时间点完全不变，只是把旧版第 3 回合的“过熟（效果变弱）”改为“仍是成熟”。
- 嫁接牌、被其他效果标记为“不会枯萎”的牌，成熟后一直保持成熟。
- 被催熟提前成熟的牌，从成熟那一刻起同样维持到“下一个回合结束”。

### 4.2 催熟（改）

只能选择**生长中**的培育牌，每次推进 1 层；成熟牌不可选（避免把牌往枯萎推）。手中没有生长中的牌时跳过。

### 4.3 成熟增益一览（审批意见第 11 条）

植物学家的治疗特色：**成熟后除了治疗，还带来各不相同的增益**。13 张培育牌的成熟效果互不重复：

| 卡牌 | 基础 | 成熟带来 |
| --- | --- | --- |
| 双生花 | 单体治疗 | 额外 1 张子株（多一次治疗） |
| 新叶萌发 | **群体**治疗 | 全队生机（持续治疗） |
| 芦荟 | 单体治疗 | 修复 3 点体力极限 |
| 龙舌兰 | 单体大治疗 | 目标攻击力 `+20%` |
| 夹竹桃 | 单体治疗 | 淬毒：目标的攻击会上毒 |
| 净化甘露 | 驱散 + 治疗 | 负面状态转移给敌人 |
| 仙人掌护甲 | 护盾 | 仙人掌：反伤 |
| 引路棘冠 | 嘲讽 | 棘冠：受击时对攻击者施加毒箭 2 |
| 千年古树 | 群体护盾 | 根深：全队本回合不损失体力极限 |
| 孢子云雾 | 群体薄毒 | 孢子护幕：全队受到中毒敌人的攻击时减伤 |
| 授粉 | 花粉 | 花粉强化（毒箭 1 → 2） |
| 毒蘑菇孢子 | 单体中毒 | 菌毒：每结算一次层数 `+1` |
| 盐青苔 | 单体穿孔 | 群体穿孔 |

## 六、临时卡

| 卡名 | id | 费用 | 效果 | 标记 |
| --- | --- | ---: | --- | --- |
| 枯萎的果实 | `withered-fruit`（原 `rotten-fruit`） | 0 | 选择任意一名角色。敌人：附加 `25%` 中毒，持续 2 拍。队友：恢复 `30%` 生命。消耗。 | 改：更名，1 费 → 0 费，增加对队友使用 |
| 双生花·子株 | `twin-flower-sprout` | 1 | 为一名队友恢复 `40%` 生命。消耗。 | 沿用 |

**枯萎的果实为什么改成 0 费**：旧版腐烂的果实 1 费，既占手牌又占法力，是“节奏变慢”的主要来源。改为 0 费后可以随手打出；植物本身已经永久失去，所以 0 费不会让枯萎变成划算的选择。数值：敌人 5 层 × 2 拍 = 10 点（约 `55%`），队友 6 点生命。
