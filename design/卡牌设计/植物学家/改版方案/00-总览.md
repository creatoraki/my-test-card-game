# 植物学家改版方案 · 总览

> 本目录是植物学家卡池的**改版设计文档**，不涉及代码改动。
>
> **基准版本**：以 `src/data/cards/botanist/` 中实际登记的 **20 张卡**为准（与《植物学家实际卡牌.md》一致），另有临时卡《腐烂的果实》《双生花·子株》。
>
> **目标**：卡池扩展到 **30 张**，稀有度为 **普通 15 / 罕见 10 / 稀有 5**。保留**穿孔 / 满弓**与**培育（含成熟 / 过熟 / 催熟）**，以**中毒**作为第三支柱：既能和炼金术士通过中毒联动，也能反过来强化植物学家的弓箭。每张卡都要有别的卡没有的功能模板。

## 一、现状诊断

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 中毒与弓箭各自为政 | 毒蘑菇孢子、孢子云雾只是“顺便上毒”，没有一张牌会因为目标中毒而打得更好 | 中毒像是借来的机制，和穿孔 / 满弓没有化学反应 |
| 与炼金术士只是共用状态 | 两名角色都会上毒，但彼此的牌不会读取对方铺的毒 | 同队时没有“1 + 1 > 2”的体验 |
| 两种持续伤害口径不一 | 代码里中毒与灼烧的扣血方式相同，但设计文档把中毒写成永久、把烧伤写成逐回合减半 | 玩家与策划对“毒和火有什么区别”理解混乱 |
| 攻击牌同质化 | 攻击牌几乎都是“伤害 + 穿孔 + 满弓 N：某奖励” | 牌与牌之间只剩满弓奖励不同 |
| 缺少跨角色接口 | 只有龙舌花信、引路棘冠碰到队友 | 植物学家很难帮队友吃到穿孔收益 |

## 二、角色定位

**一句话定位：用淬毒的荆棘箭给敌人打孔，让毒液撑开伤口，在手牌里养大自己的花园。**

植物学家是**“铺层 → 兑现”型的输出辅助**：中毒让目标更容易被穿孔，穿孔攒满后满弓兑现；培育让手里的牌越放越强。炼金术士铺的毒同样会被植物学家读取，植物学家铺的毒也会被炼金术士的催化引爆、相位蔓延、恒温坩埚利用。

### 四大支柱

| 支柱 | 关键词 | 负责什么 | 张数（主要归属） |
| --- | --- | --- | ---: |
| 弓 | 穿孔 / 满弓 | 叠易伤层数；满弓时消耗层数换取爆发 | 12 |
| 毒 | 中毒 / 毒箭 / 毒发 | 铺持续伤害；让中毒目标更容易叠穿孔，满弓时引爆毒 | 6 |
| 园 | 培育 / 成熟 / 过熟 / 催熟 | 牌在手里成长，用时间换取价值 | 8 |
| 愈 | 治疗 / 护盾 / 生机 | 支援队友，多数通过培育成长 | 4 |

> 大多数牌会同时碰到两根支柱，这里只按“主要卖点”归类。

### 毒与弓的三条关联

| 关联 | 实现方式 | 代表卡牌 |
| --- | --- | --- |
| 毒 → 穿孔 | **毒箭 N**：命中中毒的敌人时额外附加穿孔 N | 连续射击、藤蔓缠绕、箭毒木、菌丝网络 |
| 满弓 → 毒 | **毒发 N**：满弓时立即结算目标中毒 N 次 | 毒刺箭、孢子云雾（过熟） |
| 卡牌专属联动 | 按中毒剩余回合附加穿孔、中毒结算时附加穿孔、中毒目标改为全队吸血、满弓时传染中毒 | 箭毒木、菌丝网络、汲血蔓、毒蘑菇孢子 |

### 与炼金术士的联动（只联动中毒）

| 方向 | 说明 |
| --- | --- |
| 炼金术士 → 植物学家 | 反应釜壁、腐骨酸雨、恒温坩埚铺的毒，会触发植物学家的毒箭、毒发、箭毒木、汲血蔓、菌丝网络 |
| 植物学家 → 炼金术士 | 植物学家铺的毒，可以被催化引爆转成灼烧、被相位蔓延复制、被恒温坩埚增殖 |

### 设计红线

1. **中毒与灼烧使用同一套扣血规则**（见 01 文档第一节），两者的差异只体现在卡牌交互上。
2. **植物学家只施加中毒，不施加灼烧**，也不读取灼烧。
3. **穿孔不放大中毒伤害**，毒发的伤害也不受穿孔加成。毒与弓的关联只通过毒箭、毒发和卡牌效果实现。
4. **穿孔上限 10 层不动**。
5. **培育与嫁接依赖“手牌回合结束不弃置”**（已在代码中确认：回合结束时没有弃置手牌的流程）。

## 五、与旧版相比的改动

| 内容 | 处理 | 理由 |
| --- | --- | --- |
| 连续射击、藤蔓缠绕 | 增加毒箭 | 让弓箭牌能从中毒目标身上获得额外穿孔 |
| 孢子云雾 | 果实加成设上限 `+30%`；过熟改写为“毒发 1” | 原版加成无上限；“立即结算一次”统一为毒发关键词 |
| 食虫陷阱 | 删除“满弓击杀后转移穿孔”，改为敌人出招时触发的延迟陷阱 | 原效果与回收射击同属“满弓后处理穿孔”，功能不够独立 |
| 汲血蔓 | 删除满弓分支，改为“目标中毒时全队吸血” | 让吸血牌成为中毒的读取方 |
| 光合储能培育分支的催熟 | 改为抽 2 张 | 催熟的入口集中到荆棘鞭击、新叶萌发，避免模板重复 |
| 腐烂的果实 | 规则不变，仍然附加中毒 | 中毒保留为植物学家的第三支柱 |

## 六、待确认问题

> **实装已定（2026-09-24）**：删除千年古树的屏障（代码中护盾本就不会在回合开始衰减）；花期采用“成熟牌培育效果 / 过熟牌过熟效果各额外结算一次”；嫁接只限其他角色的牌；菌丝网络每回合上限 2 层；炼金术士的中毒统一补上持续 2 回合。以下为原始待确认记录。

1. **保留比例**：目前有 13 张保留原效果。如果希望改动更大，可以优先重做枯萎孢子、双生花、龙舌兰、净化甘露这 4 张普通卡。
2. **易燃是否只对灼烧生效**：扣血规则统一后，易燃（灼烧伤害翻倍）是灼烧唯一的专属放大器。建议保持现状，把它视为炼金术士的卡牌交互；如果希望毒与火完全对称，可以给中毒也设计一个对应的状态。
3. **嫁接的范围**：方案限定为“其他角色的牌”，以强调辅助定位；也可以放开为任意手牌。
4. **花期强度**：过熟牌依次结算三段效果可能过强，备选方案是“过熟牌的过熟效果额外结算一次”。
5. **菌丝网络的上限**：每名敌人每回合最多因此获得 2 层穿孔。炼金术士同时铺毒时可能提速太快，可以改为每回合 1 层。
