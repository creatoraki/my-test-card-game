# 卡牌效果模板库

> **用途**：后续修改、生成卡牌时，从本库挑选「触发条件 + 额外奖励 / 额外惩罚」进行拼装。
>
> **不收录**：普通常规效果（造成 X% 伤害、获得 X% 护盾、治疗 X%、抽 N 张等无条件结算），以及已有的角色词条本身（弃牌、瞄准、登阶、日蚀、月蚀、组装、共鸣、革命、瀑布、汇星、应星、狩猎、追忆、回响、急诊、深度治疗、痊愈、穿孔、满弓、培育等），它们的规则以《卡牌词条和数值设定.md》和各角色文件为准。
>
> **收录**：非词条的触发条件、条件达成后的额外奖励、卡牌附带的额外惩罚 / 代价。
>
> **配套**：奖励与惩罚中出现的 BUFF / DEBUFF / 卡牌状态（残影、架势、标记、悬赏、借贷、过载等）的具体效果、叠加规则与配合关系，见《[状态模板.md](状态模板.md)》。

## 一、拼装公式

```
卡牌效果 = 基础效果 + [触发条件 → 额外奖励] + [额外惩罚]
```

- **触发条件**（第二节，编号 `C-`）：决定额外奖励 / 额外惩罚何时结算。
- **额外奖励**（第三节，编号 `R-`）：条件满足后追加的收益。
- **额外惩罚**（第四节，编号 `P-`）：无条件代价，或条件未满足 / 条件满足时附带的负面结果。
- 一张卡建议最多「1 个条件 + 1 个奖励 + 1 个惩罚」，稀有卡可以放宽到 2 个条件或 2 个奖励。
- 文本书写统一格式：`基础效果；[条件]：[奖励]。[惩罚]。`
  - 示例：造成 `90%` 攻击力的伤害；**完成斩杀**：抽 `1` 张牌。使用后失去 `3` 点 HP。

### 1.1 强度折算参考

以《卡牌词条和数值设定.md》的 1 AP 标准伤害 `90%`、1 AP 治疗 / 护盾 `50%` 为锚点：

| 价值单位 | 约等于 |
| --- | --- |
| 抽 1 张牌 | 伤害倍率 `30%` ~ `40%` |
| 回复 1 点法力 | 伤害倍率 `45%` ~ `60%` |
| 本卡费用 -1（单次） | 伤害倍率 `45%` ~ `60%` |
| 额外攻击 1 次（同倍率） | 本卡伤害翻倍，需要把基础倍率压低 |
| 1 层可叠加 BUFF / DEBUFF（持续 1 回合） | 伤害倍率 `10%` ~ `20%` |
| 眩晕 1 回合 | 伤害倍率 `60%` 以上，普通卡慎用 |

**条件难度系数**（奖励强度 = 折算价值 ÷ 触发概率的大致倒数）：

| 难度 | 触发频率 | 奖励可放大到 |
| --- | --- | --- |
| 易 | 大多数回合能达成 | 标准折算的 `1.0` 倍 |
| 中 | 需要规划手牌或站位 | `1.5` 倍 |
| 难 | 需要整套构筑支持 | `2.0` 倍以上，可做质变 |

**惩罚折算**：惩罚价值按对等奖励的 `70%` 计算——惩罚往往可规避，不能按 1:1 抵扣。

## 四、额外惩罚模板（P）

惩罚分三种挂法：

- **无条件惩罚**：打出就付出，用于抬高基础数值（参考血坏）。
- **未达成惩罚**：条件未满足时结算，奖励和惩罚形成「赌」的张力。
- **达成后代价**：强力奖励附带的副作用，防止奖励过于干净。

### 4.1 生命代价

| 编号 | 惩罚 | 书写示例 |

| P-03 | 队友失去生命 | 随机 1 名队友失去 `4` 点 HP。 |
| P-04 | 降低体力极限 | 体力极限 `-3`，本场战斗有效。 |
| P-05 | 护盾清空 | 打出后移除自身所有护盾。 |
| P-06 | 护盾转为伤害 | 自身护盾减半，减少的部分变为自伤。 |

### 5.3 双向赌局结构

奖励与惩罚共享同一个条件，满足给奖励，不满足给惩罚：

```
基础效果；[条件]：[奖励]；否则：[惩罚]。
```

- 条件难度应为「中」，玩家能主动争取达成，但失败并不罕见。
- 惩罚价值 ≈ 奖励价值的 `50%`，失败时仍有基础效果兜底。
- 惩罚应选择**下回合生效**的类型（P-13、P-14、P-61），给玩家留出应对窗口。

## 六、设计约束

1. **条件必须可见**：所有条件在出牌前应能在界面上判断（高亮、预览数值）。斩杀、命中、暴击这类结算后条件，卡面预览需标记为「若…」。
2. **禁止无限循环**：返回手牌（R-22）、降费（R-25、R-26）与抽牌（R-20）组合时，必须附带 P-16 / P-17 或每回合次数上限。
3. **计数条件必须写上限**：C-05、C-17、C-69 及 R-12、R-13 均需要写明最大值。
4. **普通卡**：只使用难度「易 / 中」的条件和 3.1 ~ 3.5 的奖励；禁止 R-06、R-51、R-80 ~ R-83、P-33。
5. **罕见卡**：可以组合 1 个条件 + 2 个奖励，或加入双向赌局。
6. **稀有卡**：可以使用难度「难」的条件、质变奖励（R-06、R-51）与局外收益 / 局外惩罚。
7. **跨角色接口**：C-31（目标带指定状态）与 C-44（自身带指定 BUFF）是模组连携的主要入口；设计新卡时优先引用其他角色能稳定产出的状态。
8. **角色倾向**：同一种条件不要同时成为两名角色的核心。例如「完成斩杀」偏剑士 / 猎手向，「状态持续期间被攻击」偏防御向，「目标带负面状态」偏炼金术士 / 植物学家向。
