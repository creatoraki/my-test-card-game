# 炼金术士改版方案 · 总览

> 本目录是炼金术士卡池的**改版设计文档**，不涉及代码改动。
>
> **基准版本**：以 `src/data/cards/alchemist/` 中实际登记的 **18 张主体卡 + 9 张组装奖励卡**为准。《炼金术士实际卡牌.md》记录的是更早的 14 张版本，已落后于代码。
>
> **目标**：主体卡扩展到 **30 张**，稀有度为 **普通 15 / 罕见 10 / 稀有 5**。保留“不打直伤、以灼烧为主、中毒为辅”的定位，把**组装 BUFF** 与**共鸣强化**从“贴在卡上的标签”改造成“可以持有、兑现、转化的资源”，并补上与植物学家联动的**反应**接口。每张卡都要有别的卡没有的“钩子”。

## 一、现状诊断

上一轮改版解决了“回法力泛滥”“直伤与 DOT 混杂”的问题，定位已经清楚；但卡牌之间的**决策深度**仍然不够。

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 组装 BUFF 只是计数器 | 除了“凑满 3 种”之外没有任何作用；只有腐骨酸雨读取数量 | 持有组装 BUFF 本身没有价值，玩家只会“能凑就凑”，逆向拆解与半成品也就难以体现取舍 |
| 灼烧只有“烧”和“延” | 灼烧的用法只有：放着烧、永燃炉芯延长、热能回收转盾 | 缺少“提前兑现”的选择，也就没有“等易燃还是现在收”的抉择 |
| 共鸣全是“+数值” | 共鸣相关牌里，除焰核共鸣外都是“共鸣：数值 +X” | 攒下的强化只能跟着这张牌一起打出，没有别的用法；阶梯只有 1 / 2 / 3 费，缺 0 费底座 |
| 与植物学家只联动中毒 | 植物学家的毒会被炼金术士读取，但炼金术士的火与植物学家的毒之间没有任何化学反应 | 同队时“毒 + 火”各打各的 |
| 功能 / 被动过少 | 功能 3 张、被动 3 张，且三张被动里两张是“DOT 自动增长” | 卡组骨架单一，稀有卡里只有共振调谐能改变打法 |
| 结构重复 | 相位蔓延的单体保底与永燃炉芯都是“灼烧持续 +1”；余温结晶、热能回收、缓冲溶液都是“火 → 盾” | 违反“同一种结构在池内只出现一次” |

## 二、角色定位

**一句话定位：把一切都当作原料——组装、火焰、毒液、共鸣，都可以攒着、兑现，或者炼成别的东西。**

炼金术士是**“转化”型的持续伤害角色**。其他角色的资源通常只有“积累 → 消费”两步，炼金术士的每种资源都有**四种去向**：

| 资源 | 攒着 | 兑现 | 转化 | 放弃换爆发 |
| --- | --- | --- | --- | --- |
| 组装 BUFF | 被汞蒸气、腐骨酸雨、半成品读取 | 凑齐 3 种组装成功 | 逆向拆解：拆掉并**释放** | 终末合剂：全部三倍释放 |
| 灼烧 | 放着烧；永燃炉芯延长；易燃时翻倍 | 烬灭、过量催化：**焚尽**，一次性结算剩余伤害 | 热能回收：火 → 盾 | 衔尾蛇：到期时变成毒 |
| 中毒 | 恒温坩埚增殖 | 植物学家的毒发 | 催化引爆：毒 → 火 | 衔尾蛇：到期时变成火 |
| 共鸣强化 | 留在手里越叠越多 | 打出被强化的牌 | 余韵：传给更低费的牌 | 共鸣崩解：全部拆成群体灼烧 |

### 四大支柱

| 支柱 | 关键词 | 负责什么 | 张数（主要归属） |
| --- | --- | --- | ---: |
| 火 | 灼烧 / 易燃 / 焚尽 | 主输出：铺层、延长、易燃翻倍或焚尽兑现（二选一）、转成护盾 | 9 |
| 毒与反应 | 中毒 / 反应 | 副输出：群体铺毒、毒转火、扩散；补上另一种 DOT 时触发反应 | 9 |
| 组装 | 组装 A ~ D / 释放 | 组装 BUFF 既是“配方进度”，也是可以拆开使用的原料 | 6 |
| 共鸣 | 共鸣 / 余韵 | 从高费往低费打；强化可以叠、可以传、可以拆 | 6 |

> 大多数牌会同时碰到两根支柱，这里只按“主要卖点”归类。

### 设计红线

1. **不设攻击倍率直伤**。输出全部来自灼烧与中毒；焚尽伤害由灼烧层数决定，也不读取攻击倍率。
2. **不设回法力效果**。资源补偿只允许抽牌、组装 BUFF、共鸣强化。
3. **组装规则不变**：同时拥有任意 3 种不同组装 BUFF 立即组装成功，奖励按缺失字母分类随机获得，因此最多同时持有 2 种。
4. **易燃与焚尽互不叠加**：易燃只放大按回合结算的灼烧，不放大焚尽。同一堆火，要么等易燃翻倍烧，要么现在焚尽。
5. **灼烧只由炼金术士施加**（包括淬火涂层借队友之手施加的灼烧，来源仍是炼金术士）；中毒与植物学家共享。
6. **共鸣强化只存在于手牌**，牌离开手牌时清除（余韵、共鸣崩解是唯二的例外出口）。

### 与植物学家的联动

| 方向 | 说明 |
| --- | --- |
| 植物学家 → 炼金术士 | 植物学家铺的毒让双相药剂“补火即反应”；被催化引爆转成灼烧；被衔尾蛇在到期时转成灼烧 |
| 炼金术士 → 植物学家 | 汞蒸气、腐骨酸雨、反应釜壁铺的毒触发毒箭 / 毒发 / 箭毒木 / 菌丝网络；王水蚀刻的【蚀刻】放大植物学家的弓箭直伤；淬火涂层让植物学家的箭矢点火 |
| 状态种类 | 灼烧、易燃、蚀刻都会被植物学家的枯萎孢子计入“负面状态种类” |

> 植物学家的红线“只施加中毒、不读取灼烧”不受影响：淬火涂层施加的灼烧来源是炼金术士。

### 稀有度调整

- **燃素爆燃：罕见 → 稀有**。它是唯一的群体易燃，也是“易燃翻倍”路线成立的前提，属于“有它才成流派”。
- **缓冲溶液：稀有 → 罕见**。它本质上是一张“大数值护盾”，不改变任何规则，不足以占据稀有卡位。

## 五、构筑路线

四条路线各自有明确的核心牌与“每回合要做的决定”，并且可以两两组合。

| 路线 | 核心牌 | 每回合的决定 |
| --- | --- | --- |
| **火** | 燃素爆燃、助燃松脂、烬灭、永燃炉芯 | 同一堆火：**等易燃翻倍烧**、**再延一回合**、**转成护盾**，还是**现在焚尽**？易燃与焚尽只能选一个。 |

### 典型回合示例

**火（易燃与焚尽二选一）**：目标身上有 3 段灼烧共 90 层，剩余 2 回合，敌人下回合要放大招。
- 打助燃松脂（1 AP）：这一拍灼烧翻倍，造成 180 点，剩下的 90 点下回合再烧；省下的 2 AP 可以做别的事。
- 打烬灭（2 AP）：焚尽 90 × 2 × 1.5 = 270 点立刻到账，如果能击杀，大招就不会发生。
- 打热能回收（2 AP）：拿走 45 层，全队获得 90 点护盾，硬扛大招。

**共鸣阶梯（两回合）**：手牌为燃素爆燃（3）、谐波药剂（2）、焰核共鸣（1）、共鸣音叉（0）。
- 第一回合打燃素爆燃：谐波、焰核、音叉各获得 1 次强化。
- 第二回合打谐波药剂：焰核、音叉再各 +1；余韵把谐波身上的 1 次传给最低费的音叉。此时焰核 2 次、音叉 3 次。
- 接着打音叉（0 费）：对目标施加灼烧，再对 3 名随机敌人各弹射一次；或者改打共鸣崩解，把手上 5 次强化全部换成群体灼烧。

**炼成（组装取舍）**：持有组装 A、C，手里有汞蒸气和翠玉镀层（组装 B）。
- 先打汞蒸气：持有 C，群体中毒；再打翠玉镀层，凑齐 A、B、C，组装成功，随机获得一张被动奖励（缺 D）。
- 或者先打逆向拆解拆掉 C（释放：群体中毒），再打翠玉镀层，只持有 A、B，等下一次组装时凑成缺 C 或缺 D。
- 或者什么都不凑，留着 A、C 等终末合剂三倍释放。

## 六、与旧版相比的改动

| 内容 | 处理 | 理由 |
| --- | --- | --- |
| 组装 BUFF | 新增**释放**：被逆向拆解、半成品、终末合剂拆开使用时，按字母结算不同的即时效果 | 让组装 BUFF 成为真正的资源，产生“留着 / 凑满 / 拆掉”的取舍 |
| 灼烧 | 新增**焚尽**，并规定易燃不放大焚尽 | 给灼烧一个“提前兑现”的出口，与易燃形成二选一 |
| 反应 | 新增关键词 | 让炼金术士的火与植物学家的毒产生化学反应 |
| 共鸣 | 新增 0 费底座、余韵、崩解 | 让强化可以往下传、可以拆掉兑现 |
| 相位蔓延 | 单体保底由“灼烧持续 +1”改为“复制给目标自身” | 与永燃炉芯重复 |
| 腐骨酸雨 | 层数上调到统一基准 | 当前群体 `10%` 远低于基准 |
| 反应釜壁 | 组装 D → B | 让每种字母都有 3 张定位不同的来源 |
| 逆向拆解 | 移除组装 BUFF 换护盾 → 移除并释放 | 护盾与 B 的释放重复；释放让“拆哪个”变成有意义的选择 |
| 半成品 | 回合结束护盾 → 回合结束释放一个持有的组装 BUFF | 同上，并奖励“持有组装 BUFF” |
| 终末合剂 | “消耗数 + 1”次群体 DOT → 每种三倍释放 | 让“放弃组装成功”的收益取决于你留着哪两种 |
| 余温结晶（奖励卡） | 替换为《共振晶簇》 | 与热能回收、缓冲溶液同为“火 → 盾” |
| 过量催化（奖励卡） | 灼烧 + 中毒 → 灼烧 + 焚尽 | 给焚尽第二个来源 |
| 燃素爆燃 / 缓冲溶液 | 稀有度互换 | 见第三节 |

## 七、已确认事项（2026-09-28）

1. **组装命名**：保留组装 A / B / C / D，不改名。
2. **组装奖励**：维持“按缺失字母分类，随机获得 1 张”。
3. **焚尽与易燃**：焚尽**不受**易燃影响。易燃只放大按回合结算的灼烧，两者形成二选一。
4. **反应判定时机**：在本卡施加状态**之后**判定。因此反应牌都只施加一种 DOT，“补上另一种”时触发，收益相应下调。
5. **衔尾蛇**：可以连续转化，每次减半，层数不足 1 时停止。
6. **不设持有加成**：组装 BUFF 不附带“持有时生效”的被动加成，只保留“释放”；“持有”的价值由汞蒸气、腐骨酸雨、半成品、终末合剂体现。
7. **旧文档**：《炼金术士改版方案.md》已删除，本方案以代码为基准。

> 所有百分比、层数均为初值，需要在实战中校准。
