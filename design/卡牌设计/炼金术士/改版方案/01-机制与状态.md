# 炼金术士改版方案 · 机制与状态

> 本文件统一炼金术士改版涉及的组装、关键词、状态和组装奖励卡口径。标记说明：`已有` = 代码中已实装；`改` = 已有但规则需调整；`新设` = 本方案新增。
>
> 本文中“灼烧 X%”“中毒 X%”均指施加**炼金术士攻击力 X%** 的层数；“护盾 X%”均指**炼金术士治愈力 X%**。

---

## 一、组装（已有，新增释放）

### 1.1 组装规则（已有，不改）

1. 组装分为 A、B、C、D 四种；打出带“组装 X”的牌后获得对应的组装 BUFF，同种不叠加。
2. 同时拥有任意 3 种不同组装 BUFF 时立即**组装成功**：消耗这 3 种，按缺失的字母**随机**获得 1 张该分类的奖励卡（见第二节）。
3. 因此玩家**最多同时持有 2 种组装 BUFF**。

| 组合 | 缺失字母 | 奖励分类 |
| --- | --- | --- |
| B + C + D | 缺 A | 攻击奖励 |
| A + C + D | 缺 B | 防御奖励 |
| A + B + D | 缺 C | 功能奖励 |
| A + B + C | 缺 D | 被动奖励 |

### 1.2 释放（新设）

> **释放**：按组装 BUFF 的字母，结算一次对应的即时效果。

| 字母 | 释放（每次） | 记忆点 |
| --- | --- | --- |
| A | 对一名随机敌人施加灼烧 `30%`，持续 2 回合 | 火 |
| B | 生命最低的队友获得护盾 `40%` | 盾 |
| C | 对所有敌人施加中毒 `15%`，持续 2 回合 | 毒 |
| D | 手牌中所有共鸣牌各获得 1 次共鸣强化（不受费用限制） | 共鸣 |

释放只由以下三张牌触发：

| 卡牌 | 释放方式 | 是否移除组装 BUFF |
| --- | --- | --- |
| 逆向拆解 | 选择 1 种，释放 1 次 | 移除 |
| 半成品 | 回合结束时随机 1 种，释放 1 次 | **不移除** |
| 终末合剂 | 全部持有的，每种释放 3 次 | 移除，且不触发组装成功 |

**设计意图**：以前组装 BUFF 只是“配方进度”，逆向拆解只用来“甩掉挡路的字母”。现在“拆哪一个”本身就是在四种即时效果之间做选择，而“留着不凑”也有半成品、终末合剂、汞蒸气、腐骨酸雨四张牌给出回报。

### 1.3 组装来源

每种字母由 3 张定位不同的牌提供：

| 字母 | 提供卡（归类 / 费用 / 稀有度） | 说明 |
| --- | --- | --- |
| A | 引火试剂（攻击 1 / 普通）、余烬护壁（防御 2 / 普通）、淬火涂层（功能 1 / 罕见） | 启动器 + 破盾反击 + 队友点火 |
| B | 腐骨酸雨（攻击 2 / 普通）、翠玉镀层（防御 1 / 普通）、反应釜壁（防御 2 / 罕见） | 群体铺毒 + 低费护盾 + 受击铺毒 |
| C | 催化引爆（攻击 2 / 普通）、双相药剂（攻击 1 / 普通）、共振调谐（功能 2 / 稀有） | 毒转火 + 反应补火 + 共鸣引擎 |
| D | 谐波药剂（攻击 2 / 普通）、焰核共鸣（攻击 1 / 罕见）、助燃松脂（功能 1 / 罕见） | 共鸣中段 + 共鸣受体 + 易燃 |
| 任意 | 万能配件（指定）、半成品（被丢弃时补缺）、提纯（不满足条件时补缺） | 调度工具 |

**核心取舍**：想要防御奖励（缺 B），就要忍住不打翠玉镀层、反应釜壁、腐骨酸雨——为了拿防御奖励，先放弃防御牌。想要被动奖励（缺 D），就要放弃整条共鸣中段。

带组装的主体卡为 **12 / 30**（上一版 8 / 18），比例从 `44%` 降到 `40%`。

## 二、组装奖励卡（改）

> 规则不变：按缺失字母分类，**随机**获得 1 张。除被动类外，奖励卡统一为 **1 AP、速攻、消耗**，不含任何回法力效果；被动类奖励卡没有费用，回合结束时进入消耗区。

| 分类 | 卡名 | id | 效果 | 标记 |
| --- | --- | --- | --- | --- |
| 攻击（缺 A） | 过量催化 | `over-catalysis` | 对目标施加灼烧 `50%`（持续 2 回合），然后**焚尽**目标。 | 改 |
| 攻击（缺 A） | 链式燃烧 | `chain-burst` | 对所有敌人施加灼烧 `50%`（持续 2 回合），并施加易燃 1 回合。 | 已有 |
| 防御（缺 B） | 相变护膜 | `phase-membrane` | 全队获得护盾 `60%`。 | 已有 |
| 防御（缺 B） | 回生药剂 | `rejuvenation-potion` | 选择一名队友，恢复 `60%` 生命，并恢复等量体力极限。 | 已有 |
| 防御（缺 B） | 滋补魔药 | `tonic-potion` | 全队恢复 `60%` 生命。 | 已有 |
| 功能（缺 C） | 共鸣催化剂 | `resonance-catalyst` | 手牌中所有共鸣牌各获得 1 次共鸣强化（不受费用限制）；抽 1 张牌。 | 已有 |
| 功能（缺 C） | 灵感药剂 | `inspiration-potion` | 抽 2 张牌。 | 已有 |
| 被动（缺 D） | 赏金猎人 | `bounty-hunter` | 在手中时，每完成一次击杀获得 1 层赏金猎人，战斗结算掉率 `+30%`。 | 已有 |
| 被动（缺 D） | 共振晶簇 | `resonance-crystal` | 在手中时，你打出共鸣牌时，被它强化的每张牌额外获得 1 次强化。 | 新设（替换余温结晶） |

- **过量催化**：原效果“灼烧 + 中毒”与主体卡的火毒组合重复，改为焚尽的第二个来源。两个攻击奖励正好对应火的两条出口：过量催化是焚尽，链式燃烧是易燃。
- **共振晶簇**：原《余温结晶》（施加灼烧时获得护盾）与热能回收、缓冲溶液同为“火 → 盾”，替换为直接服务共鸣阶梯的被动。它是被动奖励（缺 D）——你放弃了 D 字母的共鸣牌，它帮你把剩下的共鸣牌叠得更高。

## 三、持续伤害与火系关键词

### 3.1 统一口径（已有，不改）

灼烧与中毒使用同一套扣血规则，详见《[植物学家改版方案/01-机制与状态.md](../../植物学家/改版方案/01-机制与状态.md)》第一节：层数 + 持续回合，每次施加形成独立的一段，每拍每层扣 1 点生命，无视护盾，默认持续 2 回合。

数值基准：1 AP 单体 ≈ `40%` × 2 回合；群体每个目标按单体的 `0.6` ~ `0.75` 倍。

### 3.2 易燃（已有）

目标处于易燃时，受到的**按回合结算**的灼烧伤害翻倍。**易燃不放大焚尽。**

本方案中的来源：燃素爆燃（群体）、助燃松脂（单体）、链式燃烧（奖励卡）。

### 3.3 焚尽（新设）

> **焚尽**：移除目标身上的全部灼烧，立即造成等同于这些灼烧**剩余总伤害**的伤害。

| 规则 | 口径 |
| --- | --- |
| 剩余总伤害 | 对每一段灼烧计算“层数 × 剩余结算次数”，然后求和。 |
| 伤害性质 | 持续伤害性质：无视护盾，不受穿孔加成，不触发“被攻击”类效果，不受蚀刻加成。 |
| 易燃 | **不受易燃影响**，也不会移除目标的易燃。 |
| 目标没有灼烧 | 不造成伤害，不返还费用。 |

### 3.4 同一堆火的四种用法

| 用法 | 代表卡 | 得到什么 | 失去什么 |
| --- | --- | --- | --- |
| 延长 | 永燃炉芯 | 多烧一回合 | 需要被动牌留在手里 |
| 易燃翻倍 | 助燃松脂、燃素爆燃 | 这一拍翻倍；便宜 | 只有一拍，剩下的慢慢烧 |
| 焚尽 | 烬灭、过量催化 | 所有剩余伤害立刻到账，可以抢在敌人大招前斩杀 | 灼烧清空，易燃白挂；反应态、缓冲溶液的计数随之消失 |
| 转盾 | 热能回收 | 全队护盾 | 一半的灼烧 |

> 易燃与焚尽是**互斥**的两条出口：目标已经易燃时，焚尽等于浪费易燃；准备焚尽时，就没必要先挂易燃。

## 四、反应（新设）

> **反应**：本卡施加状态**之后**，若目标同时带有灼烧与中毒（称为**反应态**），结算反应效果。

| 规则 | 口径 |
| --- | --- |
| 判定时机 | 本卡施加状态之后。本卡自己施加的灼烧 / 中毒计入。 |
| 来源 | 灼烧与中毒的来源不限，植物学家的中毒同样计入。 |
| 显示 | 处于反应态的敌人显示“反应”标记，方便玩家判断。 |
| 群体牌 | 逐个目标判定。 |

**反应牌只施加一种 DOT**，由“补上另一种”来触发，避免一张牌自己完成反应：

| 反应牌 | 本卡施加 | 目标需要已经带有 | 反应效果 |
| --- | --- | --- | --- |
| 双相药剂 | 灼烧 | 中毒（汞蒸气、腐骨酸雨、植物学家……） | 抽 1 张牌 |
| 王水蚀刻 | 中毒 | 灼烧（引火试剂、谐波药剂……） | 目标获得【蚀刻】 |

衔尾蛇让灼烧与中毒到期时互相转化，是长期维持反应态的稀有引擎。

**反应与催化引爆的取舍**：催化引爆会移除目标的全部中毒，打出后目标立刻离开反应态。反应流需要决定“这回合是把毒转成火，还是留着毒继续吃反应收益”。

## 五、共鸣（已有）与余韵（新设）

### 5.1 共鸣（已有，不改）

- 打出一张共鸣牌时，手牌中所有**费用低于该牌**的共鸣牌各获得 1 次共鸣强化。
- 同一张牌可以多次获得强化，效果按次数累加；卡面“共鸣：”一行说明**单次**强化的收益。
- 强化只存在于手牌中，牌离开手牌时清除。

本方案的共鸣费用阶梯：

| 费用 | 共鸣牌 | 角色 |
| --- | --- | --- |
| 0 AP | 共鸣音叉 | 底座：任何共鸣牌都能强化它，每次强化多弹射一个随机目标 |
| 1 AP | 翠玉镀层、焰核共鸣 | 受体：护盾数值 / 强化 3 次后变群体 |
| 2 AP | 余烬护壁、热能回收、谐波药剂 | 中段：既被强化，也强化 0 ~ 1 费；谐波药剂带余韵 |
| 3 AP | 缓冲溶液、燃素爆燃 | 顶端：打出时强化所有低费共鸣牌；缓冲溶液带余韵 |
| 引擎 | 共振调谐（非共鸣牌） | 无视费用强化全部共鸣牌，唯一能强化 3 费牌的主体卡 |
| 出口 | 共鸣崩解（非共鸣牌） | 拆掉全部强化，换成群体灼烧 |

另有组装 D 的释放、共鸣催化剂、共振晶簇三种辅助来源。

### 5.2 余韵（新设）

> **余韵**：本卡打出后，把本卡这次打出时拥有的共鸣强化次数，原样加给手牌中**费用最低的另一张共鸣牌**。

- 费用相同时，取手牌中位置最靠左的一张。
- 余韵与共鸣的正常触发互不影响：打出谐波药剂时，低费共鸣牌先按共鸣规则各获得 1 次，然后最低费的那一张再额外获得余韵传来的次数。
- 本卡没有强化时，余韵不结算。
- 余韵牌：谐波药剂、缓冲溶液。

**设计意图**：以前强化只能“跟着这张牌一起打掉”，余韵让它可以沿着阶梯往下流，最终汇聚到 0 费的共鸣音叉上。

## 六、自身与队友状态

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |
| --- | --- | --- | --- | --- |
| 组装 A ~ D | 已有 | 组装进度；可被释放（见 1.2）。 | 同种不叠加，最多同时 2 种。 | 带“组装 X”的牌 |
| 余烬护壁 | 已有 | 护盾被击破时，对击破者施加记录的灼烧。 | 随护盾移除。 | 余烬护壁 |
| 反应釜壁 | 已有 | 护盾存在期间每受到 1 次攻击，对攻击者施加记录的中毒。 | 随护盾移除。 | 反应釜壁 |
| 淬火 | 新设 | 持有者的攻击每次命中，对目标施加灼烧 `12%`（来源为炼金术士，持续 2 回合）；每张牌最多触发 2 次。 | 不可叠加，持续 2 回合。 | 淬火涂层 |
| 贤者之石 | 新设 | 组装成功时，从本次消耗的 3 种组装 BUFF 中选择 1 种保留。 | 本场战斗，不可叠加，不可驱散。 | 贤者之石 |
| 衔尾蛇 | 新设 | 炼金术士施加的灼烧某一段自然到期时，对同一敌人施加该段层数 `50%` 的中毒（持续 2 回合）；任意来源的中毒某一段自然到期时，对同一敌人施加该段层数 `50%` 的灼烧（来源为炼金术士，持续 2 回合）。转化出的段到期时继续转化，层数不足 1 时停止。 | 本场战斗，不可叠加，不可驱散。 | 衔尾蛇 |

## 八、引擎改动清单（供后续实装参考）

| 改动 | 涉及卡牌 | 说明 |
| --- | --- | --- |
| 释放 | 逆向拆解、半成品、终末合剂 | 按组装字母分派 4 种一次性效果，支持“释放 N 次”“释放但不移除”。 |
| 组装成功保留 | 贤者之石 | 组装成功消耗 BUFF 后，按状态让玩家选择 1 种放回。 |
| 两种组装成功 | 提纯 | 新条件“恰好持有 2 种组装 BUFF”；奖励分类由玩家从 2 个缺失字母中选择，分类内仍随机。 |
| 焚尽 | 烬灭、过量催化 | 遍历目标的灼烧分段，求“层数 × 剩余结算次数”之和，移除分段后一次性结算；**不读取易燃**。 |
| 反应判定 | 双相药剂、王水蚀刻 | 新条件“目标同时带有灼烧与中毒”，在本卡施加状态之后判定；敌人头顶增加反应态标记。 |
| 余韵 | 谐波药剂、缓冲溶液 | 打出后读取本卡的共鸣强化次数，加给手牌中费用最低的另一张共鸣牌。 |
| 共鸣弹射 | 共鸣音叉 | 按共鸣强化次数，对随机敌人追加施加灼烧（可重复选中）。 |
| 移除全部共鸣强化并计数 | 共鸣崩解 | 清空手牌中所有牌的共鸣强化，把总次数传给后续施加灼烧的效果。 |
| 持有指定组装条件 | 汞蒸气 | 新条件“持有组装 C”。 |
| 淬火 | 淬火涂层 | 队友攻击命中钩子，按“每张牌”计数上限；可参照植物学家《授粉》的花粉写法。 |
| DOT 到期转化 | 衔尾蛇 | 分段自然到期时派发事件，状态监听后施加另一种 DOT；被移除的分段不派发。 |
| 蚀刻 | 王水蚀刻 | 直接伤害结算时读取目标状态，增伤 `20%`。 |
| 共振晶簇 | 奖励卡 | 共鸣强化结算时读取手牌中是否有本卡。 |

可以复用的现有实现：

- `GAIN_SQUAD_BUFF` / `REMOVE_SQUAD_BUFF`（含“待选择组装”“随机缺失”）：组装 BUFF 的获得与指定移除。
- `activeCardResonance` 计数：共鸣音叉、焰核共鸣、余韵都基于它扩展。
- `CONSUME_STATUS` + `lastConsumedStatusStacks`：催化引爆已有写法，焚尽可参照。
- `SPREAD_STATUS`、`EXTEND_STATUS`：相位蔓延、永燃炉芯继续沿用。
- `squadBuffCount`、`burningFoeCount`、`aliveFoeCount` 计数：腐骨酸雨、缓冲溶液、相位蔓延继续沿用。
