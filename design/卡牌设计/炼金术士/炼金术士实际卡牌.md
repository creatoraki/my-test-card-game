# 炼金术士实际卡牌

> 本文件记录 `src/data/cards/alchemist/` 中**实际登记**的卡牌，与代码保持一致。改版思路、取舍与构筑路线见《[改版方案/00-总览.md](改版方案/00-总览.md)》。
>
> 共 **30 张主体卡**（普通 15 / 罕见 10 / 稀有 5）+ **9 张组装奖励卡**。
>
> 口径：“灼烧 / 中毒 X%”指施加**炼金术士攻击力 X%** 的层数；“护盾 X%”指**炼金术士治愈力 X%**；未注明时持续 2 回合。

## 一、机制速查

| 机制 | 规则 | 代码落点 |
| --- | --- | --- |
| 组装 | 获得组装 A ~ D；同时持有任意 3 种时立即组装成功，按缺失字母随机获得该分类的奖励卡。 | `engine/combat/squadBuff.ts` |
| 释放 | A：随机敌人灼烧 `30%`；B：生命最低的队友护盾 `40%`；C：所有敌人中毒 `15%`；D：手牌共鸣牌各强化 1 次。 | `engine/effects/effectsAssemble.ts` |
| 焚尽 | 移除目标全部灼烧，立即造成 Σ（每段层数 × 剩余回合）的伤害；无视护盾，不受易燃、蚀刻、穿孔影响。 | `engine/effects/effectsDot.ts` |
| 易燃 | 按回合结算的灼烧伤害翻倍；不影响焚尽。 | `engine/statuses/abandonedFloor.ts` |
| 反应 | 本卡施加状态之后，目标同时带有灼烧与中毒（来源不限）时结算；不显示标记。 | `engine/combat/reaction.ts` |
| 共鸣 | 打出共鸣牌时，手牌中费用更低的共鸣牌各获得 1 次强化；强化离手清除。 | `engine/cards/resonance.ts` |
| 余韵 | 打出后，把本卡的强化次数加给手牌中费用最低的另一张共鸣牌（同费取最左）。 | `engine/cards/resonance.ts` |
| 蚀刻 | 受到的直接伤害 `+20%`；持续伤害不受影响。 | `engine/statuses/alchemist.ts` |
| 淬火 | 队友攻击每次命中，对目标施加灼烧（来源为炼金术士）；每张牌最多 2 次。 | `engine/statuses/alchemist.ts` |
| 贤者之石 | 本场战斗，组装成功时从本次消耗的字母中选择 1 种保留。 | `engine/combat/squadBuff.ts` |
| 衔尾蛇 | 本场战斗，敌人的灼烧 / 中毒某段自然到期时，施加该段 `50%` 层数的另一种 DOT；被移除的分段不转化。 | `engine/statuses/dotEvents.ts` |
