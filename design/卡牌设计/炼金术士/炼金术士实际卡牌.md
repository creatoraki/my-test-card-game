# 炼金术士实际卡牌（第一版卡牌模型）

本批共 **14 张角色主体卡**，另沿用已通过检验的 **9 张组装奖励卡**，合计 23 张。

> 本文件只确定**卡牌结构模型**。所有百分比、层数、阈值均为按《卡牌词条和数值设定.md》基准填入的初值，后续平衡可整体调整，不影响结构。

## 一、设计准则（本次重做的核心）

初版的问题是：**组装字母和共鸣只是贴在伤害卡上的标签**，卡与卡之间是「造成 X% 伤害 + 组装 A」与「造成 Y% 伤害 + 组装 B」的关系，属于 ABCD 与 ABCE 的细微差别。

本版参照剑士的做法。剑士 10 张攻击卡之所以互不重复，是因为**每张卡对"弃牌"这一资源的用法在结构上完全不同**：自弃触发（雪花）、主动弃（落叶）、弃牌降费（迦具土）、自伤放大（血坏）、费用转伤害（幻月）、被弃回手成长（岚）、局内计数（落樱）、血线阈值（狼雀）、全弃终结（天隙流光）。

因此炼金术士的原则是：

**把「组装 BUFF」和「共鸣强化」当作可投放、可消费、可拆除、可转换、可复制的实体资源，而不是被动标签。**

由此得到三条硬性规则，用于判断一张新卡能不能进池：

1. **每张卡必须回答"我对资源做了什么"**，而不是"我贴了哪个标签"。投放 / 消费 / 移除 / 复制 / 缩放 / 转换 / 引爆 / 打破规则，各自成立一种结构。
2. **同一种结构在池内只出现一次**。若两张卡的动词序列相同，只有数值或字母不同，则合并为一张。
3. **奖励分支必须可被玩家操纵**。每个组装字母都由 **2 张定位完全不同的卡**提供，玩家靠"打哪张、不打哪张"来选择奖励分支，这个取舍本身就是玩法。

## 二、机制约定

### 组装

- 组装分为组装 A、B、C、D 四种子词条；打出带组装词条的卡后获得对应 BUFF，同种不叠加。
- 同时拥有任意 3 种不同组装 BUFF 时立即触发**组装成功**，消耗触发本次成功的 3 种 BUFF，第 4 种保留。
- 组装成功按本次 3 种部件的组合获得 1 张临时配方卡（见第五节）。
- **组装 BUFF 可以被主动移除或消费而不触发成功**（逆向拆解、终末合剂），这是本版新增的关键自由度。

### 奖励分支对照（决定卡组构筑目标）

| 组合 | 缺失部件 | 奖励类别 |
| --- | --- | --- |
| B + C + D | 缺 A | 攻击奖励 |
| A + C + D | 缺 B | 防御奖励 |
| A + B + D | 缺 C | 功能奖励 |
| A + B + C | 缺 D | 被动奖励 |

### 共鸣

- 打出一张共鸣牌时，手牌中所有**费用低于该牌**的共鸣牌各获得 1 次共鸣强化。
- 共鸣强化只作用于当前手牌；卡牌离开手牌后未使用的强化清除。
- 同一张卡可多次获得强化，效果按次数累加；每张卡的共鸣行说明**单次**强化收益。

### 异常状态（本职业主要输出手段）

| 状态 | 结算 | 特性 |
| --- | --- | --- |
| 中毒 | 每层每回合损失 5 点 HP | 无视护甲与护盾，不衰减，长线累积 |
| 烧伤 | 每层每回合造成 8 点伤害 | 可被护盾吸收，每回合结束后层数减半（向下取整），前重后轻 |

中毒与烧伤刻意设计成相反的曲线：中毒是"慢慢滚雪球"，烧伤是"立刻兑现然后蒸发"。这样"引爆"和"蔓延"两类卡对两种状态的价值完全不同，不会退化成同一种资源。

> **烧伤的具体定义为本次新增，待确认**，见第六节待办项 1。

## 三、主体卡

## 攻击卡

### 点金试射

- 费用：1 AP
- 卡类型：普通卡
- 稀有度：普通
- 消耗：否
- 效果：造成 `90%` 攻击力的伤害；组装 A；若你当前没有任何组装 BUFF，抽 1 张牌。
- 归类：攻击
- 结构：**启动器**。唯一一张"越早打越强"的卡，负责把第一个部件铺上桌，回合中后期打出时收益自然衰减。

### 腐骨酸雨

- 费用：2 AP
- 卡类型：普通卡
- 稀有度：普通
- 消耗：否
- 效果：**不造成直接伤害**；对所有敌人施加攻击力 `25%` 层数的中毒；你每拥有 1 个组装 BUFF，层数额外 `+15%` 攻击力；组装 B。
- 归类：攻击
- 结构：**零直伤 · 部件数缩放**。全池唯一一张伤害为 0 的攻击卡，收益完全由"手上攒了几个部件"决定，逼迫玩家先铺件再输出。

### 催化引爆

- 费用：2 AP
- 卡类型：速攻卡
- 稀有度：普通
- 消耗：否
- 效果：消耗目标身上**全部中毒层数**，每消耗 1 层造成 `2` 点伤害（无视防御）；若本次消耗层数 ≥ `20`，回复 `1` AP；组装 C。
- 归类：攻击
- 结构：**引爆兑现**。反向消费 DOT，把长线收益一次性提前结算。与腐骨酸雨构成"播种—收割"的一组，但两张卡的动词完全相反。

### 相位蔓延

- 费用：2 AP
- 卡类型：普通卡
- 稀有度：普通
- 消耗：否
- 效果：造成 `60%` 攻击力的伤害；将目标身上的中毒与烧伤层数各 `50%`（向下取整）复制给其他所有敌人。**不提供组装。**
- 归类：攻击
- 结构：**扩散/传染**。全池唯一一张不带任何组装词条的攻击卡——它的定位就是"这回合我不推进组装"，本身即是对奖励分支的取舍。

### 焰核共鸣

- 费用：1 AP
- 卡类型：速攻卡
- 稀有度：罕见
- 消耗：否
- 效果：造成 `50%` 攻击力的伤害并施加 `3` 层烧伤；组装 D；共鸣：烧伤层数 `+3`；本卡每累计获得 3 次共鸣强化，本次改为对**所有敌人**生效。
- 归类：攻击
- 结构：**共鸣受体 · 强化后质变**。唯一一张会因为强化次数而**改变作用范围**（单体→群体）的卡，鼓励留在手里挨强化而不是立刻打出。

### 终末合剂

- 费用：3 AP
- 卡类型：普通卡
- 稀有度：稀有
- 消耗：是
- 效果：消耗你当前**全部**组装 BUFF（**不触发组装成功**）；每消耗 1 个：对所有敌人造成 `70%` 攻击力的伤害并施加攻击力 `20%` 层数的中毒。
- 归类：攻击
- 结构：**放弃奖励换爆发的终结技**。对标剑士的天隙流光。它把"这局我不要奖励卡了"做成一个明确的按钮，是整个组装体系的压力阀。

## 防御卡

### 翠玉镀层

- 费用：1 AP
- 卡类型：速攻卡
- 稀有度：普通
- 消耗：否
- 效果：获得 `35%` 治愈力的护盾；组装 B；共鸣：护盾倍率 `+10%`。
- 归类：防御
- 结构：**共鸣阶梯底端**。纯受体，本身不强化别人，价值完全来自"被打出的高费共鸣卡强化了几次"。

### 反应釜壁

- 费用：2 AP
- 卡类型：普通卡
- 稀有度：普通
- 消耗：否
- 效果：全队获得 `60%` 治愈力的护盾；该护盾存在期间，队伍每受到 1 次攻击，对攻击者施加攻击力 `15%` 层数的中毒；组装 D。
- 归类：防御
- 结构：**反伤护盾**。唯一一张把"挨打"转成输出资源的卡，收益随敌方出手次数增长，与"敌人越多越强"的群体牌形成不同的强度曲线。

### 溶解替身

- 费用：2 AP
- 卡类型：速攻卡
- 稀有度：普通
- 消耗：否
- 效果：选择一名队友，移除其**全部**负面状态；每移除 1 个，全队获得 `25%` 治愈力的护盾（若一个都没移除，仍获得 1 次）；组装 A。
- 归类：防御
- 结构：**净化转护盾**。收益完全由敌方压制强度决定的浮动牌，在无 debuff 局面是废牌，在重压局面是全场最强防御。

## 功能卡

### 万能配件

- 费用：2 AP
- 卡类型：速攻卡
- 稀有度：普通
- 消耗：否
- 效果：**选择 1 种组装词条**（A/B/C/D）并获得对应 BUFF；抽 1 张牌。
- 归类：功能
- 结构：**万能件**。玩家指定奖励分支的正向工具，把组装从"看手牌吃什么"变成"我要什么"。

### 逆向拆解

- 费用：1 AP
- 卡类型：速攻卡
- 稀有度：普通
- 消耗：否
- 效果：**移除自身 1 个随机的组装 BUFF**；回复 `2` 点 AP 并抽 1 张牌。
- 归类：功能
- 结构：**反向消费部件**。与万能配件互为镜像：一个用来"补上想要的字母"，一个用来"甩掉挡路的字母"。这两张一起把奖励分支从随机变成可控，是本套卡组的操作核心。

### 共振调谐

- 费用：2 AP
- 卡类型：普通卡
- 稀有度：稀有
- 消耗：否
- 效果：手牌中所有共鸣卡各获得 `2` 次共鸣强化（**不受费用限制**）；组装 C。
- 归类：功能
- 结构：**打破规则的引擎**。全池唯一一张无视"费用低于本卡"这条共鸣前提的卡，是共鸣流的唯一发动机，也是共鸣阶梯的顶端。

## 被动卡

### 恒温坩埚

- 费用：无
- 卡类型：被动卡
- 稀有度：罕见
- 消耗：否
- 效果：你的回合结束时，使所有已中毒的敌人中毒层数额外 `+10%` 攻击力；有敌人在中毒状态下死亡时，回复 `1` AP。本卡被丢弃时，立即结算一次全场中毒伤害。
- 归类：被动
- 结构：**DOT 引擎**。让"场上已存在的毒"自行增长，奖励铺毒后拖延的打法。

### 半成品

- 费用：无
- 卡类型：被动卡
- 稀有度：普通
- 消耗：否
- 效果：你的回合结束时，随机获得 1 个你当前**没有**的组装 BUFF；本卡被丢弃时，立即获得 1 个你缺少的组装 BUFF。
- 归类：被动
- 结构：**自动积件**。它会持续把你往"凑齐 3 件"推，代价是**你无法控制它给你哪个字母**——它和逆向拆解构成"自动积累 vs 手动纠偏"的对抗关系，这是这套卡组最主要的决策张力。

## 四、结构差异对照表

用于自检"是否又变回了 ABCD / ABCE"。任意两行的动词序列都不相同：

| 卡牌 | 对资源做了什么 | 全池唯一性 |
| --- | --- | --- |
| 点金试射 | 投放部件，空场时额外抽牌 | 唯一"越早越强"的卡 |
| 腐骨酸雨 | 按部件数缩放群体播毒 | 唯一直伤为 0 的攻击卡 |
| 催化引爆 | 消费目标 DOT 换即时伤害 | 唯一清空 DOT 的卡 |
| 相位蔓延 | 复制 DOT 到其他敌人 | 唯一无组装词条的攻击卡 |
| 焰核共鸣 | 接收共鸣强化，累积后改变作用范围 | 唯一会变更目标范围的卡 |
| 终末合剂 | 消费全部部件且不触发成功 | 唯一主动放弃奖励的卡 |
| 翠玉镀层 | 纯共鸣受体 | 共鸣阶梯底端 |
| 反应釜壁 | 把承受攻击转为施加 DOT | 唯一反伤卡 |
| 溶解替身 | 把移除的 debuff 数转为护盾 | 唯一收益随敌方压制浮动的卡 |
| 万能配件 | 指定投放任意部件 | 唯一可选字母的卡 |
| 逆向拆解 | 移除自身部件换 AP 与抽牌 | 唯一移除部件的卡 |
| 共振调谐 | 无视费用规则批量强化共鸣 | 唯一打破共鸣前提的卡 |
| 恒温坩埚 | 让已存在的 DOT 自行增长 | 唯一 DOT 增殖引擎 |
| 半成品 | 自动补缺部件（不可控） | 唯一自动获得部件的卡 |

## 五、组装字母分布

每个字母由 **2 张定位完全不同的卡**提供，确保四条奖励分支都能被主动构筑，且每条分支都要付出"少打一张好牌"的代价：

| 字母 | 提供卡（归类 / 费用） | 说明 |
| --- | --- | --- |
| A | 点金试射（攻击 1）、溶解替身（防御 2） | 一张启动器 + 一张浮动防御 |
| B | 腐骨酸雨（攻击 2）、翠玉镀层（防御 1） | 一张核心播毒 + 一张低费护盾 |
| C | 催化引爆（攻击 2）、共振调谐（功能 2） | 一张收割 + 一张共鸣引擎 |
| D | 反应釜壁（防御 2）、焰核共鸣（攻击 1） | 一张反伤 + 一张共鸣受体 |
| 任意 | 万能配件（指定）、半成品（随机补缺） | 调度工具 |
| 无 | 相位蔓延、终末合剂、逆向拆解、恒温坩埚 | 不推进或反向消耗组装 |

**核心取舍**：想要攻击奖励（缺 A）就必须放弃点金试射与溶解替身；想要被动奖励（缺 D）就必须放弃反应釜壁与焰核共鸣。每条奖励路线都在牺牲一部分卡池强度。

## 六、共鸣费用阶梯

| 费用 | 共鸣卡 | 角色 |
| --- | --- | --- |
| 1 AP | 翠玉镀层、焰核共鸣 | 受体（被强化） |
| 2 AP | 共振调谐 | 发动机（无视费用强化全部） |

共鸣卡刻意只做 3 张。共鸣是本职业的**次要机制**，用于给"留牌不打"提供理由，不承担主要输出，避免和组装抢占卡位。

> 组装组合决定奖励分类；每次组装成功**随机获得 1 张**该分类的卡。

| 卡牌 | 效果 |

| 卡牌 | 效果 |
| --- | --- |

| **无限财宝** | 此卡在手中时，若重新完成组装，则获得临时卡「无限财宝」：抽 4 张牌，恢复 4 点 AP。 |

## 九、稀有度分布

稀有度只表达**强度层级**，不表达机制复杂度：普通卡构成卡组的日常骨架，罕见卡强度明显高出一截，稀有卡是卡池上限。

| 稀有度 | 数量 | 卡牌 | 定位 |
| --- | ---: | --- | --- |
| 普通 | 8 | 点金试射、腐骨酸雨、催化引爆、相位蔓延、翠玉镀层、溶解替身、万能配件、逆向拆解 | 卡组骨架。单张收益与费用基本等价，价值来自与其他卡的配合而非自身强度 |
| 罕见 | 4 | 焰核共鸣、反应釜壁、恒温坩埚、半成品 | 强度明显高一截。要么持续产出（两张被动），要么把一次性费用转成随时间增长的收益 |
| 稀有 | 2 | 终末合剂、共振调谐 | 卡池最强。终末合剂是唯一的爆发终结技，共振调谐是唯一打破共鸣规则的引擎，两者都能单独决定一整套构筑 |

**分级理由**：

- **普通**：包含全部 4 张基础输出卡与全部 3 张低强度调度卡。腐骨酸雨、催化引爆、相位蔓延虽然结构独特，但收益都依赖前置条件（部件数、目标毒层、多目标），空转时接近废牌，因此归入普通。
- **罕见**：焰核共鸣有质变上限（单体→群体）；反应釜壁把防御回合转成输出回合；恒温坩埚与半成品是仅有的两张零费用持续产出卡，不打出即生效，强度天然高于任何单次结算的卡。
- **稀有**：终末合剂可一次性把全部部件兑换为群体爆发＋群体中毒，是唯一的"清盘"按钮；共振调谐无视费用阶梯批量强化，是共鸣流成立的唯一前提。两张卡都属于"有则成套、无则不成流派"。
