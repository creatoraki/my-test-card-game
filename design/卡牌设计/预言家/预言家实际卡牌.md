# 预言家实际卡牌

> **状态**：已登记至 `src/data/cards/prophet/`，共 30 张正式卡（普通 15 / 罕见 10 / 稀有 5），另有临时卡《伴星》《光谱碎片》。卡池配置见 `src/data/roster/characters.ts`。
>
> 设计来源：`改版方案/` 目录。本文件记录**实际落地的口径**，与方案不一致的地方以本文件为准。

## 一、关键词口径

- **汇星 N**：预言家获得 N 层星辉。星辉上限 3 层，《银河》可以提高到 5 层。
- **应星**：结算费用时优先用星辉替代法力水晶，每层替代 1 点，牌面费用不变。
- **星契**：常驻卡牌增益。这张牌的所属者变为预言家，并可以用星辉支付。本场战斗持续；打出、离手都不会移除，也不能被引力牵引搬运或被光谱分解剥离。
- **瀑布**：本卡的当前费用严格高于手牌中其他所有可打出的牌时触发。【倒泻】【天顶星】可以视为满足瀑布条件。
- **星印**：预言家专属卡牌增益，包括沉重、逆流、多米诺、彗尾、流光。
  - 每个星印使费用 +1，同名星印不叠加。
  - 打出时先结算本牌效果，再以**预言家**为来源结算星印收益，然后移除星印；预言家阵亡时只保留抬价，收益不再结算。
  - 离开手牌（弃置、回合结束）时移除，不结算收益。
- **预言**：`预言（期限）：条件。应验：奖励。落空：结果。`
  - 同时只能存在 1 个预言。打出异名预言时，旧预言直接移除（不结算落空）；打出同名预言时只刷新期限，进度保留。
  - 预言不可驱散。状态提示显示剩余期限，《天启》还会显示累计进度。

| 星印 | 打出收益 |
| --- | --- |
| 沉重 | 无 |
| 逆流 | 汇星 1 |
| 多米诺 | 抽 1 张牌 |
| 彗尾 | 对随机敌人造成预言家攻击力 30% 的伤害 |
| 流光 | 本次出牌视为速攻，不推进时刻 |
