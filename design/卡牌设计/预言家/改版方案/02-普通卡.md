# 预言家改版方案 · 普通卡（15）

> 数值锚点：攻击 1 / 2 / 3 AP = `90%` / `150%` / `200%`；治疗与护盾 1 / 2 / 3 AP = `50%` / `80%` / `120%`。汇星 1 约等于伤害倍率 `40%`，抽 1 张约等于 `35%`。
>
> 普通卡原则：**一个钩子，一眼能读懂**，不依赖整套构筑也能打出基础价值。

## 攻击

### 碎星（回归 · 重做）

- **代码 id**：`star-shatter`
- **费用**：1 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：一名敌人
- **效果**：造成 `70%` 攻击力的伤害；应星。本次每消耗 1 层星辉，随机使 1 张其他手牌获得【彗尾】（优先选择没有彗尾的牌）。
- **卡面文本**：造成 `{0}` 点伤害。应星。每消耗 1 层星辉，随机使 1 张其他手牌获得彗尾。
- **独有特色**：把星辉“打碎”嵌进其他手牌。本身是 1 费牌，只能消耗 1 层星辉；被星印抬价之后可以一次碎出 2～3 枚彗尾，是星印体系的“星印复印机”。
- **数值核算**：`70%` + 彗尾延迟的 `30%` = `100%`，代价是被嵌入的牌费用 `+1`，而这份代价又会喂给瀑布和《小行星带》。

### 登月（微调）

- **代码 id**：`moon-landing`
- **费用**：0 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：一名敌人
- **效果**：造成 `40%` 攻击力的伤害。瀑布：额外造成 `100%` + 当前费用 × `50%` 攻击力的伤害。
- **卡面文本**：造成 `{0}` 点伤害。瀑布：额外造成 100% + 当前费用 ×50% 攻击力的伤害。
- **独有特色**：0 费牌几乎不可能成为唯一最高费，只有被星印抬价后才会“起飞”。它是星印最理想的载体：抬到 2 费时，瀑布总伤害为 `40% + 200% = 240%`。
- **改动**：基础伤害 `50%` → `40%`。0 费无条件 `50%` 在只有 3 点法力的环境里偏高。

### 天穹断罪（回归 · 重做）

- **代码 id**：`celestial-verdict`
- **费用**：3 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：一名敌人
- **效果**：造成 `180%` 攻击力的伤害；应星。若目标的招式将在 `1` 时刻内发动：该招式推迟 `1` 时刻。
- **卡面文本**：造成 `{0}` 点伤害。应星。若目标的招式即将发动，将其推迟 1 时刻。

- **设计说明**：3 费牌天然容易成为最高费，所以**不给瀑布**；星辉是它的主要支付方式，3 层星辉可以免费打出。
- **数值核算**：`180%` + 应星 + 条件推迟，对照 3 AP 标准 `200%`。

### 极光（回归 · 重做）

- **代码 id**：`aurora`
- **费用**：1 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：一名队友
- **效果**：为一名队友提供 `40%` 治愈力的护盾。使手牌中当前费用最高的 1 张牌获得【流光】（并列时随机；已有流光的牌跳过）。

- **代码 id**：`astrology`
- **费用**：0 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：自身
- **效果**：查看抽牌堆顶 3 张牌，选择 1 张加入手牌并附加【沉重】；其余牌留在原位。

- **独有特色**：卡池中唯一的“挑牌”。代价是【沉重】，但对预言家来说，沉重本身就是一次“免费的抬价”。

### 预知魔眼（重做）

- **代码 id**：`foresight-eye`
- **费用**：1 AP
- **卡类型**：普通卡（normal）
- **稀有度**：普通（common）
- **目标**：自身
- **效果**：翻开抽牌堆顶 1 张牌。若为攻击牌，由其所属角色自动对随机敌人使用，不消耗法力；否则加入手牌。自动使用不触发瀑布、汇星与星印。
- **卡面文本**：翻开抽牌堆顶 1 张牌：攻击牌自动对随机敌人使用，其他牌加入手牌。
- **独有特色**：预言家替队友“提前出手”。翻到队友的 3 费攻击时，等于用 1 费打出一张 3 费牌；翻到其他牌也不亏，等于 1 费抽 1。
- **改动**：费用 2 → 1；删除含糊的“获得【天顶星】”描述，改为明确的“不消耗法力、不触发任何附加效果”。可与《占星术》先挑牌、后翻牌配合。

### 吉兆（新增）

- **代码 id**：`good-omen`
- **费用**：0 AP
- **卡类型**：速攻卡（fast）
- **稀有度**：普通（common）
- **目标**：自身
- **效果**：预言（至下回合结束）：任意敌人被击杀。应验：汇星 2。
- **卡面文本**：预言（至下回合结束）：有敌人被击杀。应验：汇星 2。
- **独有特色**：预言体系的入门牌。0 费、速攻，打出后什么都不发生，要靠队伍的击杀来兑现。同名预言不叠加，多带也只能刷新期限，避免连锁暴涨。
- **数值核算**：条件难度“中”，奖励按 1.5 倍放大：汇星 2 ≈ `80%` 伤害价值，折算后等价于一张 1 费牌，符合 0 费 + 条件的定位。
