# 预言家改版方案 · 机制与状态

> 本文件统一预言家改版涉及的关键词、卡牌增益、角色状态和临时卡口径。标记说明：`已有` = 代码中已实装；`改` = 已有但规则需调整；`新设` = 本方案新增。

---

## 一、关键词口径

### 1.1 星辉三件套（已有）

| 关键词 | 口径 |
| --- | --- |
| 汇星 N | 卡牌成功使用后，预言家获得 N 层星辉。星辉上限 `3`（《银河》可提高）。 |
| 应星 | 结算费用时，优先用星辉替代法力水晶，每层星辉替代 1 点。牌面费用不变。 |
| 星契 | 卡牌增益。带有星契的牌视同应星。**改**：星契牌可以消耗**小队中预言家**的星辉，不再只限于牌的所属角色。 |

**本方案引用的两个支付条件**（引擎中已有）：

- **全额星辉支付**：本次费用全部由星辉支付，没有消耗法力水晶（对应 `fullyStarPaid`）。
- **每消耗 1 层星辉**：按本次实际消耗的星辉层数计数（对应 `activeCardStarSpent`）。

### 1.2 瀑布（已有，补充一条）

- 使用本卡时，若本卡的**当前费用**严格高于手牌中其他所有可打出的牌，则触发瀑布效果。
- 本身费用越低的牌，瀑布奖励应该越好；本身费用越高的牌，瀑布奖励应该越小。
- **补充**：“按当前费用缩放”的瀑布奖励（星瀑、登月）属于例外——它们奖励的是**被星印抬高的费用**，而不是牌面费用，所以允许随费用增长。

### 1.3 星印（新设，统一已有的三种增益）

**星印**是预言家专属的一类卡牌增益，共同规则如下：

1. 每个星印使所挂载牌的费用 `+1`。
2. 牌被打出时，先完成本牌效果，再结算星印效果，然后移除该星印。
3. 同名星印不能重复挂在同一张牌上；不同星印可以共存，费用分别 `+1`。
4. 星印效果**永远以预言家为来源**：汇星加给预言家，伤害按预言家的攻击力计算，即使挂在队友的牌上也一样。
5. 星印牌离开手牌（被弃、被消耗）时，星印一并移除，不结算效果。

| 星印 | 标记 | 打出收益 | 主要来源 |
| --- | --- | --- | --- |
| 沉重 | 已有 | 无，只抬价。 | 占星术 |
| 逆流 | 已有 | 汇星 1。 | 逆流 |
| 多米诺 | 已有 | 抽 1 张牌。 | 多米诺（被动） |
| 彗尾 | 新设 | 对随机敌人造成预言家攻击力 `30%` 的伤害。 | 碎星 |
| 流光 | 新设 | 本牌视为速攻，不推进时刻。 | 极光 |

> **为什么抬价是收益**：抬价后的牌更容易成为唯一最高费（触发瀑布），可以消耗更多星辉（碎星、天顶星、坠星序列按消耗量结算），并且能被《小行星带》《黑洞》《登月》读取。代价是真实的法力压力——这正是星辉存在的意义。

### 1.4 预言（新设）

**预言**是预言家对未来下的断言，写法统一为：

```
预言（期限）：[条件]。应验：[奖励]。落空：[结果]。
```

| 规则 | 口径 |
| --- | --- |
| 挂载 | 打出预言牌后，预言家获得对应的预言状态，状态名为【预言·卡名】。 |
| 应验 | 期限内条件达成时，立即结算应验效果并移除该预言。 |
| 落空 | 期限结束时条件仍未达成，结算落空效果（没写落空则直接移除）。 |
| 叠加 | 同名预言不叠加，再次打出时刷新期限，进度保留。不同预言可以同时存在。 |
| 驱散 | 预言不可被驱散。 |
| 可见性 | 状态提示中必须显示条件、剩余期限和当前进度（例如《天启》显示“已消耗星辉 4 / 6”）。 |
| 指定敌人 | 针对某名敌人的预言（《凶兆》），同时在该敌人身上显示【凶兆】标记，该敌人死亡时预言直接落空。 |

预言属于效果模板中“状态持续期间满足条件时触发”的结构（C-20 系），区别在于它**只挂在预言家身上**，并且自带落空分支。

| 状态 | 标记 | 效果 | 叠加 / 持续 | 来源 |

| 天顶星 | 已有 | 下一张带瀑布效果的牌无视费用比较触发瀑布，随后移除。 | 1 层。 | 天顶星 |
| 引力透镜 | 已有 | 下一张实际触发瀑布的牌，其瀑布效果额外结算一次，随后移除。 | 1 层。 | 引力透镜 |
