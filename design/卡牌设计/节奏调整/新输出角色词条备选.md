# 新输出角色 · 词条备选

> **状态**：备选清单，待你挑选。本文不含代码改动。
>
> 用法：第二章是**词条库**（30 个词条，可自由组合；K11~K20 为第二批、K21~K30 为第三批补充，均为触发条件类）；第三章是我推荐的 **5 套角色方案**（每套两个特色关键词 + 初始卡组样例）。你可以直接选一套，也可以从词条库里自己搭两个。

---

## 一、设计约束

新角色需要同时满足以下条件，词条库里每一项都按这些约束检查过。

| 约束 | 说明 |
| --- | --- |
| 不撞现有机制 | 已占用：弃牌 / 速攻（剑士）、星契 / 瀑布 / 星印 / 预言（预言家）、穿孔 / 满弓 / 毒箭 / 培育（植物学家）、组装 / 共鸣 / 灼烧 / 中毒（炼金术士）、保险 / 回响 / 急诊（精算师）。 |
| 可做成模组 | 角色的两个关键词都要能做成"关键词模组"，装到其他角色的牌上形成连携（制造者自己不能装）。 |
| 初始卡组自洽 | 只靠初始 5 张就能在一场战斗内触发自身关键词至少 2 次（见《初期节奏调整方案》1.3）。 |
| 输出定位 | 初始 5 张至少 4 张造成伤害；面板攻击力不低于剑士的 105 量级。 |
| 回应节奏问题 | 优先选择能缓解"卡比费少"（根因三）或能缩短战斗（根因四）的机制。 |

数值口径沿用《卡牌词条和数值设定》：1 费标准 90%，2 费 150%，3 费 200%。

## 二、词条库

### K1 · 瞄准（词条设定库已有，未被使用）

- **规则**：用瞄准牌攻击**未被瞄准**的目标时，为其附加【被瞄准】；攻击**已被瞄准**的目标时，移除【被瞄准】并触发瞄准效果。【被瞄准】战斗内保留，所有瞄准牌共用。
- **卡面示例**：标定射击（1 费）：60% 伤害。瞄准：额外造成 90% 伤害。
- **模组形态**：瞄准模组（攻击牌）——按上述规则附加 / 消耗被瞄准；触发时本次伤害 +40%。
- **优点**：两拍节奏清晰，"队友上标记、本人收割"的连携一目了然。
- **风险**：第一拍收益低，需要 0 费或速攻的上标记牌来补节奏。

### K2 · 伺机 N

- **规则**：目标的下一个招式将在 N 时刻内发动时触发。
- **常见效果**：伤害提高、推迟目标招式 1 时刻、打断蓄力。
- **模组形态**：伺机模组（攻击牌）——伺机 1：本次伤害 +30%。
- **优点**：唯一真正围绕本作核心特色"时刻轴"的输出词条，鼓励玩家读敌人意图、卡点出手。
- **风险**：依赖敌人招式排程的可读性；战斗界面必须清楚显示"距离发动还有几个时刻"。
- **已有先例**：预言家《天穹断罪》的"目标招式将在 1 时刻内发动时推迟 1 时刻"，判定口径可直接复用。

### K3 · 处决 X%

- **规则**：目标当前生命 ≤ 最大生命 X% 时触发。
- **常见效果**：伤害翻倍、击杀返还法力、必定暴击。
- **模组形态**：处决模组（攻击牌）——处决 25%：本次伤害 +50%。
- **优点**：直接缩短战斗收尾；和植物学家 / 炼金术士的中毒、灼烧压血线天然配合。
- **风险**：首领战前半段完全不触发，需要第二个词条承担首领战。

### K4 · 狩猎（词条设定库已有，未被使用）

- **规则**：用狩猎牌**击杀**目标时，获得 1 层【狩猎】（上限 3，战斗内保留）。打出狩猎牌时，按当前层数重复其狩猎效果。
- **首领补丁**：首领每损失 25% 最大生命，视为一次击杀（每个 25% 段只算一次）。
- **卡面示例**：回收钩索（1 费）：60% 伤害。狩猎：对随机敌人造成 40% 伤害。
- **模组形态**：猎获模组（攻击牌）——本卡击杀目标时，为制造者获得 1 层狩猎。
- **优点**：越打越快的雪球感，多敌人遭遇战里非常爽。
- **风险**：第一场击杀前没有收益；层数上限必须严格。

### K5 · 连击 N

- **规则**：本回合全队已打出的攻击牌数（不含本卡）≥ N 时触发。剑士弃牌自动打出的攻击牌计入。
- **卡面示例**：勾拳（1 费）：80% 伤害。连击 1：抽 1 张牌。
- **模组形态**：连击模组（攻击牌）——连击 2：抽 1 张牌。
- **优点**：全队任何输出都能喂，和剑士、植物学家、预言家都能直接联动。
- **风险**：全队每回合 3 点法力，一回合最多 3~4 张攻击牌，N 只能取 1~3；需要 0 费攻击牌撑次数。

### K6 · 终结

- **规则**：本回合每打出一张攻击牌获得 1 点【连段】（全队共享，回合结束清零）。终结牌打出时消耗全部连段，每点提供卡面写明的加成。
- **卡面示例**：上勾拳（1 费）：50% 伤害。终结：每点连段伤害 +25%。
- **模组形态**：终结模组（攻击牌）——终结：每点连段本次伤害 +15%。
- **优点**：给"一回合打很多张"一个明确出口，回合内出牌顺序有讲究。
- **风险**：与连击共用"攻击牌计数"，单独使用时深度一般，适合与 K5 打包。

### K7 · 装填 N

- **规则**：本卡打出后不进入弃牌堆，而是**回到手牌**，装填 -1；装填为 0 时正常进入弃牌堆，再次抽到时装填重置。
- **卡面示例**：速射手枪（1 费）：60% 伤害。装填 2。
- **模组形态**：装填模组（1 费攻击牌）——装填 1；本卡伤害 -20%。
- **优点**：直接解决"卡比费少"：一张牌能打多次，法力不再浪费。
- **风险**：一直占着手牌位置；数值必须压在 60%~70%，否则会挤掉队友出牌。

### K8 · 过热

- **规则**：本回合每打出一次本卡，本卡获得 1 层【过热】：伤害 +30%、费用 +1。回合结束时清空。
- **卡面示例**：霰弹（2 费）：全体 50% 伤害。过热。
- **模组形态**：过热模组（攻击牌）——同上，每层伤害 +25%。
- **优点**：与装填天然配对；抬费本身就是限次器，不需要额外次数上限。还能借抬费触发预言家的瀑布。
- **风险**：单独使用时（没有装填 / 回手）几乎不会触发第二层。

### K9 · 蓄能 N

- **规则**：队伍中有蓄能角色时，回合结束未用完的法力转为【蓄能】（上限 3，战斗内保留）。带"蓄能 N"的牌打出时，可额外消耗 N 层蓄能获得强化。**蓄能不能用来支付费用**（与预言家的星辉区分）。
- **卡面示例**：高压电弧（2 费）：130% 伤害。蓄能 2：伤害 +100%。
- **模组形态**：蓄能模组（任意牌）——打出时若有蓄能，消耗 1 层，本卡数值 +40%。
- **优点**：把第 3 回合起每回合浪费的 1 点法力直接变成伤害，精准回应根因三。
- **风险**：新增一种全队资源，界面要有位置显示；和星辉的区别必须在文案里写清楚。

### K10 · 追击

- **规则**：本回合该目标已被我方攻击命中过时触发（来源不限，包括本角色之前打出的牌）。
- **卡面示例**：跳线（1 费）：所有敌人 40% 伤害。追击：对已被命中的敌人额外 40%。
- **模组形态**：追击模组（攻击牌）——追击：本次伤害 +30%。
- **优点**：鼓励集火，几乎任何队友都能满足条件，上手门槛低。
- **风险**：条件太容易满足，深度有限；适合做副词条。

### 第二批词条（K11~K20 · 触发条件类）

> **口径**：词条只定义"什么时候触发"，触发后结算什么由每张卡在冒号后自己写（同一个词条在不同卡上可以是加伤、抽牌、施加状态等）。模组形态 = 该触发条件 + 一条固定效果。
>
> 每个词条都标注了对应《效果模板》里的条件编号；没有现成编号的是本批新设的条件。判定依据都是战斗代码里已有的数据：敌人护盾跨回合保留、敌人意图分 攻击 / 防御 / 增益 / 减益 / 特殊 五类、敌人行动点攒到大招消耗 1.5 倍时强制放大招、手牌回合结束不弃置、普通牌和待机推进时刻而速攻牌不推进、每回合法力 3 点不结转。名称已避开项目中已占用的（伏击、破绽、背水、接力等）。

### K11 · 击穿（C-15）

- **触发条件**：本卡的伤害把目标的护盾打空时触发（结算前目标有护盾、结算后护盾为 0）。多段攻击只判定一次。
- **卡面示例**：
  - 破壳锤（1 费）：80% 伤害。击穿：再造成 60% 伤害。
  - 撬棍（1 费 · 速攻）：50% 伤害。击穿：目标获得 2 回合破甲。
- **模组形态**：击穿模组（攻击牌）——击穿：追加 40% 伤害。
- **优点**：回收装甲、充能外壳、防御意图在两张地图里都很常见，护盾是战斗拖长的原因之一（根因四）；引擎已有护盾被击破的钩子。
- **风险**：不上盾的敌人完全不触发，适合做副词条。

### K12 · 先制（C-85 的出牌时版本）

- **触发条件**：打出时，本回合还没有任何敌人发动过招式。判定在本卡推进时刻之前，所以回合第一张普通牌也能满足。
- **卡面示例**：
  - 抢攻（1 费 · 速攻）：70% 伤害。先制：抽 1 张牌。
  - 迎头痛击（1 费）：90% 伤害。先制：伤害 +50%。
- **模组形态**：先制模组（攻击牌）——先制：本次伤害 +30%。
- **优点**：直接围绕时刻轴；速攻牌不推进时刻，回合开头连打速攻牌能稳定满足，与剑士速攻、预言家流光星印天然联动。界面只需一个"先制中"标识。
- **风险**：与挑战词条「抢拍」都看"敌人第一次行动前"，文案要区分；敌人招式延迟只有 1 时刻时，普通牌最多只有一张能触发。

### K13 · 后发 N（C-83）

- **触发条件**：打出时，本回合已推进至少 N 个时刻（普通牌、待机都算）。
- **卡面示例**：
  - 蓄满一枪（2 费）：130% 伤害。后发 2：伤害 +100%。
  - 收网（1 费）：70% 伤害。后发 1：抽 1 张牌。
- **模组形态**：后发模组（攻击牌）——后发 2：本次伤害 +30%。
- **优点**：与先制正好相反——先制奖励"抢在敌人之前"，后发奖励"顶着敌人出招再打"，让待机从纯粹的拖延变成铺垫。
- **风险**：推进时刻会让敌人出招，玩家要先扛一轮伤害；需要战斗界面清楚显示本回合已推进的时刻数。

### K14 · 看破（C-34 的细化）

- **触发条件**：目标当前蓄力的招式**不是攻击招式**（防御 / 增益 / 减益 / 特殊）时触发；目标本回合没有在蓄力时也算。
- **卡面示例**：
  - 趁虚而入（1 费）：80% 伤害。看破：伤害 +60%。
  - 破势（1 费）：70% 伤害。看破：目标招式推迟 1 时刻。
- **模组形态**：看破模组（攻击牌）——看破：本次伤害 +30%。
- **优点**：鼓励"敌人要打就防、敌人上盾或上增益就猛攻"；与 K11 击穿组成"它上盾我就拆"的闭环；与「洞察」状态天然联动。
- **风险**：⚠ 现有战斗界面**默认隐藏敌人意图**，只有目标带「洞察」时才显示招式类型，平时只显示倒计时与"⚠ 行动 / ✦ 蓄势"提示。需要二选一：①卡牌在手时，对满足看破的敌人单独高亮；②新角色自带洞察来源。另外攻击招式占比很高的敌人几乎不触发；与 K2 伺机同为读招词条，不建议放在同一角色身上。

### K15 · 孤注 N（C-61）

- **触发条件**：打出时手牌（不含本卡）不超过 N 张。N 取 1~2。
- **卡面示例**：
  - 最后一发（1 费）：90% 伤害。孤注 1：伤害翻倍。
  - 甩手雷（1 费）：所有敌人 50% 伤害。孤注 2：抽 2 张牌。
- **模组形态**：孤注模组（攻击牌）——孤注 2：本次伤害 +40%。
- **优点**：手牌回合结束不弃、上限 7，玩家习惯囤牌；孤注给"打空手牌"一个理由。与剑士弃牌清手牌直接联动。
- **风险**：抽牌效果会让孤注失效，新角色卡池里的抽牌要克制。

### K16 · 倾注（C-58）

- **触发条件**：支付本卡费用后，法力恰好为 0。只看法力水晶；本卡费用为 0 或全额用星辉支付时不触发。
- **卡面示例**：
  - 倾泻弹幕（2 费）：所有敌人 60% 伤害。倾注：再结算 1 轮 40%。
  - 余烬弹（1 费）：80% 伤害。倾注：抽 1 张牌。
- **模组形态**：倾注模组（费用 1 及以上的牌）——倾注：本卡数值 +30%。
- **优点**：直接奖励"把法力花光"，精准回应"卡比费少"（根因三）；条件是开关型，手牌上高亮"本次可倾注"即可。
- **风险**：与 0 费牌、星辉支付的边界必须在文案里写清；与 K9 蓄能方向相反（一个要花光、一个要留下），不能同时出现。

### K17 · 破阵 X%（C-03）

- **触发条件**：目标当前生命不低于最大生命 X%（常用 100% / 80%）。
- **卡面示例**：
  - 开刃（1 费）：80% 伤害。破阵 100%：伤害 +60%。
  - 横扫（2 费）：所有敌人 70% 伤害。破阵 80%：对满足条件的敌人额外 40%。
- **模组形态**：破阵模组（攻击牌）——破阵 100%：本次伤害 +30%。
- **优点**：处决的反面：处决负责收尾，破阵负责开局，多敌人遭遇战的第一轮清场非常有感；与装备属性"冲锋精通"天然叠加。
- **风险**：每个敌人通常只能吃到一次，首领战偏弱；与处决放在同一角色身上会两头不靠中间段。

### K18 · 穿插（C-54）

- **触发条件**：上一张打出的牌属于其他角色。回合第一张牌不触发。
- **卡面示例**：
  - 掩护射击（1 费）：80% 伤害。穿插：抽 1 张牌。
  - 交叉火力（2 费）：150% 伤害。穿插：伤害 +50%。
- **模组形态**：穿插模组（任意牌）——穿插：本卡数值 +25%。
- **优点**：引擎已记录上一张打出的牌，**零新系统**；把"队伍"变成出牌顺序上的决策，装在其他角色的牌上同样成立。
- **风险**：与 K5 连击、剑士连续弃牌这类"同角色连打"的思路相反；状态模板里已有同义的「接力」状态，二者不要同时上线。

### K19 · 据守（C-42）

- **触发条件**：本卡所属角色当前有护盾。
- **卡面示例**：
  - 盾击（1 费）：70% 伤害。据守：额外造成自身当前护盾 50% 的伤害。
  - 稳射（1 费）：80% 伤害。据守：命中 +20%、暴击率 +20%。
- **模组形态**：据守模组（攻击牌）——据守：本次伤害 +30%。
- **优点**：护盾跨回合保留，精算师、炼金术士的护盾都能喂；让防护牌在输出角色手里也有进攻价值。只靠初始的基础防护即可自洽。
- **风险**：敌人集火该角色把盾打掉后整套失效；护盾数值高的队伍里条件几乎恒真，深度有限。

### K20 · 临界（新设条件）

- **触发条件**：目标当前行动点已达到其大招消耗（即下一次有能力放大招）。没有大招的敌人按其最贵的招式计算。
- **卡面示例**：
  - 截断（1 费）：70% 伤害。临界：目标失去 2 点行动点。
  - 要害一击（2 费）：130% 伤害。临界：伤害 +80%。
- **模组形态**：临界模组（攻击牌）——临界：本次伤害 +30%。
- **优点**：敌人行动点是本作独有的系统（每回合回点、跨回合保留、1.5 倍时强制放大招）；临界把"首领快要放大招了"变成可读、可利用的时机，首领战价值很高。
- **风险**：需要在敌人身上显示行动点与大招阈值；杂兵战触发频率取决于敌人回点速度，需要实测。

### 第三批词条（K21~K30 · 触发条件类）

> 口径同第二批：词条只定义触发条件，效果写在每张卡的冒号后。本批按"读什么"分组：读命中结果（K21）、读目标（K22~K25）、读战场（K26）、读出牌顺序（K27~K28）、读战斗进程（K29）、读自身（K30）。名称已避开项目中已占用的「蓄势」（通用模组名、敌人增益意图提示）。

### K21 · 会心（C-12）

- **触发条件**：本次攻击至少有一段暴击时触发。判定在伤害结算之后，所以效果只能写"追加 / 后续"类。
- **卡面示例**：
  - 精确点射（1 费）：80% 伤害。会心：抽 1 张牌。
  - 弱点打击（1 费）：70% 伤害，暴击率 +20%。会心：目标获得 1 回合易伤。
- **模组形态**：会心模组（攻击牌）——会心：追加 30% 伤害。
- **优点**：暴击率、爆伤已是完整的面板与装备属性，会心把它们从"数值期望"变成"有事件感的触发"；引擎的伤害效果已支持"暴击时结算"，零新系统。
- **风险**：纯随机，节奏不可控；暴击率最终值封顶 70%，新角色面板暴击率需要给到 20% 左右，否则初始卡组难以"一场触发 2 次"。

### K22 · 首击（C-16）

- **触发条件**：目标本回合还没有受到过我方伤害（任意来源）。
- **卡面示例**：
  - 破门（1 费）：80% 伤害。首击：伤害 +50%。
  - 散射（2 费）：所有敌人 60% 伤害。首击：对满足条件的敌人附加 1 回合虚弱。
- **模组形态**：首击模组（攻击牌）——首击：本次伤害 +30%。
- **优点**：鼓励分散攻击、每个敌人先"开一刀"，多敌遭遇战里收益稳定；群攻牌天然能吃满。
- **风险**：与 K10 追击条件完全相反，不能出现在同一角色身上；首领单体战每回合只有第一张牌能触发；引擎目前只记录"我方被敌人打过"，需要补一份"敌人本回合被我方打过"的记录。

### K23 · 恶毒 N（C-32）

- **触发条件**：目标身上的减益种类不少于 N 种。N 取 2~3。
- **卡面示例**：
  - 落井下石（1 费）：70% 伤害。恶毒 2：伤害 +80%。
  - 撕裂（1 费）：80% 伤害。恶毒 3：再造成 1 段 60% 伤害。
- **模组形态**：恶毒模组（攻击牌）——恶毒 2：本次伤害 +30%。
- **优点**：中毒、灼烧、穿孔、迟滞、蚀刻、虚弱、易伤、破甲……全队的减益都能喂，是最开放的跨角色接口；引擎已有"目标减益种类"计数，状态图标本身就是界面。
- **风险**：减益少的队伍（剑士 + 预言家）很难触发；与炼金术士的反应（灼烧 + 中毒）观感接近，但条件更宽，需要在数值上低于反应。

### K24 · 对决（C-38）

- **触发条件**：场上存活的敌人只剩 1 名。
- **卡面示例**：
  - 单挑（1 费）：90% 伤害。对决：伤害 +40%。
  - 死斗（2 费）：140% 伤害。对决：抽 1 张牌。
- **模组形态**：对决模组（攻击牌）——对决：本次伤害 +25%。
- **优点**：首领战几乎全程触发，普通战的收尾阶段也会触发，正好补"首领战拖沓"；引擎已有存活敌人计数，零新界面。
- **风险**：会召唤小怪的首领会让条件断断续续；多敌遭遇战前半段完全无用，必须与一个群战向词条搭配。

### K25 · 擒王（C-37）

- **触发条件**：目标是场上当前生命最高的敌人（并列都算）。
- **卡面示例**：
  - 斩首（2 费）：150% 伤害。擒王：伤害 +60%。
  - 截击射击（1 费）：70% 伤害。擒王：目标招式推迟 1 时刻。
- **模组形态**：擒王模组（攻击牌）——擒王：本次伤害 +30%。
- **优点**：把"打谁"变成决策：多敌战里要不要先啃最肉的那个；首领通常是生命最高者，首领战稳定触发。
- **风险**：首领战里与 K24 对决效果重叠，二者不要放在同一角色身上；打残最高生命的敌人后目标会切换，与"集火收尾"的直觉相反。

### K26 · 乘胜（C-04）

- **触发条件**：本回合已有敌人死亡（任意来源，包括中毒、灼烧）。
- **卡面示例**：
  - 追亡（1 费）：80% 伤害。乘胜：回复 1 点法力。
  - 横扫残敌（2 费）：所有敌人 60% 伤害。乘胜：伤害 +50%。
- **模组形态**：乘胜模组（攻击牌）——乘胜：本次伤害 +30%。
- **优点**：多敌战的连锁清场感；和 K4 狩猎不同，不要求本卡亲手击杀、也不积层，全队任何击杀都能开启，规则更轻。
- **风险**：首领单体战完全不触发；引擎需要补一个"本回合是否有敌人死亡"的标记（现有记录只针对挑战词条的首次击杀）。

### K27 · 按兵（C-56）

- **触发条件**：本回合还没有打出过攻击牌（任何角色）。
- **卡面示例**：
  - 蓄力一击（2 费）：150% 伤害。按兵：伤害 +60%。
  - 架枪（1 费 · 速攻）：60% 伤害。按兵：命中 +30%、暴击率 +30%。
- **模组形态**：按兵模组（攻击牌）——按兵：本次伤害 +30%。
- **优点**：给"先出防护 / 功能牌、再打第一刀"一个理由，回合内出牌顺序从"先打伤害"变成"先布防再爆发"；引擎已记录本回合出过的牌。
- **风险**：每回合只有第一张攻击牌能触发；与 K5 连击、K6 终结方向相反，不能同角色同带。

### K28 · 合拍 N（C-51）

- **触发条件**：本卡恰好是本回合打出的第 N 张牌（任何角色、任何类型都计数）。
- **卡面示例**：
  - 第三拍（1 费）：80% 伤害。合拍 3：伤害翻倍。
  - 二连（1 费 · 速攻）：70% 伤害。合拍 2：抽 1 张牌。
- **模组形态**：合拍模组（攻击牌）——合拍 3：本次伤害 +40%。
- **优点**：精确计数形成出牌顺序谜题，全队任意牌都能凑数；手牌上可以直接高亮"下一张就是第 N 张"。
- **风险**：与 K5 连击（攻击牌数 ≥ N）思路接近，不要同角色同带；每回合法力 3 点，N 只能取 2~3，取 3 时需要 0 费牌或星辉凑数。

### K29 · 久战 N（C-81）

- **触发条件**：战斗已进入第 N 回合及以后。N 取 3~4。
- **卡面示例**：
  - 耐心狙击（1 费）：70% 伤害。久战 3：伤害 +80%。
  - 消耗战（2 费）：130% 伤害。久战 4：抽 2 张牌。
- **模组形态**：久战模组（攻击牌）——久战 3：本次伤害 +30%。
- **优点**：战斗越拖越强，专门回应首领战拖沓；回合数界面上已有，零新系统。
- **风险**：普通战 2~3 回合就结束时完全无用，前几回合角色像白板，初始卡组必须有不靠词条的基础输出。

### K30 · 全盛（C-41）

- **触发条件**：本卡所属角色的生命已达到体力极限（当前可回复的上限，而不是最大生命）。
- **卡面示例**：
  - 全力挥击（2 费）：150% 伤害。全盛：伤害 +50%。
  - 从容射击（1 费）：80% 伤害。全盛：暴击率 +30%。
- **模组形态**：全盛模组（攻击牌）——全盛：本次伤害 +30%。
- **优点**：体力极限是本作独有的设定（受伤会留下永久损伤），"回满到极限"比"满血"更容易达成；与精算师保险到期回血、回响形成新联动，治疗角色的溢出治疗不再浪费。
- **风险**：被敌人打一下就失效，敌人集火时很不稳定；与 K19 据守同属"读自身"类，同角色不要同带。

## 三、推荐角色方案

### 方案一 · 回收猎人（狩猎 + 处决）⭐ 推荐

- **概念**：控制终端最常见的工单是"回收失控机器人"。回收猎人是冬眠前的机械回收员，带电磁鱼叉和切割刃，专门收拾残骸。
- **单机制**：处决负责收尾；狩猎负责击杀后的连锁。
- **混合机制**：处决击杀 → 获得狩猎层 → 狩猎效果"对随机敌人造成伤害"把下一只压进处决线 → 再击杀。
- **与现有角色联动**：植物学家 / 炼金术士的中毒、灼烧压血线 → 处决；剑士的弃牌自动打出补刀算作击杀来源（若为狩猎牌）。
- **为什么推荐**：最直接回应"战斗拖太长"；规则简单，不需要新界面；世界观契合度最高。

| 初始卡 | 费用 | 效果 |
| --- | ---: | --- |
| 切割鱼叉 | 1 | 90% 伤害。处决 30%：伤害翻倍。 |
| 回收钩索 | 1 | 60% 伤害。狩猎：对随机敌人造成 40% 伤害。 |
| 拆解刃 | 1 · 速攻 | 70% 伤害。处决 30%：击杀时回复 1 点法力。 |
| 废料炸弹 | 2 | 所有敌人 60% 伤害。狩猎：再结算 1 轮 30%。 |
| 基础防护 | 1 | 50% 护盾 |

建议面板：HP 65 / 攻击 105 / 治愈 80 / 防御 5 / 暴击 15% / 爆伤 150%。

### 方案二 · 测绘狙击手（瞄准 + 伺机）

- **概念**：冬眠前的城市测绘员，用测距仪改装的长枪。冷静、慢、一枪致命。
- **单机制**：瞄准两拍出爆发；伺机卡敌人出招前的时刻出手。
- **混合机制**：瞄准的第二拍如果同时满足伺机，追加"推迟目标招式 1 时刻"——爆发与控制同时到账。
- **与现有角色联动**：瞄准模组让剑士 / 植物学家帮忙上标记；预言家《天穹断罪》同为伺机口径。
- **适合**：想要一个首领战专家、喜欢读招的玩法。

| 初始卡 | 费用 | 效果 |
| --- | ---: | --- |
| 标定射击 | 1 | 60% 伤害。瞄准：额外造成 90% 伤害。 |
| 校准 | 0 · 速攻 | 使一名敌人被瞄准。伺机 2：抽 1 张牌。 |
| 穿心弹 | 2 | 120% 伤害。瞄准：伤害 +80%，且不可被格挡。 |
| 截击 | 1 · 速攻 | 70% 伤害。伺机 2：推迟目标招式 1 时刻。 |
| 基础防护 | 1 | 50% 护盾 |

建议面板：HP 55 / 攻击 110 / 治愈 80 / 防御 0 / 暴击 20% / 爆伤 170%。

### 方案三 · 枪械技师（装填 + 过热）

- **概念**：城市维护部门的武器维修技工，一把反复改装的连射手枪。
- **单机制**：装填让同一张牌一回合打多次；过热让重复打出越打越痛。
- **混合机制**：装填负责"能再打一次"，过热的抬费负责"不能无限打"，两者互为限制，不需要额外次数上限。
- **与现有角色联动**：过热抬费 → 手牌最高费 → 预言家瀑布；炼金术士淬火"每次命中附加灼烧"吃多次打出。
- **适合**：想彻底解决卡流瓶颈、喜欢一回合连打的爽感。

| 初始卡 | 费用 | 效果 |
| --- | ---: | --- |
| 速射手枪 | 1 | 60% 伤害。装填 2。过热。 |
| 霰弹 | 2 | 所有敌人 50% 伤害。过热。 |
| 换弹 | 0 · 速攻 | 一张手牌的装填 +1，抽 1 张牌。 |
| 冷却喷雾 | 1 · 速攻 | 移除手牌所有过热，每移除 1 层获得 15% 治愈力的护盾。 |
| 基础攻击 | 1 | 90% 伤害 |

建议面板：HP 60 / 攻击 100 / 治愈 85 / 防御 5 / 暴击 10% / 爆伤 150%。

### 方案四 · 地下拳手（连击 + 终结）

- **概念**：冬眠前的地下格斗场拳手，赤手配机械拳套（普通武器池里已有拳套）。
- **单机制**：连击看本回合全队打了几张攻击牌；终结把这些攻击牌换成一记重拳。
- **混合机制**：0 费刺拳垫连段 → 连击牌过牌 → 终结牌收尾，回合内出牌顺序有讲究。
- **与现有角色联动**：剑士的弃牌自动打出白送连段；预言家星辉支付让一回合能多打一张攻击牌。
- **适合**：喜欢团队节奏、每回合都在规划出牌顺序的玩法。

| 初始卡 | 费用 | 效果 |
| --- | ---: | --- |
| 刺拳 | 0 · 速攻 | 30% 伤害。 |
| 勾拳 | 1 | 80% 伤害。连击 1：抽 1 张牌。 |
| 上勾拳 | 1 | 50% 伤害。终结：每点连段伤害 +25%。 |
| 组合拳 | 2 | 3 段各 40% 伤害。连击 2：追加 1 段。 |
| 基础防护 | 1 | 50% 护盾 |

建议面板：HP 70 / 攻击 100 / 治愈 80 / 防御 5 / 闪避 20% / 暴击 10%。

### 方案五 · 电网技师（蓄能 + 追击）

- **概念**：城市独立电网至今仍在运转。电网技师是冬眠前的线路维修员，用改装电弧枪接入城市电网。
- **单机制**：蓄能把剩余法力存下来；追击奖励集火同一目标。
- **混合机制**：本回合先用便宜的牌命中目标（满足追击），剩余法力留作蓄能，下一回合用高压电弧一次性放掉。
- **与现有角色联动**：任何队友的攻击都能满足追击；精算师 / 炼金术士这类费用用不满的队伍最受益。
- **适合**：想要一个"永不浪费法力"的稳定输出位，上手最简单。

| 初始卡 | 费用 | 效果 |
| --- | ---: | --- |
| 电弧点射 | 1 | 80% 伤害。追击：获得 1 层蓄能。 |
| 电容充能 | 0 · 速攻 | 获得 1 层蓄能。 |

## 五、自由组合时的注意

| 组合 | 说明 |
| --- | --- |
| 蓄能 + 装填 | 两个都在解决卡流 / 法力浪费，功能重叠，不建议同时出现。 |
| 处决 + 追击 | 都偏"收尾加伤"，缺少前期铺垫，初始卡组难以自洽。 |
| 连击 + 过热 | 都是"本回合打多张"，可行，但需要 0 费牌，数值风险较高。 |
| 瞄准 + 处决 | 可行：瞄准打爆发，处决收尾；首领战偏强、杂兵战偏弱。 |
| 伺机 + 任意 | 伺机依赖时刻倒计时显示，先确认界面能支持再选。 |
| 击穿 + 看破 | 推荐：敌人上盾时意图不是攻击，看破先加伤，击穿再收尾，两个词条读同一个时机。 |
| 先制 + 后发 | 可行但上手难：回合前半段要别推进时刻，后半段要推进时刻，同一角色的牌会互相拉扯。 |
| 倾注 + 蓄能 | 冲突：倾注要求把法力花光，蓄能要求留下法力。 |
| 孤注 + 穿插 | 可行：孤注要清手牌、穿插要交替出牌，都鼓励一回合多出牌，方向一致。 |
| 破阵 + 处决 | 不建议：一个只管满血、一个只管残血，中段完全没有触发。 |
| 临界 + 伺机 | 都是读首领的时机词条，杂兵战偏弱，初始卡组要保证有不靠词条的基础输出。 |
| 首击 + 追击 | 冲突：条件完全相反。 |
| 首击 + 乘胜 | 推荐：首击负责多敌开刀，乘胜负责第一只倒下后的连锁清场，两者都偏多敌战，需要队友补首领战。 |
| 恶毒 + 久战 | 推荐：减益随回合堆叠，久战随回合解锁，越打越强，首领战专精。 |
| 对决 + 擒王 | 首领战里两者几乎同时满足，功能重叠。 |
| 按兵 + 连击 / 终结 | 冲突：按兵要求本回合还没出攻击牌，连击 / 终结要求出过很多张。 |
| 合拍 + 连击 | 都在数本回合出牌张数，深度重叠。 |
| 全盛 + 据守 | 都读自身状态，被集火时同时失效。 |
| 会心 + 擒王 | 可行：擒王打首领稳定触发，会心提供随机爆点，适合"首领杀手"定位。 |
