# 咒术师 · 机制与状态

> 本文件统一咒术师的关键词、代价机制、专属状态、关键词模组、初始卡组与面板口径。标记说明：`已有` = 代码中已实装；`模板` = 《状态模板》中已列但未实装；`新设` = 本方案新增。
>
> 本文中“X% 伤害”均指**咒术师攻击力 X%**；“护盾 X%”均指**咒术师治愈力 X%**；未注明时持续 2 回合。

---

## 一、关键词

### 1.0 词条奖励口径：只给机制，不给数值

满足恶毒或后发之后，卡牌必须**换一种工作方式**，不能只是“同样的事做得更多”。

| 禁止作为词条奖励 | 允许作为词条奖励 |
| --- | --- |
| 伤害 / 护盾 / 治疗 +X% | **形态**：作用范围改变（单体 → 全体、单体减益 → 全体减益） |
| 对同一目标追加一段伤害 | **规则**：视为速攻、无视防御 / 格挡 / 护盾、改写本回合时刻推进 |
| 本场战斗永久 +X% 数值 | **时序**：推迟招式、打断招式、封住大招 |
| 多施加几层、多施加一种同类减益 | **流转**：返回手牌、从牌堆挑牌、夺取增益、复制 / 汇集减益 |
| 持续时间单纯延长 | **关系**：敌人之间传导伤害、操纵敌人攻击、反转敌人招式、即死 |

> 卡牌的**基础效果**可以按数值读取（如咒爆按种类兑现、盈煞按抽走的行动点加伤），因为那是这张牌本身的玩法，不是词条奖励。

### 1.1 恶毒 N（新设 · 触发条件 C-32）

> **恶毒 N**：判定时，目标身上的**减益种类**不少于 N 种，则结算冒号后的效果。

| 口径 | 说明 |
| --- | --- |
| 计入什么 | 目标身上所有 `kind = debuff` 的状态，**按种类计数**，层数与段数不影响（三段中毒仍算 1 种）。队友施加的减益同样计入。标记类状态（锁魂、疫病、咒丝）不计入。 |
| 判定时机 | 在本卡**写在前面的效果结算之后**判定。因此“先施加厄运，再造成伤害；恶毒 3”中，本卡施加的厄运会计入。 |
| 群体牌 | 逐个目标分别判定。 |
| N 的取值 | **3~4**。普通卡 3；罕见卡 3~4；稀有卡 4。减益很容易堆起来，2 种不构成门槛。 |
| 咒誓 | 持有咒誓时，判定种类视为 +1（见稀有卡《咒誓》）。 |
| 界面 | 手牌中有恶毒牌时，悬停敌人显示“当前减益 X 种”；满足条件的敌人描边高亮。 |

引擎已有“主目标减益种类”计数（`primaryDebuffKinds`），只需新增关键词判定。

### 1.2 后发 N（新设 · 触发条件 C-83）

> **后发 N**：打出本卡时，本回合已经推进了不少于 N 个时刻，则结算冒号后的效果。

| 口径 | 说明 |
| --- | --- |
| 怎么计数 | 已推进时刻数 = 当前时刻 − 回合起始时刻。**全队**的普通牌都计入（法力是全队共享的）。 |
| 判定时机 | 本卡**自己的推进不计入**——判定在本卡结算前、推进时刻前完成。 |
| N 的取值 | **2~5**，只有起始卡迟咒用 2。普通卡 2~3；罕见卡 3~4；稀有卡 5。 |
| 界面 | 回合信息处显示“本回合已推进 X 时刻”；满足后发的手牌高亮。 |

**时刻预算**：每回合法力 3 点（全队共享），待机每回合 1 次。

| 推进来源 | 法力 | 推进 |
| --- | ---: | ---: |
| 任意 1 费普通牌 | 1 | 1 |
| 待机 | 0 | 1 |
| 敲更（0 费普通牌） | 0 | 1 |
| 沉吟 | 1 | 2 |
| 逢魔时刻（之后每张普通牌） | 0 | +1 |
| 速攻牌 | — | 0 |

- 不用任何加速：两张 1 费牌 + 待机 = 3，第三张 1 费牌满足**后发 3**。
- **后发 4**：敲更 + 待机 + 沉吟 = 4，只花 1 点法力，剩 2 点打收尾。
- **后发 5**：在后发 4 的基础上再打一张 1 费牌，剩 1 点法力收尾；或者用逢魔时刻。

**设计意图**：时刻轴原本是“代价”——推进时刻会让敌人出手。后发把它变成“资源”：咒术师愿意让时间流逝，代价是队伍要先扛住敌人的招式。

### 1.3 饲咒 N（新设 · 代价机制 P-57）

> **饲咒 N**：目标敌人获得 N 点行动点。

这是咒术师的**负面修正**：带饲咒的牌，数值高于同费用基准，代价是敌人更早攒够行动点、被迫提前放大招。

| 口径 | 说明 |
| --- | --- |
| 结算时机 | 本卡伤害结算**之后**。若目标已被击杀，饲咒不生效（因此“打死它”就是免除代价的方法）。 |
| 承担者 | 默认是本卡主目标；卡面可以改写（如嫁祸由其他敌人承担）。 |
| 效果 | 只增加行动点，**不会让敌人立即行动**，也不改变当前正在蓄力的招式。影响的是敌人下一次抽招与“行动点 ≥ 大招消耗 × 1.5 时强制放大招”的判定。 |
| 上限 | 不设上限；首领被喂得越多，越可能连续放大招。 |
| 界面 | 敌人身上必须显示**行动点**与**大招阈值**，否则玩家无法评估代价（见总览 Q2）。 |

**饲咒闭环**：喂（丧钟、嫁祸、敕令、咒誓）→ 锁（锁魂钉封住大招）→ 收（盈煞抽走行动点兑现成伤害）。

| 结构 | 卡牌 | 说明 |
| --- | --- | --- |
| 固定代价 | 丧钟 | 每次打出都付 |
| 转嫁代价 | 嫁祸 | 由生命最低的其他敌人承担，可以“喂给快死的小怪” |
| 条件代价 | 敕令 | 后发未满足时才付，提前打出要付钱 |
| 全体代价 | 咒誓 | 所有敌人各获得行动点，换取本场战斗的规则改写 |
| 封锁 | 锁魂钉 | 恶毒满足时，被喂满的敌人暂时放不出大招 |
| 收益端 | 盈煞 | 抽走目标的行动点变成伤害，把代价变燃料 |

## 二、专属状态

| 状态 | 种类 | 标记 | 效果 | 持续 | 叠加 | 来源 |
| --- | --- | --- | --- | --- | --- | --- |
| 厄运 | 减益 | 新设 | 持有者受到攻击时，攻击者本次暴击率 +20%。 | 2 回合 | 不叠层，刷新持续 | 咒钉、护身符（反咒）、漏刻 |
| 怨咒 | 减益 | 新设 | 持有者每受到 1 段攻击伤害（命中且造成伤害），额外失去施加者攻击力 10% 的生命；无视防御、格挡与护盾。 | 2 回合 | 不叠层，刷新持续 | 缠丝、漏刻 |
| 封印 | 减益 | 模板 | 无法获得增益。 | 2 回合 | 不叠层，刷新持续 | 封口符、漏刻 |
| 锁魂 | 标记 | 新设 | 不会因行动点达到阈值被强制放大招；下一次抽招不会抽到大招。持有者发动一次招式后移除。不计入减益种类，不可驱散。 | 直到下次发动招式 | 不叠层 | 锁魂钉 |
| 疫病 | 标记 | 新设 | 本回合内，持有者每获得 1 种减益，其他所有敌人也获得一份相同的减益（层数、持续相同）。复制出的减益不会再次扩散。不计入减益种类。 | 本回合 | 不叠层 | 疫咒 |
| 咒丝 | 标记 | 新设 | 持有者受到攻击伤害后，其他持有咒丝的敌人失去该伤害 40% 的生命；无视防御、格挡与护盾；传导出的生命损失不会再次传导。场上只剩 1 名持有者时无效。不计入减益种类。 | 本回合 | 不叠层 | 蔓咒 |
| 反咒 | 增益 | 新设 | 本回合内受到敌方攻击时，对攻击者施加厄运 1 回合。 | 本回合 | 不叠层 | 护身符 |
| 停摆 | 增益 | 新设 | 本回合内，我方打出的所有牌都不推进时刻（视为速攻打出）；待机仍正常推进。 | 本回合 | 不叠层 | 停摆 |
| 咒誓 | 增益 | 新设 | 本场战斗中，咒术师的恶毒判定时，目标减益种类视为 +1。不可驱散。 | 本场战斗 | 不叠层 | 咒誓 |
| 逢魔 | 增益 | 新设 | 本回合内，咒术师的普通牌每张多推进 1 时刻。 | 本回合 | 不叠层 | 逢魔时刻 |

### 通用减益（已有）

| 状态 | 效果 | 咒术师来源 |
| --- | --- | --- |
| 虚弱 | 造成的攻击伤害 ×0.7 | 蔓咒 |
| 萎靡 | 攻击力 -15% | 迟咒（后发 2 时改为全体） |
| 破甲 | 防御力 -5 | 定身符 |

咒术师**单人**最多能提供 6 种减益（厄运、怨咒、封印、虚弱、萎靡、破甲）。起始卡组一回合就能凑出 3 种（怨咒、萎靡、厄运），恶毒 4 需要专门铺垫或队友配合。

### 设计说明

- **怨咒不是持续伤害**：它按受击段数结算，多段攻击（剑士、缠丝）收益最高。这让它与中毒、灼烧不在同一条轴上。
- **厄运服务于输出**：咒术师面板暴击率 15%，厄运让全队打这个目标时更容易暴击，也给装备里的暴击属性一个落点。
- **封印直接采用《状态模板》已列的口径**，与“驱散类卡先清后封”的模板用法一致（见封口符）。
- **锁魂、疫病、咒丝是标记而不是减益**：它们是词条奖励，如果也算一种减益，就会反过来帮自己凑恶毒，形成自循环。

## 三、关键词模组

沿用《角色关键词模组设计》的约定：由咒术师在装配舱制造，**不能装在咒术师自己的牌上**。模组效果同样遵守 1.0 的口径，只给机制。

| 模组 | 装配条件 | 效果 |
| --- | --- | --- |
| 恶毒模组 | 单体攻击牌，且不属于咒术师 | 恶毒 3：本次攻击无法被闪避与格挡。 |
| 后发模组 | 普通牌（非速攻），且不属于咒术师 | 后发 3：本卡视为速攻打出，不推进时刻。 |

> 不设饲咒模组：饲咒是代价机制，单独做成模组等于"给敌人送行动点"，没有收益。

## 四、关键词与队伍节奏

| 问题 | 咒术师的回应 |
| --- | --- |
| 根因三：卡比费少 | 敲更 0 费抽牌；咒钉满足恶毒后回手；窥魂后发时从牌堆挑牌 |
| 根因四：战斗拖长 | 饲咒的超额数值、咒丝传导、百鬼夜行全体化、咒杀即死，都直接缩短战斗 |
| 时刻轴的价值 | 后发让“推进时刻”有收益；停摆、后发模组又能在攒够时刻后把推进关掉，给剑士的速攻流提供反向搭档 |

| --- | --- | --- |
| 基础攻击 | 通用 | 输出 |
| 基础治疗 | 通用 | 续航 |
| 基础防护 | 通用 | 防护 |
| 咒钉 | 普通卡 | 自带厄运；恶毒 3 时回手 |
| 迟咒 | 普通卡 | 施加萎靡；后发 2 时萎靡改为全体 |
| 缠丝 | 普通卡 | 提供怨咒 |

- **输出牌 4 张**（基础攻击、咒钉、迟咒、缠丝），满足输出定位。
- **关键词自洽**：缠丝 → 待机 → 迟咒（后发 2，全体萎靡）→ 咒钉（怨咒 + 萎靡 + 厄运，恶毒 3，回手），刚好 3 点法力，第一回合就能让两个关键词各触发一次。

## 六、引擎改动清单

| 内容 | 改动 | 涉及 |
| --- | --- | --- |
| 恶毒 | 新增关键词条件：目标减益种类 ≥ N；群体牌逐目标判定；咒誓 +1；标记类状态不计入 | 效果条件、卡牌词条注册 |
| 后发 | 新增计数：本回合已推进时刻（当前时刻 − 回合起始时刻），判定在本卡推进前 | 效果条件 |
| 饲咒 | 新增效果：目标敌人行动点 +N；伤害后结算，目标已死亡时跳过；支持指定承担者 | 效果类型、敌人行动点 |
| 抽走行动点（盈煞） | 新增效果：移除目标至多 N 点行动点，按实际移除数加伤 | 效果类型、敌人行动点 |
| 行动点显示 | 敌人身上显示行动点与大招阈值 | 战斗界面 |
| 厄运 / 怨咒 / 反咒 / 咒誓 / 逢魔 | 新增状态；怨咒挂在“受到攻击后”钩子，按段触发 | 状态定义 |
| 封印 | 新增状态（按《状态模板》口径）：施加增益时拦截 | 状态定义 |
| 锁魂 | 新增标记：跳过强制大招判定；抽招时排除大招；发动招式后移除 | 状态定义、敌人行动 |
| 疫病 | 新增标记：挂在“获得减益后”钩子，复制给其他敌人且标记为不可再扩散 | 状态定义 |
| 咒丝 | 新增标记：挂在“受到攻击伤害后”钩子，向其他持有者传导生命损失 | 状态定义、伤害 |
| 停摆 / 沉吟 / 逢魔 | 出牌推进时刻数可被卡牌或状态修改（含改为 0） | 出牌推进 |
| 减益改为全体（迟咒） | 卡牌效果的施加目标可被条件改写为所有敌人 | 效果条件 |
| 夺取增益（噬魂） | 新增效果：把目标 1 个增益按剩余持续转移给咒术师 | 状态转移 |
| 打断招式 | 新增效果：取消目标当前蓄力的招式并重新抽招，已扣行动点不返还 | 敌人行动 |
| 反转招式（咒怨人偶） | 新增效果：敌人攻击招式的目标改为发动者自身 | 敌人行动、被动卡 |
| 操纵（牵线傀儡） | 新增效果：目标对另一名敌人造成其攻击力 X% 的伤害 | 伤害 |
| 汇集（万咒归宗） | 新增效果：把其他敌人的全部减益转移到目标 | 状态转移 |
| 即死（咒杀） | 新增效果：生命低于阈值时直接击杀，首领阈值单独配置 | 伤害 |
| 被动事件 | 新增“敌人发动招式时”“时刻推进后”两种被动触发 | 被动卡 |
| 已有可复用 | 推迟招式、驱散增益、转移减益、吸血、回手、预知、抽牌、多段伤害 | — |
