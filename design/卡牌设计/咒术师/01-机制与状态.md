# 咒术师 · 机制与状态

> 本文件统一咒术师的关键词、饲咒效果、专属状态、关键词模组、初始卡组与面板口径。标记说明：`已有` = 代码中已实装；`模板` = 《状态模板》中已列但未实装；`新设` = 本方案新增。
>
> 本文中“X% 伤害”均指**咒术师攻击力 X%**；“护盾 X%”均指**咒术师治愈力 X%**；未注明时持续 2 回合。

---

## 一、关键词

> **词条 = 触发条件**。咒术师只有两个词条：**恶毒**（看目标）与**后发**（看时刻）。“饲咒”不是词条，而是一种效果，见第二节。

### 1.0 词条奖励口径：只给机制，不给数值

满足恶毒或后发之后，卡牌必须**换一种工作方式**，不能只是“同样的事做得更多”。

| 禁止作为词条奖励 | 允许作为词条奖励 |
| --- | --- |
| 伤害 / 护盾 / 治疗 +X% | **形态**：作用范围改变（单体 → 全体、单体减益 → 全体减益） |
| 对同一目标追加一段伤害 | **规则**：视为速攻、无视防御 / 格挡 / 护盾、免除代价 |
| 本场战斗永久 +X% 数值 | **时序**：推迟招式、封住大招 |
| 多施加几层、多施加一种同类减益 | **流转**：返回手牌、从牌堆挑牌、夺取增益、复制 / 汇集 / 继承减益 |
| 持续时间单纯延长 | **关系**：敌人之间传导伤害、交换行动点、操纵敌人攻击、反转敌人招式、即死 |

> 卡牌的**基础效果**可以按数值读取（如咒爆按种类兑现、盈煞按抽走的行动点加伤），因为那是这张牌本身的玩法，不是词条奖励。
>
> **不打断招式**：咒术师不提供“打断敌人正在蓄力的招式”的效果，时序类奖励只有推迟与封大招。

### 1.1 恶毒 N（新设 · 触发条件 C-32）

> **恶毒 N**：判定时，目标身上的**减益种类**不少于 N 种，则结算冒号后的效果。

| 口径 | 说明 |
| --- | --- |
| 计入什么 | 目标身上所有 `kind = debuff` 的状态，**按种类计数**，层数与段数不影响（三段附骨仍算 1 种）。队友施加的减益同样计入。标记类状态（锁魂、疫病、咒丝）不计入。 |
| 判定时机 | 在本卡**写在前面的效果结算之后**判定。因此“先施加厄运，再造成伤害；恶毒 3”中，本卡施加的厄运会计入。 |
| 群体牌 | 逐个目标分别判定。 |
| N 的取值 | **3~4**。普通卡 3；罕见卡 3~4；稀有卡 4。减益很容易堆起来，2 种不构成门槛。 |
| 咒誓 | 持有咒誓时，判定种类视为 +1（见稀有卡《咒誓》）。 |
| 界面 | 手牌中有恶毒牌时，悬停敌人显示“当前减益 X 种”；满足条件的敌人描边高亮。 |

引擎已有“主目标减益种类”计数（`primaryDebuffKinds`），只需新增关键词判定。

### 1.2 后发 N（新设 · 触发条件 C-83）

> **后发 N**：打出本卡时，本回合已经推进了不少于 N 个时刻，则结算冒号后的效果。

| 口径 | 说明 |
| --- | --- |
| 怎么计数 | 已推进时刻数 = 当前时刻 − 回合起始时刻。**全队**的普通牌都计入（法力是全队共享的）。 |
| 判定时机 | 本卡**自己的推进不计入**——判定在本卡结算前、推进时刻前完成。 |
| 停摆 | 对持有停摆的目标打出的攻击牌不推进时刻，因此也不给后发攒时刻。 |
| N 的取值 | **2~5**，只有起始卡迟咒用 2。普通卡 2~3；罕见卡 3~4；稀有卡 5。 |
| 界面 | 回合信息处显示“本回合已推进 X 时刻”；满足后发的手牌高亮。 |

**时刻预算**：每回合法力 3 点（全队共享），待机每回合 1 次。

| 推进来源 | 法力 | 推进 |
| --- | ---: | ---: |
| 任意 1 费普通牌 | 1 | 1 |
| 待机 | 0 | 1 |
| 敲更（0 费普通牌） | 0 | 1 |
| 沉吟 | 1 | 2 |
| 装有后发模组的队友攻击牌 | 按原费用 | 2 |
| 逢魔时刻（之后每张普通牌） | 0 | +1 |
| 速攻牌 | — | 0 |
| 对停摆目标打出的攻击牌 | — | 0（覆盖沉吟、逢魔、后发模组的额外推进） |

- 不用任何加速：两张 1 费牌 + 待机 = 3，第三张 1 费牌满足**后发 3**。
- **后发 4**：敲更 + 待机 + 沉吟 = 4，只花 1 点法力，剩 2 点打收尾。
- **后发 5**：在后发 4 的基础上再打一张 1 费牌，剩 1 点法力收尾；或者用逢魔时刻。

**设计意图**：时刻轴原本是“代价”——推进时刻会让敌人出手。后发把它变成“资源”：咒术师愿意让时间流逝，代价是队伍要先扛住敌人的招式。停摆则反过来，让集火某个目标时不再惊动敌人。

## 二、饲咒（效果，不是词条）

> **饲咒**是一种**负面效果**，与“自身失去 10% 生命”属于同一类概念：卡面直接写“目标获得 N 点行动点”，不使用“饲咒 N”这样的词条写法。“饲咒”只作为支柱名与设计用语保留。

带这类效果的牌，数值高于同费用基准，代价是敌人更早攒够行动点、被迫提前放大招。

| 口径 | 说明 |
| --- | --- |
| 卡面写法 | “然后目标获得 2 点行动点”“生命最低的其他敌人获得 1 点行动点”“所有敌人各获得 1 点行动点”。 |
| 结算时机 | 写在伤害之后，按卡面顺序结算。若目标已被击杀，跳过（因此“打死它”就是免除代价的方法）。 |
| 效果 | 只增加行动点，**不会让敌人立即行动**，也不改变当前正在蓄力的招式。影响的是敌人下一次抽招与“行动点 ≥ 大招消耗 × 1.5 时强制放大招”的判定。 |
| 上限 | 不设上限；首领被喂得越多，越可能连续放大招。 |
| 界面 | 敌人身上必须显示**行动点**与**大招阈值**，否则玩家无法评估代价（见总览 Q2）。 |

**饲咒闭环**：喂（丧钟、嫁祸、敕令、咒誓）→ 锁 / 挪（锁魂钉封住大招、偷天换日把行动点换给小怪）→ 收（盈煞抽走行动点兑现成伤害）。

| 结构 | 卡牌 | 说明 |
| --- | --- | --- |
| 固定代价 | 丧钟 | 每次打出都付 |
| 转嫁代价 | 嫁祸 | 由生命最低的其他敌人获得行动点，可以“喂给快死的小怪” |
| 条件代价 | 敕令 | 后发未满足时才付，提前打出要付钱 |
| 全体代价 | 咒誓 | 所有敌人各获得行动点，换取本场战斗的规则改写 |
| 封锁 | 锁魂钉 | 恶毒满足时，被喂满的敌人暂时放不出大招 |
| 挪移 | 偷天换日 | 后发满足时，把首领攒满的行动点换给另一名敌人 |
| 收益端 | 盈煞 | 抽走目标的行动点变成伤害，把代价变燃料 |

## 三、专属状态

咒术师**不施加任何通用减益**（虚弱、萎靡、破甲、易伤等），自己的减益只有下表中的 5 种。

| 状态 | 种类 | 标记 | 效果 | 持续 | 叠加 | 来源 |
| --- | --- | --- | --- | --- | --- | --- |
| 厄运 | 减益 | 新设 | 持有者受到攻击时，攻击者本次暴击率 +20%。 | 2 回合 | 不叠层，刷新持续 | 咒钉、蔓咒、护身符（反咒）、漏刻 |
| 怨咒 | 减益 | 新设 | 持有者每受到 1 段攻击伤害（命中且造成伤害），额外失去施加者攻击力 10% 的生命；无视防御、格挡与护盾。 | 2 回合 | 不叠层，刷新持续 | 缠丝、漏刻 |
| 封印 | 减益 | 模板 | 无法获得增益。 | 2 回合 | 不叠层，刷新持续 | 封口符、漏刻 |
| 停摆 | 减益 | 新设 | 我方（全队）对持有者打出的**攻击牌**不推进时刻；群体攻击牌只要目标中有一名持有停摆，就不推进。功能牌、防御牌与待机照常推进。 | 1 回合 | 不叠层，刷新持续 | 定身符 |
| 附骨 | 减益 | 新设 | 每拍每层受到 1 点伤害，无视护盾，不降低体力极限。**与中毒、灼烧使用同一套扣血规则。** | 5 回合 | 每次施加形成独立一段，各段分别计时 | 迟咒 |
| 锁魂 | 标记 | 新设 | 持有者的下一次抽招不会抽到大招，也不会因行动点达到阈值被强制放大招；抽到招式后移除。不计入减益种类，不可驱散。 | 直到下次抽招 | 不叠层 | 锁魂钉 |
| 疫病 | 标记 | 新设 | 本回合内，持有者每获得 1 种减益，其他所有敌人也获得一份相同的减益（层数、持续相同）。复制出的减益不会再次扩散。不计入减益种类。 | 本回合 | 不叠层 | 疫咒 |
| 咒丝 | 标记 | 新设 | 持有者受到攻击伤害后，其他持有咒丝的敌人失去该伤害 40% 的生命；无视防御、格挡与护盾；传导出的生命损失不会再次传导。场上只剩 1 名持有者时无效。不计入减益种类。 | 本回合 | 不叠层 | 蔓咒 |
| 反咒 | 增益 | 新设 | 本回合内受到敌方攻击时，对攻击者施加厄运 1 回合。 | 本回合 | 不叠层 | 护身符 |
| 咒誓 | 增益 | 新设 | 本场战斗中，咒术师的恶毒判定时，目标减益种类视为 +1。不可驱散。 | 本场战斗 | 不叠层 | 咒誓 |
| 逢魔 | 增益 | 新设 | 本回合内，咒术师的普通牌每张多推进 1 时刻。 | 本回合 | 不叠层 | 逢魔时刻 |

### 3.1 附骨数值口径

**基准**：附骨**跳满 3 回合**的总伤害，与同费用卡牌施加的中毒（持续 2 回合）总伤害相同；剩下 2 回合是附骨“拖得久”的收益。

| 对照 | 层数 | 持续 | 跳满 3 回合 | 跳满全程 |
| --- | --- | ---: | ---: | ---: |
| 毒刺箭（1 费，植物学家） | 攻击力 30% | 2 回合 | 攻击力 60% | 攻击力 60% |
| 迟咒（1 费，咒术师） | 攻击力 20% | 5 回合 | 攻击力 60% | 攻击力 100% |

- 换算公式：**附骨层数 = 同费中毒层数 × 2 / 3**。之后新增的附骨来源都按这个比例定层数。
- 层数按引擎口径换算（攻击力 ÷ 5 × 倍率，取整）：咒术师攻击力 110 时，迟咒施加 4 层附骨，每拍扣 4 点，5 回合共 20 点。
- 分段规则与中毒相同：再次施加形成新的一段，各段独立倒计时，同一时间内层数相加。

### 3.2 停摆口径

- **只看攻击牌**：对停摆目标打出的攻击牌推进 0 时刻，覆盖沉吟、逢魔、后发模组带来的额外推进。
- **全队生效**：剑士、炼金术士等队友对停摆目标出的攻击牌同样不推进。
- **群体牌**：目标中只要有一名持有停摆就不推进。
- **与后发相反**：停摆让敌人不会因为集火而出手，但也让后发停止计数。先攒时刻、再上停摆收尾，是时辰路线的标准节奏。

### 3.3 设计说明

- **怨咒不是持续伤害**：它按受击段数结算，多段攻击（剑士、缠丝）收益最高。
- **附骨是唯一的持续伤害**：沿用中毒的扣血规则，但层数低、持续长，跳满 3 回合才追平中毒。它与中毒、灼烧是不同的状态，种类分开计数，不会被炼金术士的反应、植物学家的毒发读取。
- **厄运服务于输出**：咒术师面板暴击率 15%，厄运让全队打这个目标时更容易暴击。
- **封印直接采用《状态模板》已列的口径**，与“驱散类卡先清后封”的模板用法一致（见封口符）。
- **锁魂、疫病、咒丝是标记而不是减益**：它们是词条奖励，如果也算一种减益，就会反过来帮自己凑恶毒，形成自循环。
- **种类上限**：咒术师单人最多提供 5 种减益（厄运、怨咒、封印、停摆、附骨）。起始卡组一回合就能凑出 3 种（怨咒、附骨、厄运），恶毒 4 需要专门铺垫或队友配合。

## 四、关键词模组

沿用《角色关键词模组设计》的约定：由咒术师在装配舱制造，**不能装在咒术师自己的牌上**。

| 模组 | 装配条件 | 效果 |
| --- | --- | --- |
| 恶毒模组 | 单体攻击牌，且不属于咒术师 | 恶毒 3：本次攻击无法被闪避与格挡。 |
| 后发模组 | 攻击牌（非速攻），且不属于咒术师 | 本卡推进 2 个时刻；本卡结算时攻击力视为 +20。 |

- **后发模组不带条件**：它的作用是让队友的牌替咒术师攒时刻，多推进的 1 时刻是代价，+20 攻击力是补偿。它不是词条奖励，因此不受 1.0 的“只给机制”限制。
- **攻击力 +20 只作用于本卡**：按装配者攻击力 +20 计算本卡的伤害，打出后即恢复。
- **对停摆目标打出时**：不推进时刻，攻击力 +20 照常生效。
- **不设饲咒模组**：饲咒是效果而不是词条，单独做成模组等于“给敌人送行动点”，没有收益。

## 五、关键词与队伍节奏

| 问题 | 咒术师的回应 |
| --- | --- |
| 根因三：卡比费少 | 敲更 0 费抽牌；咒钉满足恶毒后回手；窥魂后发时从牌堆挑牌 |
| 根因四：战斗拖长 | 饲咒的超额数值、附骨持续扣血、咒丝传导、百鬼夜行全体化、咒杀即死，都直接缩短战斗 |
| 时刻轴的价值 | 后发让“推进时刻”有收益；后发模组让队友替咒术师攒时刻；停摆让全队集火某个目标时不推进时刻，给剑士的速攻流提供同向搭档 |

| 内容 | 改动 | 涉及 |
| --- | --- | --- |
| 恶毒 | 新增关键词条件：目标减益种类 ≥ N；群体牌逐目标判定；咒誓 +1；标记类状态不计入 | 效果条件、卡牌词条注册 |

| 抽走行动点（盈煞） | 新增效果：移除目标至多 N 点行动点，按实际移除数加伤 | 效果类型、敌人行动点 |

| 厄运 / 怨咒 / 反咒 / 咒誓 / 逢魔 | 新增状态；怨咒挂在“受到攻击后”钩子，按段触发 | 状态定义 |
| 附骨 | 新增状态：复用中毒的分段与每拍扣血规则，持续 5 回合；不带中毒标签，不被毒发、反应读取 | 状态定义 |
