# 咒术师 · 卡牌设计总览

> 本目录是新角色**咒术师**的卡牌设计文档，不涉及代码改动。
>
> **目标**：设计 **30 张**主体卡，稀有度为 **普通 15 / 罕见 10 / 稀有 5**。咒术师是**输出角色**，两个特色关键词为 **恶毒** 与 **后发**，并配套代价机制 **饲咒**（以增加目标敌人行动点作为负面修正，换取卡牌超额数值）。每张卡都有其他卡没有的“独立模型”，池内不出现结构相同的两张牌。
>
> **词条口径**：满足恶毒 / 后发后，卡牌**换一种工作方式**（变全体、变速攻、回手、打断、封大招、反转招式、即死……），不给“伤害 +X%”之类的数值奖励。详见《01》1.0。

## 一、角色定位

**一句话定位：先把咒一道道缠上去，再等时辰到了收网——必要时，拿敌人的气势喂养咒术。**

咒术师是**“蓄势收割”型的直伤输出角色**。剑士靠弃牌和速攻抢节奏，咒术师反其道而行：

| 维度 | 剑士 | 咒术师 |
| --- | --- | --- |
| 出手时机 | 速攻，不推进时刻，抢在敌人之前 | 后发，回合越往后牌越“变形”，愿意让时刻流逝 |
| 变强方式 | 自身的弃牌、回手、累计层数 | 目标身上的减益种类够了，牌就换一种玩法（全队都能喂） |
| 风险 | 弃掉关键牌 | 推进时刻让敌人出手；饲咒让敌人提前放大招 |

### 三大支柱

| 支柱 | 关键词 / 机制 | 负责什么 | 张数（主要归属） |
| --- | --- | --- | ---: |
| 缠咒 | 恶毒 | 叠减益种类，种类够了牌就变形：回手、夺取、传导、打断、反转、即死；也能复制、汇集、兑现减益 | 14 |
| 时辰 | 后发 | 推进时刻、冻结时刻，回合后段变全体、变速攻、拖招式 | 9 |
| 饲咒 | 饲咒 | 喂敌人行动点换数值 → 锁住大招 → 抽走行动点变伤害 | 5 |
| 防护 | — | 带咒的护盾、把队友的减益转嫁给敌人 | 2 |

> 大多数牌会同时碰到两根支柱，这里只按“主要卖点”归类。

### 设计红线

1. **不施加他人专属的减益**：中毒、灼烧、穿孔、迟滞、蚀刻、易燃、捕虫夹都不由咒术师施加。咒术师自己的减益来源只有：通用的 **虚弱 / 萎靡 / 破甲**，以及专属三咒 **厄运 / 怨咒 / 封印**。队友施加的任何减益都计入恶毒。
2. **不设持续伤害**：怨咒按“受到攻击的段数”结算，不按回合结算，与炼金术士、植物学家的持续伤害体系区分。
3. **不设回法力效果**。资源补偿只允许抽牌、挑牌与回手。
4. **不施加易伤与眩晕**：易伤（×1.5）会让收割失控；眩晕普通卡禁用，咒术师用“推迟 / 打断 / 封锁 / 反转招式”代替。
5. **饲咒只给敌人加行动点，不让敌人立即行动**，也不改变敌人当前已在蓄力的招式。
6. **门槛**：恶毒 N 取 **3~4**（减益很容易堆起来）；后发 N 取 **2~5**，2 只给起始卡，普遍 3~5。
7. **词条奖励只给机制**：禁止伤害 / 护盾 +X%、追加同目标一段、永久数值成长、多上几层减益。
8. **标记不计入恶毒**：锁魂、疫病、咒丝是标记而不是减益，防止词条奖励反过来帮自己凑恶毒。

## 四、构筑路线

| 路线 | 核心牌 | 每回合的决定 |
| --- | --- | --- |
| **缠咒收割** | 万咒归宗、咒誓、疫咒、蔓咒、断魂咒、咒杀 | 先上哪几种咒？种类够了是**让牌变形**（回手、传导、打断、即死），**用咒爆一次兑现清空**，还是**汇集到首领身上**？ |
| **时辰** | 逢魔时刻、停摆、百鬼夜行、敲更、沉吟 | 这回合要推进几个时刻？冲到多高再用停摆定住？每推进一次敌人就可能出手，收益和挨打要算清楚。 |
| **饲咒** | 丧钟、嫁祸、锁魂钉、盈煞、敕令 | 喂多少行动点换伤害？喂完是用锁魂钉封住大招、用盈煞抽回来，还是赶在大招前把它打死？ |

三条路线的交点：**饲咒喂出的行动点**被盈煞抽走；**后发推进的时刻**让漏刻铺咒、让咒钉回手后还能接着攒时刻；**无声咒**满足恶毒时不推进时刻，又会拖慢后发——每回合都要在“缠”与“等”之间取舍。

### 与队友的联动

| 队友 | 联动 |
| --- | --- |
| 植物学家 | 中毒、穿孔、迟滞各算一种减益，是恶毒最好的燃料；疫病之后施加的中毒会扩散给全场 |
| 炼金术士 | 灼烧、蚀刻、易燃各算一种；反应态（灼烧 + 中毒）的目标再加一种咒就满足恶毒 3 |
| 剑士 | 多段攻击、弃牌自动打出都会触发怨咒，也会沿咒丝传导；剑士的速攻不推进时刻，与咒术师的后发互补（剑士抢前半回合，咒术师收后半回合） |
| 精算师 | 后发和饲咒都会让我方多挨打，保险、急诊正好接住 |
| 预言家 | 预言家的减益与天穹断罪的“推迟招式”可以替咒术师拖住饲咒喂大的首领 |

### 典型回合示例

**起始卡组的第一回合**：手牌为缠丝、迟咒、咒钉、基础防护，法力 3。

- 缠丝（怨咒 + 两段，推进到 1）→ 待机（2）→ 迟咒（后发 2 满足，萎靡改为全体，推进到 3）→ 咒钉（先上厄运，目标有怨咒、萎靡、厄运，恶毒 3 满足，咒钉回到手牌）。
- 两个关键词各触发一次；下一回合咒还在，咒钉可以继续反复打。

**饲咒闭环**：首领身上已有 3 种减益，还差 2 点行动点就会被迫放大招。

- 第一回合：丧钟（`200%`，饲咒 2，首领已经够放大招）→ 锁魂钉（恶毒 3 满足，首领被锁魂，这次不会强制放大招）。
- 第二回合：盈煞（抽走 4 点行动点，`200%`），首领的大招被推远一整轮。

**时辰路线的一回合**：手牌有逢魔时刻、敲更、沉吟、停摆、窥魂、百鬼夜行。

- 逢魔时刻 → 敲更（推进到 2）→ 沉吟（推进到 5）→ 停摆（后发 4 满足，推进到 7 后冻结）→ 百鬼夜行（后发 5 满足，全体，不再推进）。3 点法力用完，敌人不会因为最后一张牌而提前出手。
