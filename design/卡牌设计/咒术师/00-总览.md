# 咒术师 · 卡牌设计总览

> 本目录是新角色**咒术师**的卡牌设计文档，不涉及代码改动。
>
> **目标**：设计 **30 张**主体卡，稀有度为 **普通 15 / 罕见 10 / 稀有 5**。咒术师是**输出角色**，两个特色词条（触发条件）为 **恶毒** 与 **后发**；另有一类代价效果 **饲咒**（目标敌人获得行动点），它是效果而不是词条，用来换取卡牌超额数值。每张卡都有其他卡没有的“独立模型”，池内不出现结构相同的两张牌。
>
> **词条口径**：满足恶毒 / 后发后，卡牌**换一种工作方式**（变全体、变速攻、回手、继承减益、封大招、反转招式、即死……），不给“伤害 +X%”之类的数值奖励。详见《01》1.0。

## 一、角色定位

**一句话定位：先把咒一道道缠上去，再等时辰到了收网——必要时，拿敌人的气势喂养咒术。**

咒术师是**“蓄势收割”型的直伤输出角色**。剑士靠弃牌和速攻抢节奏，咒术师反其道而行：

| 维度 | 剑士 | 咒术师 |
| --- | --- | --- |
| 出手时机 | 速攻，不推进时刻，抢在敌人之前 | 后发，回合越往后牌越“变形”，愿意让时刻流逝 |
| 变强方式 | 自身的弃牌、回手、累计层数 | 目标身上的减益种类够了，牌就换一种玩法（全队都能喂） |
| 风险 | 弃掉关键牌 | 推进时刻让敌人出手；饲咒让敌人提前放大招 |

### 三大支柱

| 支柱 | 词条 / 效果 | 负责什么 | 张数（主要归属） |
| --- | --- | --- | ---: |
| 缠咒 | 恶毒（词条） | 叠减益种类，种类够了牌就变形：回手、夺取、传导、继承、反转、即死；也能复制、汇集、兑现减益 | 14 |
| 时辰 | 后发（词条） | 推进时刻、用停摆让集火不推进，回合后段变全体、变速攻、拖招式、挪行动点 | 9 |
| 饲咒 | 敌人获得行动点（效果） | 喂敌人行动点换数值 → 锁住大招 → 抽走行动点变伤害 | 5 |
| 防护 | — | 带咒的护盾、把队友的减益转嫁给敌人 | 2 |

> 大多数牌会同时碰到两根支柱，这里只按“主要卖点”归类。

### 设计红线

1. **只施加专属减益**：咒术师不施加任何通用减益（虚弱、萎靡、破甲、易伤等），也不施加他人专属的减益（中毒、灼烧、穿孔、迟滞、蚀刻、易燃、捕虫夹）。自己的减益只有 **厄运 / 怨咒 / 封印 / 停摆 / 附骨** 5 种。队友施加的任何减益都计入恶毒；替身草人“转移”队友身上的减益不算施加。
2. **唯一的持续伤害是附骨**：附骨与中毒共用扣血规则，持续 5 回合，**跳满 3 回合的总伤害与同费中毒持平**（层数 = 同费中毒层数 × 2/3）。怨咒按“受到攻击的段数”结算，不算持续伤害。
3. **不设回法力效果**。资源补偿只允许抽牌、挑牌与回手。
4. **不施加易伤与眩晕，也不打断招式**：咒术师处理敌方招式只用“推迟 / 封锁 / 挪走行动点 / 反转”，已经在蓄力的招式无法取消。
5. **饲咒是效果不是词条**：卡面直接写“目标获得 N 点行动点”；只加行动点，不让敌人立即行动，也不改变敌人当前已在蓄力的招式。
6. **门槛**：恶毒 N 取 **3~4**（减益很容易堆起来）；后发 N 取 **2~5**，2 只给起始卡，普遍 3~5。
7. **词条奖励只给机制**：禁止伤害 / 护盾 +X%、追加同目标一段、永久数值成长、多上几层减益。
8. **标记不计入恶毒**：锁魂、疫病、咒丝是标记而不是减益，防止词条奖励反过来帮自己凑恶毒。

## 四、构筑路线

| 路线 | 核心牌 | 每回合的决定 |
| --- | --- | --- |
| **缠咒收割** | 万咒归宗、咒誓、疫咒、蔓咒、断魂咒、咒杀 | 先上哪几种咒？种类够了是**让牌变形**（回手、传导、继承、即死），**用咒爆一次兑现清空**，还是**汇集到首领身上**？ |
| **时辰** | 逢魔时刻、定身符、偷天换日、百鬼夜行、敲更、沉吟 | 这回合要推进几个时刻？冲到多高再用定身符上停摆？每推进一次敌人就可能出手，收益和挨打要算清楚。 |
| **饲咒** | 丧钟、嫁祸、锁魂钉、偷天换日、盈煞、敕令 | 喂多少行动点换伤害？喂完是用锁魂钉封住大招、用偷天换日换给小怪、用盈煞抽回来，还是赶在大招前把它打死？ |

三条路线的交点：**饲咒喂出的行动点**被盈煞抽走、被偷天换日挪走；**后发推进的时刻**让漏刻铺咒、让咒钉回手后还能接着攒时刻；**无声咒**满足恶毒时不推进时刻，**停摆**让集火不推进时刻，两者都会拖慢后发——每回合都要在“缠”与“等”之间取舍。

### 与队友的联动

| 队友 | 联动 |
| --- | --- |
| 植物学家 | 中毒、穿孔、迟滞各算一种减益，是恶毒最好的燃料；疫病之后施加的中毒会扩散给全场。附骨与中毒是两种状态，各算一种 |
| 炼金术士 | 灼烧、蚀刻、易燃各算一种；反应态（灼烧 + 中毒）的目标再加一种咒就满足恶毒 3 |
| 剑士 | 多段攻击、弃牌自动打出都会触发怨咒，也会沿咒丝传导；剑士对停摆目标出的攻击牌同样不推进时刻，可以和咒术师一起集火 |
| 精算师 | 后发和饲咒都会让我方多挨打，保险、急诊正好接住 |
| 预言家 | 预言家的减益与天穹断罪的“推迟招式”可以替咒术师拖住饲咒喂大的首领 |
| 任意队友 | 装上后发模组的攻击牌推进 2 时刻并获得攻击力 +20，替咒术师攒后发 |

### 典型回合示例

**起始卡组的第一回合**：手牌为缠丝、迟咒、咒钉、基础防护，法力 3。

- 缠丝（怨咒 + 两段，推进到 1）→ 待机（2）→ 迟咒（后发 2 满足，附骨改为全体，推进到 3）→ 咒钉（先上厄运，目标有怨咒、附骨、厄运，恶毒 3 满足，咒钉回到手牌）。
- 两个关键词各触发一次；下一回合附骨还在扣血，咒钉可以继续反复打。

**饲咒闭环**：首领身上已有 3 种减益，还差 2 点行动点就会被迫放大招，旁边有一只残血小怪。

- 第一回合：丧钟（`200%`，首领获得 2 点行动点，已经够放大招）→ 锁魂钉（恶毒 3 满足，首领被锁魂，这次不会强制放大招）。
- 第二回合：敲更 → 待机 → 沉吟（推进到 4）→ 偷天换日（后发 4 满足，首领与残血小怪交换行动点）→ 用剩下的法力打死小怪。或者直接打盈煞，抽回丧钟喂出去的 2 点（`150%`）。

**时辰路线的一回合**：手牌有逢魔时刻、敲更、沉吟、定身符、百鬼夜行。

- 逢魔时刻 → 敲更（推进到 2）→ 沉吟（推进到 5）→ 定身符（速攻，对首领施加停摆；后发 3 满足，首领招式推迟 1 时刻）→ 百鬼夜行（后发 5 满足，改为全体；目标中有停摆持有者，不再推进）。3 点法力用完，敌人不会因为最后一张牌而提前出手。
