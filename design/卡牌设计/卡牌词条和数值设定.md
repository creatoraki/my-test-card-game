基础数值：
攻击卡： 1AP标准是90%伤害， 上下浮动到70%-110%，弱的可以有70 80 90 三档，超模只允许有100 和110两档
2AP 标准 150%  3AP 标准 200% ，2AP和3AP的上下限允许较大偏离。

治疗和护盾数值目标为 1AP 50% 2AP 80% 3AP 120% 治疗和护盾的树枝强度离标准模型不应该偏移过大


# 弃牌：
造成5点伤害，丢弃一张牌 / 造成5点伤害，被丢弃时自动对随机目标使用。

# 共鸣

打出共鸣牌的时候，所有手牌中费用低于打出卡的共鸣卡会得到强化。
比如 - 炎爆术：造成10点伤害，共鸣：伤害+2。

# 瞄准

造成10点伤害，瞄准：额外攻击一次。 瞄准的机制是，使用瞄准卡攻击没有被瞄准的目标时，给目标上一个叫被瞄准的debuff，那么下次使用瞄准类卡牌攻击目标，则会消除目标的瞄准debuff，并触发瞄准词条的额外收益。

# 登阶

造成10点伤害，登阶：抽1张牌。 （登阶触发条件，上一张打出的牌费用低于当前卡牌可触发）

# 日蚀

抽牌堆顶部3张卡内每有一张属于当前角色的卡牌，则触发一次日蚀额外效果。
例： 造成8点伤害，日蚀：额外攻击1次
月蚀：
弃牌堆顶部3张内每有一张属于当前角色的卡牌，则触发一次月蚀额外效果。

# 组装

组装词条的卡分4个子词条，分别是组装ABCD，比如 积木攻击：造成100%的伤害，组装A。
打出组装卡后，角色获得组装A的BUFF，当角色集齐任意3个组装BUFF，则触发组装成功，获得奖励，根据组装素材种类的不同，获得不同的临时奖励卡牌，比如组装了BCD，则火卡一张临时卡牌，能回复3点法力，组装了ABD，则是获得一张临时卡牌，效果是抽3张卡 类似这样的机制

# 革命

当该词条的所属卡为手牌中费用最低卡时。可以触发革命特效 ：例如：造成20点伤害，革命：抽1张牌

# 瀑布
当该词条的所属卡为手牌中费用最高卡时。可以触发瀑布特效 ：例如：造成20点伤害，瀑布：抽1张牌

# 狩猎
使用狩猎词条的攻击卡击杀目标时，会获得BUFF狩猎层数，上限3层。 狩猎卡被打出时，会根据角色身上的狩猎BUFF层数重复触发狩猎特效，例如：造成20点伤害，狩猎：额外攻击一个随机目标

# 星契
- 汇星 带有汇星词条的卡牌，在使用后，会给角色施加星辉BUFF，施加的层数和卡牌汇星词条对应的数字相同。 比如火球术：造成80%伤害，汇星1.
- 应星 带有应星词条的卡牌，可以使用星辉来替代法力水晶进行释放。
