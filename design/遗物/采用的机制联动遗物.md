# 采用的机制联动遗物

## 弃牌与手牌回收

| 名称 | 效果 |
| --- | --- |
| 碎纸机 | 每回合第 2 次有牌被丢弃时，抽 1 张牌。 |
| 回形针 | 回合结束时，手牌中第一张被动牌改为以「丢弃」方式离手，会触发它被丢弃时的效果（每场战斗 2 次）。 |
| 回刃挂绳 | 每场战斗，第一次用速攻攻击牌击杀敌人后，将弃牌堆中最早进入的一张非速攻攻击牌返回手牌。 |

## 速攻与心眼

| 名称 | 效果 |
| --- | --- |
| 软木刀镡 | 每场战斗，第一次在同一回合打出两张速攻牌后，可以选择一张手牌，使其获得心眼。 |

## 回手负担与费用上涨

| 名称 | 效果 |
| --- | --- |
| 松紧带 | 每回合第一次有牌回到手牌时，不叠加回手负担。 |
| 秤砣 | 打出当前费用高于原始费用的牌时，该牌的攻击力与治愈力 +30。 |

## 零费牌与临时卡

| 名称 | 效果 |
| --- | --- |
| 零钱袋 | 每回合打出第 2 张 0 费牌后，抽 1 张牌。 |
| 便签本 | 每回合第一次打出临时卡后，返还 1 点法力。 |

## 培育、成熟与枯萎

| 名称 | 效果 |
| --- | --- |
| 修枝剪 | 每场战斗，前两次打出成熟牌后，随机使一张其他生长中的培育手牌，将其推进 1 层。 |
| 腐叶土 | 培育牌枯萎时，额外获得 1 张枯萎的果实。 |

## 多段攻击与穿孔

| 名称 | 效果 |
| --- | --- |
| 钉枪 | 每回合第一张多段攻击牌，每段命中时为目标附加 1 层穿孔。 |
| 卷尺 | 敌人的穿孔被一次性移除 4 层或以上时（采收、满弓），抽 1 张牌（每回合 1 次）。 |

## 中毒、灼烧与持续伤害

| 名称 | 效果 |
| --- | --- |
| 炉钩 | 焚尽目标后，对其施加 3 层中毒，持续 2 回合。 |
| 滴管 | 每回合第一次毒发时，目标身上所有中毒的持续时间 +1 拍。 |

## 嘲讽、保险与护盾

| 名称 | 效果 |
| --- | --- |
| 警示背心 | 我方单位获得嘲讽时，同时获得 6 层保险，持续 2 回合。 |
| 回执 | 每次理赔后，持有者获得等同于本次实际回复量 25% 的护盾。 |

## 组装与共鸣

| 名称 | 效果 |
| --- | --- |
| 废料小盒 | 每场战斗，第一次尝试获得一个已经持有的组装部件时，改为释放该部件一次，不移除它。 |
| 白瓷试剂盘 | 组装成功获得可打出的奖励卡时，该卡下一次打出的费用降低 1 点，最低为零。 |
| 谐振铜片 | 打出当前费用至少 2 点的牌后，免费获得一次共鸣强化，每场最多 2 次。 |

## 厄运、暴击与痛楚

| 名称 | 效果 |
| --- | --- |
| 稻草结 | 对同时带有厄运与痛楚的敌人造成暴击伤害后，该敌人的痛楚提前结算 1 拍。 |
| 顶针 | 每回合第一次提前结算痛楚时，额外结算 1 拍。 |

## 推迟招式与敌人行动点

| 名称 | 效果 |
| --- | --- |
| 门挡 | 敌人的招式被推迟时，为其附加 2 层穿孔。 |

## 预言应验与落空

| 名称 | 效果 |
| --- | --- |
| 应验书签 | 每场战斗，第一次预言应验并结算完原有奖励后，查看抽牌堆顶 2 张牌，选择 1 张加入手牌，另一张置于抽牌堆底。 |
| 许愿签 | 预言落空时，抽 1 张牌。 |
