# 项目采用的遗物

> **状态**：已采用遗物清单，已与代码对齐（2026-09-30）。
> **数据源**：`src/data/items/relics/`（祝福 `blessings/<稀有度>.ts`、诅咒 `curses/<稀有度>.ts`，文件名即稀有度；一次性渠道按来源分文件：`blessings/picnic.ts`、`blessings/blessingBox.ts`）；类型、渠道枚举与中文标签见 `src/items/relic.ts`。
> 本文与代码冲突时以代码为准，改数据后请同步本文。

## 一、遗物的四个维度

| 维度 | 字段 | 取值 |
| --- | --- | --- |
| 极性 | `relic.polarity` | 祝福遗物 `blessing` / 诅咒遗物 `curse` |
| 生效层 | `relic.scope` | 战斗中生效 `battle`（战斗引擎读取）/ 探索中生效 `explore`（探索会话读取） |
| 稀有度 | `rarity` | 普通 `common` / 精良 `fine` / 稀有 `rare`（史诗、传说档目前没有遗物） |
| 发放渠道 | `relic.channel` | 缺省即「普通」，只有渠道限定的遗物才标注，见下表 |

### 发放渠道（来源限定）

| 渠道 | 字段值 | 说明 |
| --- | --- | --- |
| 普通 | `normal`（缺省不写） | 祝福遗物进入随机池，可从遗物匣、流浪货商、据点商店、通关奖励、圣水池净化、神龛升级获得 |
| 首领掉落限定 | `bossDrop` | 不进随机池，只由首领掉落表按 id 指名。**目前没有遗物使用** |
| 特殊事件限定 | `specialEvent` | 不进随机池，只由特定事件 / 可交互物按 id 指名。**目前没有遗物使用** |
| 野餐限定 | `picnic` | 不进任何随机池，只由野餐食谱按 id 指名，以一次性物资发放 |
| 祝福匣限定 | `blessingBox` | 只进临时遗物池，只能从临时祝福匣抽出，以一次性物资发放 |

野餐限定和祝福匣限定统称**一次性渠道**：只在本次探索生效，不能寄回，远征结束后消失，永远进不了仓库。两者**互不相通**：野餐遗物不会从临时祝福匣抽出，祝福匣遗物也不会被食谱指名（`relicCatalog.test.ts` 校验）。

### 遗物池（`pools.ts`，随机发放的唯一入口）

- **随机池**：普通渠道的全部祝福遗物（各稀有度）。遗物匣、流浪货商、据点商店、通关奖励、圣水池净化、神龛升级共用，可按稀有度收窄。
- **临时遗物池**：随机池中的普通档祝福遗物 + 祝福匣限定遗物（**不含野餐限定**）。供「临时祝福匣」使用，发放的实例带一次性标记；同一趟已持有或待领取的同款不会重复抽到。
- 诅咒遗物不进任何随机池。

### 价格

| 稀有度 | 据点商店买价 | 回收价 |
| --- | --- | --- |
| 普通 | 500 | 100 |
| 精良 | 600 | 150 |
| 稀有 | 1200 | 300 |

- 回收价只给「祝福遗物且非一次性渠道」挂上；诅咒遗物不可回收，只能到圣所（圣水池）净化。
- 一次性遗物永远到不了仓库，因此没有回收价。

## 二、新手教学奖励

教学关的「遗物储备箱」按 id 指名以下三件，三选一。它们本身是**稀有档、普通渠道**的祝福遗物，同样会进入随机池（详见下方「祝福遗物 · 稀有」）：

- 护心镜
- 旧式发条
- 轻质羽毛

另外，教学关起始房固定放置一个「临时祝福匣」（从临时遗物池抽一件一次性遗物，抽不到野餐遗物）；普通地图的起始房也会生成它。
