# 项目采用的遗物

> **状态**：已采用遗物清单。遗物效果按当前项目设定整理；新手教学奖励独立列出，其余遗物按设计稀有度归档。

## 新手教学奖励

新手教学提供遗物奖励，三选一：

| 遗物 | 效果 |
| --- | --- |
| 护心镜 | 每场战斗中，首次有角色生命降至最大生命的一半以下时，使其获得 8 点护盾。 |
| 旧式发条 | 第 3、6、9……回合开始时，额外抽 1 张牌。 |
| 轻质羽毛 | 每场战斗第一回合的换牌次数 +2。 |

| --- | --- |

| 折叠货箱 | 小队负重适应 +5。 |
| 双头插座 | 每回合首次连续打出 3 名不同队员的卡牌时，抽 1 张牌。 |

| 全家福 | 队伍中无阵亡队员时，全队攻击力与治愈力 +10；有队员阵亡后本场战斗失效。 |
| 净化滤网 | 在 4 回合内赢得战斗时，返还 3 点净化粒子。 |
