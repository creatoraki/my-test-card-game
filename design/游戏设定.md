## 一、背景

人类时代的能源与维生系统已经耗尽。部分富人选择进入冬眠，等待未来解决资源问题；冬眠仓的备用能源最终耗尽，主角一行在 3300 年代被强制唤醒，对外界现状一无所知。

离开舱室后，主角找到上一批苏醒者留下的信。信中写明：如果有新的冬眠仓成员读到这封信，写信的人应当已经死亡。上一批人约在 2600 年代苏醒；他们能确认的信息同样有限，只知道这座城市里已经没有人类。

城市没有停止运作。人类时代的系统已经耗尽，但城市独立电力仍由电子生命维护，霓虹与基础设施持续运转。居住和活动于其中的是电子生命与各类自治机械。主角的目标是探索这座无人类居住、却仍由机械生命维持运转的城市。

人类为何消失、上一批苏醒者经历了什么，以及电子生命如何看待人类，均未确定，应通过后续内容逐步补充。

## 二、生存环境

### 粒子污染与过滤装置

室外空气存在会危害人类的 X 粒子污染。人类外出必须携带粒子过滤装置；装置消耗净化粒子，而净化粒子只能在基地设施中补充。

探索时间会持续消耗净化粒子，因此一次出门可探索的距离受装置剩余能量限制。装置能量越高，外界敌对单位越弱、掉落越少；能量越低，敌对单位越强、掉落越好。装置能量耗尽前应返回基地。

### 量子隧穿售货机

城市中设有量子隧穿售货机。只要支付城市居民积分，售货机就能量子隧穿购买物资。

但城市可供人类使用的物资极少，食物主要是营养膏。居民积分是人类获取补给的主要来源。

### 控制终端与城市任务

大厦内设有控制终端，可接取城市维护任务并获得城市居民积分。任务让主角代替机械生命完成城市仍需执行的工作，主要包括：

- 回收失控机器人；
- 维修城市装置；
- 运送物资；
- 其他城市维护工作。

控制终端如何识别和接纳人类、任务由谁发布，当前不作额外设定。

## 三、探索与战斗

### 地下城探索

主角从据点选择一张地下城地图后进入探索。探索由 **5~7 段阿弥陀签式「失真路由图」**驱动：每段公开 5 个终点事件并短暂展示线路，玩家选择入口后信号自动走线，抵达一个事件并结算。每段推进都会消耗粒子过滤装置的净化粒子，**净化粒子是探索层唯一的难度与时限轴**——能量越低，敌人越强、我方污染越重、掉落越好。详见 `探索模式设计.md`。

### 背包负重

小队共用 32 格背包空间。每占用 1 格，全队命中率、暴击率与闪避率各降低 1%。玩家需要持续决定携带物资或将其舍弃。

探索层的产出全部是**占格的实物**（废料 / 模组材料 / 装备 / 数据存档 / 消耗品），**团灭时背包全部遗失**，活着回到据点才算数。战斗胜利**绝不直接掉落城市居民积分**，只掉落物品；其中**废料**分类的物品可带回据点出售，换取城市居民积分。城镇通货只有一种：**城市居民积分**，直接来源为控制终端工单，间接来源为出售带回的废料。

### 卡组战斗

小队成员各自拥有个人卡组；进入战斗时，所有个人卡组合并为小队战斗卡组。战斗中的自动抽牌、手牌上限与抽牌数均为小队共享属性。

### 经验与卡牌模组

角色不设等级。战斗与探索获得的经验值用于锻造个人卡组，可用于抽取卡牌、删除卡牌、降低最大卡组上限，以及解锁更高稀有度的卡牌。

每个角色拥有两个特色关键词；角色的专属卡牌围绕自身关键词设计，并能生产对应的关键词模组。模组装配于卡牌，消耗材料，不使用经验值进行数值强化；装配后仅该卡牌获得对应关键词标签及其机制效果。

角色不能将与自身特色关键词相同的关键词模组装配至个人卡牌。其他不具备该关键词的角色可装配该模组，使其卡牌参与对应关键词的连锁，从而与模组生产者形成连携。

### 背景依据

| 游戏机制 | 背景依据 |
| --- | --- |
| 每次探索有距离限制 | 粒子过滤装置只能携带有限净化粒子，且只能回基地补充。 |
| 能量越低，战斗越危险、掉落越好 | 过滤装置的防护能力随净化粒子下降而减弱，主角会进入更高风险的污染区域。 |
| 工单与废料出售获得积分 | 主角通过控制终端代替机械生命完成城市维护工作，或将探索中带回的废料出售给据点设施，获得城市居民积分。战斗本身只掉落物品。 |
| 积分购买补给 | 量子隧穿售货机使用城市居民积分结算，人类可购买的物资以营养膏等少量补给为主。 |
| 背包越满，命中、闪避、暴击越低 | 携带的物资越多，负重越高，行动与战斗表现越差。每格分别降低三项属性 1%。 |

## 四、据点设施

| 设施 | 功能 |
| --- | --- |
| 冬眠舱 | 唤醒新队友。 |
| 控制终端 | 接取任务、选择地下城、结算城市居民积分。 |
| 过滤装置充能台 | 为粒子过滤装置补充净化粒子。 |
| 训练室 | 配队，以及消耗经验值锻造个人卡组。 |
| 模块装配舱 | 消耗材料制造与装配关键词模组，使其他角色的卡牌接入对应连锁。 |
| 物资中转仓 | 背包与库存管理。 |
| 废料回收站 | 收购探索中带回的废料，换取城市居民积分。 |
| 量子配给终端 | 使用城市居民积分购买道具与营养膏。 |
| 生物维护舱 | 治疗与污染处理。 |
| 克隆室 | 角色死亡后，消耗据点资源克隆同类型的初级角色。 |
