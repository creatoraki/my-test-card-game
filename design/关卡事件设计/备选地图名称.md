# 备选地图名称

目前已实装的地图为「废弃楼层」与「生态方舟」。以下提供 20 个后续新地图的备选名称，围绕人类消失后仍由电子生命与自治机械维持运转的城市展开。

名称以四字为主，便于与现有地图保持一致；每项附带简短场景方向，方便筛选。场景方向仅为构思，不代表已确定的世界观或开发计划。

| 序号 | 备选名称 | 场景方向 |
| --- | --- | --- |
| 1 | 雾锁街区 | 粒子雾笼罩的商业街，店铺灯牌与清洁机械仍按旧日作息运转。 |
| 2 | 无人车站 | 不再有人候车的轨道枢纽，检票闸机与巡检机械仍在值守。 |
| 3 | 霓虹暗巷 | 巨型广告屏背后的狭窄巷道，废线、维修摊与失控机械交错分布。 |
| 4 | 静默商场 | 广播停息的购物中心，导购机械守着空荡货架与封闭店面。 |
| 5 | 尘封档案 | 保存人类时代记录的档案设施，自动索引与安保系统仍在运行。 |
| 6 | 冷眠禁区 | 大片冬眠设施所在的封锁区域，残余供能与医疗机械维持着旧指令。 |
| 7 | 锈蚀工厂 | 生产线长期运转的工业设施，废料堆积，装配机械反复制造旧型号零件。 |
| 8 | 废料熔炉 | 城市废料回收与熔炼中心，高温炉膛、传送带与分拣机械组成迷宫。 |
| 9 | 凝霜冷库 | 保存旧时代物资的低温仓储区，冷雾、结霜管线与搬运机械遍布其中。 |
| 10 | 循环水厂 | 仍在净化城市用水的处理设施，过滤池、泵站与维护机械层层相连。 |
| 11 | 污染管网 | 城市地下的排放与输送网络，泄漏粒子与管道检修机械形成探索阻碍。 |
| 12 | 深井泵站 | 深入地下的垂直抽水设施，井壁平台与升降装置连接不同作业层。 |
| 13 | 雷鸣电站 | 持续为城市供能的发电设施，放电设备与电力维护机械构成鲜明主题。 |
| 14 | 余烬热井 | 利用地下热源运转的能源设施，蒸汽、炽热裂隙与耐热机械交错出现。 |
| 15 | 天穹栈桥 | 高楼之间的空中交通通道，悬空平台、货运轨道与无人运输机往来穿梭。 |
| 16 | 云端港口 | 高处的无人货运停泊区，吊运机械与自动运输载具持续装卸物资。 |
| 17 | 镜面高塔 | 覆满反射幕墙的城市高塔，观测装置与安保机械隐藏在光影之间。 |
| 18 | 信号灯塔 | 维持城市通信的高层设施，天线阵列、信号中继与巡检机械构成主体。 |
| 19 | 算力蜂巢 | 密集排列的计算节点与散热通道，维护机械穿行于蜂巢般的机房。 |
| 20 | 机械庭院 | 电子生命维护的城市园庭，景观装置、人工水景与园艺机械自成秩序。 |
