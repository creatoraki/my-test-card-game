# 第六章 养成覆盖矩阵与定价尺度

## 6.1 覆盖矩阵

每一项养成资源必须有明确的**主投放口**（保证玩家找得到）和**次投放口**（保证不至于一路都遇不到）。

| 养成项 | 主投放口 | 次投放口 | 整趟保底 |
| --- | --- | --- | --- |
| 经验 | 改造间 | 补给站 / 谜面 | — |
| 卡组抽卡 / 删卡 | 改造间 | 终端 / 谜面 | ≥1 次 |
| 卡组等级推进 | 改造间（重档） | 险境 | — |
| 净化污染卡 | 补给站 | 终端 | 有污染时 ≥1 次 |
| 装备获取 | 拾荒场 | 异常源 / 谜面 | — |
| 装备强化（升阶 / 熔铸 / 重铸） | 改造间 | 险境 | ≥1 次 |
| 模组 | 拾荒场 | 改造间 | — |
| 通用材料 / 水晶 / 地区材料 | 拾荒场 | 险境 / 谜面 | — |
| 换金物与积分 | 终端 | 拾荒场 | — |
| 临期食品 | 拾荒场 | 补给站 | ≥2 次 |
| 消耗品 | 补给站 | 拾荒场 | — |
| 祝福遗物 | 谜面 | 险境 / 终端 | ≥1 次接触 |
| 诅咒遗物 / 印记 | 险境 | 谜面 | — |
| **训练点 / 徽章** | **改造间** | **终端（委托奖励）** | **≥1 次** |
| HP / 体力极限 | 补给站 | 谜面 | 受损时 ≥2 次 |
| 污染 / 怪癖清理 | 补给站 | 终端 | — |
| 粒子 | 接驳口（消耗） | 险境（少量回补） | — |
| 寄件保险 | 终端 | 接驳口 | ≥1 次 |
| 路线信息与改道 | 接驳口 | 终端 | — |
| 战斗签与战斗条件 | 异常源 | 接驳口 | ≥2 次 |

## 6.2 价值点（VP）尺度

给所有奖惩一把统一的尺子，供后续平衡使用。**数值为首版基准，需实战校准。**

**锚点**：`1 VP = 10 居民积分 = 1 净化粒子 ≈ 1 格背包背一整趟的代价`

| 奖励 | VP | 奖励 | VP |
| --- | ---: | --- | ---: |
| 通用材料 ×1 | 2 | 全队各 10 经验 | 6 |
| 地区 low / mid / boss 材料 | 3 / 5 / 15 | 单人 30 经验 | 6 |
| 绿晶 / 蓝晶 / 红晶 | 4 / 10 / 25 | 免费抽卡 | 8 |
| 铜币 / 银币 / 金币 | 5 / 20 / 50 | 免费删卡 | 10 |
| 糖块 / 圣水 / 医疗包 | 3 / 5 / 20 | 净化污染卡 ×1 | 6 |
| 临期食品 ×1 | 4 | 全队回 20% HP | 8 |
| 随机模组 | 12 | 修体力极限 10 点 / 人 | 25 |
| 随机装备 | 15 | 治疗一个怪癖 | 40 |
| 装备三选一 | 25 | 免一个节点粒子消耗 | 4 |
| 装备升一阶 | 35 | 一次寄件机会 | 10 |
| 羁绊重铸 | 30 | 战斗签多停一次 | 18 |
| 祝福遗物（随机） | 35 | 预置挑战词条（0.4 档） | 12 |
| 祝福遗物三选一 | 50 | 敌方少一个 | 20 |
| **临时训练点 +1** | 20 | 重照桥接 | 12 |
| **永久训练点 +1** | 60 | 扫描全部谜面 | 15 |
| 城市权限 +1 | 15 | 加时（多一个末段节点） | 20 |

| 惩罚 | VP（负） | 惩罚 | VP（负） |
| --- | ---: | --- | ---: |
| 全队掉 10% 最大 HP | 8 | 污染卡 ×1（全队合计） | 15 |
| 全队 +10 污染 | 12 | 强制丢弃 1 格 | 6 |
| 印记 ×1（轻 / 中 / 重） | 15 / 30 / 50 | 诅咒遗物 ×1 | 35 |
| 背包上限 −2 格（本轮） | 10 | 封锁一条通道（下轮） | 12 |
| 城市权限 −1 | 15 | 体力极限 −10 点 / 人 | 25 |

## 6.3 档位与期望值

| 档位 | 净期望 VP | 出现位置 |
| --- | ---: | --- |
| 轻 | 10-18 | 第 1-2 段主力 |
| 中 | 20-35 | 第 2-3 段主力 |
| 重 | 40-65 | 第 3-4 段、静默带 |
| 稀世 | 80+ | 第 4 段谜面、重档险境、委托完成奖励 |

**平衡口径**：

1. 一个选项的期望净值 = Σ(结果 VP × 权重) − 代价 VP。同一事件内各选项的期望净值差距**不得超过 25%**，差异应体现在方差与养成方向上，而不是「有一个明显的最优解」。
2. **额外消耗粒子只改变操作成本，不得提高奖励品质档位** —— 否则粒子作为难度轴的定位会被架空。粒子只能买：路线信息、路线操作、时间（加时）、安全性（降低翻车率），不能买更好的东西。
3. 风险选项的期望净值可以比稳健选项高 10-15%，作为「承担方差」的溢价，但不能高到让稳健选项没人选。

# 第七章 投放规则

## 7.1 每轮配额

| 约束 | 规则 |
| --- | --- |
| 节点总数 | 20（含静默带的轮次为 19） |
| 谜面 | 恰好 3 个 |
| 类型多样性 | 每轮至少出现 5 种不同节点类型 |
| 补给站 | 至少 1 个；队伍最低血量比 < 50% 时至少 2 个 |
| 险境 | 至多 3 个；第 1 轮至多 1 个 |
| 改造间 | 至少 1 个 |
| 带「本轮」尺度效果的节点 | 至少 3 个 |
| 带「永久」尺度效果的节点 | 至少 2 个 |
| 同一事件 ID | 整趟远征不重复 |
| 同一原型 | 连续两轮不重复 |

## 7.2 整趟保底

一趟 6 轮远征必须保证玩家有机会接触到（**「有机会」= 该节点出现在图上且至少一条入口能走到**）：

- ≥1 次遗物接触（谜面或险境）
- ≥1 次训练点 / 徽章相关事件
- ≥1 次寄件机会
- ≥1 次装备强化机会
- ≥1 次卡组改造机会
- ≥2 次纯补给（无附加风险的治疗）

保底采用「窗口投放」：把保底项分配到轮次窗口（如遗物接触投在第 3-5 轮），窗口内未自然出现则强制替换一个同地带节点。

## 7.3 自适应权重

事件池按队伍当前状态加权，避免「残血时连着三轮只出拾荒场」这种最败兴的体验。

| 状态信号 | 权重调整 |
| --- | --- |
| 最低血量比 < 40% | 补给站 ×2.0，险境 ×0.5 |
| 任一角色污染 ≥ 70 | 含净化 / 降污染效果的事件 ×2.5 |
| 背包占格 ≥ 20 / 24 | 终端（变现、寄件）×2.0，拾荒场 ×0.4 |
| 背包占格 ≤ 8 | 拾荒场 ×1.8 |
| 粒子档位 ≥ 4（告急 / 枯竭） | 接驳口（省粒子类）×1.5，加时类 ×0.3 |
| 队伍未接触过遗物且轮次 ≥ 4 | 遗物相关 ×3.0 |
| 身上有 ≥2 个印记 | 含清洗效果的事件 ×2.5 |
| 有未完成委托 | 委托结算点 ×2.0 |

**上限**：自适应调整后，任何单一类型在一张图上的占比不得超过 40%，保证图面仍然多样。

## 7.4 地带与类型的生成顺序

1. 抽 5 个地带标签（含 1/3 概率的静默带判定）
2. 按 55 / 35 / 10 规则为 20 个位置生成节点类型
3. 应用 7.1 配额校验，不满足则局部重掷
4. 应用 7.3 自适应权重，从事件池为每个节点抽具体事件（按段位选档）
5. 抽 3 个位置转为谜面（优先落在「符合地带」的位置上，制造「看似安全的地带里藏了个问号」）
6. 应用 7.2 保底窗口检查

# 第八章 风险与惩罚体系

## 8.1 三级惩罚

| 级别 | 持续 | 出路 | 使用场合 |
| --- | --- | --- | --- |
| **即时** | 结算完即结束 | 无需出路 | 掉血、丢粒子、丢背包格 |
| **持续** | 本轮 / N 轮 / 整趟 | **同趟内必须可洗** | 印记、封锁通道、背包缩容、负重加重 |
| **永久** | 带回据点 | 据点设施（生物维护舱、圣水池、营养舱） | 污染卡、体力极限、怪癖、诅咒遗物 |

## 8.2 印记：新的持续惩罚载体

**诅咒遗物占背包格，对已经背满的玩家是双重打击，也让「接受一个诅咒」的决策被负重问题污染。**因此新增「印记」作为事件层的主力持续惩罚：

- 不占背包格，不进仓库，回城自动消失（或折算成少量积分补偿）
- 可叠加，同名可叠层
- **清洗出路明确**：终端的「清洗服务」、接驳口的「线路复位」、部分补给站，都能移除 1 个印记

首版 6 个印记示例：

| 印记 | 效果 | 档位 |
| --- | --- | ---: |
| 漏电 | 每抵达一个节点额外 −2 粒子 | 轻 |
| 锈蚀 | 全队命中 −8 | 轻 |
| 超载 | 每场战斗结束全队 −5 HP | 中 |
| 拖曳 | 背包有效负重 +3 格 | 中 |
| 共振 | 每打出 5 张牌全队 +1 污染 | 重 |
| 封条 | 战斗签只能停 2 次 | 重 |

## 8.3 惩罚设计检查表

新增任何惩罚前逐条过：

1. 这一趟里，玩家在哪种节点能解决它？（说不出来 → 降级为即时惩罚）
2. 它对「贪多的玩家」比对「保守的玩家」更痛吗？（好的惩罚应该惩罚贪婪，而不是惩罚运气）
3. 它会不会直接导致团灭而玩家无从预判？（会 → 必须在选项里明示风险等级）
4. 它是否顺带给了玩家好处？（例如掉粒子会提高掉落系数 —— 用它做惩罚时要意识到这一点，必要时配合额外代价抵消）

## 8.4 掉血的硬约束

- 单次事件掉血不超过最大 HP 的 **30%**
- 掉血会顺带压低体力极限（三段血量规则），文案必须让玩家读得到「这会留下永久损伤」
- 任何可能**直接打死角色**的选项，必须二次确认，并在确认框里显示哪些角色处于致死范围

# 第九章 事件的内部结构规范

## 9.1 骨架

```text
事件
├─ 到达文案（1 段，2-3 句）
├─ 选项 ×2-3
│   ├─ 选项文案（1 句，动作描述）
│   ├─ 代价标签（明示：粒子 / HP / 背包 / 永久 / 风险等级）
│   ├─ 收益提示（模糊：「可能获得…」）
│   └─ 加权结果 ×2-3（权重和 100）
│        ├─ 结果文案（1-2 句）
│        └─ 效果清单
└─ 尾声（可选，用于埋线与跨节点机制的提示）
```

## 9.2 硬性要求

| # | 要求 |
| --- | --- |
| 1 | 每个事件 **2-3 个选项**，其中必须恰好有 **1 个低方差稳健档**，保证任何队伍状态下都有可执行选项 |
| 2 | 每个选项 **2-3 个加权结果**，权重和为 100，直接写百分数 |
| 3 | **代价必须明示**：粒子数、HP 百分比、背包格数、「不可逆」标记、风险等级（低 / 中 / 高）全部渲染在选项上 |
| 4 | **收益必须模糊**：只写方向与档位（「少量材料」「一件装备」「重档回报」），不写具体件数 |
| 5 | 选项、每个结果都要有**独立故事文案**，一句也不能复用 |
| 6 | 带永久代价的选项**必须二次确认** |
| 7 | 险境类事件**必须提供无代价离开的选项**；其他类不提供空手离开（节点粒子已经付过了） |
| 8 | 奖励一律「**先展示、后领取**」：实物进拾取框可放弃，待办进队列，处理完才能确认节点 |
| 9 | 全部中文，不出现英文文本 |
| 10 | 节点卡片上预览的代价，必须与实际结算值完全一致 |

## 9.3 文案基调

世界观是 3300 年代无人类的霓虹都市，城市由电子生命与自治机械维持运转。文案基调：

- 机械仍在尽职地执行早已没有意义的流程（分诊机还在叫号、印刷台还在问要不要重印）
- 玩家是闯入者，不是主人；系统把你误认成「员工」「患者」「访客」是常见的戏剧来源
- 不写人类角色的内心戏，写机械的固执与荒诞
- 每个事件的到达文案要给出**一个可被操作的物件**（阀门、柜门、传送带、终端），让选项显得自然

# 第十章 跨节点系统：让事件之间有记忆

三套轻量状态，共同构成远征的长线经营层。

## 10.1 城市权限（0-5 级）

一个整数，整趟有效，回城清零（折算少量积分）。

| 来源 | 变化 |
| --- | --- |
| 完成一份城市工单委托 | +1 |
| 归还失物 / 修复设施类事件 | +1 |
| 在终端用积分购买权限 | +1（价格递增） |
| 破坏设施、赖账、委托失败 | −1 |

| 权限 | 解锁 |
| --- | --- |
| 1 | 终端服务打折；接驳口开放「重照」 |
| 2 | 终端出现第三个服务槽；可接「运输」委托 |
| 3 | 接驳口开放「扫描」与「改道」；终端可赊账 |
| 4 | 终端出现重档服务（装备升阶、遗物交换）；可接「狩猎」委托 |
| 5 | 远征结算时额外获得一份重档奖励；接驳口开放「预定」 |

权限给了经济线一个**长线目标**，也让「第 2 轮那个不起眼的修复设施事件」在第 5 轮产生回报。

## 10.2 埋线（因果事件对）

约 8 组「因—果」事件对。因节点出现并被玩家处理后，果节点进入后续轮次的投放池并保底出现一次。

| 埋线 | 因 | 果 |
| --- | --- | --- |
| 放生 | 放走一台被困的拾荒机器人（放弃它身上的零件） | 它带同伴回来报恩，给重档材料 |
| 留信 | 在旧苏醒者的信旁留下补给（消耗 2 件物品） | 第 5-6 轮出现「回信」，给祝福遗物 |
| 记名 | 在员工名册上写下自己的名字 | 后续终端把你当正式员工，服务全免费一次 |
| 抵押 | 把 2 格物品存进抵押柜 | 下一轮的拾荒场可取回并翻倍 |
| 播种 | 在温室节点种下一份种子（消耗食品） | 后续节点收获大量食品 |
| 断电 | 关掉一个分区的电源（当场得大量材料） | 后续该地带节点全部降档 |
| 追踪 | 给逃跑的宝箱怪打上标记 | 后续异常源必然是宝箱怪战，且掉落翻倍 |
| 借贷 | 向终端赊账 | 远征结算时双倍扣除，还不上则带印记回城 |

埋线是**叙事密度最高**的部分，也是「这一趟和上一趟不一样」的主要来源。

## 10.3 委托（可主动接取的跨轮目标）

在终端接取，一次最多持有 2 份。

| 类型 | 目标 | 失败判定 | 奖励档位 |
| --- | --- | --- | --- |
| **运输** | 带着一件占 2 格、不可丢弃的货物走完 N 个节点 | 丢弃 / 团灭 | 重 |
| **狩猎** | 本轮或下轮战斗中达成指定条件（如不使用治疗、N 回合内结束） | 战斗结束未达成 | 重 |
| **勘测** | 本轮走满 4 段 / 经过 2 个指定类型节点 | 提前离开路线图 | 中 |
| **净化** | 在 N 轮内把全队污染降到阈值以下 | 超时 | 重 |
| **清算** | 在远征结束前累计带回 N VP 的换金物 | 未达标 | 稀世 |

**失败代价是「权限 −1」而不是硬惩罚** —— 委托应该是让玩家主动给自己加约束的乐趣来源，而不是陷阱。
