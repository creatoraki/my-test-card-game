# 第一章 需要新增的系统能力

## 1.1 第一批：让新系统能跑起来（必须）

没有这些，01 与 02 定义的框架无法成立。

| 能力 | 说明 | 改动量 |
| --- | --- | --- |
| 事件结构支持「代价明示 / 收益模糊」 | 选项需要渲染代价标签与风险等级；旧 UI 不渲染选项描述，所有得失只能写在正文里 | 小（UI 为主） |
| 印记系统 | 不占格、可叠加、可清洗的持续负面状态；事件层的主力惩罚载体 | 中 |
| 城市权限 | 整趟有效的整数状态 + 事件与选项的可见性门槛 | 小 |
| 扣居民积分 | 过路费、赎金、赊账结算；注意不能吃能量档位倍率 | 极小 |
| 诅咒遗物投放 | 复用现有遗物发放路径，候选池换成诅咒池，去掉「已拥有折积分」的祝福专用逻辑 | 小 |
| 临时 / 永久训练点 | 小队天赋树新增点数存量，并允许在远征途中分配 | 中 |
| 地带标签生成 | 路线图生成器按地带加权分配节点类型（55 / 35 / 10） | 中 |
| 谜面独立事件池 | 与普通事件池分离，按 35 / 35 / 30 配比抽取 | 小 |
| 自适应投放权重 | 按队伍血量、污染、背包、粒子档位调整事件池权重 | 中 |

## 1.2 第二批：路线层与战斗层挂钩（核心体验）

这一批决定新系统是否真的比旧系统好玩——铁律四完全落在这里。

| 能力 | 说明 | 改动量 |
| --- | --- | --- |
| 重照 / 扫描 / 改道 | 桥接的二次揭示、谜面揭示、强制跨道 | 中 |
| 短路 / 加时 | 跳段与追加第 5 推进段 | 中 |
| 封锁通道 / 预定 / 地带重掷 | 跨轮的路线干预 | 中 |
| 战斗签操作（多停 / 锁定 / 重掷 / 塞符号 / 同花放宽） | 需要事件层能向战斗签写入参数 | 中大 |
| 预置挑战词条 | 开战时注入指定挑战词条 | 中 |
| 战前增益与敌方削弱 | 向战斗建局接缝写入修正 | 中 |
| 背包格临时增减 | 背包容量需从常量改为会话字段，并贯穿所有入包调用点 | 大 |

## 1.3 第三批：长线与叙事（锦上添花）

| 能力 | 说明 | 改动量 |
| --- | --- | --- |
| 埋线（因果事件对） | 因节点写标记，果节点保底投放到后续轮次 | 中 |
| 委托系统 | 接取、追踪、结算、失败判定，最多同时持有 2 份 | 中大 |
| 推运结构（同节点可重复搜刮） | 同一节点内多次结算并可随时停手 | 中 |
| 献祭型结算 | 以玩家当前家当为输入生成回报 | 中 |
| 卡牌改写（升稀有度 / 附标签） | 触及卡牌数据层与限携规则 | 大 |
| 装备熔铸 / 事件内升阶 | 复用据点升阶逻辑 | 中 |
| 世界观线索收集 | 档案 / 图鉴，不影响数值 | 小 |

# 第二章 首版落地范围建议

不要一次做完。建议分三期，每期都能独立验证手感。

## 2.1 一期：骨架验证（最小可玩）

| 项目 | 范围 |
| --- | --- |
| 节点类型 | 补给站、拾荒场、改造间、险境、谜面（**5 类**；暂缓接驳口 / 终端 / 异常源） |
| 地带标签 | 补给带、废料带、工程带、断层带（**4 个**；暂缓枢纽带与静默带） |
| 新增能力 | 1.1 全部 |
| 事件数量 | 每类 6-8 个原型，合计约 **35 个**，按段位缩放覆盖四段 |
| 跨节点 | 只做**城市权限**，不做埋线与委托 |

**验证目标**：

1. 地带 + 桥接是否真的让「选入口」变成有意义的决策？
2. 「代价明示 / 收益模糊」是否让选项更难选？（更难选是好事）
3. 推运结构（压缩废料山）与分次下注（高压检修井）是否成为玩家最期待遇到的节点？

## 2.2 二期：接上路线与战斗

| 项目 | 范围 |
| --- | --- |
| 节点类型 | 补齐接驳口、终端、异常源；加入枢纽带与静默带 |
| 新增能力 | 1.2 全部（背包格临时增减可延后） |
| 事件数量 | 补到约 **60 个**原型 |

**验证目标**：

1. 花粒子买路线信息是否值得？（如果玩家从不选「重照」，说明定价或揭示时长有问题）
2. 事件能碰战斗签之后，路线图收益的评估是否变复杂了？（变复杂是好事）
3. 静默带是否被玩家主动选择，还是被当成「少一个节点的亏本路」？

## 2.3 三期：长线与叙事

| 项目 | 范围 |
| --- | --- |
| 跨节点 | 埋线 8 组、委托 5 类、推运与献祭结构 |
| 新增能力 | 1.3 全部 |
| 事件数量 | 补到约 **80 个**原型，足够支撑一趟远征不重样 |

**验证目标**：

1. 两趟远征之间的差异感是否明显？
2. 玩家会不会为了完成委托而主动改变路线？（会 → 委托系统成立）
3. 赊账带回下一趟的印记，是有趣的余韵还是纯粹的挫败？

# 第三章 待确认清单

下一轮设计前需要定稿的问题：

1. **VP 尺度的锚点是否成立**（1 VP = 10 居民积分 = 1 净化粒子）。需要用实际一趟远征的总产出反推校准。
2. **临时训练点**在远征中途分配后是否允许重置；小队徽章能否中途更换。
3. **印记回城后的处理**：自动消失 / 折算积分补偿 / 可带回下一趟。赊账埋线依赖第三种。
4. **战斗签能接受哪些外部参数注入**，是否会破坏其 8 符号的规则一致性。
5. **静默带的出现概率**（暂定 1/3）与「少一个节点」是否会让玩家感到吃亏。
6. **谜面池 35 / 35 / 30 配比是否让「赌问号」的期望为正**。期望为负则玩家会永远绕开谜面，整个未知节点机制失效——这是三期里最需要实测的一条。
7. 事件原型的**地图皮肤化规则**：通用原型在不同地图下替换哪些要素（地点名、地区特色材料、敌人档位），以及每张地图是否保留少量专属事件。
