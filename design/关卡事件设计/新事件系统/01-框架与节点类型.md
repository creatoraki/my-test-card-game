# 探索节点事件系统 · 框架与节点类型

> **状态**：重设计方案，需求文档阶段，不含实现细节。
>
> 本文定义设计铁律、八种节点类型、路线图上的节点分布、效果的时间尺度与效果原语库。
> 投放、平衡、惩罚与跨节点机制见 [02-投放与平衡规则.md](02-投放与平衡规则.md)；示例事件见 [03-示例事件册.md](03-示例事件册.md)；需要新增的系统能力与落地批次见 [04-能力缺口与落地批次.md](04-能力缺口与落地批次.md)。
>
> 本方案**摒弃旧事件系统的全部机制与规则**，从可玩性重新设计。旧文档 `../事件奖惩清单.md` 仅作为资源底表参考。

---

## 为什么重做

旧事件系统是一台「奖励贩卖机」：节点事件的职责基本只剩下把养成资源发给玩家。这带来三个问题：

1. **事件与路线图脱节**。路线图玩法的核心是「记桥接 → 选入口 → 决定走多深」，但事件从不作用于路线，玩家选入口只是在选一串奖励，记忆玩法没有被事件放大。
2. **事件与战斗签脱节**。每轮末必然有一场战斗，事件却完全碰不到它，两个小游戏各玩各的。
3. **决策深度不足**。多数事件是「选一个选项 → 看一段文案 → 领一份随机奖励」，没有真实代价，也没有跨节点的记忆。

# 第一章 设计目标与四条铁律

## 1.1 一句话目标

> 让玩家在看路线图时想的不是「哪条路奖励多」，而是**「我想吃到哪一串节点，我记不记得住怎么走到那儿，走过去我还剩多少本钱」**。

## 1.2 四条铁律

所有事件必须同时满足，违反任何一条的事件直接废弃重做。

| 铁律 | 内容 | 反例（旧系统里常见的写法） |
| --- | --- | --- |
| **一、每个节点都是一次有代价的决策** | 每个事件的所有选项都必须付出至少一种代价：粒子、HP、背包格、时间（放弃另一个选项）、风险、永久损伤。不存在「点确认就领奖」的节点。 | 「你找到一个箱子。选项一：打开。获得齿轮 ×2。」 |
| **二、代价明示，收益模糊** | 玩家在点下选项前，必须能准确读到自己要付什么；但**不能**准确读到会拿到什么。收益写「可能获得装备或高阶材料」，不写「获得齿轮 ×1、电池 ×1」。 | 选项文案把奖励清单列死，选择退化成算术比大小。 |
| **三、每个惩罚都要有出路，且出路在同一趟远征里可触达** | 设计任何惩罚时，先指明「这一趟里，玩家在哪种节点能把它洗掉」。带回据点才能解决的惩罚，至多作为最重的一档。 | 事件给了污染，但这一趟根本遇不到净化手段。 |
| **四、至少 1/4 的节点改变「下一步怎么走」** | 每轮 20 个节点里，必须有相当比例的事件作用于**路线图本身**或**本轮即将发生的战斗**，而不只是发资源。 | 20 个节点全是不同包装的资源发放器。 |

## 1.3 三个新增的结构性抓手

本方案相对旧系统的三处根本改动，后文所有设计都由它们派生：

1. **通道有性格**（第三章）：路线图的 5 条通道不再是均匀随机的节点袋子，而是各有主题地带。记桥接的收益从「记住路」升级为「我要吃到工程带那一串」。
2. **事件能碰战斗签**（第四章、第五章）：路线图的收益第一次可以直接兑换成「这一场怎么打」——多停一次轮、锁一格、预置挑战词条、削弱敌人。
3. **事件之间有记忆**（第十章）：城市权限、埋线、委托三套轻量跨节点状态，让第 2 轮的选择在第 5 轮兑现。

# 第二章 节点类型：玩家在图上看到的八种标识

节点类型是**玩家选入口时唯一的决策依据**，所以类型数量必须少到能一眼扫完、彼此差异必须大到值得为之改路。定为 8 类。

| # | 类型 | 图标语义 | 一句话 | 主养成线 | 典型代价 |
| --- | --- | --- | --- | --- | --- |
| 1 | **补给站** | 十字 / 青蓝 | 修队伍：血、体力极限、污染、怪癖、消耗品 | 生存线 | 粒子、额度有限（只能救一个方向） |
| 2 | **拾荒场** | 箱子 / 灰褐 | 搜实物：材料、水晶、换金物、食品、装备与模组 | 资源线 | 背包格、时间、推运翻车 |
| 3 | **改造间** | 齿轮 / 紫 | 改构筑：卡组、装备羁绊、模组、遗物、训练点 | 构筑线 | 拿一样换一样、永久不可逆 |
| 4 | **险境** | 感叹号 / 红 | 明码赌注：用损伤与永久代价换高档回报 | 风险线（跨全部养成） | HP、污染、印记、诅咒遗物 |
| 5 | **接驳口** | 线路 / 青绿 | 操作路线图：重照桥接、扫描谜面、改道、跳段、加时 | 探索元玩法 | 粒子（唯一稳定的粒子出口） |
| 6 | **终端** | 屏幕 / 金 | 经济与契约：交易、委托、赊账、权限、寄件、变现 | 经济线 | 食品、积分、信用、还债 |
| 7 | **异常源** | 裂纹 / 黑 | 战斗相关：额外战斗、战斗签操作、本轮战斗条件改写 | 战斗线 | 打一场、粒子、被追击 |
| 8 | **谜面** | 问号 / 白 | 落地才揭示的高方差事件，自成一池 | 全线（高方差） | 未知本身 |

## 2.1 类型不是「事件分类标签」，而是「承诺」

玩家看到某个图标，就必须能预期到那一类的**行为模式**（而非具体奖励）：

- 看到补给站 → 「我能把队伍修好一部分，但不可能全修好，我得选修哪一样。」
- 看到拾荒场 → 「我会拿到占格的实物，背包要有空间，可能要冒点风险多拿。」
- 看到改造间 → 「这里会永久改写我的构筑，而且大概率要我交出点什么。」
- 看到险境 → 「我可以完全不赌，但赌了可能血赚也可能带伤一整趟。」
- 看到接驳口 → 「我可以买路线信息或改路线，代价是粒子。」
- 看到终端 → 「我可以做交易或接活，这里的东西跟我这趟的信用挂钩。」
- 看到异常源 → 「这会影响我这一轮末的那一仗。」
- 看到谜面 → 「什么都可能发生。」

**这八条承诺是硬约定**。任何一个事件如果放在某类节点下却不符合该类的承诺，就换类或废弃。

## 2.2 谜面节点的特殊地位

每张路线图固定 3 个谜面节点（沿用现有规模），但它们**不是「被藏起来的普通事件」，而是有独立事件池**。谜面池的构成配比：

| 占比 | 性质 | 说明 |
| --- | --- | --- |
| 35% | 纯惊喜 | 无代价的重档收益。制造「问号是好东西」的期待，让赌谜面有正期望。 |
| 35% | 高风险高回报 | 代价即时且明确，但只有落地才知道要付什么。 |
| 30% | 献祭型 | 要求玩家交出**当前已拥有的东西**（背包物品、遗物、一名角色的一张卡、当前粒子），换取远超其价值的回报。 |

献祭型是谜面独有的结构：它的代价取决于玩家此刻的家当，所以同一个事件对不同局面的玩家完全是两件事。

接驳口的「扫描」功能可以提前揭示谜面 —— 于是「要不要花粒子买掉这层未知」本身成了一个决策。

# 第三章 通道性格：把节点类型铺到路线图上

这一章是整套设计的空间层，决定了「选入口」到底在选什么。

## 3.1 问题

每轮 20 个节点，玩家最多经过 4 个。如果节点类型在 20 个位置上均匀随机，那么无论选哪个入口，期望都一样，**选入口就退化成了掷骰子**，记桥接也失去了意义。

## 3.2 方案：地带标签

每轮生成路线图时，先给 A-E 五条通道各分配一个**地带标签**（从 6 个标签中无重复抽 5 个）：

| 地带 | 节点类型倾向 | 玩家心智 |
| --- | --- | --- |
| **补给带** | 补给站 / 终端 | 「我残血了，走这条。」 |
| **废料带** | 拾荒场 / 终端 | 「我背包还空，来这条捞一把。」 |
| **工程带** | 改造间 / 接驳口 | 「我要改构筑，这条最值。」 |
| **断层带** | 险境 / 异常源 | 「粒子快没了，干脆去赌产出。」 |
| **枢纽带** | 接驳口 / 终端 / 异常源 | 「我要买路线信息、接活、寄件。」 |
| **静默带** | 节点少但档位高（见 3.4） | 「就三个节点，但每个都是重的。」 |

节点类型的生成权重：**55% 符合本通道地带 / 35% 通用池 / 10% 反差节点**。

那 10% 的反差节点是刻意的：补给带里出现一个险境、断层带里出现一个补给站。它保证「按地带记路」不会变成无脑选择，也制造记忆的意外感。

## 3.3 桥接与地带的互动（记忆玩法的真正价值）

桥接会把信号甩到相邻通道，所以玩家实际走的 4 个节点往往跨越 2-3 个地带。于是记桥接的动机被具体化为：

> 「我记得从 B 入口出发，第 2 段会被桥到 C；C 是工程带，那我这一轮能吃到两个改造间。」

配套约定：

- 地带标签**在桥接揭示前就对玩家可见**（通道首端显示地带图标），因为它是选入口的依据。
- 桥接仍然只揭示一次，不因地带可见而削弱记忆压力。
- 生成器需保证：**至少存在一条入口，其路径能连续经过 2 个同地带节点**，否则地带设计不成立。

## 3.4 静默带

每轮有 1/3 概率把某条通道设为静默带：该通道只有 3 个节点（第 2 段为空白直通），但每个节点的**档位强制上调一档**（见 `02-投放与平衡规则.md` 6.3）。

它提供一种截然不同的路线策略：少吃一个节点，省 3-5 粒子，但吃到的每一口都更重。同时它让路线图在视觉上不再是整齐的 5×4 网格。

## 3.5 段位与档位

| 推进段 | 粒子消耗 | 事件档位倾向 | 设计口径 |
| --- | --- | --- | --- |
| 第 1 段 | 3 | 轻档为主 | 稳定、低方差、几乎无永久代价 |
| 第 2 段 | 3 | 轻 / 中 | 开始出现真实取舍 |
| 第 3 段 | 4 | 中 / 重 | 永久代价与永久收益登场 |
| 第 4 段 | 5 | 重 / 稀世 | 高方差，值得为它硬撑一段 |

**同一个事件原型按段位缩放，而不是为每段单独写事件**。一个「压缩废料山」在第 1 段是小堆废料，在第 4 段是整座塌方的料山：结构一样、档位不同、文案换一句。这让内容复用率大幅提高。

# 第四章 效果的四种时间尺度

旧系统的效果几乎全是「即刻」。新系统把时间尺度做成一等公民 —— 一个事件的味道，很大程度上由它作用在哪个尺度决定。

| 尺度 | 作用范围 | 玩家感受 | 典型效果 |
| --- | --- | --- | --- |
| **即刻** | 结算完即结束 | 拿到手就完事 | 给物、治疗、掉血、粒子增减 |
| **本轮** | 到本轮推进战斗结束 | 「我这一轮要打的那一仗变了」 | 战斗签操作、战前增益、预置挑战词条、敌方情报、临时负重适应 |
| **跨轮** | N 轮或到远征结束 | 「我得记着这笔账」 | 委托、印记、城市权限、埋线、临时训练点、封锁通道 |
| **永久** | 带回据点 | 「这趟真的改变了我的队伍」 | 卡组变动、装备与羁绊、模组、遗物、体力极限、怪癖、永久训练点 |

## 4.1 「本轮」尺度是本次设计最大的新增面

因为每轮末必然有一场战斗，事件可以直接兑换成「怎么打这一场」。这把两个原本互不相干的小游戏缝在了一起，也给了玩家一条全新的收益评估维度：

> 「这个接驳口能让我战斗签多停一次 —— 那我这一轮大概率能停出三连，收益比拿两块材料高多了。」

具体手段见 5.6。

## 4.2 尺度配比要求

每轮 20 个节点中，四种尺度的节点数建议：即刻 8-10、本轮 4-6、跨轮 3-4、永久 2-4。

**硬约束**：每轮至少 3 个节点带「本轮」尺度效果（呼应铁律四），至少 2 个节点带「永久」尺度效果（保证养成推进感）。

# 第五章 效果原语库

按玩家可感知的方式分组，不按实现分类。标 ✅ 者为需要新增的系统能力，汇总见 `04-能力缺口与落地批次.md`。

## 5.1 队伍状态（生存线）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
| 治疗 · 全队 | 按最大 HP 百分比 | |
| 治疗 · 指定一人 | 玩家指定 | |
| 治疗 · 集中 | 自动挑伤最重者回满，其余少量 | |
| 修体力极限 · 全队 / 一人 | 修永久损伤，价值远高于同数值回血 | |
| 降污染 · 全队 / 一人 | | |
| 治怪癖 | 移除一个永久 debuff | |
| 净化污染卡 | 断污染源头 | |
| **临时负重适应** | 本轮 / N 轮内全队负重适应 +N | ✅ |
| **抵抗屏障** | N 轮内免疫下一次污染或掉血结算 | ✅ |

## 5.2 实物与经济（资源线）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
| 定额给物 | 指名物品与数量，不吃掉落系数。用于确定性奖励 | |
| 搜刮掷点 | 掷一张掉落表，**吃掉落系数 K**。用于「看运气」 | |
| 随机装备 / 装备候选 | | |
| 随机模组 / 模组箱 | | |
| 临期食品 | 探索内货币，延迟兑现 | |
| 居民积分增 | 不占格的收益 | |
| **居民积分减** | 过路费、赎金、罚款 | ✅ |
| 强制丢弃背包格 | 按稀有度从低到高丢 | |
| 强制拾取 | 不可放弃的负担物 | |
| 开投递口 | 寄件保险，团灭也保得住 | |
| **背包格临时增减** | N 轮内背包上限 ±N | ✅ |
| **物品变现** | 背包内物品按汇率换成不占格的积分 / 权限 | ✅ |

## 5.3 构筑（构筑线）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
| 免费抽卡 / 删卡 | 指定角色 | |
| 卡组等级等价经验 | 直接推一名角色的卡组等级 | |
| 经验 · 全队 / 单人 | | |
| 污染卡组 | 惩罚 | |
| **卡牌改写** | 把一张卡升稀有度 / 附加一个临时标签 | ✅ |
| 装备羁绊重铸 | 极贵，不可当中档收益 | |
| **装备熔铸** | 消耗两件装备产出一件更高阶 | ✅ |
| **装备升阶（事件内）** | 直接把一件已穿戴装备升一阶 | ✅ |
| 祝福遗物 · 随机 / 指名 / 候选三选一 | | |
| **诅咒遗物投放** | 有出路的负面常驻（据点圣水池可净化） | ✅ |
| **遗物交换** | 交出一件已有遗物换更高稀有度 | ✅ |
| **训练点 · 临时** | 整趟内 +N 训练点，可当场在徽章树上分配 | ✅ |
| **训练点 · 永久** | 带回据点的存量点 | ✅ |
| **徽章切换** | 远征中途换一次小队徽章（重分配训练点） | ✅ |

> **临时训练点是本方案最看重的一条新增**：它把小队天赋从「出发前配好的静态面板」变成「路上能成长的东西」，一举补上旧系统「事件对小队天赋树零影响」的最大空白，并且让「中途加点」成为远征里少有的、纯粹令人愉快的高光时刻。

## 5.4 探索资源（探索线）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
| 粒子增减 | 上限 100。**回补必须稀缺且有代价**，不得形成稳定循环 | |
| 免节点粒子消耗 | 接下来 N 个节点免基础消耗 | |
| **粒子透支** | 允许粒子降到 0 以下并继续推进，代价按负值加倍换算成惩罚 | ✅ |

## 5.5 路线操作（新增的一整层）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
| **重照** | 再次揭示本轮全部桥接（时长可比首次短） | ✅ |
| **扫描** | 揭示 1-3 个谜面节点的真实类型或全貌 | ✅ |
| **改道** | 本段结束后强制跨到指定相邻通道 | ✅ |
| **短路** | 跳过下一段直达更深段：省粒子，但少吃一个节点 | ✅ |
| **加时** | 本轮追加第 5 段（1 个额外节点，档位按最高档） | ✅ |
| **封锁通道** | 指定通道本轮 / 下轮不可进入（惩罚或代价） | ✅ |
| **预定** | 为下一轮指定某个节点类型必然出现 | ✅ |
| **地带重掷** | 重掷下一轮的地带标签分配 | ✅ |

## 5.6 战斗挂钩（新增的一整层）

| 原语 | 说明 | 新增 |
| --- | --- | --- |
