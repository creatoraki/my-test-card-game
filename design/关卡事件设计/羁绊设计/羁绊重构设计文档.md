# 《霓虹都市》· 羁绊重构设计文档

> **状态**：已审查定稿（2026-10-08），进入实装。
>
> **范围**：替换《羁绊设计概览.md》第三～六章与《具体羁绊设定.md》的全部效果。计数来源（装备羁绊词条）、门槛规格（3/6/9、4/8/12、6/12）、色签展示（BondTag）沿用现行实现。
>
> **结论先行**：羁绊从“属性加成表”改为 **18 条规则型羁绊**，分 6 个系别、每系 3 条；每一档都改变一条战斗规则，不再提供“攻击力 +10”式的纯数值收益。另有 4 张塔罗牌预留给二期。

## 一、现状诊断

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 只有数值 | 已实装 6 条中 5 条是纯属性（攻击、命中、暴击、治疗效果、护盾强度），愚者是抽牌数 | 玩家只会感觉“面板变高了”，不会因为羁绊改变打法；与卡牌词条“满足后换一种工作方式”的口径相冲突 |
| 与装备属性重复 | 武器、防具、饰品本身就提供攻击、命中、暴击 | 羁绊和装备词条做的是同一件事，凑羁绊等于多穿半件装备 |
| 没有接入核心系统 | 时刻轴、速攻、待机、敌人行动点与大招、濒死、增减益种类都没有羁绊涉及 | 本作最有特色的“时刻调度”在构筑层没有出口 |
| 旧规则型设计过时 | 隐者“丢弃最下方”、月亮/太阳“按牌堆张数加攻击力”、命运之轮“逐回合加攻击力” | 前者是随机惩罚，后两者仍然是数值；且写于时刻轴、6 格装备之前 |
| 定向困难 | 随机池只有 6 条，偏向重铸只有“进攻 / 防守”两档 | 扩到 15 条以上后，不改获取方式就凑不出门槛 |
| 新手不可感知 | 编队页只显示“暂无羁绊词条”（见《试玩体验评审》） | 羁绊没有存在感 |

## 二、设计原则

### 2.1 五条红线

1. **每一档都带来规则变化**。允许的收益：形态改变（单体→全体、溅射）、规则改写（无视闪避 / 格挡 / 防御、视为速攻、伤害上限）、时序（视为速攻、自动出牌、悬置到下回合）、流转（抽牌、回手、预知、结转法力）、因果（反伤、转移、扩散、复活）。
   禁止：攻击力 / 命中 / 暴击 / 治疗效果 +X 这类可以直接写进装备面板的收益。
2. **资源羁绊例外**。愚者（抽牌）与魔术师（法力）直接改资源数量，本身就是规则级的变化，但它们必须使用最贵的 **6/12** 规格。
3. **全队共享，不绑定角色**。羁绊的触发条件只读通用概念（攻击牌、费用、速攻、待机、时刻、增益 / 减益、护盾、治疗、格挡、闪避、击杀、濒死），不读任何角色专属资源（恶毒、星辉、保险、穿孔、组装字母……）。羁绊可以与某名角色“合拍”，但没有这名角色也必须有用。
4. **不抢角色招牌**。以下机制留给角色本身，羁绊不提供：打断或推迟招式、操纵敌人、喂 / 抽 / 换敌人行动点、施加角色专属状态。推迟招式的收益本身也偏小（回合结束时所有待出招式都会清算），不适合作为高档奖励。
5. **所有触发写明次数上限**。凡是“触发后给牌 / 法力 / 回手”的效果都写“每回合至多 N 次”，避免 0 费牌无限循环。

### 2.2 门槛规格分配

门槛只用三种规格（沿用现行规定）：

| 规格 | 条数 | 适用 | 本方案 |
| --- | ---: | --- | --- |
| 3 / 6 / 9 | 13 | 常规羁绊，3 档逐步成型，3 点即可作为“副羁绊”点缀 | 力量、战车、审判、高塔、女祭司、命运之轮、星星、倒吊人、隐者、月亮、太阳、节制、正义 |
| 4 / 8 / 12 | 3 | 改写生死规则的重羁绊，12 档需要中后期才能凑出 | 皇帝、死神、恶魔 |
| 6 / 12 | 2 | 直接加资源的引擎羁绊 | 愚者、魔术师 |

### 2.3 点数预算

计数规则不变：每件装备 1 条羁绊词条，提供 1 点；只统计上阵 3 人已装备的格子。

| 卡组等级 | 每人可用格 | 全队上限 | 典型组合 |
| --- | ---: | ---: | --- |
| 0～1 | 3（主武器、主防具、主饰品） | 9 | 9 / 6+3 / 3+3+3 / 4+4 |
| 2～3 | 4（+副武器） | 12 | 12 / 9+3 / 6+6 / 6+3+3 |
| 4～5 | 5（+副防具） | 15 | 12+3 / 9+6 / 6+6+3 |
| 6 | 6（+副饰品） | 18 | 12+6 / 9+9 / 9+6+3 / 6+6+6 / 3×6 |

设计含义：

- **3 点档**要单独拿得出手，鼓励后期“六个 3 点”的杂糅构筑。
- **9 点档**是前期唯一能摸到的终极档，3/6/9 规格的 9 档要做得最“好玩”。
- **12 点档**要占全队 2/3 的格子，只在中后期出现，所以可以改写生死规则。

## 四、通用口径

以下用语在第五章所有羁绊里含义一致。

| 用语 | 口径 |
| --- | --- |
| 攻击牌 | 含伤害效果的卡牌（倍率伤害、固定伤害都算）。被动卡不算。 |
| 一次攻击 | 一张攻击牌对一名目标的结算算 **1 次**，多段伤害不重复计数；群体牌对每个目标各算 1 次。 |
| 重攻 | **基础费用 ≥ 2** 的攻击牌。读卡牌定义的费用，不受降费、模组、星光支付影响。 |
| 击杀 | 敌人因我方任何来源（卡牌、持续伤害、反伤、溅射、尸爆）死亡。 |
| 固定伤害 | 跳过防御与格挡、不判定命中与暴击（与现行伤害管线口径一致），仍被护盾吸收。 |
| 通用增益池 | 锋利、铁壁、再生、荆棘。 |
| 通用减益池 | 虚弱、易伤、破甲、萎靡、致盲。 |
| 自动打出 | 牌不经玩家操作直接结算（命运之轮 9、倒吊人 9）：0 费、不推进时刻；需要目标时攻击指向随机敌人，治疗 / 护盾指向生命最低的队友。 |
| 本回合 / 每回合 | 以我方回合为单位；次数上限在下回合开始时重置。 |
| 生效时机 | 开战时按门槛快照，战斗中换装不影响本场（现行口径）。 |

数值统一标注为**初版**，平衡阶段再调。

## 五、羁绊详述

### 锋刃系

#### 1. 力量 VIII ·「驯狮」 `strength` · 3/6/9

> 以柔驯猛。贵的牌要打得稳、打得开、打得住。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 重攻**不会被格挡**。 |
| 6 | 重攻命中后，对其他所有敌人造成本次伤害 **30%** 的固定伤害（溅射）。 |
| 9 | 每回合**第一张重攻**视为**速攻**，且费用 **−1**（降费后仍算重攻）。 |

- **玩法问题**：每回合 3 点法力，要不要压在一张 2～3 费牌上？9 档让贵牌既打得起，又能抢在敌人出手前落地——2 费重攻只花 1 点法力、不推进时刻，剩下 2 点还能接一张。
- **合拍**：魔术师（法力）、星星（低费速攻补位）、各角色的 2～3 费终结牌。
- **实现要点**：伤害管线格挡段跳过标记；结算后钩子打溅射；9 档在出牌期写“视为速攻 + 临时费用 −1”，由 `playAdvance` 与 `cost.ts` 读取，手牌中符合条件的第一张重攻高亮并显示降费后的费用。

#### 2. 战车 VII ·「驰骋」 `chariot` · 3/6/9

> 两头狮子朝不同方向拉，驾车的人只看一个目标。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 本回合**第 2 次及以后**攻击同一名敌人时，无视其闪避。 |
| 6 | 本回合**第 3 次及以后**攻击同一名敌人时，无视其防御。 |
| 9 | 击杀一名本回合已被攻击过 **2 次以上**的敌人时，下一张攻击牌**视为速攻**（每回合 1 次）。 |

- **玩法问题**：集火一个，还是分摊伤害？9 档奖励“打穿一个再转向”的节奏。
- **合拍**：低费多段牌、审判（残血处决）、死神（击杀连锁）。
- **实现要点**：`BattleState` 记录本回合 `{敌人 id → 被攻击次数}`；命中段、防御段读取；击杀钩子写“下一张攻击牌速攻”标记，由 `playAdvance` 读取。

#### 3. 审判 XX ·「号角」 `judgement` · 3/6/9

> 号角落下的那一刻，罪与罚同时兑现。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 攻击生命低于 **30%** 的敌人时**必定暴击**（突破暴击率上限）。 |
| 6 | 暴击击杀时，**溢出伤害**转移给生命最低的另一名敌人（可连锁，转移伤害按固定伤害结算）。 |
| 9 | 暴击伤害**无视目标的防御与护盾**。 |

- **玩法问题**：先把哪只打到斩杀线？6 档让“最后一刀”变成连锁收割。
- **合拍**：高暴伤装备、战车（集火）、死神（击杀连锁）。
- **实现要点**：暴击段前判定目标生命比例；扣血段计算溢出值，交给击杀钩子转发；9 档在防御与护盾段读暴击标记。

### 壁垒系

#### 4. 高塔 XVI ·「崩塌」 `tower` · 3/6/9

> 塔会倒，但倒下的砖石会砸向攻城的人。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 角色的护盾被**打空**时，对攻击者造成等于**被打掉护盾量**的固定伤害。 |
| 6 | 有护盾的角色被施加减益时，改为失去 **8** 点护盾抵消该减益（护盾不足 8 点则照常施加）。 |
| 9 | 3 档的碎盾反击改为对**所有敌人**生效。 |

- **玩法问题**：护盾是叠厚一点让它扛住，还是故意给薄盾让它碎出反击？
- **合拍**：护盾类卡牌、精算师（受击联动）、节制（减益处理）。
- **实现要点**：护盾段新增“护盾从正值归零”事件；状态施加前钩子（与现有异常抗性同一位置）。

#### 5. 女祭司 II ·「帷幕」 `priestess` · 3/6/9

> 帷幕之后的静默知识：伤口愈合之外，还要看见下一道伤。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 溢出的治疗量转为等量**护盾**。 |
| 6 | 治疗生命低于 **30%** 的角色时，额外移除其 **1** 个减益。 |
| 9 | 每回合**第一张单体治疗牌**改为作用于**全队**。 |

- **玩法问题**：提前满血治疗不再浪费；9 档让“单体奶”在关键回合变“群奶”。
- **合拍**：精算师、植物学家园艺牌、高塔（溢疗变护盾再碎盾反击）。
- **实现要点**：`ops.heal` 返回溢出值；9 档在出牌期把单体治疗目标改写为全体，只改一次。

#### 6. 皇帝 IV ·「王座」 `emperor` · 4/8/12

> 秩序的意义，是不让任何一个人独自承受。

| 门槛 | 效果 |
| ---: | --- |
| 4 | 队友受到敌人**单体攻击**时，由当前生命最高的**另一名**队友代为承受 **30%**（直接扣其护盾 / 生命，不再判定格挡与闪避）。 |
| 8 | 敌人每回合**第一次全体攻击**，改为只命中当前生命最高的队友（伤害不变）。 |
| 12 | 我方任何角色受到的**单次伤害**不超过其最大生命的 **25%**。 |

- **玩法问题**：12 档让首领的大招不再秒人，玩家可以放心把节奏交给后发、待机这类“让时间流逝”的玩法。
- **合拍**：高生命 / 高防御角色、女祭司、时序系整体。
- **实现要点**：扣血前钩子（分担、上限）；敌人招式结算前把全体目标收束为单体，需要在 `enemy/ai` 出招时读羁绊状态。

### 时序系

#### 7. 命运之轮 X ·「轮转」 `wheel` · 3/6/9

> 时间在转，只要你肯让它转。

| 门槛 | 效果 |
| ---: | --- |
| 3 | 本回合推进满 **3** 个时刻时，抽 **1** 张牌（每回合 1 次）。 |
| 6 | 本回合推进满 **5** 个时刻时，获得 **1** 点法力（每回合 1 次）。 |
| 9 | **命运馈赠**：本回合推进满 **6** 个时刻时，抽牌堆顶的 **1** 张牌立即以 **0 费自动打出**（每回合 1 次）。 |

- **玩法问题**：推进时刻本来是代价（敌人会出手），轮转把它变成收入。9 档把“这回合拖得够久”直接兑现成一张白送的牌，翻到什么打什么，保留命运之轮的赌运味道。
- **合拍**：咒术师（后发）、倒吊人（待机）、0 费普通牌。
- **实现要点**：读取现成的“本回合已推进时刻数”（`hexGate` 已有计数）；9 档在推进时刻钩子里判定。馈赠的牌：
  - 需要目标时，攻击指向随机敌人，治疗 / 护盾指向生命比例最低的队友；
  - **不推进时刻**，避免在推进途中再次触发推进；
  - 回合结束清算剩余敌人招式时的时刻推进**不计入**三档里程碑（那不是玩家主动让时间流逝）；
  - 翻到被动卡时改为放入手牌，再翻下一张；抽牌堆为空时按现行规则先洗牌；

- **时刻预算参考**：3 张 1 费普通牌 + 1 次待机 = 4 时刻；满 5 需要 0 费普通牌或倒吊人 3 档；满 6 需要两者之一再加一张。

## 六、获取与定向

18 条羁绊平均到每件装备只有 1/18 的概率命中想要的那条，必须给玩家“定向”的手段。

### 6.1 系别重铸（替换现行“进攻 / 防守”偏向）

| 项目 | 现行 | 重构后 |
| --- | --- | --- |
| 偏向选项 | `offense` / `defense` 两档 | 6 个系别任选 1 个 |
| 结果池 | 进攻 4 条 / 防守 3 条 | 该系别 3 条中排除当前那条，二选一 |
| 不选偏向 | 全池随机 | 全池随机（价格更低） |

- 据点工房的重铸与探索中的“重铸台”交互物都改为可选系别。
- 选定系别后命中目标羁绊的概率约 50%，配合价格控制节奏。

### 6.2 地图掉落偏向

每张地图偏向 2 个系别：装备掉落时 **60%** 在偏向系别内随机，**40%** 全池随机。让“去哪张图刷装备”本身成为构筑选择。

| 地图 | 偏向系别 | 理由 |
| --- | --- | --- |
| 废弃楼层 | 锋刃 · 壁垒 | 新手图，给最直观的输出与生存羁绊 |
| 生态方舟 | 蚀刻 · 因果 | 减益、持续伤害密集，同时给出应对它们的羁绊 |
| 余烬热井 | 时序 · 流转 | 新图，主打节奏 |

> 后续新地图按“每系别至少被一张地图偏向”分配。

### 6.3 新手可感知

- 教学关遗物储备箱之外，**教学关首件装备固定带愚者词条**——愚者是最好理解的羁绊。（未实装，待教学关调整时一起做）

## 八、实现概要

> 已实装（2026-10-08），以代码为准。

### 8.1 架构

- **数据**：`src/data/roster/bonds/`（`types` 类型、`frontDefs` / `tempoDefs` / `fateDefs` 三份定义、`families` 系别与地图偏向、`index` 注册表与抽取池）。`BondTier` 只剩 `squadMods`（倒吊人待机次数、愚者抽牌、魔术师法力）。
- **开战**：`store/run/launchBattle` 把激活羁绊（id + 档位）经 `BattleSetup.bonds` 交给引擎，写入 `BattleState.bond`（运行态与每回合计数，类型见 `engine/types/bonds.ts`）。
- **行为**：`src/engine/bonds/behaviors/` 按系别分六个文件，经 `bondBehaviors.ts` 注册进 `hookRegistry`，由 `runRelicHook` 与遗物同一套时点分发——羁绊在引擎眼里就是“按档位生效的隐形遗物”。
- **流程嵌入**：费用 / 速攻 / 回手 / 血契在 `bonds/bondPlay.ts`；回合边界（结转、隐者弃牌、预知选择）在 `bonds/bondRound.ts`；目标改写（女祭司 9、皇帝 8）在 `bonds/bondTargets.ts`；自动出牌（命运之轮 9、倒吊人 9）在 `bonds/bondAutoPlay.ts`。
- 伤害管线新增可写入 `dmg.flags` 的规则改写：`mustHit` 必中、`noDefense` 无视防御、`noBlock` 不判格挡、`pierceShield` 无视护盾。
- 无需考虑旧存档：旧装备上已下线的羁绊 id 由 `getBondDef` 静默跳过。
