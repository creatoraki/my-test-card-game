# 《霓虹都市》· 羁绊设计概览

> **状态**：羁绊基础机制已确认；主题定制采用塔罗牌体系，具体牌面、名称、门槛与数值待逐项设计。
> 代码实装进度见第五章。
>
> 本文记录羁绊作为装备构筑系统的通用规则，以及后续使用塔罗牌定制羁绊时需要遵守的设计边界。具体羁绊的完整方案另行记录。

---

## 一、系统定位

羁绊是由装备驱动的**全队构筑系统**，不是角色固有职业，也不是角色卡牌关键词。

- 角色关键词属于个人卡组与卡牌模组系统，围绕角色特色卡牌形成连锁。
- 羁绊属于全队装备系统，通过装备上的羁绊计数改变战斗规则或队伍属性。
- 羁绊效果应当能够被三名角色共同利用，不绑定某一名固定角色。
- 羁绊的主题、名称和叙事可以来自塔罗牌，但机制仍必须服务于现有战斗系统。

核心循环为：

$$
\text{获得装备}
\rightarrow
\text{积累塔罗主题羁绊}
\rightarrow
\text{达到激活门槛}
\rightarrow
\text{完成队伍构筑}
$$

## 二、已确认的羁绊机制

### 2.1 羁绊计数来源

三名角色各有 3 个装备槽，共计 9 个装备槽：

| 装备来源 | 羁绊贡献 |
| --- | --- |
| 普通武器 | 1 条随机羁绊，提供对应羁绊 +1 |
| 普通防具 | 1 条随机羁绊，提供对应羁绊 +1 |
| 普通饰品 | 1 条随机羁绊，提供对应羁绊 +1 |
| 羁绊饰品的固定羁绊 | 由饰品种类决定，提供对应羁绊 +1 |
| 羁绊饰品的随机副羁绊 | 随机提供其他一种羁绊 +1 |

普通装备的稀有度不会增加羁绊数量。无论普通、精良、稀有、史诗还是传说，同一件装备模型都只提供 1 条随机羁绊。

### 2.2 羁绊饰品

每一种羁绊对应一种专属羁绊饰品。羁绊饰品只能装备在饰品槽中，不提供攻击力、生命值、命中率等常规基础属性。

羁绊饰品由两条羁绊组成：

1. **固定羁绊**：由饰品种类决定，恒定提供 1 点对应羁绊。
2. **随机副羁绊**：随机提供 1 点其他羁绊，可通过重铸更换。

羁绊饰品的随机副羁绊不能与固定羁绊相同。不同羁绊饰品之间允许出现相同羁绊，因此可以通过多个饰品交叉构筑同一种主羁绊。

羁绊饰品的价值来自构筑自由度，而不是即时面板属性；选择羁绊饰品意味着放弃普通饰品的资源、输出或生存收益。

### 2.3 激活门槛

不同羁绊可以使用不同的激活门槛，不强制统一为相同档位。门槛应根据羁绊效果的稳定性、强度和构筑难度分别设计。

当前仅保留以下门槛结构作为设计参考：

| 门槛结构 | 适用倾向 |
| --- | --- |
| 3 / 6 / 9 | 适合有三档成长、需要完整投入的核心羁绊 |
| 2 / 5 / 9 | 适合较早产生效果、但完整构筑成本较高的羁绊 |
| 3 / 6 | 适合效果集中、无需三档成长的羁绊 |
| 2 / 4 / 6 | 适合小队容易混搭、阶段性收益明显的羁绊 |
| 2 / 5 | 适合只提供少量关键规则的辅助羁绊 |

羁绊计数只统计当前队伍装备提供的羁绊。装备更换、拆卸或重铸后，应重新计算激活状态。

### 2.4 重铸

重铸只调整随机羁绊，不改变装备的其他结构：

- 普通装备重铸时，只改变随机羁绊词条。
- 羁绊饰品重铸时，只改变随机副羁绊。
- 羁绊饰品的固定羁绊永远不会被重铸改变。
- 羁绊饰品的随机副羁绊始终不能与固定羁绊重复。
- 后续可以加入锁定重铸与定向重铸，但不能突破不重复规则。

## 三、塔罗牌定制框架

塔罗牌用于决定羁绊的**主题原型、机制方向、叙事意象和视觉符号**。塔罗牌不是额外的战斗资源，也不直接决定数值大小。

### 3.1 设计映射

每个羁绊以一张塔罗牌作为核心原型，按照以下字段进行定制：

| 塔罗牌信息 | 羁绊设计用途 |
| --- | --- |
| 牌名与正位含义 | 羁绊的正面主题、核心战斗价值与名称来源 |
| 逆位含义 | 羁绊的风险、代价、失控表现或低阶效果的限制 |
| 牌面人物或象征物 | 羁绊饰品名称、装备词条文案和视觉符号 |
| 元素、数字或传统对应 | 羁绊在资源、行动、生命、异常等机制中的倾向参考 |
| 牌面叙事 | 羁绊达到更高门槛时的阶段性成长逻辑 |

设计时不要求机械复制塔罗牌的完整占卜解释。应优先保留牌面的核心矛盾，再将其翻译成玩家能理解、能主动构筑的队伍效果。

### 3.2 正位与逆位的机制翻译

塔罗牌正位与逆位不直接作为两种可装备的羁绊计数，而是用于设计同一羁绊的正面力量与潜在代价：

- 正位主要决定羁绊想要提供的战斗收益。
- 逆位主要决定收益的限制条件、触发风险或未完成构筑时的表现。
- 不应把所有逆位都做成装备负面属性；羁绊系统的主要职责仍然是构筑奖励。
- 如果某张牌的逆位确实适合风险收益机制，可以将其转化为随机性、延迟收益、资源消耗或触发条件。

### 3.3 羁绊效果的边界

塔罗牌主题最终必须落在现有战斗属性或已存在的战斗规则上，优先考虑：

- HP、攻击力、防御力、命中率、闪避率、暴击率、爆伤和先手；
- 治疗、护盾、格挡、异常状态与异常抗性；
- 法力水晶、抽牌、手牌上限和战斗开始资源；
- 对低生命目标、首次攻击、受击反应、持续伤害等已有战斗行为。

新增规则应当少量、明确，并能解释为塔罗原型的自然延伸。不能仅因为牌面神秘，就为每张牌发明一套独立资源或完全不同的战斗子系统。

## 四、单个羁绊的设计模板

后续每个塔罗羁绊都按以下结构记录：

### 【羁绊名称】

- **核心塔罗牌**：大阿尔卡那 / 小阿尔卡那中的具体牌。
- **世界观身份**：对应城市中的协议、系统、遗留组织或功能模块。
- **正位主题**：希望保留的正面原型。
- **逆位矛盾**：转化为限制、风险或触发条件的部分。
- **核心机制**：羁绊主要强化的战斗规则。
- **适合队伍**：与哪些角色关键词、卡组计划或装备倾向相容。
- **激活门槛**：例如 3 / 6 / 9 或 2 / 5。
- **阶段效果**：每个门槛对应的具体效果与数值待平衡。
- **羁绊饰品**：固定羁绊饰品的名称、牌面意象与随机副羁绊规则。
- **文案意象**：装备词条、系统提示和事件文本可复用的短句方向。

## 六、待共同确定

以下内容在塔罗牌定制阶段逐项决定：

- 使用大阿尔卡那、四组小阿尔卡那，还是两者混用；
- 羁绊总数量，以及是否控制在 8 个左右；
- 每个羁绊对应一张唯一塔罗牌，还是允许同一牌产生不同流派；
- 羁绊名称采用易懂的功能名、塔罗牌名，还是“功能名 + 塔罗称号”的混合形式；
- 第一批先确定哪些塔罗牌与羁绊机制；
- 各羁绊的具体门槛、效果数值、饰品名称与装备掉落来源。
