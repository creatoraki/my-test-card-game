# 地图交互物件设计（初版骨架）

> **用途**：探索系统改为暗黑地牢式的 2D 横板房间搜索后，原先挂在路线图节点上的全部探索收益，统一改成**交互物件**形态：走到物件前 → 按交互键 → 弹出窗口 → 在窗口内完成决策 → 结算。本文定义初版的物件类型骨架。
>
> **本版范围**：只定义**类型骨架** —— 物件分几类、每类承担哪条收益线、弹窗长什么样、代价结构如何、按房间深度怎么缩放。**不写死具体物品与数值**（不写「糖块 ×2」「30 积分」），具体投放表与数值表另开文档。
>
> **上游依据**：资源与效果底表见 [事件奖惩清单.md](事件奖惩清单.md)；房间探索规则见 [`docs/corridor-exploration.md`](../../docs/corridor-exploration.md)；现有实现见 `src/data/corridorCurios.ts`。
>
> **已废弃**：路线图 / 桥接 / 战斗签相关的节点事件设计（`新事件系统/` 目录与 `探索模式设计.md`）不再作为本文依据。

## 一、设计前提

### 1.1 横板房间探索带来的三条新约束

| 新特性 | 对物件设计的约束 |
| --- | --- |
| **可以回头，但回头要付钱** | 每换一间房 −5 粒子，所以「先跳过、待会儿再来拿」是一个真实存在的决策。物件必须支持被跳过，且**跳过不惩罚**；同时小地图要能看出某间房还剩几件没处理。 |
| **一屋 1–3 件** | 同一房间里的物件**必须分属不同收益线**，否则会出现「三个箱子」的空洞体验。同屋物件的档位也要有高低差，让玩家在屋内就有取舍。 |
| **走近才看得清** | 190 设计像素以内才能开启，远处只显示外形与名称。于是「外形 → 品类」「名称 → 大致方向」「弹窗 → 具体内容」构成三层信息梯度，物件外形必须一眼可辨品类。 |

### 1.2 沿用不改的硬口径

- **粒子**：交互任意物件固定 −2（选项自带的增减另计），移动一间房 −5，战斗每回合 −1。
- **一次性**：物件处理完即变暗，不可重复领取；未处理的物件不会消失。
- **先展示后领取**：实物进拾取框（可整体放弃）、需要指定角色的进待办队列、遗物进强制取舍框；**全部处理完才能离开本房或使用传送门**。
- **惩罚必须有出路**，且出路要在同一张地图里能遇到（污染 → 净化罐 / 货商；负重 → 投递柜；掉血与体力极限 → 医疗柜）。

### 1.3 本版三条物件铁律

1. **每件物件至少制造一次判断**。纯发奖、点一下就结束的物件只允许出现在最低档（浅房、起始房）。
2. **代价明示，收益模糊**。弹窗必须写清要付出的粒子 / HP / 背包格 / 永久代价 / 风险等级；收益只写方向与档位（「可能翻出高阶材料」），不列具体件数。
3. **同屋不同线**。同一房间内不出现两件同收益线的物件。

## 二、三种交互形态

本版新增的分类轴。物件的**类型**决定给什么，**形态**决定怎么给。

| 形态 | 玩家操作 | 适用 | 目标占比 |
| --- | --- | --- | ---: |
| **A · 直接拾取** | 弹窗只有一段文案和一个「取走」按钮，点完即结算 | 浅房低档实物、纯补给 | ~25% |
| **B · 分支选择** | 2–3 个选项，每个选项 2–3 个加权结果（权重和 100） | 主力形态 | ~50% |
| **C · 推进式** | 弹窗内可反复操作，每操作一次收益累积、翻车概率上升，随时可以「见好就收」 | 风险线与深房拾荒 | ~25% |

### 2.1 推进式的通用结构

推进式是本次探索改版最值得做的新形态 —— 它把「见好就收」从路线层面搬进了单个弹窗里。统一骨架：

```text
弹窗内常驻三个信息：
  ① 已进行轮次 / 上限轮次
  ② 暂存收益（本次交互累积、尚未落袋的东西，逐条列出）
  ③ 下一轮的翻车概率（明示百分比，逐轮递增）

两个按钮：
  【再来一次】→ 掷点：成功则暂存收益增加一条并进入下一轮；翻车则触发翻车后果
  【见好就收】→ 暂存收益转入拾取框 / 待办队列，交互结束
```

约定：

- **翻车后果有两种口径**，同一物件只能选一种，并在弹窗顶部写明是哪种：
  - **吞收益**：暂存收益全部作废，交互结束，不附加其他惩罚（适合拾荒线）。
  - **付代价**：暂存收益保留，但附加一条即时惩罚（掉血 / 丢背包格 / 污染），交互结束（适合风险线）。
- 首轮翻车率必须为 **0** —— 第一次操作一定有收获，否则玩家会拒绝参与。
- 轮次上限 3–5 轮，上限越高首轮收益越低。
- 推进式**不额外扣粒子**，全程只算一次交互的 −2。

## 三、物件清单（9 类）

每类统一按：**定位 / 素材 / 投放 / 形态 / 弹窗结构 / 收益方向 / 代价 / 档位缩放 / 与谁区隔** 描述。

### 3.1 物资箱 —— 拾荒线

| 项 | 内容 |
| --- | --- |
| **定位** | 实物的主投放口，也是背包压力的主要来源。玩家看到它想的是「我还有几格」。 |
| **素材** | 当前用默认宝箱占位；期望三种外形区分档位（小箱 / 中箱 / 塌方料堆）。 |
| **投放** | 全图最高频，任意深度；起始房的那一件多为此类的最低档。 |
| **形态** | 浅房 A（直接拾取）；中深房 B；深房出 C（箱中箱：一层层往里开）。 |
| **弹窗结构** | A 档：一段文案 + 取走。C 档：推进式，翻车口径取**吞收益**（箱体锁死，已翻出的东西留在里面）。 |
| **收益方向** | 通用材料、水晶、地区特色材料、换金物、临期食品；深档可出随机装备与模组。全部占背包格。 |
| **代价** | 背包格；C 档额外承担「贪多归零」的方差。不掉血、不留永久损伤。 |
| **档位缩放** | 轻：少量低阶实物，直接拾取。中：两个方向二选一（要占格少的换金物，还是占 2 格的装备）。重：推进式 4–5 轮，深处出高阶材料。 |
| **与谁区隔** | 只发**占格的实物**。不发积分（归投递柜 / 货商）、不发经验与卡组（归数据终端）。 |

### 3.2 医疗柜 —— 生存线

| 项 | 内容 |
| --- | --- |
| **定位** | 队伍状态的唯一修复口。核心体验是「额度有限，只能救一个方向」。 |
| **素材** | 期望独立素材（带十字灯的壁挂柜）。 |
| **投放** | 每张图保底 ≥2 件；队伍最低血量比偏低时提高权重。 |
| **形态** | B（分支选择）为主；浅房可出 A 档的「取走一件消耗品」。 |
| **弹窗结构** | 2–3 个选项，分别对应三个修复方向：**当前 HP / 体力极限 / 污染与怪癖**。选一个，其余不可再选。 |
| **收益方向** | 全队或指定角色的治疗、集中治疗（重伤者回满）、体力极限修复、降污染、治怪癖、净化污染卡；也可改为「取走对应消耗品自己择时用」。 |
| **代价** | 放弃其他两个方向（时间代价）；「取走消耗品」相比「当场使用」多占背包格，作为便利性定价。 |
| **档位缩放** | 轻：只提供当前 HP 方向。中：HP 与污染二选一。重：三方向全开，且体力极限一档给到显著量级。 |
| **与谁区隔** | 只修**角色身上的东西**。不发实物资源、不碰构筑。 |

### 3.3 数据终端 —— 构筑线

| 项 | 内容 |
| --- | --- |
| **定位** | 永久收益的主投放口：卡组、装备、模组、遗物。玩家看到它想的是「这趟要不要改队伍」。 |
| **素材** | 期望独立素材（裂屏终端）。 |
| **投放** | 每张图保底 ≥1 件构筑改造机会；多出现在中深房。 |
| **形态** | B（分支选择）。 |
| **弹窗结构** | 2–3 个选项，每个选项对应一个构筑方向，且**大多要求交出点什么**（拿一样换一样）。 |
| **收益方向** | 经验（全队 / 单人）、免费抽卡 / 删卡、净化污染卡、随机模组、随机装备与装备候选、羁绊重铸、祝福遗物（随机 / 指名 / 三选一）。 |
| **代价** | 以「交换」为主：删一张卡换一张新卡、拆一件装备换材料、交出一件遗物换更高档的。重档选项带**不可逆**标记并二次确认。 |
| **档位缩放** | 轻：经验。中：抽卡 / 删卡 / 随机模组。重：装备强化、羁绊重铸、遗物。 |
| **与谁区隔** | 唯一能改写**回城后仍然存在的队伍构筑**的物件。物资箱只发原料，终端负责把原料变成构筑。 |

### 3.4 净化罐 —— 探索线（粒子）

| 项 | 内容 |
| --- | --- |
| **定位** | 全图唯一的粒子回补口，也是污染的次要出口。它直接决定玩家还能走多远。 |
| **素材** | 期望独立素材（内部有蓝光的罐体）。 |
| **投放** | 每张图 1–3 件；粒子档位跌到告急 / 枯竭时提高权重。 |
| **形态** | B；深房可出 C（超频抽取：多抽一轮多回粒子，翻车口径取**付代价**，附加污染或掉血）。 |
| **弹窗结构** | 两个选项：**回收粒子**（换探索续航）或**净化队员**（换角色状态）。二者互斥。 |
| **收益方向** | 粒子回补；降污染；「接下来 N 次交互或移动免粒子消耗」。 |
| **代价** | **回补必须带代价**，不允许出现无代价的稳定回粒子循环。可选代价：少量掉血、一格背包、放弃净化方向、或推进式的翻车风险。 |
| **档位缩放** | 轻：小额回补。中：回补与净化二选一。重：大额回补 + 免消耗，但附带一条明示的代价。 |
| **与谁区隔** | 只碰**粒子与污染**。治疗归医疗柜。 |

### 3.5 废料堆 —— 风险线

| 项 | 内容 |
| --- | --- |
| **定位** | 明码赌注。全图唯一的主动惩罚投放口，也是唯一能出「越级收益」的常规物件。 |
| **素材** | 当前用默认宝箱占位；期望独立素材（断线与金属板堆，带尖锐断口）。 |
| **投放** | 中深房为主；浅房至多 1 件；队伍残血时降低权重。 |
| **形态** | C（推进式）为主，翻车口径取**付代价**；也可出 B 档的「一次性赌注」。 |
| **弹窗结构** | 顶部固定写明**风险等级（低 / 中 / 高）**与翻车后果类型；必须提供一个**无代价离开**的按钮（风险物件的强制要求）。 |
| **收益方向** | 越级实物、随机装备与模组、高阶材料、祝福遗物；深档可给「用一个诅咒换一件重档收益」的结构。 |
| **代价** | 全队掉血（单次不超过最大 HP 的 30%，且文案必须写明会压低体力极限）、强制丢弃背包格、强制拾取负担物、污染卡、诅咒遗物。 |
| **出路对照** | 掉血与体力极限 → 医疗柜；污染 → 净化罐 / 货商；负重 → 投递柜；诅咒遗物 → 回城圣水池（最重一档，允许跨趟解决）。 |
| **档位缩放** | 轻：掉血换实物。中：推进式 3 轮。重：推进式 5 轮，末轮的收益给到稀世档，翻车附加永久代价。 |
| **与谁区隔** | 唯一可以**主动伤害玩家**的常规物件。其他八类不得附带惩罚。 |

### 3.6 投递柜 —— 保险线

| 项 | 内容 |
| --- | --- |
| **定位** | 唯一的止损手段：寄回据点的东西，团灭也保得住。对背包已满的玩家价值最高。 |
| **素材** | 期望独立素材（带灯槽的柜体）。 |
| **投放** | 每张图保底 ≥1 件；背包占格高时提高权重。 |
| **形态** | B（功能型）：选项即服务。 |
| **弹窗结构** | 两个选项：**开启投递口**（打开背包进入寄件流程）或**就地变现**（把选中的物品按汇率折成不占格的居民积分）。 |
| **收益方向** | 寄件保险；物品变现为积分；清出背包格从而降低负重惩罚。 |
| **代价** | 寄件每次消耗粒子；变现的汇率低于回城出售，用「立刻拿到且不怕团灭」定价。 |
| **档位缩放** | 轻：只开投递口。中：投递口 + 变现。重：投递口 + 变现 + 一次免粒子寄件。 |
| **与谁区隔** | 不产出任何新东西，只处理**玩家已有的东西**。 |

### 3.7 货商 —— 经济线

| 项 | 内容 |
| --- | --- |
| **定位** | 用临期食品付费的服务窗口。让食品这种「延迟兑现的奖励」有确定的兑现口。 |
| **素材** | **已有**（`废弃楼层/货商.png`）。 |
| **投放** | 每张图 1–2 件，中深房；背包占格高时提高权重。 |
| **形态** | B + 连续交易：弹窗不会因为买了一次就关闭，货架售罄或玩家主动离开才结束。 |
| **弹窗结构** | 本次登记的 2–3 个服务槽，每槽写明**收哪种食品、收几份**；买完的槽位置灰。 |
| **收益方向** | 材料 / 水晶 / 消耗品 / 食品 / 装备的二选一货架；医疗、抽卡、删卡、净化卡、治怪癖等服务；寄件服务。 |
| **代价** | 临期食品（非积分）。没有食品就什么也买不了 —— 这是它与投递柜的根本区别。 |
| **档位缩放** | 轻：两个低档货架。中：三槽，含一个服务槽。重：三槽，含一个重档服务（装备强化 / 遗物）。 |
| **与谁区隔** | 唯一收**食品**的物件，也是唯一可以在一次交互里做多笔结算的物件。 |

### 3.8 传送门 —— 结构物件（蓝 / 红两态）

| 项 | 内容 |
| --- | --- |
| **定位** | 房间之间的通行口，也是探索节奏的控制器。 |
| **素材** | **已有**（蓝色传送门 / 红色传送门）。 |
| **投放** | 每间房 1–4 座，边缘优先；全图**固定 1 座红门**。 |
| **蓝门** | 走上去 → 小地图点亮它通往的房间（侦察免费）→ 再按一次交互键才真的传送，扣 5 粒子。四座蓝门外观一致，方向只能从小地图读出。 |
| **红门** | 全图唯一，通往宝藏房。交互即进入**守门 BOSS 战**；胜利后红门变蓝门并永久开放，失败按现有战败流程处理。 |
| **弹窗结构** | 蓝门无弹窗，走上去出场景提示。红门有弹窗：写明「门后是守门者」「战斗不可中途撤离」，两个按钮【发起挑战】【暂不进入】。 |
| **收益方向** | 红门胜利给 BOSS 档战斗产出，并开放宝藏房。蓝门不产出。 |
| **代价** | 蓝门 5 粒子；红门一场高档战斗。 |
| **与谁区隔** | 唯一改变**玩家所在位置**的物件。 |

### 3.9 撤离装置 —— 结构物件（宝藏房内）

| 项 | 内容 |
| --- | --- |
| **定位** | 一趟远征的收尾开关。把「什么时候见好就收」这个决策交还给玩家。 |
| **素材** | 期望独立素材（升降平台 / 信标）。 |
| **投放** | **只在宝藏房内**，固定 1 件，不计入宝藏房的 3 件重档物件。 |
| **形态** | B + 二次确认。 |
| **弹窗结构** | 结算预览（背包里带回什么、积分多少、已寄件多少、哪些角色带着永久损伤）→ 两个按钮【启动撤离】【再等等】。启动需二次确认。 |
| **收益方向** | 结束远征并把背包与积分带回据点。 |
| **代价** | 放弃地图上尚未搜过的房间。 |
| **注意** | 撤离装置**不是一次性**的：玩家可以进宝藏房、看完预览又走掉回去继续搜，之后再回来（回头仍要付移动粒子）。 |

## 四、红门 · 守门 BOSS · 宝藏房

取消原「BOSS 房」，改为**红门守门 + 宝藏房**结构。

```text
探索房间图（若干房间，其中一间有红门）
        │
        ├─ 找到红门所在的房间
        │        │
        │        ├─【暂不进入】→ 继续搜其他房间，红门保持红色
        │        │
        │        └─【发起挑战】→ 守门 BOSS 战
        │                   ├─ 胜利 → 红门变蓝 → 可进入宝藏房
        │                   └─ 失败 → 按现有战败 / 团灭流程结算
        │
        └─ 宝藏房（3 件重档物件 + 1 台撤离装置，无黑影）
                   └─ 搜完 → 启动撤离 → 远征结算回城
```

**规则要点**

1. 全图**固定 1 座红门**，位置取离起点最深的那间死胡同（沿用原 BOSS 房的选址逻辑）。
2. 红门在小地图上有专属角标，被点亮后玩家就知道终点在哪 —— 于是「先把周围搜干净再去打」还是「直奔终点」成为一个真实决策。
3. 守门 BOSS 战不可中途撤离，弹窗必须写明这一点。
4. 胜利后红门**永久变蓝**，可以随时往返宝藏房与探索区。
5. 宝藏房**无黑影**，3 件重档物件**全部是纯收益、不带任何惩罚** —— 它是打赢 BOSS 的回报，不是第二次考验。
6. 宝藏房 3 件物件建议取**三个不同方向**：一件构筑向（数据终端重档）、一件实物向（物资箱重档）、一件修复向（医疗柜重档），避免三件同质。
7. 通关判定落在**撤离装置**上，不在 BOSS 胜利那一刻 —— 玩家可以打完 BOSS 后回头把地图搜干净再撤。

## 五、投放与配比规则

### 5.1 房间内配额

| 约束 | 规则 |
| --- | --- |
| 每间房物件数 | 1–3 件（沿用现有生成规则） |
| 起始房 | 固定 1 件，且取最低档、无风险的那一档（物资箱轻档或医疗柜轻档） |
| 同屋同线 | **禁止**：一间房内不出现两件同收益线的物件 |
| 同屋档位 | 三件物件时，至少有一件与其余两件不同档，让屋内也有取舍 |
| 风险物件 | 每间房至多 1 件；起始房与相邻房不投放 |
| 宝藏房 | 固定 3 件重档物件（三个不同方向）+ 1 台撤离装置，无风险物件 |

### 5.2 按房间深度分档

档位由**该房间到起点的最短距离**决定，与现有战斗档位取同一个深度值。

| 深度 | 档位倾向 | 口径 |
| --- | --- | --- |
| 浅（起点及相邻） | 轻档为主 | 稳定、低方差、无永久代价，直接拾取形态占比最高 |
| 中 | 轻 / 中 | 开始出现真实取舍与推进式形态 |
| 深 | 中 / 重 | 永久收益与永久代价登场，推进式轮次上限提高 |
| 宝藏房 | 重 / 稀世 | 纯收益，无代价 |

**同一原型按档位缩放，不为每档单独造物件** —— 一件「物资箱」在浅房是一个小箱子、在深房是一整座塌方的料山：结构一致、档位不同、文案换一句。这条直接决定了内容复用率。

### 5.3 整趟保底

一张图必须保证玩家**有机会遇到**（= 该物件生成在图上，且从起点可达）：

- 寄件机会 ≥1（投递柜）
- 构筑改造机会 ≥1（数据终端）
- 纯补给 ≥2（医疗柜，不附带任何风险的那一档）
- 遗物接触 ≥1（数据终端重档 / 废料堆重档 / 宝藏房）
- 粒子回补口 ≥1（净化罐）
- 食品兑现口 ≥1（货商）

保底采用「缺项补投」：生成完整张图后校验，缺哪项就把某间房里最低档的物件替换成对应类型。

### 5.4 自适应权重

生成时按队伍当前状态调整权重，避免「残血时连开三个箱子」这种最败兴的体验。

| 状态信号 | 权重调整 |
| --- | --- |
| 最低血量比 < 40% | 医疗柜 ×2.0，废料堆 ×0.5 |
| 任一角色污染偏高 | 净化罐、含净化方向的物件 ×2.5 |
| 背包接近满 | 投递柜、货商 ×2.0，物资箱 ×0.4 |
| 背包很空 | 物资箱 ×1.8 |
| 粒子档位告急 / 枯竭 | 净化罐 ×1.5 |
| 尚未接触过遗物且已过半程 | 遗物相关方向 ×3.0 |

**上限**：调整后任何单一类型在全图的占比不得超过 40%。

## 六、弹窗与文案规范

### 6.1 弹窗骨架

```text
弹窗
├─ 标题（物件名称）
├─ 到达文案（2-3 句，必须点出一个可被操作的部位：阀门、柜门、接口、投币口）
├─ 风险等级条（仅风险物件：低 / 中 / 高 + 翻车后果类型）
├─ 选项 ×1-3
│   ├─ 选项文案（1 句，动作描述）
│   ├─ 代价标签（明示：粒子 / HP / 背包格 / 不可逆 / 风险等级）
│   └─ 收益提示（模糊：「可能获得……」）
├─ 结果区（选择后展开：结果文案 1-2 句 + 效果摘要）
└─ 确认区（领取奖励 / 二次确认 / 关闭）
```

### 6.2 硬性要求

| # | 要求 |
| --- | --- |
| 1 | 每个物件 1–3 个选项；只有 1 个选项的（投递柜、撤离装置）必须是功能型物件 |
| 2 | 分支选项的加权结果权重和为 100，直接写百分数 |
| 3 | **代价必须明示**，**收益必须模糊** |
| 4 | 每个选项、每个结果都要有独立文案，一句也不复用 |
| 5 | 带永久代价的选项必须二次确认；可能直接打死角色的选项，确认框里要列出处于致死范围的角色 |
| 6 | 风险物件必须提供**无代价离开**的按钮；其他类型不提供空手离开（那 2 点粒子已经付过了） |
| 7 | 奖励一律先展示后领取，处理完才能关闭弹窗 |
| 8 | 全部中文，不出现英文文本；最小字号 18px |
| 9 | 悬浮提示一律用组件实现，不使用原生 title 属性 |
| 10 | 推进式弹窗的翻车概率必须实时显示，且与实际掷点值一致 |

### 6.3 文案基调

世界观是 3300 年代无人类的霓虹都市，城市由电子生命与自治机械维持运转：

- 机械仍在尽职地执行早已没有意义的流程（售货机还在找零、医疗柜还在念用药须知）。
- 玩家是闯入者而非主人；系统把你误认成「员工」「患者」「访客」是常见的戏剧来源。
- 不写人类角色的内心戏，写机械的固执与荒诞。
- 到达文案必须给出一个**可被操作的物件部位**，让选项显得自然。

## 七、素材需求清单

尺寸口径参照 [`src/assets/explore-corridor/README.md`](../../src/assets/explore-corridor/README.md)：交互物为单张透明 PNG，底部留出透明留白（比例登记在 `CORRIDOR_PROP_GROUND_TRIM`），贴地高度由各物件单独配置。

| 物件 | 当前素材 | 需求 | 外形要点（必须一眼读出品类） |
| --- | --- | --- | --- |
| 物资箱 | 默认宝箱素材 ✅ | 建议再出 2 张分档变体 | 小箱 / 中箱 / 塌方料山，箱扣与封条可见 |
| 医疗柜 | 无（占位） | **需要** | 壁挂柜体、青色十字灯、柜门半开 |
| 数据终端 | 无（占位） | **需要** | 裂成蛛网的屏幕、仍在发光、线缆垂落 |
| 净化罐 | 无（占位） | **需要** | 透明罐体、内部悬浮蓝光、底部阀门 |
| 废料堆 | 默认宝箱素材（占位） | **需要** | 断线与金属板堆叠、露出尖锐断口、色调偏冷灰 |
| 投递柜 | 无（占位） | **需要** | 立式柜、投递口、绿色联机指示灯 |
| 货商 | 货商.png ✅ | 够用 | — |
| 蓝色传送门 | 蓝色传送门.png ✅ | 够用 | 四方向外观一致（刻意设计） |
| 红色传送门 | 红色传送门.png ✅ | 够用 | 与蓝门同构，仅配色与特效不同 |
| 撤离装置 | 无（占位） | **需要** | 升降平台 / 信标塔，指向上方，与传送门明显不同 |

优先级：**废料堆 > 医疗柜 > 数据终端 > 净化罐 > 投递柜 > 撤离装置 > 物资箱分档变体**。废料堆排第一是因为它与物资箱共用宝箱素材，而两者的收益与风险完全相反，混淆的代价最大。
