# 地图交互物件设计

> **范围**：只定义**地图上的交互物件**（玩家在节点场景里点到的死物），不定义节点事件本身。
>
> **上位约束**：可用的奖惩原材料见 [事件奖惩清单.md](事件奖惩清单.md)；食品交易边界见 [临期食品.md](../物品设计/消耗品及货币/临期食品.md)。本文只挑选，不发明新资源。

## 一、上一稿的问题

上一稿为了消灭「换皮」，把每个物件做成了**两个等权的异类分支**（A 给经验、B 给情报……）。结果是：

1. **A 和 B 几乎等价**。两边无强弱，玩家只是按口味二选一，没有任何东西值得「提前准备」。
2. **没有应对玩法**。玩家背包里带了什么、队伍是什么状态、队里有谁，对物件结果毫无影响——物件与玩家的局面脱钩。
3. **临期食品被边缘化**。食品只在「生物专属」一个小池子里出现，其余物件完全用不上它，出发前买食品这件事失去了意义。

## 二、新结构：兜底决策 + 应对决策

每个物件提供 **2-4 个决策，只能选其中一个执行**，执行后物件耗尽。

```
决策一 · 兜底    任何队伍都能选    概率支付明示代价（HP / 污染 / 粒子 / 背包格）  → 基础小奖励 A
决策二 · 应对    需满足条件甲      条件本身就是代价                        → 超额奖励 B
决策三 · 应对    需满足条件乙      条件本身就是代价                        → 超额奖励 C
（决策四 · 应对，少数物件才有）
```

### 2.1 四条结构规则

1. **兜底永远可选**。决策一不设任何条件，保证没准备的玩家也有事可做。选择后必定获得基础小奖励，再按该物件配置的概率判定是否支付一项**明示的身体或资源代价**（铁律一）：概率未触发时就是免费拿到小奖励，触发时支付代价但不撤回奖励。
2. **超额必须真的超**。应对决策的收益要让玩家一眼看出「比兜底好」，否则没人会去准备。合格的「超」有三种写法：
   - **加量并跃迁**：A 的全额 + 追加一个更高价值的类别（材料 → 材料 + 装备）；
   - **直接跃迁**：跳到更高价值的类别（换金物 → 模组）；
   - **免风险并追加**：去掉兜底的概率代价，再追加一类收益。
3. **应对决策之间必须异质**。同一个物件里的两个应对决策，**条件类型不同，超额方向也不同**。禁止出现「交面包拿装备 / 交可乐也拿装备」这种只换支付物的写法——那只是把上一稿的等价问题挪到了应对层。
4. **选项展示遵循黑盒原则**。无门槛选项必然展示；有条件选项只有在条件满足时才展示，条件不满足时完全隐藏。凡是允许玩家主动提供物品进行尝试的选项，界面文案固定为**「尝试放入什么物体看看会不会发生什么」**，不提前展示所需物品、预期收益、成功条件或失败后果。玩家必须在不知道决策结果的情况下决定是否尝试。本文表格里的条件与收益仅供设计和实现使用，不等于玩家实际看到的界面文案。

### 2.2 其他继承约束

- **每个惩罚要有本趟内的出路**：污染 → 净水槽 / 圣水；诅咒遗物 → 医疗柜 / 神龛；负重 → 压缩舱；HP → 医疗柜 / 营火。
- **粒子不作为应对条件**：粒子只能买操作成本，不能买品质。粒子可以出现在兜底决策的概率代价里，但不能成为「拿超额」的钥匙。
- **档位随推进段缩放**：同一物件在第 1 段与第 4 段结构不变、档位不同（沿用《01-框架》3.5）。

## 三、应对条件词典

应对条件分两大类。设计物件时从词典里挑，**同一物件的应对决策尽量跨大类**。

以下表格中的“设计记录示例”仅用于记录条件语义，不代表玩家实际看到的界面文案；界面按 2.1 节的黑盒展示规则处理。

### 3.1 消耗型：交出去就没了

| 编号 | 条件 | 设计记录示例 | 适合换什么 |
| --- | --- | --- | --- |
| **食** | 指定临期食品 × N | 「需要：汉堡 ×2」 | 见第四章，受食品交易边界约束 |
| **药** | 指定消耗品（糖块 / 医疗包 / 圣水） | 「需要：圣水 ×1」 | 生存线、祛污、实物 |
| **材** | 指定材料（通用 / 水晶 / 地区材料） | 「需要：霓虹灯管 ×1」 | 构筑服务、情报 |
| **币** | 换金物（铜 / 银 / 金币） | 「需要：银币 ×1」 | 买通、战斗挂钩 |
| **械** | 献祭装备（背包或穿戴中，**销毁**） | 「献上一件武器」 | 模组、熔铸、路线 |
| **祝** | 献祭祝福遗物 | 「献上一件祝福遗物」 | 更高档遗物 |
| **咒** | 献祭诅咒遗物（负资产当钥匙） | 「献上一件诅咒遗物」 | 治疗实物——同时是诅咒遗物的出路 |
| **卡** | 永久删一张卡 / 献上污染卡 | 「献上两张污染卡」 | 训练点、经验、装备 |
| **身** | 体力极限（永久） | 「指定一人永久 −15 体力极限」 | 最高档：遗物候选 |
| **负** | 交出《沉重的负担》 | 「背包里有沉重的负担」 | 负担物的出路 + 实物 |

### 3.2 门槛型：只检查，不扣除

门槛型条件不消耗东西，所以**必须再附带一项轻代价**（通常落在被检查的那名角色身上），避免变成白拿。

| 编号 | 条件 | 设计记录示例 | 设计意图 |
| --- | --- | --- | --- |
| **满** | 全员满血 | 「需要：全员生命已满」 | 奖励稳健推进的队伍 |
| **危** | 有人生命 ≤ 30% | 「需要：有队员濒危」 | 给残血局面一条逆转路 |
| **职** | 队伍中有指定职业 | 「需要：队伍中有精算师」 | 让编队影响探索；每职业至少出现 2 次 |
| **染** | 有人污染值 ≥ 60 | 「需要：有队员污染值 ≥ 60」 | 负资产反而是钥匙 |
| **格** | 背包空格 ≥ N | 「需要：背包空出 4 格」 | 奖励轻装；与「贪多」对冲 |
| **编** | 队伍满编（无阵亡） | 「需要：全员在队」 | 奖励零阵亡 |

## 四、临期食品的角色

食品是应对条件里**出现最频繁的一类**（约占全部应对决策的 1/3），它把「出发前在据点买什么」直接变成「这趟能吃到哪些超额奖励」。

### 4.1 每种食品一个方向

| 食品 | 场景里的接受者 | 换来的超额方向 |
| --- | --- | --- |
| 牛奶 | 医疗机器人 | 群体治疗、降污染、净化污染卡 |
| 面包 | 🪲 开锁甲虫、维修机器人 | 精细开箱：装备、模组 |
| 可乐 | 🧹 清运幼兽、自动售货机 | 整舱清运：换金物、食品、消耗品 |
| 汉堡 | 🐹 机械鼹鼠、笼中机械兽 | 深层挖掘：水晶、地区材料、成批实物 |
| 炸鸡 | 幸存者、流浪回收商 | 压箱底的交换：水晶、有限情报 |
| 披萨 | 高级终端、特殊商人 | 最高档的食品交易：装备 + 模组、谜面位置 |

### 4.2 机械生物

沿用《临期食品》的口径：**机械生物是物件的场景配件，不跟随队伍、不成为背包物**。它们固定趴在某类物件旁边，投喂指定食品后完成一次工作。

| 生物 | 工作 | 偏好食品 | 出现在 |
| --- | --- | --- | --- |
| 🪲 开锁甲虫 | 开箱、钻锁 | 面包 | 合金保险箱 |
| 🐹 机械鼹鼠 | 挖掘、破拆 | 汉堡 | 结晶矿脉、封存储藏室 |
| 🧹 清运幼兽 | 搬运、清运 | 可乐 | 垃圾压缩舱 |

### 4.3 食品不能买的东西

受《临期食品》4.2 约束，**以「食」为条件的决策，超额收益不得包含**：

- 遗物、训练点、体力极限修复（长期成长）；
- 战斗签、敌方削弱、挑战词条等战斗规则改写；
- 桥接重照、改道、跳段、免粒子等路线便利；
- 候选扩充、重掷等选择权。

这些高价值收益全部留给**非食品条件**（献祭、职业、队伍状态）。于是食品和其他条件天然分工：**食品买「量」和「实物」，献祭与门槛买「规则」和「长期」**。

## 七、待确认项

1. **选项显示方式（已确定）**
   - 无门槛选项必然展示。
   - 有条件选项只有在条件满足时才展示，条件不满足时完全隐藏。
   - 可以提供物品进行尝试的选项固定展示为「尝试放入什么物体看看会不会发生什么」，玩家必须在黑盒信息下决定是否尝试。
2. **机械生物的出现方式**
   - ① 作为物件的固定配件，看到物件就知道能喂谁（本文采用，推荐）
   - ② 在场景里随机游荡，可以匹配同场景任意对应物件
   - ③ 出发前挑选携带（与《临期食品》「不跟随远征队」冲突，需同步改那份文档）
3. **上一稿的「充电小猪」**：《临期食品》里只登记了开锁甲虫、机械鼹鼠、清运幼兽三种，本稿按此口径删掉了小猪。是否需要补回并在《临期食品》里登记？
4. **一个物件能执行几次**
   - ① 只能选一个决策，执行后耗尽（本文采用，推荐）
   - ② 选了兜底后，仍可补交条件升级到应对决策，但只拿差额
5. **门槛型条件的轻代价**：是否保留「门槛型必须附带轻代价」这条规则，还是允许「条件本身就是代价」（例如全员满血本身就说明玩家花了资源保血）？
6. **能力缺口**：本稿用到的 ⚙ 能力按引用次数排序为：临时训练点（3）> 谜面揭示（3）> 重照桥接（2）> 跳段（3）> 本轮末敌方情报（2）> 敌方削弱 / 战斗签多停 / 预置挑战词条 / 开局护盾 / 改道 / 遗物交换 / 装备熔铸（各 1）。落地时可先做不含 ⚙ 的物件（A1-A3、A5、A6、B1-B3、E1-E3）。
