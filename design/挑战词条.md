# 挑战词条

每场战斗从下表随机抽 2 条（`CHALLENGE_PICK`）。未被打破的词条，其奖励系数直接加进掉落系数 K
（`src/explore/rules.ts` §5.1，全加法合成）。实现见 `src/engine/challenges/`。

定价档位：`0.3` 基础 / `0.4-0.5` 中等 / `0.6-0.8` 高难。

> ⚠ 刻意不做互斥与前置过滤：冲突组合（轮转×养精蓄锐、聚焦×大屠杀、克制×抢拍，以及上阵不足
> 3 人时的轮转）照抽 —— 抽到就是少拿一份加成，由玩家自行承担。

| ID | 名称 | 图标 | 挑战描述 | 奖励系数 |
|---|---|---|---|---:|
| `mercy` | 慈悲 | `🕊` | 单次攻击不造成 25 点以上的伤害 | 0.3 |
| `no_redraw` | 不改初衷 | `🎴` | 整场战斗不得使用换牌 | 0.3 |
| `slow_start` | 养精蓄锐 | `😴` | 第 1 回合不打出任何牌 | 0.3 |
| `restraint` | 克制 | `⛓` | 每回合都保留至少 1 点法力值结束回合 | 0.4 |
| `focus_fire` | 聚焦 | `🔻` | 同一回合内造成的所有伤害必须集中于同一名敌人 | 0.5 |
| `low_cost` | 轻装上阵 | `🪶` | 整场不得打出费用大于 1 的牌 | 0.5 |
| `untouched` | 及时治疗 | `❤️` | 战斗结束时，所有成员当前生命 = 当前体力极限 | 0.6 |
| `tempo` | 抢拍 | `⏱` | 每回合都在敌人第一次行动前用完法力水晶 | 0.6 |
| `blitz` | 唯快不破 | `⚡` | 整场只打出速攻牌，不得打出普通牌 | 0.7 |

| `rotation` | 轮转 | `🔄` | 每回合都至少打出 3 种归属角色不同的牌 | 0.8 |

## 判定口径

- **只认玩家主动出牌**：弃牌联动触发的自动出牌不计为一次「打出」，与 `state.playedThisRound` 同一口径。
- **轻装上阵**的费用阈值复用 `RULES.combat.lowCostApMax`（= 1，与「低费」关键词同源），比较的是本次
  实际结算费用（已含减免），即玩家在手牌上看到的数字。
- **聚焦**只认实际掉血（`hpLost > 0`）：护盾全额吸收、未命中、持续伤害都不登记目标。
- **抢拍**每回合只在敌人第一次行动前判一次；判定时法力池非空即破。
- **克制 / 轮转**在回合结束时判定；中途取胜的那一回合不追判（与大屠杀口径一致）。
- **及时治疗**在胜利瞬间判定；阵亡成员（生命 0 ≠ 体力极限）视为已破。

## 难度定价理由

| 词条 | 理由 |
|---|---|
| 慈悲 | 前中期几乎白送，后期才开始有约束 |
| 不改初衷 | 每回合本就只有 1 次换牌，放弃成本最低 |
| 养精蓄锐 | 只亏一回合节奏，对卡组无要求 |
| 克制 | 等价于每回合只有 2 费，纯节奏损失，不需要特定卡组 |
| 聚焦 | 全场 AOE / 随机目标牌禁用；单敌遭遇战则接近免费 |
| 轻装上阵 | 卡组里高费牌整局变废牌，但 3 费能出 3 张，牌差可观 |
| 及时治疗 | 要求带治疗且不能死人；体力极限被打崩后还得回满 |
| 抢拍 | 普通牌推进时刻，得靠速攻牌抢在敌人行动点前清空 3 费 |
| 唯快不破 | 需要速攻牌占比极高的专门卡组 |
| 大屠杀 | 需攒一波爆发带走全场 |
| 轮转 | 必须满 3 人上阵、每回合 3 张 1 费且三色齐，抽牌运要求极高 |
