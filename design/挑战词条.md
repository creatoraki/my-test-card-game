# 挑战词条

每场战斗从下表随机抽 2 条（`CHALLENGE_PICK`）。未被打破的词条，其奖励系数直接加进掉落系数 K
（`src/explore/rules.ts` §5.1，全加法合成）。实现见 `src/engine/challenges/`（`defs` 定义表 / `core`
运行态 / `checks` 判定钩子），图标见 `src/ui/art/challenge/glyphs/`。

定价档位：`0.3` 基础 / `0.4-0.5` 中等 / `0.6-0.8` 高难。

> ⚠ 刻意不做互斥与前置过滤：冲突组合（轮转×养精蓄锐、聚焦×大屠杀、背水一战×及时治疗，以及上阵
> 不足 3 人时的轮转）照抽 —— 抽到就是少拿一份加成，由玩家自行承担。

## 判定口径

- **只认玩家主动出牌**：弃牌联动触发的自动出牌、羁绊自动出牌都不计为一次「打出」，与
  `state.playedThisRound` 同一口径。所有「打出 / 使用某种牌」类词条都在出牌记录写入后判定。
- **轻装上阵**的费用阈值复用 `RULES.combat.lowCostApMax`（= 1，与「低费」关键词同源），比较的是本次
  实际结算费用（已含减免），即玩家在手牌上看到的数字。
- **循序渐进**同样比较实际结算费用，且必须**严格高于**上一张（同费也算破）；每回合开始重置，回合内
  第一张牌不受限。
- **稳扎稳打**按本次实际计入的类型判定：速攻牌、以及被流光 / 无声咒等效果「视为速攻」打出的牌都算破。
- **返璞归真**：打出稀有度为罕见或稀有的牌即破；未标注稀有度视为普通。
- **背水一战**：打出牌面带治疗效果（治疗 / 理赔治疗 / 恢复体力极限，含培育、词条和命中后追加效果）的牌即破，
  不论本次是否真的治疗到人。吸血、遗物与被动牌的回复不算。
- **知足**：打出牌面带抽牌效果的牌即破，判定方式与背水一战相同（静态看牌面，不论是否真的抽到）。
  回合开始的常规抽牌、换牌补牌、被动牌 / 遗物 / 羁绊的抽牌都不算。
- **敝帚自珍**：手动丢弃、效果丢弃、出牌代价丢弃都算，不论由哪张牌或哪个被动引起；换牌、回合结束清理、
  打出后进弃牌堆、被动卡回收、虚无牌回合结束移除、羁绊（隐者）弃牌都不算。
- **光明磊落**：负面状态成功挂到敌人身上、且来源是我方单位即破 —— 卡牌、弃牌联动、被动牌、遗物一视同仁；
  被异常抗性抵抗、未命中不算；标记类状态不算负面状态（与疫病等「获得减益」监听同一口径）。
- **聚焦**只认实际掉血（`hpLost > 0`）：护盾全额吸收、未命中、持续伤害都不登记目标。
- **独当一面**与聚焦同一套登记口径，只是登记对象换成「造成伤害的我方单位」，且整场不重置：
  第一位让敌人实际掉血的成员即为主角，之后其他成员让敌人实际掉血即破。
- **克制 / 轮转**在回合结束时判定；中途取胜的那一回合不追判（与大屠杀口径一致）。
- **速战速决**：第 2 回合结算后敌人仍有存活即破；第 2 回合内取胜仍算达成。
- **擒贼擒王**：以开场时在场的敌人为比较范围，生命上限并列最高时任一即可；单敌遭遇战自动满足。
  若第一个倒下的是中途召唤 / 增援的单位，同样视为已破。
- **及时治疗**在胜利瞬间判定；阵亡成员（生命 0 ≠ 体力极限）视为已破。
- **当机立断**：使用一次「等待」即破。

## 难度定价理由

| 词条 | 理由 |
|---|---|
| 慈悲 | 前中期几乎白送，后期才开始有约束 |
| 不改初衷 | 放弃换牌，成本最低 |
| 养精蓄锐 | 只亏一回合节奏，对卡组无要求 |
| 当机立断 | 只丢掉每回合 1 次「拖时刻」的调节手段，大多数回合本就用不上 |
| 知足 | 只限制过牌型卡组，非过牌卡组几乎白送 |
| 返璞归真 | 前期白送；中后期卡组里的罕见 / 稀有牌全部变成废牌 |
| 光明磊落 | 咒术系、恶毒 / 穿孔 / 易伤体系整体停摆；非减益卡组几乎白送 |
| 克制 | 等价于每回合只有 2 费，纯节奏损失，不需要特定卡组 |
| 敝帚自珍 | 弃牌流整套联动失效，非弃牌卡组只失去清理废牌的手段 |
| 稳扎稳打 | 每张牌都推进时刻，敌人在你出牌途中行动更频繁，速攻比例越高越痛 |
| 循序渐进 | 出牌顺序被锁死且同费不能连出，3 费最多 0→1→2 三张，需要逐回合规划 |
| 背水一战 | 治疗牌整局变废牌，只能靠护盾、闪避和格挡硬扛；与及时治疗几乎互斥 |
| 速战速决 | 普通战斗靠爆发能达成；精英与首领战两回合内很难打完 |
| 擒贼擒王 | 必须先啃最硬的那个，期间小怪持续输出；单敌战免费 |
| 聚焦 | 全场 AOE / 随机目标牌禁用；单敌遭遇战则接近免费 |
| 轻装上阵 | 卡组里高费牌整局变废牌，但 3 费能出 3 张，牌差可观 |
| 及时治疗 | 要求带治疗且不能死人；体力极限被打崩后还得回满 |
| 独当一面 | 另外两人只能做辅助，输出全压在一人身上；可与轮转同时达成但极难 |
| 大屠杀 | 需攒一波爆发带走全场 |
| 轮转 | 必须满 3 人上阵、每回合 3 张 1 费且三色齐，抽牌运要求极高 |
