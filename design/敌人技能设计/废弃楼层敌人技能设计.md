# 废弃楼层敌人技能与属性记录

> 数据来源：`src/data/enemies.ts`
>
> 本文用于以文字方式调整敌人属性、技能和战斗定位。修改后需要同步更新敌人数据。
>
> 当前记录包含 **4 种小怪、2 种精英和 1 个 BOSS**（废弃楼层首图敌人分层）。

## 数值口径

- `maxHp`：敌人最大生命。
- `attack`：攻击力。倍率伤害 = 攻击力 × 技能倍率，之后仍会经过命中、暴击、防御、格挡和护盾结算。
- `defense`：防御力。
- `initiative`：先手属性。实际攻击时刻还会叠加玩家队伍先手差。
- `delay`：技能基础蓄力时刻，不是最终攻击时刻。
- `weight`：技能抽取权重。四技能敌人的权重为 `2:1:1:1`，即约 40%、20%、20%、20%。
- `actsPerRound`：每回合最多行动次数。小怪与精英缺省为 1，BOSS 为 2。
- `critDamage: 150`：暴击伤害为 150%。
- 所有当前敌人技能的额外命中修正都是 `0`。敌方统一基础命中修正另由战斗规则提供。
- 未登记的属性默认为 0，包括命中、闪避、暴击、精准、格挡、异常抗性等。
- `heavy` 标记的实际效果为：卡牌费用 +1，打出后移除。
- 技能动画只影响表现，不改变技能效果。

## 后续文字修改格式

修改敌人时建议明确写出：

- 敌人名称和数据 ID
- 最大生命、攻击力、防御力、先手、每回合行动次数
- 技能名称、基础蓄力、抽取权重
- 技能目标范围
- 伤害倍率或固定数值
- 状态名称和层数
- 特殊条件，例如“目标有护盾时”
- 是否需要新增或修改动画类型
- 是否需要同步修改遭遇战编队、掉落和战斗事件文案
