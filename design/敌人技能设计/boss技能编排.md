# 垃圾山的守护者 · 回收循环（v6 · 行动状态机）

> 本文档定义 BOSS 的行动模式为**基于技能连携的概率状态机**（以玩家护盾状态为输入、招式链为输出），并把它作为后续数值、技能、delay 调整的**唯一基础**。
> 现有技能数值**全部视为可调参数**，不会因为采用状态机而固定。建议先固定出招逻辑，再独立调整伤害、护盾、delay、权重和阈值。

---

## 一、设计目标（需求映射 1:1）

| # | 需求 | 机器化规则 |
|---|---|---|
| 1 | 碎片倾泻 & 充能重锤 = 常规连续技，让玩家在叠盾间抉择 | 两条压场招式在链中高频交替；一个惩罚无盾、一个惩罚有盾，逼玩家选"较小那头" |
| 2 | 碎片倾泻 & 护盾回收 = 连续技，防无脑叠盾 | 回收收走玩家护盾后，链**倾向**回接碎片倾泻，惩罚被吸空的无盾队 |
| 3 | 碎片倾泻 = 高威胁，不连放，给喘息窗 | 碎片倾泻自环权重 = 0，且"碎片倾泻后强制喘息"，从结构上保证窗口 |
| 4 | 护盾回收后给喘息窗让玩家破盾 | 回收后继以喘息招为主，且"回收后至少经过一个行动段才允许重锤/倾泻" |
| 5 | 压块封锁 & 守卫重击 = 喘息穿插 | 两者作为压场 vs 喘息之间的"缓冲拍"，保留少量压力 |
| 6 | 充能重锤 = 点杀绝招，玩家盾失衡时破盾 | 玩家盾达到"失衡"阈值时，**优先强制**重锤点杀 |
| 7 | 数值可调 | 见文末"可调数值表" |

## 二、状态机总览（两层判定）

### 层 1：玩家护盾意图 → BOSS 当前意图（每回合判定一次）

| 状态 | 玩家护盾触发 | BOSS 意图 | 主用招式 |
|---|---|---|---|
| **A. 叠盾失衡** | 单角色盾 ≥ X 或 全队盾总量 ≥ Y（阈值见文末） | 破玩家盾 | `充能重锤`（优先强制）+ `护盾回收` |
| **B. 无盾脆弱** | 全队盾总量 ≈ 0 | 惩罚无盾 | `碎片倾泻` |
| **C. 均衡拉锯** | 盾适中，两头都不极端 | 常规循环 + 喘息 | 压场 ↔ 喘息交替，回收周期插入 |

> 状态 A / B 是"惩罚极端"；玩家想舒服，就得待在 C（中庸叠盾）——这正是"做选择"的核心。若玩家全程待在 B，虽能免掉被回收，但会被碎片倾泻的无盾额外伤害持续惩罚，不应成为绝对正确答案。

### 层 2：技能后继权重表（状态 C 时按表抽；A / B 有覆盖）

| 当前招式 | 碎片倾泻 | 充能重锤 | 压块封锁 | 守卫重击 | 护盾回收 | 设计说明 |
|---|--:|--:|--:|--:|--:|---|
| 护盾回收 | 30 | 10 | 30 | 30 | 0 | 吸核后必给喘息窗（60%），30% 顺势碎片倾泻惩罚 |
| 碎片倾泻 | 0 | 20 | 30 | 35 | 15 | 高威胁自环 = 0；60% 喘息、20% 接重锤、15% 回充 |
| 充能重锤 | 25 | 0 | 30 | 30 | 15 | 点杀后 60% 喘息（硬直）、25% 回接碎片倾泻 |
| 压块封锁 | 25 | 30 | 0 | 25 | 20 | 控制后回压场（55%）、20% 回充 |
| 守卫重击 | 20 | 30 | 20 | 0 | 30 | 万能中转，最易回充（30%），防外壳饿死 |

（每行权重和 = 100，自环全部 = 0。权重只在**当前条件允许的候选技能**中重新归一化，并非所有条件下都必然开放。）

## 三、核心机制循环

> **BOSS 把玩家的护盾当作废料回收，转化为自己的护盾和火力；玩家需要在回收后的喘息窗口主动破盾，并在重新建盾与承受高伤之间做出选择。**

| 节点 | 机制 | 设计目的 |
| --- | --- | --- |
| **护盾回收** | 吸走所有存活玩家角色的护盾，自身获得"吸收值 + 30"的护盾，并进入充能外壳 | 惩罚无脑叠盾，让玩家观察回收时机 |
| **充能外壳** | BOSS 自身护盾存在期间，攻击伤害提高 50% | 把"是否立即破盾"变成战斗优先级 |
| **破盾反馈** | BOSS 护盾被击碎时，获得眩晕 1 层并给予玩家 1 张临时卡 | 让破盾成为玩家主动争取的反击窗口 |
| **喘息窗口** | 压块封锁、守卫重击，以及护盾回收后的短暂行动段 | 给玩家建盾、出牌和破盾的时间 |
| **点杀检查** | 某个角色的护盾明显集中或失衡时，提高充能重锤的优先级 | 阻止玩家只给一个角色堆出过厚护盾 |

## 四、技能在状态机中的职责

| 招式 | 状态机职责 | 出招限制 |
| --- | --- | --- |
| **护盾回收** | 开启一轮回收循环，改变玩家护盾的价值 | BOSS 已有护盾时通常不可用；使用后必接喘息窗口 |
| **碎片倾泻** | 高威胁全体攻击，惩罚无盾和无脑建盾 | 不可连放；使用后必接压块封锁或守卫重击 |
| **充能重锤** | 点杀绝招，惩罚护盾集中或失衡的角色 | 不可连放；同一目标连续受击需限制 |
| **压块封锁** | 低压控制，作为主要喘息技能 | 可作为高威胁技能后的强制缓冲 |
| **守卫重击** | 中压兜底，作为次级喘息技能 | 保留一点伤害和"沉重"压力，不能视为纯休息 |

## 五、状态与强制转移

### 1. 开局引导

建议 BOSS 开战固定使用**护盾回收**，让玩家立刻理解机制：

```text
开战
→ 护盾回收
→ 压块封锁 / 守卫重击
→ 进入破盾判断
```

护盾回收后不能立即接碎片倾泻或充能重锤，必须先经过至少一个喘息行动段，给玩家攻击 BOSS 护盾的机会。

### 2. 回收后的破盾窗口

护盾回收完成后，下一招只从两个喘息技能中选择：

| 下一招 | 建议权重 | 作用 |
| --- | ---: | --- |
| **压块封锁** | 60% | 更低伤害，提供清晰的破盾机会 |
| **守卫重击** | 40% | 保留一点压力，避免窗口完全没有风险 |

喘息技能结算后检查 BOSS 护盾：

- **护盾已被击破**：触发破盾反馈和眩晕，随后进入常规攻击链。
- **护盾仍然存在**：进入充能攻击链，优先考虑充能重锤或碎片倾泻。

### 3. 碎片倾泻后的强制缓冲

碎片倾泻属于高威胁攻击，不允许直接连接碎片倾泻或充能重锤：

```text
碎片倾泻
→ 压块封锁 / 守卫重击
→ 再根据状态决定下一招
```

这条规则比单纯降低碎片倾泻权重更可靠，因为它从结构上保证了玩家一定能获得喘息窗口。

### 4. 破盾后的恢复

当 BOSS 护盾被击破：

```text
BOSS 护盾被击破
→ 眩晕 1 层
→ 给予玩家 1 张临时卡
→ 眩晕结束后进入常规攻击链
```

破盾后不应立刻再次护盾回收。建议先让 BOSS 使用一次压块封锁或守卫重击，再开放常规技能权重；否则玩家刚获得奖励就会马上进入下一轮回收，节奏会过于拥挤。

## 六、守护规则（防止链条跑偏）

这些是让"概率状态机"真正可控的关键兜底：

1. **同招不复用**：自环权重 = 0（见层 2 表），同招不连续出 2 次。
2. **碎片倾泻后强制喘息**：结构上保证高威胁后必有缓冲。
3. **护盾回收后必接喘息**：给玩家真实破盾机会。
4. **充能重锤有间隔**：点杀后至少经过一个其他技能才能再次使用（防止"重锤↔碎片倾泻"无脑高伤循环）。
5. **回充保险**：若护盾回收连续 2 个回合未出现，下一次行动强制转为**护盾回收**，避免外壳机制长时间停摆。
6. **回收不叠自身**：BOSS 已有护盾时不允许再次使用护盾回收，避免护盾无限增长。

## 七、护盾失衡与充能重锤

充能重锤不是普通随机攻击，而是 BOSS 对玩家护盾分布进行检查后的点杀手段。

### 失衡判定（满足任一即是"护盾失衡"）

- 某个角色的护盾达到队伍平均护盾的 **1.5 倍以上**；
- 某个角色的护盾达到其**最大生命的高比例**，而其他角色几乎没有护盾；
- 全队护盾总量很高，但 **超过 60% 集中在同一个角色**；
- 玩家**连续多个行动只给同一个角色建盾**。

### 失衡时的处理

```text
充能重锤进入高优先级候选
→ 优先攻击护盾最高或最集中的角色
→ 结算后至少经过一个其他技能
→ 才能再次使用充能重锤
```

### 转移优先级

1. 护盾失衡时，充能重锤优先级最高。
2. 没有护盾失衡时，充能重锤回到当前技能的常规权重。
3. 充能重锤不能连续使用，也不能和碎片倾泻组成无限高伤循环。
4. 如果充能重锤当前不可用，则在压块封锁和守卫重击中选择一个作为缓冲。

## 八、决策判断顺序（伪代码）

每次决定下一招时，按"**强制条件 > 状态条件 > 技能权重 > 普通随机**"的顺序判断：

```text
每次 BOSS 行动：
  step0  判定玩家护盾状态（给出意图 A / B / C）

  step1  【第一优先级 · 强制转移】
         a) 开战固定进入 护盾回收
         b) 上一招 = 碎片倾泻 → 下一招 ∈ {压块封锁, 守卫重击}（强制喘息）
         c) 上一招 = 护盾回收 → 下一招 ∈ {压块封锁, 守卫重击}（破盾窗口）
         d) BOSS 护盾被击破 → 先结算眩晕 + 临时卡，再进入常规链
         e) BOSS 已有护盾 → 禁用护盾回收
         f) 护盾回收 连续 2 回合未出现 → 下一招 = 护盾回收（回充保险）

  step2  【第二优先级 · 条件转移】
         a) 玩家护盾失衡 → 提高充能重锤优先级并锁定目标
         b) 玩家全队重新建盾且 BOSS 无护盾 → 开放护盾回收
         c) 连续两次进入高压攻击 → 强制开放压块封锁 / 守卫重击

  step3  【第三优先级 · 普通权重】
         通过前两层后，按层 2 后继权重表抽取下一招
         （自环 = 0，抽中与上一招相同则重抽兜底）
```

## 九、完整出招流程示例

### 示例 A：玩家在回收后及时破盾

```text
护盾回收
→ 压块封锁
→ 玩家破盾
→ 破盾眩晕
→ 守卫重击
→ 充能重锤
→ 压块封锁
→ 碎片倾泻
→ 守卫重击
→ 护盾回收
```

玩家获得了明确的破盾收益，但 BOSS 仍然会回到常规攻击链，不会因为一次破盾而永久失去威胁。

### 示例 B：玩家过度集中护盾（失衡 → 点杀）

```text
守卫重击
→ 护盾失衡检查
→ 充能重锤
→ 碎片倾泻
→ 压块封锁
→ 护盾回收
→ 守卫重击
→ 继续判断是否破盾
```

玩家必须在充能重锤前分散护盾，或者接受点杀风险；碎片倾泻后虽有喘息，但继续叠盾可能触发护盾回收。

### 示例 C：玩家完全不建盾

```text
碎片倾泻
→ 守卫重击
→ 压块封锁
→ 充能重锤
→ 碎片倾泻
→ 压块封锁
```

无盾可以避免护盾被回收，但会承受碎片倾泻针对无盾目标的额外伤害，因此不应成为绝对正确答案。

## 十、玩家可读性与平衡观察点

战斗中不需要展示完整的无限链条，但应让玩家看到：

- BOSS 当前所处阶段：常规攻击、充能外壳、回收后破盾窗口、破盾眩晕；
- 下一招名称和大致威胁等级；
- 碎片倾泻后的喘息提示；
- 护盾失衡时充能重锤的目标倾向；
- BOSS 护盾被击破后的奖励和眩晕反馈。

调试和数值调整时重点观察：

- 护盾回收后，玩家是否至少拥有一次真实破盾机会；
- 碎片倾泻是否很少连续出现；
- 充能重锤是否主要在护盾失衡时产生强烈压迫，而不是随机秒杀；
- 压块封锁和守卫重击是否真的形成喘息，而不是两个不同名字的攻击技能；
- 玩家是否存在"全程不建盾"或"全程只给一个角色建盾"的绝对解；
- BOSS 自身护盾是否会因重复回收而无限增长。

最终目标是让玩家知道：**BOSS 为什么会接出这一招，以及自己现在应该争取哪个窗口。**

## 十一、可调数值表

以下参数全部可调，建议默认值供起步：

| 参数 | 作用 | 建议默认 |
|---|---|---|
| 单角色盾阈值 X | 触发"叠盾失衡" | 单个角色盾 ≥ 20 |
| 全队盾总量阈值 Y | 触发"叠盾失衡" | 全队盾总量 ≥ 45 |
| 近无盾判定 | 触发"无盾脆弱" | 全队盾总量 ≤ 8 |
| 重锤点杀覆盖概率 | 失衡时是否必出 | 90% 强制 / 留 10% 随机给压迫感 |
| 回充保险间隔 | 防外壳饿死 | 2 回合 |
| 层 2 各后继权重 | 微调节奏 | 见层 2 表 |
| 失衡判定系数 | 平均盾倍数 / 集中度 | 平均 1.5 倍 / 集中度 60% |
