# 废弃楼层小怪 · 职能分工与联动（v1）

> 本文档是废弃楼层五只常驻小怪的技能、数值和联动编排唯一依据。招式名称、延迟、倍率、权重与条件权重都是可调参数；先保持职能与联动成立，再独立调节数值。

## 一、设计目标

废弃楼层的小怪不再是同一套「普通攻击 + 减益 + 大招」模板。每只小怪都有稳定、可预期的身份，队伍编成至少提供一条需要玩家判断处理顺序的联动链：

| 小怪 | 职能 | 玩家需要读出的关系 |
| --- | --- | --- |
| 维修蜘蛛 | 点火者 | 负责把灼烧铺开，优先点燃还没有灼烧的目标 |
| 收音机机器人 | 体力极限压制者 | 追咬最近受过重击、治疗空间最大的角色 |
| 红绿灯机器人 | 控场护卫 | 用交通管制锁住单体火力，并给同伴提速 |
| 清扫无人机 | 收割者 | 灼烧出现后优先重砸灼烧目标，形成高压点杀 |
| 玻璃水母 | 扩散者 | 场上有灼烧时才把灼烧传播到其他角色 |

战斗意图默认不可见，只有洞察状态揭示。玩家不依赖图鉴说明或额外战斗提示，而是通过固定行为逐渐认识组合的危险顺序。

## 二、引擎约定

### 1. 招式目标筛选

`EnemyMove.targetPick` 支持以下值：

| 值 | 规则 |
| --- | --- |
| `highestShield` | 选择护盾最高者；护盾相同时比较护盾占最大生命比例 |
| `highestHealRoom` | 选择 `hpLimit - hp` 最大者；并列时选择当前生命更低者 |
| `withStatus` | 在带 `targetStatus` 的存活敌对目标中随机选择；没有候选时交给普通随机目标 |
| `withoutStatus` | 在不带 `targetStatus` 的存活敌对目标中随机选择；没有候选时交给普通随机目标 |

敌方存在我方嘲讽单位时，`targetPick` 不会绕过嘲讽。脚本目标返回空值后，统一随机目标函数会把目标锁在嘲讽单位中。筛选失败不在脚本目标函数内额外消耗随机数。

### 2. 条件权重

普通小怪的实际抽招权重为：

```text
(move.weight ?? 1) × 所有成立的 bias.multiplier
```

支持的条件为：

| 条件 | 判定 |
| --- | --- |
| `anyFoeHasStatus` | 任意存活敌对目标带指定状态 |
| `noFoeHasStatus` | 没有存活敌对目标带指定状态 |
| `anyFoeHealRoomAtLeast` | 任意敌对目标的 `hpLimit - hp` 达到阈值 |
| `allyCountAtLeast` | 包含自身在内的存活友方数量达到阈值 |

条件乘数为 `0` 时，该条件成立就不会抽中该招。所有小怪至少保留一招不依赖条件的可用招式，因此不会失去行动能力。BOSS 的 `ai` 状态机不读取这些条件权重。

## 三、五只小怪

### 维修蜘蛛：点火者

基础属性：`62` 生命，`60` 攻击，`21` 先手。保留原有三招：

| 招式 | 延迟 | 权重 | 效果与目标 |
| --- | ---: | ---: | --- |
| 机械撕咬 | 2 | 2 | `0.6x` 单体攻击 |
| 焊枪灼烧 | 3 | 2 | `0.5x` 单体攻击，施加灼烧 3 层、持续 3 拍；`targetPick: withoutStatus`，目标状态为灼烧 |
| 助燃喷雾 | 4 | 1 | 对全体敌人造成 `0.3x`，施加灼烧 2 层、持续 2 拍 |

焊枪灼烧在没有任何灼烧目标时权重乘 `2`。它的任务是把火铺到新目标，而不是重复刷新同一目标；当所有目标都已灼烧时，筛选失败后恢复普通随机目标。

### 收音机机器人：体力极限压制者

基础属性调整为：`48` 生命，`50` 攻击，`24` 先手。静电噪波改为单段的全频压制，消除多段伤害带来的隐性体力极限惩罚。

| 招式 | 延迟 | 权重 | 效果与目标 |
| --- | ---: | ---: | --- |
| 电波啄击 | 2 | 3 | `0.5x` 单体攻击；选择 `hpLimit - hp` 最大者，并列选择当前生命更低者 |
| 全频压制 | 5 | 1 | 对全体敌人造成单段 `0.25x` 攻击伤害，一次压低全队体力极限 |
| 污染广播 | 4 | 1 | 原有 `0.2x` 单体攻击并增加 6 点污染 |

当任意目标的治疗空间达到 `12`，电波啄击权重乘 `3`。典型链条是清扫无人机先打出高压缺口，收音机随后咬向这个刚受重击的角色，让缺口只剩约 5 点可恢复空间。

### 红绿灯机器人：控场护卫

基础属性保持：`58` 生命，`70` 攻击，`19` 先手。黄灯警示、红灯禁行和限行标记保持原效果。绿灯放行改名为交通管制：

- 延迟 `4`，基础权重 `1`；存活友方至少 2 个时权重乘 `2`。
- 自身获得 1 层嘲讽，持续 1 拍。
- 所有友方获得先手 `+4`。

交通管制会暂时锁住玩家的单体火力，使玩家用群攻绕过护卫，或等待嘲讽结束。嘲讽只覆盖玩家后续的单体敌方卡，不影响 `allFoes` 群攻。

### 清扫无人机：收割者

基础属性保持：`70` 生命，`70` 攻击，`18` 先手。清扫撞击保持原效果。高压压实调整为：

- 延迟 `5`，基础权重 `1`，倍率 `1.8x`。
- `targetPick: withStatus`，目标状态为灼烧。
- 目标带灼烧时，`damageBonus` 追加 `0.7x`，实际为 `2.5x`，约 35 点伤害。
- 任意敌对目标带灼烧时，招式权重乘 `2.5`。

破盾旋刃保持原效果，并补上 `targetPick: highestShield`，固定去处理护盾最高的角色。核心联动是「维修蜘蛛点火 → 清扫无人机重砸」；灼烧目标必须成为玩家的优先处理对象。

### 玻璃水母：扩散者

基础属性保持：`44` 生命，`62` 攻击，`20` 闪避，`24` 先手。触须电刺、电离喷雾、磁场干扰保持原效果；折光滑移的权重降为 `0.5`。

新增涡流播撒：延迟 `4`，类型为减益，基础权重 `1`，不需要主目标。效果从随机一个带灼烧的敌对目标取其灼烧层数的 `60%`，复制给其他敌对目标。

- 场上存在灼烧时，权重乘 `4`。
- 场上不存在灼烧时，权重乘 `0`，绝不空放。

它与维修蜘蛛组成「点火 → 扩散」链，双水母编成会把一名角色身上的灼烧迅速铺到全队。

## 四、遭遇战编成

站位沿用现有遭遇表的行列与取景数据，只调整敌人身份：

| 编成 | 敌人 | 主要联动 |
| --- | --- | --- |
| `n-t1-scout` | 蜘蛛 + 收音机 | 点火后锁治疗空间 |
| `n-t1-sweep` | 蜘蛛 + 无人机 | 点火后重砸，核心教学 |
| `n-t1-drift` | 蜘蛛 + 水母 | 点火后扩散 |
| `n-t2-crew` | 蜘蛛 + 收音机 + 无人机 | 点火、重砸、锁治疗的完整三段链 |
| `n-t2-beacon` | 收音机 + 红绿灯 + 无人机 | 嘲讽护住体力极限压制者 |
| `n-t2-current` | 蜘蛛 + 水母 + 红绿灯 | 点火、扩散、控场保护 |
| `n-t2-duo-crush` | 收音机 + 无人机 | 重击后双重压制治疗空间 |
| `n-t2-duo-torch` | 蜘蛛 + 红绿灯 | 护卫保护点火者 |
| `n-t3-patrol` | 蜘蛛 + 双无人机 | 一次点火后连续收割 |
| `n-t3-blockade` | 红绿灯 + 蜘蛛 + 无人机 | 控场与火力链 |
| `n-t3-swarm` | 蜘蛛 + 双水母 | 点火后双重扩散 |

`n-t4-*`、`n-mimic-*` 和 BOSS 编成保持不变。教学首战 `tut-t1-intro` 使用收音机 + 无人机，把红绿灯推迟到后续教学战斗，避免新手第一次战斗同时面对硬嘲讽和未知的目标锁定。

## 五、调参基准与观察顺序

优先保证下列关系成立，再调整绝对伤害：

1. 蜘蛛的焊枪灼烧倾向于没有灼烧的目标；全队无火时仍有较高点火率。
2. 无人机在有灼烧时明显偏向灼烧目标，并让高压压实成为约 35 点的高威胁招式。
3. 水母没有灼烧时不抽涡流播撒，有灼烧时明显提高抽取率。
4. 收音机在出现明显体力极限缺口时提高啄击频率，并咬向治疗空间最大的目标。
5. 红绿灯在有同伴时更常使用交通管制；嘲讽期间玩家单体卡只能选择红绿灯，群攻仍可正常使用。

所有延迟、倍率、基础权重、条件阈值和条件乘数均可独立调整。若联动不明显，先调条件乘数和目标筛选，再调伤害；不要通过额外战斗提示补偿机制不稳定。
