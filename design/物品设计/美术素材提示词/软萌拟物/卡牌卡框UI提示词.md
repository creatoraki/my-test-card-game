# 《霓虹都市》· 卡牌卡框 UI 美术提示词

> **画风**：软萌拟物·末世补给 UI。
>
> **适用范围**：战斗手牌、角色卡组、卡牌奖励和卡牌详情界面的卡框素材。
>
> **设计方向**：以现有卡面尺寸契约为基础，统一使用竖向约 1:1.4 的卡面比例；上方约 1:1 的区域留给卡牌插画，下方固定区域留给名称、费用和效果说明。四套卡框保持完全一致的版式和基础轮廓，只通过不同材质与配色形成风格差异，可自由用于任意卡牌。

---

## 一、统一视觉规范

- 日系二次元游戏 UI 素材，软萌拟物·末世补给风格，圆润但保留废弃未来城市设备的工业逻辑。
- 每次只生成一张完整的竖向卡牌卡框，宽高比约为 **1:1.4**，适配约 220×308 的卡面；正面平视，不能有明显透视倾斜，方便程序叠加内容。
- 卡框由上方正方形插画窗、下方固定说明区和外围结构边框组成。插画窗与说明区都必须保持空白、规整、可替换，不生成卡牌插画或文案。
- 每套卡框都必须保留相同的外框尺寸、圆角轮廓、上方正方形插画窗、下方固定说明区和内部分隔位置；只替换表面材质、边缘处理和配色，不改变版式。
- 四套卡框分别使用暖铜黄铜、冷釉陶瓷、软质工程树脂、烟彩玻璃与有色金属等材质语言；每套材质都要表现真实的表面触感、厚度、接缝和使用痕迹。
- 软萌感来自圆角、适度厚度、清晰分层和柔和阴影，不来自动物脸、拟人五官、贴纸、糖果装饰或玩具化比例。
- 四套卡框不是攻击、防御、支援或速攻等功能分类，也不对应卡牌效果、角色或稀有度；同一张卡牌可以任选其中一套视觉风格。
- 不要通过改变卡框剪影、插画窗大小、说明区高度或功能符号来区分风格；材质和配色必须是主要差异。颜色应落在边框、内衬和结构件上，不要把整张卡面染成单一的鲜艳色块或大面积霓虹光。
- 费用、卡名、角色归属、稀有度、类型、目标范围、效果文字和数值均由游戏程序后期叠加；素材本身不出现任何可读文字、字母、数字、图标或徽章。
- 普通、罕见、稀有等品质变化只增加蚀刻精度、边缘抛光和局部结构细节，不改变四类卡框的基础轮廓。不要使用物品稀有度的五档颜色直接套到卡框上。
- 背景使用透明背景；如果模型不支持透明背景，使用干净的深灰蓝纯色背景。不要生成桌面、房间、角色、手部、完整 HUD、多个卡牌或卡牌堆。

## 七、卡框素材验收重点

- 四张素材都必须是单张完整竖向卡框，比例约为 1:1.4；四套风格的外轮廓、插画窗、说明区、分隔位置和费用落位必须一致，不能因为材质装饰改变布局。
- 插画窗和说明区必须为空，不能提前生成角色、敌人、物品、技能特效、卡名、费用、数字或规则文字；后续内容由程序和独立插画素材叠加。
- **暖铜黄铜**应看出拉丝黄铜、氧化铜、象牙陶瓷和深棕橡胶，不能变成纯金卡框或锈蚀废铁。
- **冷釉陶瓷**应看出平滑釉面、雾面玻璃和冰蓝冷光，不能变成破碎瓷片、冰块或医疗设备图标。
- **软质树脂**应看出柔和树脂漫反射、硅胶边缘、注塑接缝和织物压边，不能变成糖果包装、衣服或玩具。
- **烟彩玻璃**应看出烟色玻璃、彩色边缘折射、阳极氧化铝和旧铜夹片，不能变成宝石、镜子或霓虹灯牌。
- 四套风格都必须保持同画风：圆润、轻厚涂、柔和阴影、轻微旧化和清晰功能结构；材质不同不等于画风不同。
- 四套风格都可以用于任意卡牌，不要在卡框轮廓、装饰符号或提示词中暗示攻击、防御、支援、速攻、普通、稀有等卡牌分类。
- 缩小到战斗手牌尺寸后，应先看出四种材质和配色差异，同时仍能清楚叠加插画、费用、卡名与效果文字。
- 透明背景优先；如果生成纯色背景，必须是干净深灰蓝，不得出现桌面、房间、角色手持卡牌、完整游戏界面、卡牌堆或多张卡框。
- 生成结果如果带有背景，必须是干净深灰蓝纯色；不得出现桌面、房间、角色手持卡牌、完整游戏界面、卡牌堆或多张卡框。

## 九、追加风格验收重点

- 追加的四张素材必须仍然是同一套卡框几何：外轮廓、插画窗、说明区、分隔位置和费用落位完全一致，只改变材质与配色。

- **回收纸浆**必须看出压制纸浆复合板、纸纤维层和纸带封边，不能变成文件、信封、书本或垃圾纸堆。

- **铸铁橡胶**必须看出粗哑铸铁、耐磨橡胶、铸造颗粒和掉漆，不能变成发动机、齿轮、武器或工厂场景。
- 四种追加风格与前面四种风格都保持软萌拟物·末世补给画风：圆润轮廓、轻厚涂、柔和阴影、轻微旧化和清晰结构；只改变材质和配色，不改变卡牌 UI 版式。
- 四种追加风格都可以用于任意卡牌，不表达攻击、防御、支援、速攻、普通、稀有或其他游戏分类。
- 缩小到战斗手牌尺寸后，四种材质仍应能通过大面积材质触感和主色区分，不能只依靠细小纹理；两个内容区域仍必须适合后期叠加插画和文字。

## 十、细卡框·奇幻卡通科技玻璃系列

这一组专门用于更轻薄、更精致的细卡框。它们仍然沿用统一的竖向约 1:1.4 卡面比例，但外框不再使用厚重护角、宽阔面板或大体积结构，而是使用窄边框、细分隔条和局部透明材质来制造轮廓。四套风格共享完全相同的卡框几何，只改变玻璃种类、边缘工艺、配色和少量装饰细节。

- 每次只生成一张独立的完整竖向卡牌卡框，适配约 220×308 像素的 1:1.4 卡面比例；正面平视、无明显透视倾斜，卡框居中并保留均匀安全边距。

### 6. 微圆角黑白系列验收重点

- 四张素材必须是单张完整的竖向卡框，比例约为 1:1.4；外轮廓、插画窗、说明区、分隔位置、费用落位和内容内边距完全一致。
- 四角必须是微圆角或近似直角，圆角半径约为卡面宽度的 1%—2%；如果缩小后仍明显看起来像大圆卡框、胶囊卡框或泡泡卡框，则视为不合格。
- 黑白灰必须是视觉主导色，只允许透明玻璃和中性反光参与层次；不得出现蓝、绿、红、黄、金、紫、彩虹或彩色霓虹作为装饰色。
- **黑曜玻璃·精密机匣**应看出烟黑钢化玻璃、黑色阳极氧化铝、白色陶瓷隔片和黑色密封垫，不能变成黑色宝石、厚重装甲或完整机器。
- **乳白玻璃·洁净机械**应看出白色磨砂玻璃、白色陶瓷、黑色密封线和浅灰金属，不能变成医疗设备、白色塑料玩具或大圆角家电。
- **黑白导光·模块终端**应看出黑色夹层玻璃、白色导光层、微孔金属和模块卡扣，不能变成彩色霓虹屏幕、代码界面或科幻场景。
- **银灰骨架·夹层机械**应看出透明蚀刻玻璃、银灰细骨架、黑色压片和白色垫片，不能变成齿轮机械、武器、工具或复杂设备。
