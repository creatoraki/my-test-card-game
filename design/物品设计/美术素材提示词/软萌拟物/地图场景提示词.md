# 《霓虹都市》· 地图场景美术提示词

> **画风**：软萌拟物·末世补给。
>
> **适用范围**：大厦内部房间、下水管道、天空玻璃轨道、温室花园四张地图场景背景。
>
> **使用方式**：以下每段提示词都可以独立复制。地图场景使用 16:9 横向构图，建议生成 1920×1080；同一张图可作为探索路线图背景、地图选择预览图或战斗场景底图。四张图保持相同的线稿、厚涂、光照和旧化规则，只通过空间结构、材质与主色区分地图。

---

## 一、统一视觉规范

- 日系二次元游戏场景原画，软萌拟物·末世补给风格。
- 轻度卡通化，但保留建筑、管道、轨道、玻璃和植物的功能逻辑；圆润的结构边缘与可靠的工业细节并存。
- 干净线稿，简洁厚涂，柔和阴影，小面积明确高光；避免照片质感、恐怖写实和复杂概念设定图感。
- 16:9 横向宽幅构图，建议 1920×1080；画面有清晰的前景、中景、远景层次，透视稳定，空间纵深明确。
- 场景中部保留一块相对干净、对比度适中的可读区域，方便叠加路线图、战斗单位和 UI；重要识别物放在左右两侧、远景或下方，不把主体塞满中央。
- 使用一个主色、一个辅助色和一个少量强调色；光源来自真实的设施灯、指示灯、天光或植物照明，不把整张图做成发光特效。
- 表现人类离开后仍在运行的城市：设备有轻微灰尘、划痕、氧化、旧封装和维护痕迹，但设施没有完全坍塌，仍能看出原本用途。
- 场景应像可以行走和探索的真实空间，保留通道、检修口、门、栏杆、平台、管线或植栽维护区等可理解的动线。
- 不生成角色、敌人、人物手部、车辆、完整机器人、道具堆、战斗特效、路线图、UI 面板、按钮、可读文字、数字、品牌 logo 或水印。
- 不使用过度景深、强烈镜头光晕、大片烟雾、血腥元素、恐怖尸骸、魔法城堡、纯自然森林或与地图无关的奇幻装饰。

## 三、大厦内部房间

**地图定位**：低温维生区与控制终端所在的大厦内部区域；人类离开后，楼层系统仍在执行旧的接待、维护与资源管理流程。

```text
16:9 横向游戏场景背景，建议 1920×1080，宽幅室内透视构图，日系二次元游戏场景原画，软萌拟物·末世补给风格，轻度卡通化但保留未来企业大厦内部的建筑与设备逻辑，干净线稿，简洁厚涂，柔和阴影，小面积明确高光，画面有前景、中景和远景的清晰空间层次。场景是一间位于未来超级科技公司大厦内部的低温维生与控制房间，前景是圆润的金属地面、低矮检修槽和一条通向远处的干净通道，中景两侧排列几组高大但比例友好的低温维生舱与半透明玻璃隔断，舱体外壳有轻微灰尘、旧封装边缘和维护划痕；右侧远处设置一座仍在运行的控制终端，只有不可读的几何界面光和状态点，不出现文字，左侧可见整齐的供能管线、冷却接口与一扇厚重的自动门。整体使用冷灰白作为主色，深蓝灰和旧银用于设备外壳、地面与框架，医疗青用于低温舱内部的柔和光线，少量警示橙用于远处指示灯和安全标记形状。顶部有老化但仍亮着的线性灯，空气中只有极少量冷雾与微尘，空间洁净、安静、略显空旷，表现设施仍在工作而人类已经离开的感觉。保持画面中央偏中下区域相对干净，方便叠加路线图或战斗单位。不要生成角色、敌人、人物手部、完整机器人、道具堆、可读文字、数字、品牌 logo、水印、战斗特效、复杂 UI、医疗恐怖元素、手术台、血迹或完整城市外景。
```

**验收重点**：缩小后仍应先看出“未来大厦内部房间”，再看出低温维生舱与控制终端；不能变成普通办公室、医院手术室或纯黑科技走廊。

## 四、下水管道

**地图定位**：城市地下的管网与维护通道；这里承担排水、冷却、污染过滤和设备检修等基础设施工作。

```text
16:9 横向游戏场景背景，建议 1920×1080，宽幅地下通道透视构图，日系二次元游戏场景原画，软萌拟物·末世补给风格，轻度卡通化但保留城市下水与维护设施的工程逻辑，干净线稿，简洁厚涂，柔和阴影，湿润材质的克制高光，画面有明确的前景、中景和远景纵深。场景是一段仍在运行的未来城市地下管网，前景是圆润厚实的检修栈道、低矮护栏和浅浅积水，水面有柔和而清晰的管线倒影；中景两侧分布不同粗细的巨大防水管道、带法兰接口的分流管和可开启的检修舱门，管道表面有旧维护标记形状、细小锈斑、灰尘与水汽痕迹，但结构完整；远处是一道半开启的圆形闸门，后方延伸出更深的蓝灰色管廊，墙面有少量仍在闪烁的维护指示灯和净化装置接口。整体使用湿润深灰作为主色，锈红和污水褐用于金属边缘、旧螺栓与沉积痕迹，维护青用于管道接口、净化装置和远处灯光，少量警示黄用于闸门边缘与安全区域的几何标记。空气中有薄薄的水汽和极少量漂浮微尘，光线来自顶部检修灯、管道缝隙和积水反射，氛围潮湿、安静、略有压迫感但不恐怖。保持画面中央的主要行走区域清晰，方便叠加路线图或战斗单位。不要生成角色、敌人、人物手部、完整机器人、污水怪物、血腥元素、尸骸、垃圾山、可读文字、数字、品牌 logo、水印、洪水、纯黑洞穴或大面积烟雾。
```

**验收重点**：必须同时看出巨型管道、可行走的检修通道和积水反光；不能变成自然洞穴、垃圾场或恐怖下水道。

## 五、天空玻璃轨道

**地图定位**：城市高空的玻璃轨道与运输路线；磁吸运输设施已经停摆，但透明防护结构、悬空平台和城市视野仍然保留。

```text
16:9 横向游戏场景背景，建议 1920×1080，宽幅高空透视构图，日系二次元游戏场景原画，软萌拟物·末世补给风格，轻度卡通化但保留未来城市高空运输系统的结构逻辑，干净线稿，简洁厚涂，柔和阴影，玻璃、金属与远景空气透视清晰可辨。场景是一条悬浮在未来城市高空的透明玻璃运输轨道，前景是圆润的金属检修平台、低矮安全栏杆和轨道边缘的磁吸接口，中景是一段向远方延伸的半透明玻璃轨道与分段式防护片，玻璃边缘有细小裂纹、风压磨损和旧维护卡扣，但没有破碎坠落；轨道下方可以看到被薄雾切开的城市高楼、悬空连接桥和仍在运行的少量霓虹基础设施，远景是明亮的天空与城市天际线，不出现车辆或人物。整体使用雾白与天空蓝作为主色，深靛蓝和金属灰用于轨道骨架、磁吸底座与远处建筑，霓虹青用于透明防护片边缘和磁轨接口，少量信号橙用于检修灯和分段警示形状。风从高空掠过，只有轻微流线感和薄云，不使用夸张速度线；光线柔和，玻璃反射清楚但不刺眼，表现辽阔、通透、危险边缘与仍然精密的交通设施。保持画面中央偏下的轨道行走面相对简洁，方便叠加路线图或战斗单位。不要生成角色、敌人、人物手部、车辆、飞船、完整机器人、可读文字、数字、品牌 logo、水印、玻璃碎片暴雨、夸张激光、赛博朋克广告墙、纯太空背景或无尽高楼堆叠。
```

**验收重点**：必须看出透明防护片、磁吸轨道和悬空城市高度；不能变成普通高架桥、机场、太空站或只有霓虹灯的城市夜景。

**地图定位**：城市中的封闭温室与园林区域；自动灌溉、空气过滤和植物维护系统仍在工作，植物已经沿着设施边缘持续生长。


**验收重点**：必须同时看出封闭玻璃温室、人工灌溉设施和城市植物；不能变成普通公园、野外森林或魔法花园。

## 七、统一验收标准

- 四张图都应保持软萌拟物的圆润结构、干净线稿、简洁厚涂、柔和阴影和轻微旧化，不能各自变成写实、赛璐璐或恐怖风格。
- 四张图都应是可行走、可探索的完整空间，并通过前景、中景、远景形成纵深；不能只生成一件设施或一张装饰性概念图。
- 16:9 画面中央需要保留 UI 和单位可读空间；重要地图识别物可以放在侧边或远景，但不能被背景细节淹没。
- 大厦内部房间看结构与功能，下水管道看管网与维护，天空玻璃轨道看高度与透明轨道，温室花园看人工栽培与持续生长；四者不能只靠色调区分。
- 光效只作为设施运行状态和环境光源，不替代建筑、管道、轨道或植物本体；不要把地图生成成技能特效背景。
- 所有文字、编号、品牌与 UI 都使用不可读的几何标记或直接省略，避免模型生成错误文字。
