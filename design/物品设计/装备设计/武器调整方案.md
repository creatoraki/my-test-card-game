# 《霓虹都市》· 8 种武器收束与穿甲属性调整方案

> **状态**：已按本方案落地代码，待实战观察。
>
> **目标**：将普通武器模型从 10 种收束为 8 种，并新增固定值属性「穿甲」，让武器在输出方向上形成更清晰的选择。

## 一、调整结论

1. 武器保留 8 个装备模型：太刀、穿甲弩、狙击枪、拳套、弓箭、盾斧、匕首、火炮。
2. 保留太刀与弓箭的独立武器定位；移除旧军刀与锤子，防御、闪避和格挡职责回归防具与饰品。
3. 穿甲是角色面板属性，使用固定整数，不使用百分比。
4. 非固定伤害进入防御结算时，先用「目标最终防御力 - 施放者最终穿甲」得到有效防御力，再按现有防御公式减伤。
5. 有效防御力最低为 0。穿甲不能把防御力压成负数，也不能直接造成易伤。
6. 固定伤害继续跳过防御和格挡，因此也不读取穿甲。
7. 稀有度只提高这 8 个模型已有属性的数值，不新增穿甲或删除既有代价。
8. **敌人防御力重新分层**。当前敌表防御集中在 `0~3`，穿甲、破甲和防御力整条线都没有作用空间，需要扩展为轻甲 / 中甲 / 重甲 / Boss 四档。
9. **精准改为只抵消目标闪避率**，不再叠加到基础命中之上。当前实现中精准与命中率直接相加、且敌人闪避为 0，两者完全等价，武器与饰品的属性分工无法成立。
10. 属性预算权重按实测期望伤害重新标定，不再对爆伤、穿甲使用固定线性权重。先手维持现有引擎逻辑与现有数值，不参与线性预算表。

## 二、最终 8 种武器

以下数值是普通级的第一版建议。稀有度提升时只按同一模型的数值梯度放大，不改变属性方向。

| 武器 | 类型 | 普通级建议属性 | 主要定位 |
| --- | --- | --- | --- |
| 太刀 | 固定加成型 | `攻击力 +2`、`命中率 +3%` | 稳定、泛用的基础输出 |
| 穿甲弩 | 固定加成型 | `攻击力 +1`、`命中率 +3%`、`穿甲 +6` | 对高防御目标的稳定输出 |
| 狙击枪 | 固定加成型 | `攻击力 +1`、`暴击率 +10%`、`爆伤 +35%` | 暴击构筑的持续收益 |
| 拳套 | 固定加成型 | `攻击力 +2`、`先手 +4` | 抢节奏、减少敌方蓄力窗口 |
| 弓箭 | 固定加成型 | `攻击力 +2`、`暴击率 +3%`、`爆伤 +50%` | 低触发率、高单次回报的爆发 |
| 盾斧 | 极端加成型 | `最大生命值 +30`、`攻击力 +3`、`先手 -5` | 厚重近战，牺牲速度换取攻防体量 |
| 匕首 | 极端加成型 | `最大生命值 -25`、`防御力 -4`、`攻击力 +2`、`暴击率 +12%`、`爆伤 +30%` | 玻璃炮，追求高暴击回报 |
| 火炮 | 极端加成型 | `攻击力 +4`、`暴击率 +12%`、`爆伤 +40%`、`命中率 -10%`、`先手 -2` | 低命中、高单次伤害的赌命输出 |

### 2.1 数值收敛校验

以角色基础面板（攻击 20、暴击率 5%、爆伤 150%、基础命中 90%、先手 20、最大生命 50、防御 10、上阵 3 人）为基准，计算「命中率 × 暴击期望 × 攻击力 × 防御修正」得到的期望伤害指数（无防御目标，基准为 1.00）：

| 武器 | 伤害指数 | 附带收益 / 代价 |
| --- | ---: | --- |
| 太刀 | 1.137 | 无代价，作为零门槛基准 |
| 穿甲弩 | 1.085 | 对中甲（防御 8）目标为 1.289 |
| 狙击枪 | 1.155 | — |
| 弓箭 | 1.159 | 与狙击枪同均值，方差更高 |
| 拳套 | 1.100 | 敌方蓄力 +1 刻 |
| 盾斧 | 1.150 | 有效生命 +60%，敌方蓄力 -2 刻 |
| 匕首 | 1.219 | 有效生命 -50%，防御 -4 |
| 火炮 | 1.200 | 命中 -10%，敌方蓄力约 -1 刻 |

校验目标：

- 固定加成型收敛在 `1.10~1.16`，其中零代价的太刀不应是最高值。
- 极端加成型（匕首 1.219、火炮 1.200）的输出峰值必须高于全部固定加成型，同时净属性预算更低，符合《装备设计概览》2.3 的硬约束。
- 穿甲弩对无甲目标低于太刀，对中甲以上目标显著高于太刀，是唯一收益随目标变化的武器。

### 2.2 武器之间的决策差异

- **太刀 vs 穿甲弩**：太刀对常规目标更直接；穿甲弩牺牲 1 点攻击力换取对高防目标的收益，不应成为所有战斗的默认答案。反过来也要避免它变成纯下位选项——只有敌人防御分层落地后，这个交换才成立。
- **狙击枪 vs 弓箭**：狙击枪提高暴击触发稳定性；弓箭提高暴击后的收益，二者分别服务于「更容易暴击」和「暴击后更痛」。弓箭必须自带少量暴击率，否则在 5% 基础暴击下爆伤几乎不产生收益。
- **拳套 vs 盾斧**：拳套改变战斗节奏；盾斧强化面板体量但明显延后敌方行动收益，属于两种不同的战斗计划。
- **匕首 vs 火炮**：匕首把风险放在角色生存和防御上，火炮把风险放在命中率和先手上，避免两个极端武器完全同质化。

## 三、穿甲属性规则

### 3.1 属性定义

在 `StatBlock` 中新增 `armorPen`：

- 中文名：穿甲。
- 数据类型：固定整数。
- 存储位置：使用 `mods.flat.armorPen`，不使用 `mods.pct`。
- 默认值：没有穿甲来源时为 `0`。
- 归属：施放者属性，武器是主要来源；未来敌人也可以使用同一属性。
- 作用对象：非固定伤害的防御减伤阶段。

穿甲不属于命中、精准、暴击、格挡或护盾属性，因此不会改变这些判定。

### 3.2 防御结算公式

先取得目标在装备、状态和战斗修正全部生效后的最终防御力，再读取伤害施放者的最终穿甲：

$$
D_{effective} = \max(0, D_{target} - P_{source})
$$

其中：

- $D_{target}$ 是目标最终防御力。
- $P_{source}$ 是伤害来源的最终穿甲。
- $D_{effective}$ 是本次伤害使用的有效防御力。

沿用当前防御常量 $30$：

$$
M_{defense} = 1 - \frac{D_{effective}}{D_{effective} + 30}
$$

非固定伤害在防御阶段乘以 $M_{defense}$，之后继续进入现有的格挡、护盾和生命结算。

### 3.3 结算顺序

完整顺序保持不变，只替换防御阶段的输入：

1. 施放者与目标的状态修正。
2. 命中判定。
3. 暴击判定。
4. 计算有效防御力：目标最终防御力减去来源最终穿甲，并将结果限制为不低于 0。
5. 防御减伤。
6. 格挡判定与格挡减伤。
7. 护盾吸收。
8. 生命值结算与后续受击触发。

### 3.4 边界规则

- **固定伤害**：继续跳过防御与格挡，因此不受穿甲影响。
- **无来源伤害**：没有施放者时穿甲按 0 处理，例如中毒等无来源伤害不会凭空获得穿甲。
- **反伤**：如果反伤明确记录了反伤来源，则读取该来源的穿甲；没有来源时按 0 处理。
- **必中攻击**：必中只跳过命中掷骰，不会跳过防御或穿甲结算。
- **破甲状态**：先完成目标的状态修正，再计算「最终防御力 - 穿甲」。破甲与穿甲可以叠加，但两者职责不同：破甲降低目标面板，穿甲提高攻击方穿透能力。
- **防御为负数**：最终有效防御力仍限制为 0。穿甲和破甲都不能通过防御阶段直接制造额外倍率。
- **攻击方阵营**：公式不限定玩家阵营。敌人未来拥有穿甲时，也按同一公式读取敌方来源属性。

### 3.5 直观示例

以目标防御力为 10、未触发格挡为例：

| 来源穿甲 | 有效防御力 | 防御后伤害倍率 |
| ---: | ---: | ---: |
| 0 | 10 | 75.00% |
| 3 | 7 | 81.08% |
| 6 | 4 | 88.24% |
| 12 | 0 | 100.00% |

穿甲的收益随目标防御提高而提高，但达到完全抵消后不再继续增加伤害。这能让穿甲弩克制高防敌人，同时避免低防敌人被重复放大。

## 四、属性预算权重的重新标定

### 4.1 标定口径

以 `攻击力 +1` 为锚点：基础攻击 20 时，`+1 攻击力` 等于 `+5%` 期望伤害，定义为 **2.0 预算点**。因此 **1 预算点 = 2.5% 期望伤害**。其余属性按同一口径实测折算。

| 属性 | 权重 | 依据与注意事项 |
| --- | ---: | --- |
| 攻击力 | 2.0 / 点 | 锚点属性。 |
| 命中率 | 0.45 / 点 | 基础命中 90%、上限 100%，`+1` 约等于 `+1.11%` 伤害。**全生涯只有 10 点空间**。 |
| 精准 | 0.45 / 点 | 改为只抵消闪避后，对零闪避目标价值为 0，只能按目标闪避量计价。 |
| 暴击率 | 0.20 / 点 | 爆伤 150% 时 `+1` 约等于 `+0.49%` 伤害；该权重随同件装备提供的爆伤上升。 |
| 爆伤 | `0.02 × (装备暴击率 / 5)` / 点 | **不能使用固定权重**。5% 基础暴击下 `+50%` 爆伤只值 `+2.4%` 伤害。 |
| 穿甲 | 轻甲 0.3 / 中甲 0.8 / 重甲 1.0 | 收益随目标防御上升，并被目标防御截断，属于条件权重。 |
| 最大生命值 | 0.20 / 点 | 基础 50，`+1` 约等于 `+2%` 有效生命。 |
| 防御力 | 0.25 / 点 | 在防御 10 附近取值，随自身防御升高而递减。 |
| 先手 | 不计入线性预算 | 见 4.2。 |

固定加成型的净预算目标为 **6.5~7.0**，极端加成型为 **5.0~5.5**，且极端型的输出峰值必须高于全部固定型。

### 4.2 先手为什么不参与线性预算

`partyInitiative` 取存活上阵角色的**平均值**，`enemyActDelay = max(1, round(D + S_party - S_enemy))`。3 人队时单件武器的先手要先 ÷3 再四舍五入，价值既被稀释又被取整截断：

- 拳套 `先手 +4` → 队伍 +1.33 → 敌人蓄力稳定 +1 刻。敌人招式 `delay` 集中在 3~8（均值约 5），相当于敌方输出频率下降约 17%。
- 盾斧 `先手 -5` → 队伍 -1.67 → 5 刻的招式压到 3 刻，敌方行动次数增加约 67%，是全表最重的单项代价。
- 火炮 `先手 -2` → 队伍 -0.67 → 取整后有时 -1 刻、有时 0 刻，代价不稳定。

本轮**维持现有引擎逻辑与现有先手数值**，但先手不写进线性权重表，评估时一律折算为「敌方蓄力 ±N 刻」单独描述。后续如果要让先手可线性定价，再单独讨论去掉 `round` 或改为累计小数。

### 4.3 穿甲弩的普通级预算

| 属性 | 数值 | 权重 | 预算 |
| --- | ---: | ---: | ---: |
| 攻击力 | +1 | 2.0 | 2.0 |
| 命中率 | +3% | 0.45 | 1.35 |
| 穿甲 | +6 | 0.8（中甲） | 4.8 |
| **合计** |  |  | **8.15（中甲）/ 3.35（无甲）** |

穿甲弩是全表唯一预算随目标浮动的武器：对中甲以上目标超出固定型基准，对无甲目标明显低于基准。这个波动是它的设计目的，因此不再要求它在单一目标下落进 7 点区间。穿甲不与高额攻击力、暴击率和爆伤叠加，否则它会同时克制防御目标并成为泛用最高输出。

### 4.4 命中率的稀有度空间

基础命中 90%、`hitCeilPct` 为 100%，命中率与精准全生涯只有 **10 点**可用空间。因此：

- 普通级太刀、穿甲弩的命中率定为 `+3%`，五档稀有度按 `3 / 4 / 6 / 8 / 10` 递增，传说级正好用满。
- 命中率不能作为高稀有度的主要成长属性，成长压力应放在攻击力、暴击率和穿甲上。
- 火炮的 `命中率 -10%` 在普通级已接近可接受的代价上限，高稀有度加深该代价时需要单独核算命中概率下限。

## 五、配套的系统调整

这两项不属于武器数据本身，但不做的话本方案不成立。

### 5.1 敌人防御分层

当前 `src/data/enemies.ts` 的 7 个敌人防御力为 `2 / 3 / 0 / 0 / 1 / 2 / 2`，穿甲最多只能兑现约 `+3.8%` 伤害，穿甲、破甲和防御力三条线全部落空。建议扩展为四档：

| 档位 | 防御力区间 | 未穿甲时的减伤 | 适用敌人 |
| --- | ---: | ---: | --- |
| 轻甲 | 0~2 | 0%~6% | 快速型、群体小怪 |
| 中甲 | 6~8 | 17%~21% | 常规主力敌人 |
| 重甲 | 12~16 | 29%~35% | 护甲型敌人，穿甲的主要目标 |
| Boss | 10~14 | 25%~32% | 头目，配合高生命值 |

调整敌人防御后，敌人的实际承伤会整体下降，需要同步复核敌人生命值，避免战斗长度失控。

### 5.2 精准只抵消闪避

当前 `hitChance()` 中 `命中率 + 精准` 直接相加，且敌人闪避全部为 0，精准与命中率完全等价，武器（命中）与饰品（精准）的分工在实现层不存在。调整为：

$$
P_{hit} = \operatorname{clamp}\!\left(P_{base} + \text{命中率} - \max(0,\ \text{目标闪避率} - \text{精准}),\ 5\%,\ 100\%\right)
$$

即精准只用于抵消目标闪避率，抵消不完的部分才降低命中概率；精准超出目标闪避的部分不转化为额外命中。这样精准成为专门的反闪避属性，也让本方案中武器统一使用命中率、不再借用精准变得合理。

## 六、旧武器到新武器的处理

| 旧模型 | 处理方式 | 原因 |
| --- | --- | --- |
| 太刀 | 保留 `deflection-blade` | 作为没有明显构筑门槛的泛用基准 |
| 弩 | 保留 `armor-piercing-crossbow`，显示名建议改为「穿甲弩」 | 正好承接新属性，降低新增模型成本 |
| 狙击枪 | 保留 `hunting-rifle` | 作为暴击稳定性武器，并吸收弓箭的远程精准主题 |
| 拳套 | 保留 `quickstrike-gauntlet` | 保留先手/节奏路线 |
| 弓箭 | 保留 `hunter-longbow` | 保留暴击后的爆发路线 |
| 盾斧 | 保留 `cross-sword` | 保留高生命、高攻击、低先手的极端路线 |
| 匕首 | 保留 `glass-dagger` | 保留牺牲生存换暴击的极端路线 |
| 火炮 | 保留 `heavy-cannon` | 保留牺牲命中与先手换高攻击的极端路线 |
| 军刀 | 移除 `dawn-saber`，不再作为独立武器掉落 | 由太刀承接稳定命中与输出基准 |
| 锤子 | 移除 `shock-maul`，不再作为独立武器掉落 | 由弓箭承接暴击后的爆发路线 |

本项目已确认无需兼容旧存档，因此移除的 `dawn-saber` 与 `shock-maul` 两个 `familyId` 可以直接从定义、掉落和商店候选中删除，不需要保留旧数据转换层。

## 七、对现有设计的同步要求

这份方案落地时需要同步以下内容：

1. **属性类型**：在 `src/engine/types.ts` 的 `StatBlock` 增加 `armorPen`，并补充属性注释。
2. **属性合并**：确认 `statOf`、`ZERO_STATS`、装备修正合并和所有默认面板构造都能让缺省穿甲按 0 工作。
3. **防御结算**：在 `src/engine/stats.ts` 的 `defenseMultiplier` 中加入攻击来源参数，使用来源穿甲计算有效防御；在 `src/engine/ops.ts` 调用时传入攻击来源。
4. **命中公式**：按 5.2 修改 `src/engine/stats.ts` 的 `hitChance`，让精准只抵消目标闪避率。同步复核所有提供精准的饰品、卡牌与状态。
5. **敌人数据**：按 5.1 调整 `src/data/enemies.ts` 的防御力分层，并复核受影响敌人的生命值。
6. **武器数据**：更新 `src/data/items/equipment.ts` 的 8 个武器属性，删除军刀和锤子，并把「弩」的显示名统一为「穿甲弩」。武器表从 30 件装备总数变为 28 件，文件底部的数量说明也要同步。
7. **设计文档**：同步《装备设计概览》《具体装备模板》和《游戏设定》中的武器列表、属性总数、穿甲定义、精准定义与属性权重表。
8. **掉落与商店**：检查按武器槽筛选的掉落、交易货架和商店展示，不再出现 `dawn-saber` 与 `shock-maul`。
9. **美术提示词**：删除军刀、锤子的独立提示词；更新弩的名称与穿甲视觉锚点。保留其他 8 种武器的既有素材 key 时，不需要改动素材查表结构。
10. **文案与 UI**：属性详情、装备详情和战斗伤害预览需要显示穿甲及有效防御力，但不把穿甲误写成百分比。

## 八、验证清单

编码完成后，至少验证以下行为：

- 没有穿甲的攻击与改动前的防御倍率一致。
- 防御力 10、穿甲 3 时有效防御力为 7，而不是 10 × 70%。
- 穿甲高于目标防御时，有效防御力为 0，伤害倍率为 100%。
- 固定伤害不读取穿甲，仍然跳过防御和格挡。
- 命中、暴击、格挡和护盾结算不因穿甲改变顺序。
- 破甲状态与穿甲同时存在时，先应用破甲，再扣除穿甲。
- 8 个武器模型均能正常出现在装备定义、掉落和商店展示中。
- 军刀和锤子不会再被新的掉落或商店候选生成。
- 五档稀有度不会给任意武器新增穿甲属性结构，也不会移除极端武器的负面属性。
- 精准对零闪避目标不再提高命中概率；精准高于目标闪避时，命中概率不会超过「基础命中 + 命中率」。
- 太刀与穿甲弩的传说级命中率不超过 `+10%`，不会出现撞上限后的无效加成。
- 匕首与火炮的期望伤害高于全部固定加成型武器；零代价的太刀不是伤害最高的武器。

## 九、后续平衡观察

首轮实战重点观察三类目标：

1. **低防敌人**：穿甲弩是否明显弱于太刀，确保它不是全场泛用最优。
2. **中防敌人**：穿甲弩是否与狙击枪、拳套形成可接受的横向选择，而非必选。
3. **高防敌人**：穿甲弩是否能体现专门价值，同时没有因为穿甲和破甲叠加而让防御体系失效。

如果穿甲弩在低防和高防目标上都超过其他固定加成型武器，优先下调穿甲数量或命中率，不要继续提高敌人整体防御；如果穿甲弩在高防目标上仍没有决策价值，再小幅提高穿甲，而不是给它叠加攻击力、暴击率或爆伤。

此外还要观察两点：

1. **弓箭与狙击枪的手感差异**：两者期望伤害接近（1.159 / 1.155），差异只在方差。如果玩家感知不到区别，优先拉开暴击率与爆伤的比例，而不是拉开总伤害。
2. **拳套与盾斧的先手影响**：先手维持现状，拳套的 `+1 刻` 与盾斧的 `-2 刻` 都不在线性预算内。若实战中拳套明显强于其他固定型、或盾斧因掉刻而无法使用，再回头讨论 4.2 中的先手取整问题。
