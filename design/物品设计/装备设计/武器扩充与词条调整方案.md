## 二、本轮设计规则

1. 武器分为双词条和三词条两种结构：双词条只使用主词条、副词条，三词条再增加第三词条。
2. 极端型武器可以使用两条或三条正面词条，但必须额外使用一条负面词条；负面词条在所有稀有度保留。
3. 新武器不新增 `StatBlock` 字段，不把法力、额外攻击段数或特殊卡牌规则伪装成基础属性。
4. `lowCostMastery` 与 `highCostMastery` 是卡牌结算窗口内的费用倾向词条，不等同于单纯攻击力。
5. 武器优先使用攻击力、低费/高费精通、穿甲、命中率、暴击率和爆伤；治疗力只作为少量的法术支援副词条。
6. 新武器的稀有度只提升已有词条数值，不在高稀有度追加新词条或改变负面方向。
7. 极端型武器的净属性预算应低于同稀有度固定型武器，避免极端武器成为全面上位替代。

本方案固定 6 把双词条武器：太刀、拳套、弓箭、匕首、水晶球、魔法书；另外 6 把武器使用三词条结构。

### 5.1 分布结论

- `attack`、`lowCostMastery`、`highCostMastery` 是当前武器最主要的输出构筑入口。
- `hitRate` 主要出现在太刀、穿甲弩和军刀，分别覆盖近战稳定、远程稳定和先手近战；法术支援武器不额外占用命中词条。
- `critRate` 与 `critDamage` 集中在匕首、狙击枪和锤子，形成低费暴击、高费暴击和重击爆伤三条路线。
- `healPower` 只出现在盾斧、水晶球和魔法书，作为武器槽中的支援路线，不扩展到防御属性。
- `initiative` 作为军刀和拳套的正面词条，以及盾斧和锤子的负面词条，能形成明确的行动节奏取舍。
- 双词条武器集中在“单一费用体系 + 一个功能方向”或“单一战斗方向 + 一个稳定属性”，三词条武器承担更完整的复合构筑。
- `defense`、`dodgeRate`、`precision`、`blockRate`、`healBoost`、`shieldBoost`、`ailmentResist`、`burdenAdapt`、`handLimit`、`drawCount` 当前不进入武器词条分布，继续留给防具、饰品或规则型装备。

## 六、词条调整的取舍关系

| 对比 | 主要区别 |
| --- | --- |
| 太刀 / 军刀 | 太刀是双词条的攻击与命中基准；军刀用第三词条预算补充先手，形成更完整的节奏构筑。 |
| 拳套 / 魔法书 | 两者都强化低费卡；拳套更偏攻击和抢节奏，魔法书更偏治疗与辅助循环。 |
| 火炮 / 锤子 | 火炮降低命中率，换取高费精通与远程破甲；锤子降低先手，换取更明确的暴击伤害。 |
| 水晶球 / 盾斧 | 水晶球是无负面的法术支援武器；盾斧是牺牲先手换取生命、治疗和高费精通的极端武器。 |
| 弓箭 / 穿甲弩 | 弓箭更偏低费卡与暴击；穿甲弩更偏攻击力、穿甲和命中稳定性。 |
| 匕首 / 狙击枪 | 匕首是低费速攻的脆皮极端路线；狙击枪是高费暴击的稳定路线。 |

## 七、实现清单

1. 在 `WEAPON_FAMILIES` 中新增 `saber`、`crystal-orb`、`war-hammer`、`spellbook` 四个族定义。
2. 四个新族均使用已有 `expandWeaponTiers` 生成五档稀有度，其中水晶球和魔法书使用双词条，军刀和锤子使用三词条，不单独复制稀有度物品定义。
3. 新增族的 `desc` 使用中文，并与本方案中的设计定位保持一致。
4. 复核 `assertModelValid` 对双/三词条、极端型负面词条和预算返还的校验结果。
5. 在素材查表中将四个新 `familyId` 映射到对应图标；数据层不登记素材路径。
6. 保留太刀、拳套、弓箭、匕首的双词条结构，并按第四节将水晶球、魔法书也登记为双词条。
7. 更新装备模板文档中的武器表，避免设计文档与 `weapons.ts` 的词条方向再次不一致。
8. 新增武器进入掉落池前，单独复核商店、战斗奖励和装备详情的名称、稀有度与图标查表。
