# 《霓虹都市》· 武器扩充与词条调整方案

> **状态**：已执行。
>
> **目标**：统一 12 把武器的词条结构，登记已有的 4 个武器图标，并让负面防御力在战斗中真实生效。

## 一、最终结构规则

1. 武器分为双词条和三词条两种结构：双词条只有主词条、副词条，三词条增加第三词条。
2. 12 把武器固定为 4 把双词条、4 把三词条、4 把三正面词条加一负面词条。
3. 词条顺序决定生成器的权重：主词条、副词条、第三词条对应权重 `3 / 2 / 1`。双词条每阶最低分配为 `3 / 2`，三词条每阶最低分配为 `2 / 2 / 1`。
4. 极端武器的负面词条在五档稀有度中始终保留，按阶为 `-3 / -3 / -4 / -4 / -5`，模型值返还为 `2 / 2 / 3 / 3 / 4`。
5. 同一 `familyId` 的五档稀有度只提升已有词条数值，不追加词条，也不改变负面方向。
6. 不新增 `StatBlock` 字段。低费/高费精通仍是卡牌结算窗口内的费用倾向词条，不等同于攻击力。
7. 治愈力只出现在水晶球和魔法书；盾斧改用攻击力，不再携带治愈力。
8. 防御力负面会使受到的伤害增加。穿甲只抵扣正防御，不会继续放大负防御。

### 3.1 分布结论

- `attack`、`lowCostMastery`、`highCostMastery` 是武器输出构筑的主要入口。
- `hitRate` 集中在太刀、穿甲弩和军刀，覆盖近战稳定、远程稳定和先手近战。
- `critRate` 与 `critDamage` 分布在匕首、狙击枪和锤子，分别形成低费暴击、高费暴击和重击爆伤路线。
- `healPower` 只出现在水晶球和魔法书，武器支援路线与盾斧的生命/攻击极端路线分开。
- `initiative` 同时承担拳套和军刀的节奏收益，以及匕首和盾斧的负面代价。
- `defense` 只作为锤子的负面词条出现，防御类正面属性继续留给防具与饰品。

## 四、词条取舍关系

| 对比 | 主要区别 |
| --- | --- |
| 太刀 / 军刀 | 太刀是双词条的攻击与命中基准；军刀用第三词条补充先手，形成更完整的节奏构筑。 |
| 拳套 / 魔法书 | 两者都强化低费卡；拳套偏抢节奏，魔法书偏治疗与循环。 |
| 火炮 / 锤子 | 火炮牺牲命中率换取高费精通与远程破甲；锤子牺牲防御力换取攻击、穿甲与爆伤。 |
| 水晶球 / 盾斧 | 水晶球是无负面的高费法术支援；盾斧牺牲先手换取生命、高费精通和攻击力。 |
| 弓箭 / 穿甲弩 | 弓箭偏低费远程破甲并补充攻击力；穿甲弩偏攻击、破甲和命中稳定。 |
| 匕首 / 狙击枪 | 匕首是牺牲生命的低费暴击路线；狙击枪是稳定的高费暴击路线。 |

## 五、实现结果

- `WEAPON_FAMILIES` 已登记 12 个武器族，并由 `expandWeaponTiers` 统一生成五档稀有度。
- `saber`、`crystal-orb`、`war-hammer`、`spellbook` 已映射到对应图标素材。
- 装备负面词条白名单已加入 `defense`，锤子的负防御可以进入装备模型。
- 防御结算保留正防御与穿甲的原行为，并对负防御使用对称增伤公式。
- 商店、掉落池和装备详情继续按现有的装备定义索引与 `familyId` 查表自动接入新武器，无需增加独立权重登记。
