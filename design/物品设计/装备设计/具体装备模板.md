# 《霓虹都市》· 具体装备模板

以下为装备族模板。武器由双词条与三词条两种结构组成；极端武器使用三条正面词条和一条负面词条生成模型值。同一 `familyId` 的五档稀有度沿用相同词条方向，只改变预算、上限和负面代价。

## 武器

正面词条按主词条、副词条、第三词条顺序声明，权重为 `3 / 2 / 1`。双词条每阶最低分配为 `3 / 2`，三词条每阶最低分配为 `2 / 2 / 1`。固定型武器的上限为主 `5 + 3·index`、副 `4 + 2·index`、第三 `3 + index`；极端型武器的上限为主 `6 + 4·index`、副 `5 + 3·index`、第三 `3 + 2·index`。

防御力负值会使受到的伤害增加；穿甲只抵扣正防御，不会继续放大负防御。

## 饰品

饰品全部为固定加成型，不设负面词条。正面词条按主词条、副词条、第三词条顺序声明，沿用统一装备模型的权重与五档稀有度展开规则。

穿甲结算为：目标防御力为正时取 `max(0, 目标防御力 - 攻击者穿甲)`，目标防御力为负时保持原值，超出正防御的部分不产生额外收益。所有普通装备净预算以约 20 点为目标，极端装备扣除负面属性后低于固定型；`pricing.ts` 的购买价与 `affinityRollable` 统一标记机制不变。
