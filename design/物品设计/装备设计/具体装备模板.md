# 《霓虹都市》· 具体装备模板

以下为普通级 `common` 武器模板。装备的百分点属性统一记录在 `flat`，只有按基数放大的属性使用 `pct`。

| familyId | 名称 | 属性模板 | 设计定位 |
| --- | --- | --- | --- |
| `deflection-blade` | 太刀 | `flat: { attack: 2, hitRate: 3 }` | 无代价的稳定命中与输出基准 |
| `armor-piercing-crossbow` | 穿甲弩 | `flat: { attack: 1, hitRate: 3, armorPen: 6 }` | 克制中甲、重甲目标 |
| `hunting-rifle` | 狙击枪 | `flat: { attack: 1, critRate: 10, critDamage: 35 }` | 暴击率与爆伤集中投入 |
| `quickstrike-gauntlet` | 拳套 | `flat: { attack: 2, initiative: 4 }` | 提高输出与行动节奏 |
| `hunter-longbow` | 弓箭 | `flat: { attack: 2, critRate: 3, critDamage: 50 }` | 低暴击率、高爆伤的暴击路线 |
| `cross-sword` | 盾斧 | `flat: { maxHp: 30, attack: 3, initiative: -5 }` | 牺牲先手换取生命与攻击 |
| `glass-dagger` | 匕首 | `flat: { maxHp: -25, defense: -4, attack: 2, critRate: 12, critDamage: 30 }` | 以生存代价换取高暴击输出 |
| `heavy-cannon` | 火炮 | `flat: { attack: 4, critRate: 12, critDamage: 40, hitRate: -10, initiative: -2 }` | 高输出、高命中代价的极端武器 |

穿甲的结算方式为 `max(0, 目标防御力 - 攻击者穿甲)`，超出目标防御的部分不产生额外收益。普通武器共 8 把；军刀与锤子不再属于装备池。
