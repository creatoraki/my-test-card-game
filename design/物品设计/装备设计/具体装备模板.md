# 《霓虹都市》· 具体装备模板

以下为普通级 `common` 装备模板。装备的属性统一记录在 `flat`，正负值都属于模型结构；同一 `familyId` 的其他稀有度只提高或降低这些属性，不新增属性。

## 武器

| familyId | 名称 | 属性模板 | 设计定位 |
| --- | --- | --- | --- |
| `deflection-blade` | 太刀 | `flat: { attack: 3, hitRate: 5 }` | 固定 · 命中线基准 |
| `armor-piercing-crossbow` | 穿甲弩 | `flat: { attack: 3, armorPen: 4 }` | 固定 · 穿甲线基准 |
| `quickstrike-gauntlet` | 拳套 | `flat: { attack: 2, hitRate: 3, initiative: 4 }` | 固定 · 节奏 |
| `hunter-longbow` | 弓箭 | `flat: { attack: 2, armorPen: 2, critRate: 8, critDamage: 40 }` | 固定 · 爆伤 |
| `hunting-rifle` | 狙击枪 | `flat: { attack: 2, hitRate: 3, critRate: 10, critDamage: 30 }` | 固定 · 暴击 |
| `cross-sword` | 盾斧 | `flat: { attack: 3, armorPen: 2, maxHp: 20, initiative: -5 }` | 极端 · 换生存 |
| `glass-dagger` | 匕首 | `flat: { attack: 3, hitRate: 5, critRate: 12, maxHp: -20, defense: -3 }` | 极端 · 脆皮暴击 |
| `heavy-cannon` | 火炮 | `flat: { attack: 5, armorPen: 3, hitRate: -12, initiative: -2 }` | 极端 · 高攻低命中 |

穿甲结算为 `max(0, 目标防御力 - 攻击者穿甲)`，超出目标防御的部分不产生额外收益。所有普通装备净预算以约 20 点为目标，极端装备扣除负面属性后低于固定型；`pricing.ts` 的购买价与 `affinityRollable` 统一标记机制不变。
