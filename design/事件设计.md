## 一、设计总览

### 1.1 事件与战斗

一次出击共 6 轮，每轮包含两张独立的签：

- **区域路由图**：推进并结算非战斗节点事件。
- **战斗签**：每轮固定进行一场战斗，决定战斗条件与战后收益。

战斗不属于节点事件，也不提供避战出口。前 5 轮为轻、中、中、大、大战斗，第 6 轮为 BOSS 战。

### 1.2 资源生命周期

| 资源 | 使用位置 | 远征结束时 |
| --- | --- | --- |
| 居民积分 | 据点交易终端、角色修复、设施建设 | 保留 |
| 临期食品 | 探索事件中的指定交易 | 全部丢弃 |
| 探索物资 | 战斗和节点事件 | 符合规则的物品带回据点 |
| 已寄送物资 | 投递口寄回的物品 | 团灭时仍保留 |

居民积分不能直接在探索事件中消费。玩家必须在出发前通过据点交易终端购买临期食品，再用食品交换探索中的道具或服务。

### 1.3 物品与事件的对应关系

| 物品类型 | 主要来源 |
| --- | --- |
| 地区采集材料 | 对应地图的采集事件 |
| 通用材料 | 搜集、拆解、维修和回收事件 |
| 消耗品 | 补给事件或食品交易 |
| 任务物品 | 调查、权限和特殊事件 |
| 临期食品 | 出发前据点交易终端；探索事件少量补充 |
| 部署装置 | 消耗品的 `deployable` 子类型，使用后开启隐藏区域 |

## 二、通用规则

### 2.1 事件结算与分支

- 每个节点只结算一个事件。
- 抵达后先打开浮层，再选择处理方式；抵达不等于自动结算。
- 默认提供两个选项，代价和效果只认被选中的选项。
- `choices[0]` 是主选项，节点卡上的 `energyDelta` 用于预览它。
- `choices[1]` 必须有代价：消耗粒子、减少收益、承担风险或放弃收益。

### 2.2 净化粒子

- 每个节点默认消耗 3 点；分支可额外增减。
- 每个战斗回合消耗 1 点；战斗签本身不消耗粒子。
- 不使用“每段固定消耗”或“战斗开始固定扣除”的旧口径。
- 推进越深，战斗时粒子越少，风险和收益都应提高。

### 2.3 临期食品

临期食品的完整规则见[《临期食品设计》](物品设计/消耗品及货币/临期食品.md)。本章只记录事件侧的使用约束：

- 经济事件只允许食品交换生存补给、装备与道具、材料，以及少量隐藏区域情报和特殊入口服务。
- 经济事件不提供战斗规则修改、长期成长、普通路线便利、剧情关系或食品互换。
- 高价值交易可以附带卡牌污染、战斗强化或物品损失等风险。

经济事件模型：

- **生存补给**：治疗、重点治疗、净化、护盾和医疗消耗品。
- **装备与道具**：装备、消耗品、部署装置和模组。
- **材料交换**：通用材料、地区材料、模组材料和稀有材料；不提供维修、精炼、重铸或材料加工。
- **有限情报**：仅揭示隐藏区域、隐藏宝库或特殊事件节点的位置。
- **极少数路由服务**：仅开启隐藏区域或解除特殊入口封锁，不跳过节点、不免除粒子、不重排路线、不直接移动。
- **风险修饰**：高价值交易可附带卡牌污染、后续战斗强化或物品损失等代价。

战斗规则修改、长期成长、普通路线便利、选择权与重掷、持续规则改变、剧情关系、任务物品和 NPC 权限归入剧情或其他特殊事件，不归入经济事件。

### 2.4 深度与抽取

- 每轮路由图为 5 通道 × 4 推进段，共 20 个节点。
- 事件用 `depth: [min, max]` 声明可出现的推进段。
- 浅段放稳定收益，深段放高方差收益和风险事件。
- 抽取按类别保底，范围是整张图；`disabled: true` 的事件不会抽取。

### 2.5 恢复与损伤

常规恢复包括生命、重点治疗、护盾、卡牌污染净化、状态清除、医疗补给和战前整备。常规风险包括掉血、治疗受阻、护盾破坏、卡牌污染扩散、负面状态、医疗资源损失和恢复设施损坏。

- 事件治疗只恢复当前 HP，不修复体力极限。
- 事件直接掉血不结疤，压力来自治疗资源和后续战斗状态。
- 体力极限修复、濒死处理和阵亡处理只放入稀有特殊或终局事件。

### 2.6 战斗相关效果

事件和战斗签可影响下一场战斗，但必须明确范围和持续时间，包括敌我先手、敌方生命、敌人数量、污染卡牌、场景卡、挑战词条、战利品、品质和经验。

先手只用于计算敌方攻击时刻：

$$
T_{attack}=max(1,D_{skill}+S_{party}-S_{enemy})
$$

战斗中必须显示每个敌人的 `T_attack`，并随先手变化实时更新。

## 三、节点事件分类

类型见 [src/explore/types.ts](../src/explore/types.ts)，事件池见 [src/data/exploreEvents.ts](../src/data/exploreEvents.ts)。

| 类别 | `kind` | 状态 | 用途 |
| --- | --- | --- | --- |
| 生存 | `heal` | 已实现 | 回复生命、重点治疗、净化 |
| 成长 | `loot` | 已实现 | 材料、装备、消耗品、少量临期食品、数据 |
| 经济 | `merchant` | 已设计 | 指定食品换指定道具或服务 |
| 特殊 | `special` | 已设计 | 快递站等一次性远征功能 |
| 路由 | `route` | 已设计 | 揭示桥接、路线信息、侧向跨接 |
| 能量 | `energy` | 已实现 | 粒子、捷径、提前结束、能量换资源 |
| 风险 | `hazard` | 已实现 | 掉血、污染卡牌、丢弃背包、风险换收益 |
| 终局 | `retreat` 等 | 第 5 轮起 | 撤离、补给、宝库 |

事件表现形式包括即时确定、抵达后二选一和持续影响。即使是即时事件，也应经过落点浮层确认。

事件类别不是互斥标签，一个事件可以组合多个效果维度。代价和收益也不要求属于同一类别，例如承担风险可以获得能量，受到伤害可以获得临期食品。事件表中的主类别用于抽取和展示，具体分支效果按实际内容组合。

## 五、战斗签

### 5.1 普通轮转轮

转轮有 8 个公开符号：5 张战斗卡、3 张战前准备卡。玩家暂停 3 个槽位，再从结果中选择 1 张。两类卡都必须进入战斗，只改变条件、战术或收益。

| 战斗卡 | 作用 | 首图示例 |
| --- | --- | --- |
| 稳定推进 | 少额外压力，稳定结算 | 清运班组 |
| 节奏控制 | 改变先手或敌方关键时刻 | 巡回信标，敌方先手 +2 |
| 环境压力 | 引入污染卡牌或持续干扰 | 粉尘作业区 |
| 场景战术 | 提供本场特殊卡牌 | 维护平台 |
| 高风险收益 | 增加可预判难点，提高收益 | 首回合手牌 -1，掉落系数 +0.40 |

| 战前准备卡 | 效果 |
| --- | --- |
| 战前补给 | 全队回复 15% HP，获得 1 个消耗品 |
| 战前情报 | 公示敌人的 `T_attack` 与多段技能 |
| 战场改造 | 获得 1 至 2 张场景特殊卡牌 |

### 5.2 同花加成

| 结果 | 掉落系数加成 |
| --- | ---: |
| 3 张相同 | +1.50 |
| 2 张相同 | +0.50 |
| 全不同 | +0 |

加成统一以加法合入掉落系数 `K`，作用于掉落率、品质和经验。普通轮与 BOSS 轮均保持 8 种符号，避免改变三连概率基线。

### 5.3 BOSS 轮与战斗档位

第 6 轮的 8 个符号全部是 BOSS 卡，差异来自先手、场景卡、污染卡牌、挑战词条和 BOSS 起始阶段。

| 档位 | 设计职责 |
| --- | --- |
| 轻战斗 | 建立节奏；只突出一个问题，不投放多段伤害 |
| 中战斗 | 检验局内强化，处理敌方配合或环境干扰 |
| 大战斗 | 检验构筑、资源和风险承受能力；第 5 轮可降级 |
| BOSS | 汇总核心机制，不只提高数值 |

挑战词条按档位分池。“静默”只投放轻战斗；“无伤”移出轻战斗池，避免成为白送的高额加成。

### 5.4 战后

- 胜利后结算实物战利品、经验和下一轮可用的战后整备。
- 失败时结束远征，背包按失败规则处理。
- BOSS 胜利后直接完成远征。
- 主战利品只能是实物，不能直接奖励居民积分；废料回据点后再兑换积分。

## 六、待实现与待定事项

### 6.1 待实现

- 指定食品交易系统：食品数据、据点采购、交易事件和食品清除。
- 特殊事件：快递站寄回物资，最多 6 个道具且每次远征限用一次。
- 路由类事件：桥接揭示、路线信息、侧向跨接。
- ~~战斗签老虎机的完整接入。~~ **已实现**（`explore/slot.ts` + `data/slotSymbols.ts` + `ui/SlotReels.tsx`），但三张卡的效果按现有引擎降级，见 6.2。
- 体力极限、结疤、濒死和阵亡处理。
- 战斗签缺的引擎能力：场景特殊卡牌、开战污染卡牌、开局手牌修正。补上这三样即可把「环境压力 / 场景战术 / 战场改造」还原成设计口径。

### 6.2 待定

- 各类食品的据点采购价格、背包占格和堆叠上限。
- 各个商人接受的食品种类与服务价格。
- 探索事件补充食品的数量与出现频率。
- 污染卡牌的加权方向：正向针对主力牌，或反向回避核心牌。
- 暂时净化的供给量与污染卡牌累计量的匹配。
- 高风险事件、战斗卡和能量档位之间的掉落加成平衡。
- 转轮可读性：`EXPLORE_RULES.slot.symbolMs`（当前 150ms）与同花加成 +0.50 / +1.50 是耦合的一组，必须一起调。
- 三张降级卡的临时效果是否长期保留：环境压力 = 敌方 +1 力量、场景战术 = 敌方行动间隔 +1、战场改造 = 敌人 HP ×0.9。
