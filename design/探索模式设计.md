# 探索模式：路线图与战斗签

## 一、玩法概述

探索模式是一趟由 **6 轮区域推进**组成的远征。每轮依次经历两个部分：

1. **路线图**：玩家观察一张短时公开的路线，选择入口并沿路线推进，决定要不要继续深入。
2. **战斗签**：玩家操作老虎机，从三张结果中选一张，确定本轮战斗的条件，然后进行必然发生的战斗。

探索模式的乐趣来自两种不同的判断：

- 路线图考验玩家能否记住并追踪路径，以及何时应该见好就收。
- 战斗签考验玩家的停轮时机，以及在战斗收益和战斗条件之间做选择。

一趟远征不是单纯向前推进。玩家需要在队伍状态、净化粒子、背包空间和潜在收益之间做取舍：

- **净化粒子**会随着探索和战斗逐步消耗。粒子越少，后续战斗越危险，但奖励也越好。
- **队伍状态**跨轮保留。治疗和补给能让远征继续，但不一定值得为此冒险深入。
- **战利品**占用背包空间。主动撤退可以带回当前背包，团灭或战斗失败则会损失尚未寄回的战利品。

玩家可以在任意一轮少走几个节点，甚至直接进入战斗。越深入，越有机会遇到高价值事件，但也越可能消耗更多资源或错过安全撤离的时机。

## 二、一趟远征的流程

```text
开始远征
   ↓
第 1 轮路线图 → 选择推进深度 → 战斗签 → 推进战斗
   ↓
第 2 轮路线图 → 选择推进深度 → 战斗签 → 推进战斗
   ↓
第 3 轮路线图 → 选择推进深度 → 战斗签 → 推进战斗
   ↓
第 4 轮路线图 → 选择推进深度 → 战斗签 → 推进战斗
   ↓
第 5 轮路线图 → 选择推进深度 → 战斗签 → 推进战斗
   ↓
第 6 轮路线图 → 选择推进深度 → BOSS 战斗签 → BOSS 战
   ↓
通关、主动撤退，或因战斗失败结束
```

路线图决定本轮可以获得什么，战斗签决定本轮要面对怎样的战斗。路线图上的战斗不是终点；每轮的战斗签都会在路线图结束后出现，因此一趟完整远征最多进行 6 场战斗。

## 三、路线图

### 3.1 图形结构

每轮生成一张横向路线图：

- **5 条通道**，从左到右编号为 A-E。
- **4 个推进段**，每段都有 5 个节点，共 20 个节点。
- **桥接**连接相邻通道。信号向右推进，遇到桥接就必须跨到另一条通道。

示意：

```text
入口       第 1 段        第 2 段        第 3 段        第 4 段
A  ● ─────── 节点 ──┬──── 节点 ─────── 节点 ──┬──── 节点
B  ● ─────── 节点 ──┴──── 节点 ──┬───── 节点 ──┴──── 节点
C  ● ─────────────── 节点 ──┴───── 节点 ─────── 节点
D  ● ─────── 节点 ──────── 节点 ─────── 节点 ─────── 节点
E  ● ─────── 节点 ──────── 节点 ─────── 节点 ─────── 节点
```

图上的节点事件大部分完整展示，但每张图会固定隐藏 3 个节点（全图随机抽取）：它们显示为带问号的「未知节点」，使用独有的事件类型样式，只有真正走到（落地）之后才会揭示真实事件。桥接则只在短时间内公开。路线图的核心不是寻找未知事件，而是记住桥接的位置，并判断自己选中的入口最终会经过哪些节点——未知节点让「记忆路线」多了一层赌注：你可能正走向一个风险事件而不自知。

### 3.2 观察与选路

每轮路线图按以下顺序进行：

1. **生成路线**：路线图和 20 个节点出现，桥接暂时隐藏。
2. **查看节点**：玩家可以阅读所有节点（未知节点只能看到占位浮卡），了解这一轮可能遇到的补给、资源、风险和撤离机会。
3. **揭示桥接**：玩家主动开始一次短暂揭示，整张图的桥接同时出现。
4. **选择入口**：桥接隐藏后，玩家从 A-E 中选择一个入口通道。本轮只能选择一次入口。
5. **沿路线推进**：信号按照刚才看到的桥接自动移动，抵达当前通道上的节点。
6. **处理节点**：玩家选择节点事件的处理方式并获得结果，然后决定继续还是离开路线图。

路线图的桥接只揭示一次。玩家可以在揭示前慢慢查看节点，但不能在桥接消失后重新查看整张路线。这样，玩家记住的不是一张抽象图，而是“从这个入口出发，我会依次遇到哪些事件”。

### 3.3 节点与推进深度

抵达节点后，玩家先处理事件，再做一次推进决策：

| 选择 | 结果 |
| --- | --- |
| **继续推进** | 沿路线进入下一个推进段，获得更多收益，也承担更多资源消耗和风险 |
| **前往下一区域** | 放弃本轮剩余节点，结束路线图并进入战斗签 |

最多可以推进 4 个节点。推进得越深，路线的不确定性和事件的波动越大：浅段偏向稳定补给和基础资源，深段更可能出现装备、大额收益或高风险事件。

这使每个节点都形成一个小型决策：

> 我还记得后面的路线吗？队伍和背包还能承受下一段吗？眼前的收益是否值得继续冒险？

玩家也可以不进入任何节点，直接前往战斗签。这样做会放弃本轮的路线收益，但能保留资源和时间。

### 3.4 路线图结束

玩家选择离开路线图，或推进完第 4 段后，本轮路线结束。系统会展示完整桥接和玩家实际走过的路径，让玩家知道自己是正确记住了路线，还是在某个位置记错了。

随后进入本轮的战斗签。

## 四、战斗签：老虎机

### 4.1 玩法结构

战斗签是每轮路线图之后的第二个小游戏。它不负责决定“打不打”，而是决定“以什么条件打这一场”。

- 转轮共有 **8 个公开符号**。
- 其中通常是 **5 张战斗卡**和 **3 张战前准备卡**。
- 玩家依次按下 3 次暂停键，定住 3 个槽位。
- 三个槽位全部定住后，玩家从结果中选择 1 张卡执行。

```text
转轮 1：  [滚动] → 按停 → [结果 1]
转轮 2：  [滚动] → 按停 → [结果 2]
转轮 3：  [滚动] → 按停 → [结果 3]
                         ↓
                 三选一并进入战斗
```

路线图考验记忆和追踪，老虎机考验时机和取舍。两个部分使用不同的操作感觉，避免一趟远征重复进行同一种小游戏。

### 4.2 两类卡片

**战斗卡**直接改变本轮战斗的规则或环境，例如：

- 稳定推进：战斗压力较低，结算稳定。
- 节奏控制：改变敌我先手或关键行动时机。
- 环境压力：加入污染、持续干扰或必须优先处理的目标。
- 场景战术：提供适合当前战斗的场景能力。
- 高风险收益：增加可预判的战斗难点，同时提高战斗收益。

**战前准备卡**先提供一次战前优势，然后仍然进入战斗，例如：

- 战前补给：治疗队伍或提供消耗品。
- 战前情报：展示敌方的关键行动信息。
- 战场改造：获得场景能力或改变战场条件。

准备卡不是避战卡。即使三个槽位全部出现准备卡，玩家也会在结算准备效果后随机获得一张战斗卡并进入战斗，因此每轮战斗始终会发生。

### 4.3 同花奖励与三选一

如果 3 个槽位中出现相同卡片，会得到额外的战斗收益：

| 结果 | 奖励 |
| --- | --- |
| 两张相同 | 获得小幅额外收益 |
| 三张相同 | 获得大幅额外收益 |
| 三张不同 | 没有同花奖励，但拥有更多战术选择 |

追求三连可以换取更好的掉落和经验，但会减少可选方案；主动停成三张不同的卡，则更容易根据队伍状态选择合适的战斗条件。

因此，老虎机的关键不是单纯追求最高奖励，而是在两个目标之间取舍：

- **赌同花**：尝试停出相同卡片，换取更高收益。
- **保留选择**：停出不同卡片，从三种战斗条件中挑最适合当前队伍的一种。

### 4.4 BOSS 战斗签

第 6 轮的战斗签不会出现普通推进战斗，而是提供 8 种不同的 BOSS 开局条件。玩家仍然进行三次停轮和一次三选一，但结果会影响 BOSS 战的先手、场景、挑战条件或阶段状态。

BOSS 战斗签同样保持 8 个符号，使普通轮和 BOSS 轮的老虎机规则一致。它不能被用来跳过 BOSS，只能决定挑战 BOSS 的方式。

## 五、远征的结束

一趟远征有三种主要结果：

| 结果 | 说明 |
| --- | --- |
| **BOSS 胜利** | 完成远征，带回尚未寄回的战利品 |
| **主动撤退** | 提前结束远征，带回当前背包中的战利品 |
| **战斗失败或团灭** | 远征结束，尚未寄回的战利品丢失；经验等即时收益保留 |

探索模式的完整循环可以概括为：

> 看路线，记桥接，选入口；在节点前决定走多深；用老虎机决定战斗条件；带着尽可能多的战利品活着回来。
